# manga/ — マンガ知識ベース(ノウハウ蓄積庫)

CryptoManga Studios が **マンガのシナリオ制作・編集・制作進行** で使うノウハウを、ソース付きで貯めていくフォルダ。
`kindle/` が出版事業の知識ベースであるのと同様に、ここは **マンガ制作の知識ベース**。

## 運用ルール
1. **1ノウハウ = 1ファイル**。`テンプレート/ノウハウカード.md` をコピーして該当カテゴリに置く。
2. **必ず出典を書く**(動画URL・タイムスタンプ・話者)。出典のない「それっぽい一般論」は貯めない。
3. **原文の丸写しはしない**(著作権)。要点を自分の言葉で要約し、短い引用のみ。
4. 動画を見た記録は `ソース台帳/` に必ず残す(未視聴・視聴済・カード化済)。
5. 実際の制作で使えた/使えなかったを `検証メモ` 欄に追記し、使える順に育てる。

## 構成
- `ノウハウ/01_ネーム・構成` … ネーム、コマ割り、構成、引きの作り方
- `ノウハウ/02_キャラ・世界観` … キャラ設計、世界観、読み切りの作り方
- `ノウハウ/03_編集者の視点・講評` … 編集部の評価基準、ネーム講評の観点
- `ノウハウ/04_ヒット・重版の法則` … 重版・連載獲得の秘訣
- `ノウハウ/05_業界知識・収益` … 連載の収入、業界構造、持ち込み/新人賞
- `ノウハウ/06_制作進行・作画` … 制作フロー、アシスタント、進行管理
- `ソース台帳/` … 学習元の一覧と進捗
- `テンプレート/` … ノウハウカードの雛形
