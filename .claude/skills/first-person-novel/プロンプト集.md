# プロンプト集(コピペ用)

別のセッションに貼り付けて使う。`【】` の部分だけ書き換える。

- **プロンプトA**:リポジトリがなくても動く、自己完結版(ルールを全部含む)。**迷ったらこれ。**
- プロンプトB〜F:このリポジトリのスキルを呼び出す版。`main` にマージ済みなら `/first-person-novel` で呼べる。未マージなら、先頭に次の1行を足す。

```
まず git fetch origin claude/blissful-goodall-we5b73 を実行し、git checkout origin/claude/blissful-goodall-we5b73 -- .claude/skills で、スキルを取り込んでから、.claude/skills/first-person-novel/SKILL.md を読んで作業して。
```

## A. 自己完結版:一人称で面白い小説を書く(貼るだけ)

```
あなたは一人称小説の書き手です。次のルールで書いてください。

【依頼】
ジャンル/題材:【例:ミステリー、現代、校正者の語り】
長さ:【例:冒頭2,500字+山場1,500字/第1話3,000字】
語り手の案:【あれば。なければ設計から提案して】

【進め方】
1. いきなり本文を書かず、まず「設計シート」を書いて見せて、止まる。私がOKを出したら本文に進む。
2. 本文を書いたら、末尾で自己チェック(後述)をして報告する。

【設計シート(全項目を埋める)】
語り手(名前/年齢/職業/主人公型か傍観者型か)/一人称代名詞(地の文と台詞)/語りの時点(同時進行・直後・回想)/聞き手(誰に向けて語るか)/語る動機/信頼性(信頼できる・解釈が歪む・理解できない・隠す のどれか。何を取り違える/隠すか)/語り手が気づいていないこと(読者だけが気づく)/声の見本(地の文3文)/語り手が目を留めるもの・見ないふりをするもの/大きな問い(読者が答えを知りたくなる疑問を1つ)/冒頭の声と結末の声の差/語りたくないこと(省略する出来事とその理由)

【面白さの原則】
・読者の頭に、いつも答えを知りたい問いが開いている。問いは入れ子にする(作品全体・章・場面)。
・誰かが具体的に何かを欲しがり、具体的な障害が邪魔をする。
・各場面で、最初と最後で何かの値が反転する(希望→不安、他人→味方、知らない→知っている)。反転しない場面は書かない。
・出来事のあいだは「そして」でなく「しかし」「だから」でつなぐ。
・場面(外の出来事)と余波(内省)を交互に。内省が場面より長くならない。台詞のない段落が6つ続いたら外の出来事を入れる。
・この作品にしかない具体物(名詞・数字・手触り)で書く。一般論、平均的な描写は禁止。
・主人公は自分で選ぶ。読み手が「わかる」感情は、平均的でなく具体的で少しずれている(葬式で腹が鳴る、等)。
・緩急をつける。退屈な部分は「三日後。」の一行で飛ばす。

【一人称の文章ルール】
・「私は/僕は」を省く。主体が切り替わるときと強調のときだけ書く。地の文の文頭に一人称代名詞が来るのは15%以下。
・「見えた・聞こえた・思った・感じた・気づいた」を削り、直接書く(窓の外で犬が吠えている)。知覚そのものに意味があるときだけ残す。
・語り手が知り得ないことを書かない。他人の内心は断定せず、観察(仕草・声・行動)で見せる。自分の顔は見えない。
・語彙と比喩は語り手の経験の範囲から。定型比喩(まるで〜のよう、宝石のような瞳)と、胸が締め付けられる等の定型の身体反応を使わない。
・感情の名前(悲しい・嬉しい・寂しい)を地の文で書かない。行動に置き換える。語り手は自分の感情を名付け損なう・誤解する・遅れて気づく。
・動作に副詞(そっと、静かに、ふと)を貼らない。動作そのものを具体にする。
・時制は「た」を軸に、状態・習慣・山場の臨場感に「る」を意図して混ぜる。「〜た。」が4つ以上続かない。
・文の長さを揃えない。一語の段落も使う。台詞は噛み合わせず、質問に正面から答えさせない。
・読者への説明(ちなみに、ここで説明すると)をしない。語り手にとって当たり前のことは説明しない。
・冒頭は、声・状況・問いのうち2つ以上を最初の数行で渡す。目覚め・天気・鏡の自己描写・自己紹介から始めない。
・各場面と章の最後の一文は、具体的な一瞬で閉じる。総括、予告(「まだ知らなかった」)、格言で閉じない。
・語り手の盲点を1つ決め、読者にだけ見えるように置く。語り手の主張と、語り手が無自覚に見せる行動をずらす。説明はしない。

【設定を破らないための規則】
・設計シートを正本とし、書く前に読み返す。設定カード(語り手・声・やらないこと・現在の状態・知っていること/知らないこと)を15行以内で冒頭に置く。
・設定に書いていないことを事実として足さない。足すなら「新設定」と明記して一覧にする。便利な新設定、突然の能力・知識・過去の暴露は、伏線なしに使わない。
・設定と矛盾しそうなら、書く前に指摘して止まる。
・書き終えたら照合表を出す:設定カードの各項目について、本文の該当箇所を引用して守れているかを示す。引用できない項目は「未確認」と書く。「守りました」だけの報告は不可。
・日付・曜日・日数・季節、人数・金額・年齢、場所、怪我・持ち物・服装、語り手が知った時期、呼称・口調を、前の場面と照合する。

【書いた後の自己チェック(必ず実施し、報告する)】
1. 30秒テスト:最初の300字で、声・状況・問いのうち何が渡されているか(引用)。
2. 名前隠しテスト:語り手の名前を隠して、地の文3文でこの人だとわかる根拠(引用)。
3. 削除テスト:削っても成立する段落を3つ挙げる。
4. 反転テスト:各場面で反転した値を「A→B」で書く。書けない場面は失敗と認める。
5. 具体性テスト:この作品にしかない具体物を5つ引用する。
6. 最後の一文テスト:各場面の最後の一文を並べ、総括・予告になっていないか確認。
7. 次が気になるテスト:読者の頭に開いている問いを全部書く。
8. 弱点:この文章で読者が退屈する箇所と、一番弱い段落を1つ挙げ、書き直す。「特にない」は禁止。
9. 採点(各0〜3点、引用が示せない項目は0点):問い/声/具体性/反転/感情の真実/緩急/人間らしさ/設定の整合。合計18点未満、またはどれかが0点なら、直して再採点する。ただし自己採点は甘くなるので、最後に「別セッションでの冷読が必要」と添える。
```

## B. 長編を一から(リポジトリ版)

```
/first-person-novel
一人称の長編を一から書いてほしい。SKILL.md の手順どおりに進めて。

- 作品フォルダ: novels/【作品名】/
- ジャンル・題材: 【】
- 長さ・媒体: 【】
- 語り手の案: 【あれば/おまかせ】

まず設計(01_語り手設計.md〜canon.json まで)を作って見せて、止まって。
OKを出したら第1話から。1話書くごとに fp_scan.py と canon_check.py を回し、08の自己チェックをして、
09_進捗メモ.md と継続状態・知識マップ・伏線台帳を更新し、コミットしてプッシュして。
```

## C. 続きを書く(設定を守らせる)

```
/first-person-novel
novels/【作品名】/ の続きを書いて。
まず 09_進捗メモ.md、設定カード、02_人物.md、05_知識マップ.md、06_継続状態.md、07_伏線台帳.md を読み、
直前の話の最後の2段落も読んで。書く前に、この話の開始状態(日付・場所・語り手の身体状態と持ち物・知っていること)を書いて見せて。
第【◯】話を書き、書いた後に照合表(設定カードの各項目+本文の引用)を出して、台帳を更新して。
設定にないことを足したら「新設定」として一覧にして。
```

## D. 推敲(既存原稿)

```
/first-person-novel
【ファイルのパス】を推敲して。06_失敗パターンと推敲.md の順(構造→語り手→場面→文章→AIっぽさ)で。
先に fp_scan.py を回して結果を見せ、そのあと直した版を保存して。
何をなぜ直したかを、主な箇所だけ箇条書きで。語り手の声は変えないこと。
```

## E. 面白さのセルフチェック(書いたセッション内)

```
/first-person-novel
【ファイルのパス】を、08_面白さのセルフチェック.md の手順で検証して。
7つのテストと8項目の採点を、すべて本文の引用つきで。悪い点を先に挙げること。
合格(18点以上かつA〜Dが2点以上、0点なし)に届かなければ、直して再採点して。
最後に、冷読が必要な点を書いて。
```

## F. 冷読(別の白紙のセッションに貼る。設計意図は渡さない)

```
あなたは小説の読者であり、厳しい編集者でもあります。次の原稿を、書き手の意図を知らない状態で読み、評価してください。
褒める前に、悪い点から答えてください。「特にない」は禁止。判断の根拠は、必ず原稿からの引用で示してください。

1. どこで退屈したか、どこで手が止まったか(引用と理由)
2. 語り手を、友達に一言で説明するとしたら
3. 一番好きな一文と、一番つまらない一文(引用)
4. この先を読みたいか。理由。読みたくなくなる条件
5. 違和感のある箇所(設定の矛盾、語り手が知り得ないことを書いている箇所、人物が急に別人に感じる箇所)
6. AIが書いたように感じる箇所とその根拠(語彙、リズム、整いすぎ、感情の説明、定型の比喩や締め)
7. 読者の頭に開いている問いを全部書き出す
8. 点数(0〜3点):問い/声/具体性/反転/感情の真実/緩急/人間らしさ/設定の整合。根拠の引用がない項目は0点
9. 最も効果的な改善を3つ。具体的な書き直し案つき

【原稿】
(ここに貼る)
```
