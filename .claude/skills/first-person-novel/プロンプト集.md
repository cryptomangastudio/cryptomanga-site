別のセッションに貼り付けて使う。`【】` の部分だけ書き換える。

- **プロンプトA**:リポジトリがなくても動く、自己完結版。**迷ったらこれ。**(改訂3:禁止事項を減らし、例文を除き、体温の力学を追加した)
- プロンプトB〜F:このリポジトリのスキルを呼び出す版。`main` にマージ済みなら `/first-person-novel` で呼べる。未マージなら、先頭に次の1行を足す。

```
まず git fetch origin claude/blissful-goodall-we5b73 を実行し、git checkout origin/claude/blissful-goodall-we5b73 -- .claude/skills で、スキルを取り込んでから、.claude/skills/first-person-novel/SKILL.md を読んで作業して。
```

## A. 自己完結版:一人称で面白い小説を書く(貼るだけ)

```
あなたは一人称小説の書き手です。次の方針で書いてください。

【依頼】
ジャンル/題材:【】
長さ:【例:冒頭2,500字+山場1,500字/第1話3,000字】
語り手の案:【あれば。なければ設計から提案して】

【進め方】
1. いきなり本文を書かず、まず「設計シート」を書いて見せて、止まる。私がOKを出したら本文に進む。
2. 本文を書いたら、末尾で自己チェックをして報告する。

【設計シート(全項目を埋める。空欄を許さない)】
語り手(名前/年齢/職業)/一人称代名詞(地の文と台詞)/語りの時点(同時進行・直後・回想)/語りの相手(誰に向けて、何を認めさせたい・許してほしいのか)/語る動機/恥(人に知られたくない本音。嫉妬・見栄・後ろめたさなど)/守りたいプライド(自分はこういう人間だ、という自己像)/冷静を装う文のどこで恥とプライドが漏れるか(場面を2つ)/語り手が気づいていないこと(読者だけが気づく)/大きな問い(読者が答えを知りたくなる疑問を1つ)/冒頭の声と結末の声の差/語りたくないこと(省略する出来事とその理由)

【面白さの軸】
・読者の頭に、答えを知りたい問いが常に開いている。
・語り手は具体的に何かを欲しがり、具体的な障害がある。語り手が自分で選ぶ。
・各場面の最初と最後で、何かが反転する。反転しない場面は書かない。
・出来事は「しかし」「だから」でつなぐ。場面(外の出来事)と内省を交互に。内省が長くならない。
・この作品にしかない具体物で書く。一般論・平均的な描写は避ける。退屈な部分は飛ばす。

【体温(最重要)】
・語り手は完璧でない。恥とプライドを持ち、冷静を装った文の随所から、本人の意図に反して漏れる。本人は気づかない、または認めない。恥の中身は直接書かない。
・笑いは、ジョークではなく、語り手が真面目なほど出るずれ(真剣さと状況のずれ、見栄の露見、礼儀や段取りへの逃避)で作る。語り手を笑わせようとしない。
・語り手は誰かに向けて語っている。その相手に認めさせたいことが、語りの偏りになる。
・侮蔑や皮肉だけで埋めない。軽蔑している対象の裏に、別の感情(依存・愛情・恐れ)を一点だけ見せる。
・反応の種類を場面ごとに変える。同じ型の反応・同じ構文・同じ工夫を3回以上繰り返さない。
・語り手が自分の感情を正確に解説する文(「〜だと気づいていた」型)を書かない。感情は行動とそのずれで見せる。
・自己訂正・言い直し(カッコなど)は作品全体で1回まで。職業や属性の一般化(「〜者は〜するものだ」型)は作品全体で1回まで。職業は行動で示す。気の利いた警句や比喩は、場面に1つまで。

【一人称の守り】
・語り手が知り得ないこと、見えないものを書かない。他人の内心は断定せず、観察で見せる。
・「私は/僕は」を省く。「見えた・聞こえた・思った」は、知覚そのものに意味があるときだけ残す。
・定型の比喩と定型の身体反応を使わない。語彙と比喩は語り手の経験の範囲から、新しく作る。
・冒頭は、声・状況・問いのうち2つ以上を最初の数行で渡す。目覚め・天気・自己紹介から始めない。場面と章の最後は、総括・予告・格言でなく、具体的な一瞬で閉じる。

【例文の流用の禁止】
この依頼文に含まれる語句・言い回しを本文に流用しない。表現はすべて、語り手の経験から新しく作る。

【設定を破らないための規則】
・設計シートを正本とし、書く前に読み返す。設定カード(語り手・声・やらないこと・現在の状態・知っていること/知らないこと)を15行以内で冒頭に置く。
・設定に書いていないことを事実として足さない。足すなら「新設定」と明記して一覧にする。突然の能力・知識・過去の暴露は、伏線なしに使わない。
・設定と矛盾しそうなら、書く前に指摘して止まる。
・書き終えたら照合表を出す:設定カードの各項目について、本文の該当箇所を引用して守れているかを示す。引用できない項目は「未確認」と書く。「守りました」だけの報告は不可。
・日付・曜日・日数・季節、人数・金額・年齢、場所、持ち物・身体状態、語り手が知った時期、呼称・口調を、前の場面と照合する。

【書いた後の自己チェック(必ず実施して報告)】
1. 30秒テスト:最初の300字で渡されているもの(声・状況・問い)を引用。
2. 削除テスト:削っても成立する段落を3つ。
3. 反転テスト:各場面で反転した値を「A→B」で。書けない場面は失敗と認める。
4. 流用テスト:この依頼文の語句・例が本文に出ていないか探す。見つからなければ、探した範囲を書く。
5. 反復テスト:同じ構文・型の工夫が3回以上出ていないか。
6. 体温テスト:(a)恥とプライドが漏れた箇所を引用。引用できなければ0点。(b)語り手を好きになれる点と笑える点を、引用つきで1つずつ。(c)感情を解説している文がないか。(d)侮蔑一色になっていないか。
7. 弱点:読者が退屈する箇所と、一番弱い段落を1つ挙げて書き直す。「特にない」は禁止。
8. 採点(各0〜3点、引用がなければ0点):問い/声/具体性/反転/感情の真実/緩急/人間らしさ/設定の整合/体温/独自性(流用・反復なし)。採点は直す箇所を見つけるためのもので、合格の判定には使わない。最後に「合格かどうかは、別セッションでの冷読と人間の判断が必要」と添える。
```

## B. 長編を一から(リポジトリ版)

```
/first-person-novel
一人称の長編を一から書いてほしい。SKILL.md の手順どおりに進めて。

- 作品フォルダ: novels/【作品名】/
- ジャンル・題材: 【】
- 長さ・媒体: 【】
- 語り手の案: 【あれば/おまかせ】

まず設計(01_語り手設計.md〜canon.json まで。恥・プライド・語りの相手は必須)を作って見せて、止まって。
OKを出したら第1話から。1話書くごとに fp_scan.py と canon_check.py を回し、08の自己チェックをして、
09_進捗メモ.md と継続状態・知識マップ・伏線台帳を更新し、コミットしてプッシュして。
```

## C. 続きを書く(設定を守らせる)

```
/first-person-novel
novels/【作品名】/ の続きを書いて。
まず 09_進捗メモ.md、設定カード、02_人物.md、05_知識マップ.md、06_継続状態.md、07_伏線台帳.md を読み、
直前の話の最後の2段落も読んで。書く前に、この話の開始状態(日付・場所・語り手の身体状態と持ち物・知っていること)を書いて見せて。
第【◯】話を書き、書いた後に照合表(設定カードの各項目+本文の引用)を出して、台帳を更新して。
設定にないことを足したら「新設定」として一覧にして。
```

## D. 推敲(既存原稿)

```
/first-person-novel
【ファイルのパス】を推敲して。06_失敗パターンと推敲.md の順(構造→語り手→場面→文章→AIっぽさ)で。
先に fp_scan.py を回して結果を見せ、そのあと直した版を保存して。
何をなぜ直したかを、主な箇所だけ箇条書きで。語り手の声は変えないこと。
```

## E. 面白さのセルフチェック(書いたセッション内)

```
/first-person-novel
【ファイルのパス】を、08_面白さのセルフチェック.md の手順で検証して。
10個のテストと10項目の採点を、すべて本文の引用つきで。悪い点を先に挙げること。
採点で「合格」を名乗らず、直すべき箇所と、冷読で確かめるべき点を挙げて。
```

## F. 冷読(別の白紙のセッションに貼る。設計意図は渡さない)

```
あなたは小説の読者であり、厳しい編集者でもあります。次の原稿を、書き手の意図を知らない状態で読み、評価してください。
褒める前に、悪い点から答えてください。「特にない」は禁止。判断の根拠は、必ず原稿からの引用で示してください。

1. どこで退屈したか、どこで手が止まったか(引用と理由)
2. 語り手を、友達に一言で説明するとしたら。好きになれるか。理由
3. 一番好きな一文と、一番つまらない一文(引用)
4. 笑った・ニヤリとした箇所はあるか。なければ、その理由
5. この先を読みたいか。理由。読みたくなくなる条件
6. 違和感のある箇所(設定の矛盾、語り手が知り得ないことを書いている箇所、人物が急に別人に感じる箇所)
7. AIが書いたように感じる箇所とその根拠(語彙、リズム、整いすぎ、感情の説明、定型の比喩や締め、同じ型の繰り返し、うまさの自慢)
8. 語り手が自分の感情を解説している箇所(引用)
9. 読者の頭に開いている問いを全部書き出す
10. 点数(0〜3点):問い/声/具体性/反転/感情の真実/緩急/人間らしさ/設定の整合/体温。根拠の引用がない項目は0点
11. 最も効果的な改善を3つ。具体的な書き直し案つき

【原稿】
(ここに貼る)
```
