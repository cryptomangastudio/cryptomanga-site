# 一人称小説スキル

「面白い小説とは何か」を分析し、一人称に特化したルールにし、他のセッションに貼れるプロンプトにしたもの。ジャンル非依存。

## 最初に読むもの

| やりたいこと | 読むもの |
|---|---|
| 貼り付けて使う(迷ったらこれ) | `プロンプト集.md` のA(自己完結版) |
| 面白さの仕組みを知りたい | `references/01_面白さの原理.md` |
| 書き始める前の設計 | `references/02_一人称の設計.md`(設計シート) |
| 一文ごとのルール | `references/03_一人称の文章ルール.md` |
| 一人称ならではの技法 | `references/04_一人称でしかできないこと.md` |
| 場面・章・冒頭・結末の設計 | `references/05_場面と構成.md` |
| 失敗の診断と推敲 | `references/06_失敗パターンと推敲.md`(悪い例/良い例つき) |
| 設定無視・矛盾・キャラ崩壊を防ぐ | `references/07_設定の保持と破綻防止.md` |
| 面白いかを確かめる | `references/08_面白さのセルフチェック.md`、`samples/` |

## 進め方

1. **設計を先に書く**:`02_一人称の設計.md` の設計シートを埋め、`07` の設定カード(15行)と正本ファイルを作る。ユーザーに見せて確認。
2. **場面ごとに書く**:`05` の「場面を書く前の5つの問い」に答えてから本文。書く前に開始状態(日付・場所・身体状態・知っていること)を書き、書いた後に照合表(設定項目×本文の引用)を出す。
3. **機械チェック**:
   ```bash
   python3 .claude/skills/first-person-novel/scripts/fp_scan.py 原稿.md
   python3 .claude/skills/first-person-novel/scripts/canon_check.py canon.json 原稿.md
   ```
4. **セルフチェック**:`08` の7つのテストと採点(引用必須、悪い点が先)。合格しなければ直して再採点。
5. **冷読**:書いたセッションとは別の白紙セッションで読ませる(`プロンプト集.md` F)。冷読と自己採点がずれたら冷読を信じる。
6. **ユーザーの判断**:最終的な「面白い」は人間が決める。

## 守ること

- **自己申告を信じない。**「設定を守りました」「面白いです」は証拠にならない。引用つきの照合・採点のみ受け付ける。
- **設定は会話ではなくファイルが正本。**セッションを開始したら最初に正本を読む。本文と食い違ったら、どちらを正にするか決めて記録してから直す。
- **設定にないことを足すときは「新設定」と明記する。**便利な新設定や突然の能力は伏線なしに使わない。
- **一人称の制約を破らない。**語り手が知り得ないこと、見えないものを書かない。
- **整いすぎを疑う。**`creative-writing/anti-ai-tells.md` を最後に必ず通す。ロマンスファンタジーなら `romance-fantasy` スキルも併用。

## 他のスキルとの関係

- `creative-writing`:構成・キャラ・世界観・編集の一般技術。本スキルはその一人称特化。
- `romance-fantasy`:ジャンル固有の様式。一人称で書くなら本スキルと併用する(令嬢の一人称は `romance-fantasy/references/prose-style-ja.md` も参照)。
