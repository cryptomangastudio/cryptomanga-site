# サンプル02『赤字は鉛筆で』(改訂3:体温を入れる試み)

サンプル01の標本的な冷たさを直す試み。設計の変更点は次のとおり。評価の記録は `sample_02_評価.md`。

```
■語り手:僕/二十九歳/外注の校正者/回想型/聞き手=特定しない(ただし語るのは「あとで」を言い続けた自分の弁明のため)
■声:丁寧で、事務的で、少し間が抜けている。怒らない。逃げるときほど礼儀正しくなる
■恥(人に知られたくないこと):妹の最後の頼みに「あとで」と返して、そのままにした
■守りたいプライド:自分は仕事のできる、感情的でない人間だということ
■動機:なぜ語るか=この「あとで」を、いつか誰かに白状するため(未開示)
■盲点:妹の頼みは校正の依頼ではなく、会いたいという合図だったこと(未開示)
■大きな問い:死後に刷られた紙に、妹の筆跡で書き込んだのは誰か
■変更点:職業の自己言及をなくし、行動で示す。自己訂正の言い回しは1回だけ。感情は解説せず、行動のずれと「あとで」の一点に集める。侮蔑一色にせず、水野は普通の人として書く
```

---

妹から校正の依頼が来たのは、八か月ぶりだった。

正確には、文林社から宅配便が届いただけで、依頼人は死んでいる。ただ、ゲラの一枚目の余白に、鉛筆でこうあった。

〈ここ、兄さんならどう直す？〉

ここ、とは、どこだ。一枚目はタイトルと著者名と「再校」の判子があるだけで、直すところがない。妹は昔からこうだった。何も指さずに、これだけ書く。人の時間を一行で借りておいて、借用書は出さない。

「ど」の濁点だけ、いつもの癖で、字から離れている。

玄関で箱を開けたので、まだ靴を履いていた。紙の束を片手で持ち上げたとき、もう片方の手が勝手に、上着のポケットの赤ペンを探していた。鉛筆の書き込みに赤を重ねるのは、妹が相手なら昔からやってきたことだ。やってきたが、いまやったら返事になる。手を戻した。

ゲラの右上には、出力日が刷ってある。見たくなかったが、見た。

十一月二日。今日が六日だから、四日前。

鉛筆の線は、インクの上にあった。芯の粉が、活字の黒の上に乗っている。刷ったあとに書いたのだ。誰かが、四日前より、あとに。

妹は三月に死んでいる。

靴を脱ごうとして、右から脱ぐのか左から脱ぐのかわからなくなった。毎日やっていることなのに。結局、かかとを踏んで脱いだ。母に見られたら叱られる脱ぎ方だった。

廊下に立ったまま、水野に電話をかけた。「お世話になっております」と言ってしまい、言ってから、この男に世話になった覚えはないと思った。

「あ、届きました？　よかった」

水野は何か食べていた。紙袋を探る音がする。

「一枚目に、鉛筆の書き込みがあります」

「ああ、先生のメモですね。原稿のあちこちにあるんですよ。毎回、同じ言い回しで。兄さんならどう直す、って。お兄さん、ご存じですよね」

毎回。

知らない、とは言えなかった。知っているのは一回だけだ。三月の頭に同じ文面のメールが来て、僕は「あとで」と返した。妹が死んだのは三月二十一日で、僕のあとでは、まだ来ていない。

「このゲラは、四日前に出力されたものですね」

「ええ、再校なので」

「妹は三月に亡くなっています」

「……ええ」

「四日前に刷った紙に、どうやって鉛筆で書くんでしょう」

紙袋の音が止まった。かわりに、水野の背後でコピー機が動いているのが聞こえた。

「お兄さん」と水野は言い、少し間を置いて、言い直した。「あの、うちの校閲が、先生の前の書き込みを新しいゲラに写したんです。筆跡ごと。そのほうが、お兄さんが読むとき、」

「筆跡ごと」

「はい」

「写せるものですか」

「写せ……ますよ。プロですから」

プロ、の言い方がおかしかった。自分で言って、自分で確かめるような言い方だった。

水野のほうから切れた。

靴下のまま廊下に立って、もう一度、鉛筆を見た。

妹の「ど」は、濁点が離れる。僕が子供のころ、何度もくっつけて見せたが、直らなかった。

いま見ると、くっついていた。

直したのは、誰だ。
