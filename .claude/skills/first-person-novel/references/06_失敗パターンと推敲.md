# 失敗パターンと推敲

## 一人称の典型的な失敗 12

| # | 症状 | 原因 | 処方 |
|---|---|---|---|
| F1 | 「私は」「僕は」で文が始まる | 主語を省いていない | R1:省く。主体が切り替わるときと強調のときだけ残す |
| F2 | 「見えた」「聞こえた」「思った」「感じた」だらけ | フィルター語 | R2:削って直接書く |
| F3 | 語り手が知らないはずのことを書いている | 視点の滑り(他人の内心、いない場所) | R3:観察に直すか、伝聞・推測にする |
| F4 | 語り手が自分の感情を正確に解説する | 感情の説明過多 | R8:行動に置き換える。名付け損なわせる |
| F5 | 内省が何段落も続いて物語が止まる | 余波が長い | 外の出来事を入れる。余波は場面の三分の一以下 |
| F6 | 全員の話し方が語り手と同じ | 台詞の口調がない | 人物ごとに語尾・語彙・長さを変える |
| F7 | 声がない(誰が語っても同じ) | 声の設計不足 | 「私」を「彼女」に置き換えて成立するなら主観がない。偏りを足す |
| F8 | 説明が多い、設定を語り手が読者に向かって解説する | 説明の理由がない | R12:語り手が引っかかった瞬間にだけ出す |
| F9 | 章末が毎回「この時はまだ知らなかった」 | 予告の乱用 | 回想型の予告は作品全体で数回まで(T5) |
| F10 | 語り手が優等生で、欠点も偏見もない | 好感度優先 | 偏見・恥・嫉妬・見栄を一つ与え、行動に漏らす |
| F11 | 時制・代名詞・語調が途中で変わる | 設計の不統一 | 設計シートに戻す。変えるなら事件として |
| F12 | 冒頭で自己紹介・目覚め・鏡の自己描写 | 定番の入り方に逃げた | `05_場面と構成.md` 冒頭の型 |

## 推敲の順序

構造から文章へ。後ろの工程で前の工程の問題は直せない。

### パス1:構造

- 作品を貫く問いは何か。結末で閉じているか。
- 各章の最初と最後で、何かの値が反転しているか。反転しない場面は削るか作り直す。
- 章のつながりが「そして」だけになっていないか。「しかし/だから」が入るか。
- 中盤で止まっていないか。

### パス2:語り手

- 設計シートと矛盾していないか(代名詞、語りの時点、聞き手、信頼性)。
- 語り手が知り得ない情報を書いていないか。
- 語り手の欲求が各場面で見えるか。語り手が自分で選んでいるか。
- 声が最初から最後まで保たれているか。変化させたなら意図的か。
- 語り手の盲点が、読者にだけ見えるように置かれているか。

### パス3:場面

- 場面の最初の一文が、状況か声か問いを渡しているか。
- 最後の一文が、具体的な一瞬か。総括・予告・格言になっていないか。
- 余波が長すぎないか。
- 台詞が情報伝達だけになっていないか。質問に正面から答えていないか。

### パス4:文章

- `scripts/fp_scan.py` を回す。
- 「私は」の連発、フィルター語、感情の名指し、「た」の連続を直す。
- 声に出して読む。引っかかる箇所は、ほとんど文が悪い。
- 比喩は1場面に1つ。語り手の経験から出た比喩か。
- 全文の長さをそろえすぎていないか。

### パス5:AIっぽさ(最後に必ず)

- `creative-writing/anti-ai-tells.md` のチェックリスト。
- 感情が整った順序で来ていないか。決めゼリフが各場面にないか。意味のないディテールが一つもない世界になっていないか。
- 全場面が同じ密度で書かれていないか。人間は退屈なところを飛ばし、好きなところを異様に長く書く。

## 書き比べ:一人称の悪い例と良い例

場面:語り手(会社員)が、同僚の退職の送別会に出席している。

### 悪い例

> 私は居酒屋の入口に立った。私は店内を見渡した。奥の座敷に、同僚たちが集まっているのが見えた。
>
> 今日は、長年一緒に働いてきた田中さんの送別会だ。私は田中さんのことを、とても尊敬していた。いつも優しくて、頼りになる先輩だったからだ。そんな田中さんがいなくなってしまうと思うと、胸が締め付けられるような悲しみを感じた。
>
> 私は静かに席に着いた。田中さんが私に気づいて、優しく微笑んだ。
>
> 「来てくれてありがとう。あなたには本当にお世話になったわ」
>
> 私は嬉しいような、寂しいような、複雑な気持ちになった。田中さんは私のことをとても大切に思ってくれていたのだと思った。
>
> この時の私は、まだ知らなかった。この夜が、すべての始まりになることを。

症状:F1(「私は」連発)、F2(見えた/思った)、F4(感情の解説)、F8・F10(優等生の語り手、尊敬の説明)、F9(予告)、台詞が情報伝達だけ、感情を二つ並べる平均化。

### 良い例

> 座敷の奥で、田中さんが花束を持て余していた。
>
> 私の席は、入口にいちばん近い端だった。幹事が気を利かせたのか、それとも余った席がそこだけだったのか。生ビールが二杯、すでに手元に置いてある。誰かが私の分まで頼んでおいてくれたらしい。
>
> 「あれ、来てくれたんだ」
>
> 田中さんが、花束ごとこちらに手を振った。来るに決まってるでしょう、と言いかけて、やめた。去年、私が異動になったとき、田中さんは送別会に来なかった。
>
> 「うん。花、似合ってますよ」
>
> 「重いの、これ。後でそっちに半分あげる」
>
> 半分あげるって、どうやって。聞き返す前に、隣の席の子が田中さんの話に割って入って、二人は笑いはじめた。私はビールの泡が消えるのを見ていた。ジョッキは汗をかいて、コースターが水を吸いきっている。
>
> 帰り際、田中さんの花束から白いのが一本抜けて、私の鞄のそばに落ちた。拾った。返しそびれた。家に着くまで、傘みたいに持っていた。

何が違うか:

| 悪い例 | 良い例 |
|---|---|
| 「私は〜」で毎文始まる | 主語をほとんど書かない。冒頭は田中さんから入る |
| 「尊敬していた」「悲しみを感じた」と感情を解説 | 感情の名前は一度も出ない。去年の送別会に来なかったことと、花を拾って返せなかったことで関係の温度を見せる |
| 田中さんが語り手の気持ちを台詞で確認する | 台詞は噛み合わず、軽口で終わる。「半分あげる」の意味を聞き返せない |
| 「優しく微笑んだ」「静かに席に着いた」の副詞 | 副詞なし。花束を持て余している、の具体 |
| 優等生で尊敬一色の語り手 | 少し根に持っている。去年のことを覚えていて、言わない |
| 「この時の私は、まだ知らなかった」で閉じる | 具体的な一瞬(白い花を傘みたいに持って帰る)で閉じる |
| 感情が複数並んで平均化(嬉しいような寂しいような) | 感情を一つも名指さない。読者が組み立てる |
