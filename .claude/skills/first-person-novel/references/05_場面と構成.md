# 場面と構成(一人称版)

構成の一般論は `creative-writing/story-structure.md` にある。ここでは一人称で書くときに具体的に効く手順だけを置く。

## 場面を書く前の5つの問い

1. **語り手はこの場面で何を欲しがっているか。**(具体的に。言質、時間、許し、嘘をつき通すこと)
2. **何が邪魔をするか。**(人、状況、自分の癖)
3. **場面の最初と最後で、何の値が反転するか。**(希望→不安、他人→味方、知らない→知っている)
4. **語り手は何を見落とすか。**(盲点。読者にだけ見える手がかり)
5. **場面の最後の一文は、具体的な一瞬か。**(総括や予告ではない)

答えられない場面は、まだ書く準備ができていない。

## 場面と余波の配分

- 場面(外):目標→衝突→挫折。他人がいて、何かが起きる。
- 余波(内):反応→ジレンマ→決断。語り手が一人で考える。
- 一人称は余波が書きやすいので、**余波が場面より長くなりがち**。余波は場面の三分の一以下を目安にする。
- 余波の中でも、語り手は動く(手を動かす、歩く、食べる、電話をかける)。思考だけが何段落も続くのは避ける。

## 冒頭:最初の一文・最初の一段落

冒頭で読者に渡すものは、次の3つのうち2つ以上:

- **声**:この語り手の語り方
- **状況**:今、何が起きているか
- **問い**:読者が答えを知りたくなる疑問

型:
- **行動から入る**:「兄の葬式の帰り、私は生まれて初めて口紅を買った。」(状況+問い)
- **宣言から入る**:語り手の偏見や断言で声を出す。「私は昔から、他人の傘を借りることが苦手だった。」
- **矛盾から入る**:言っていることと状況がずれる。
- **中間(in medias res)から入る**:騒動の最中に放り込み、背景はあとで漏らす。

避けるもの:
- 目覚め、天気、鏡の前の自己描写から始める
- 名前・年齢・職業の自己紹介(`03_一人称の文章ルール.md` R15)
- 世界観や背景の説明から始める
- 「これは私の物語である」のような物語の宣言(声や問いが伴うときは可)

最初の1ページを書いたら、**語り手の名前・性別・年齢を隠しても、この人の声だとわかるか**を試す。

## 章の終わり(引き)

一人称の章末は、語り手の「次の行動」か「新しい情報」か「言い残し」で切る。

- 危機型:ピンチの一瞬で切る
- 謎型:不可解な事実を一つ見せて切る
- 決意型:語り手が何かを決めたところで切る(実行は次章)
- 反転型:それまでの理解が覆る一文で切る
- 余韻型:静かな具体的な一瞬で切る(毎章引きで切ると読者が疲れる。5章に1章は余韻で閉じる)

総括で閉じない:「この時の私は、まだ何も知らなかった」はほとんどの場合、弱い。

## 中盤(だれる箇所)の立て直し

中盤で止まるのは、ほぼ次のどれか。

- 語り手が受け身:事件に反応しているだけ。→ 語り手に能動的な選択をさせる。
- 障害が同じ質:同じ強さの障害の繰り返し。→ 外の障害→人との衝突→自分の弱さ、と質を変えて上げる。
- 問いが開いていない:→ 新しい問いを一つ開く。または古い問いの答えを部分的に出して、別の問いを開く。
- 内面の繰り返し:→ 同じ悩みを違う言葉で繰り返している。削るか、状況を動かす。
- 中間点がない:→ 物語の半分あたりで「勝ったと思ったら悪化」か「全て失ったと思ったら、本当に必要なものに気づく」を置く(`creative-writing/story-structure.md`)。

## 結末

- 問いに答える:作品全体で開いた大きな問いは、結末で必ず閉じる(答えが「ノー」でもよい)。
- 変化を見せる:冒頭の声と結末の声に差があるか(`04_一人称でしかできないこと.md` T8)。
- 余韻を残す:全てを説明しない。最後の一文は、行動か具体物で終える。
- 回想型なら、「語る私」が今どこにいて、なぜ語ったのかが、結末で一つ分かるようにする。

## 設計の手順(まとめ)

1. 設計シート(`02_一人称の設計.md`)を埋める。
2. ログライン、冒頭の声と結末の声の差を一行ずつ書く。
3. 大きな問いを一つ決める。
4. 中間点と最大の危機を先に決める。
5. 章立て(各章の「しかし/だから」のつながりを確認)。
6. 各章の欲求/障害/反転する値を一行ずつ書く。
7. 書き始める。
