# 一人称でしかできないこと

三人称で書けることを一人称で書き直しても、一人称を選んだ意味がない。一人称の武器は**「語り手の偏り」がそのまま物語の面白さになる**こと。以下は、一人称でとくに効く技法。

## T1. 言っていることと、起きていることのずれ(アイロニー)

語り手が主張することと、地の文が無自覚に見せてしまう事実が食い違う。読者は語り手より先に真実を知る。

- 「私は彼のことなど何とも思っていない。ただ、駅の階段を上がるとき、改札の向こうを三度確かめただけだ。」
- 語り手は否定している。読者は行動を見ている。**語り手が否定するほど、読者は信じなくなる。**

使い方:
- 語り手の主張(解釈)は書き手が決める。その横に、主張を裏切る行動の事実(観察)を一つ置く。事実は正直に、解釈だけをずらす。
- ずれは説明しない。気づくのは読者の仕事。

## T2. 語り手の盲点(語り手が気づいていないこと)

設計シート(`02_一人称の設計.md`)の「語り手が気づいていないこと」を、読者にだけ見えるようにする。

- 他人の台詞や反応を、語り手は誤読しているが、台詞そのものは正確に書かれている。読者は台詞から正しく読める。
- 例:「店長は『いつでも辞めていいよ』と笑った。私が信頼されている証拠だと思った。」読者には、辞めてほしいというサインに見える。
- 盲点は一つ決めて、作品全体で少しずつ見せる。一場面で全部見せない。

## T3. 声そのものを娯楽にする

何を語るかより、**どう語るか**で読ませる。語り手の言い回し、脱線、決めつけ、口癖、偏った愛が面白ければ、筋が静かでも読める。

- 森見登美彦の饒舌で大仰な語り、太宰治の自己卑下の手記、夏目漱石『吾輩は猫である』の猫の観察。いずれも筋より声が読ませている。
- 声が強い作品は、**語り手が何を面白がるか**が決まっている。部屋に入って何に目を留めるか、人をどう分類するか。
- 脱線は短く、戻りは意図的に。脱線が筋を止めるなら削る。脱線から戻ったときに、その脱線が語り手の心情を漏らしていれば合格。

## T4. 語りたくないことを避ける(省略の圧力)

語り手が、ある出来事の周りを何度も回りながら、核心に入れない。読者は避けている中心の形を感じる。

- 「あの日のことは、また今度話す。」を繰り返す語り手。
- 時間的に、その出来事の直前と直後は詳しく、当日だけ短い。
- 核心を語るときは、文が急に短くなる/急に説明が消える/他の話題に逃げる。
- 避ける理由(罪悪感、恥、まだ受け入れていない)を書き手が決めておく。理由が弱いと、ただのもったいぶりになる。

## T5. 後知恵と予告(回想型だけ)

語る私は結末を知っている。これを使って、読者に先の予感を与える。

- 「あのときは、それが最後の夏になるとは思わなかった。」
- 効く条件:ごく少なく、重みのある場面だけ。毎章で使うと、緊張が死に、読者は「どうせ悲劇になる」と身構えるだけになる。
- 予告は結果ではなく、**何かが起こることだけ**を言う(何が・誰が・どうなるかは言わない)。
- 語る私が全部を知っているなら、「なぜ今それを話すのか」に答えられるようにする(`02_一人称の設計.md` 動機)。

## T6. 聞き手の存在を使う

特定の「あなた」に語りかける形式では、「あなた」との関係が物語になる。

- 湊かなえ『告白』のように、各章を別の人物の一人称の語りにして、同じ出来事を別の角度から見せると、章ごとに読者の理解が更新される(驚きの原理)。
- 手記・手紙・遺書の形式では、冒頭か末尾で形式の種明かしをすると、それまでの語りの意味が変わる。太宰治『人間失格』は、外側の「私」が手記を紹介する枠をつけることで、手記の語りを読者が相対化できる。
- 語りかけられる「あなた」が、語りの終盤で答える/答えない、という使い方もできる。

## T7. 複数の一人称(多視点)

一人称を章ごとに切り替える場合。

- 各語り手の声を明確に分ける:代名詞、文末、語彙、目を留めるもの、リズム。章の頭に語り手の名前を置く手もあるが、**名前がなくても誰の章か数行でわかる**のが理想。
- 同じ出来事を二人の語り手が語るときは、**事実は一致させ、解釈と省略だけをずらす**。事実がずれると、どちらが嘘をついているのかを読者が追うだけの話になる。
- 章の切れ目に、次の語り手へ橋をかける(前の語り手が最後に見たものが、次の語り手の最初の一文に出てくる)。

## T8. 語り手が変わることで、物語が終わる

三人称では「主人公が変わった」と地の文が説明するしかない。一人称では、**語り手の語り方が変わる**ことで、変化を説明せずに見せられる。

- 冒頭で他人を軽蔑する言葉で呼んでいた語り手が、終盤で同じ人物を名前で呼ぶ。
- 冒頭は饒舌で逃げていた語り手が、終盤で言葉少なに核心を語る。
- 冒頭で語れなかったことを、結末でようやく語れる。

設計時に、「冒頭の声」と「結末の声」の差を一行で書いておく。

## T9. 一人称の制約を武器にする

| 制約 | 武器にする方法 |
|---|---|
| 他人の心の中がわからない | 読者も同じだけわからない。誤読が起こり、誤読が物語を動かす |
| 自分のいない場所のことは書けない | 伏せられた情報が、サスペンスと好奇心になる |
| 自分の顔が見えない | 他人の反応が、語り手の見え方を教える。自分の評価と他人の反応のずれが人物になる |
| 語り手が死ぬと語れない | 生き延びた/書き残した理由が、そのまま動機になる |
| 語り手の知識の範囲が狭い | 読者が語り手と一緒に学ぶ(新人、転生者、よそ者の語り手が有利) |

## 一人称にしないほうがいい場合

- 物語が、語り手の知らない複数の場所で同時に進行する(群像劇、戦争、陰謀)。
- 語り手の内面より、世界や社会の俯瞰を見せたい。
- 語り手が「語る価値のある声」を持たない設定で、声を設計する余裕がない。

このとき一人称にこだわるなら、章ごとの複数一人称(T7)か、語り手が資料・手紙・記録を読む形式にする。
