# 一人称の設計:書き始める前に決める8つのこと

一人称は「私が見たことを書けばいい」ので簡単に見えるが、実際には三人称より決めることが多い。ここを決めずに書き始めると、語り手が途中で全知になったり、声がぶれたり、なぜこの人が語っているのか読者にわからなくなったりする。**以下の8項目を「設計シート」として先に書き出す。**

## 1. 語り手は誰か:主人公型か、傍観者型か

- **主人公型**:物語の中心にいる人物が自分のことを語る。もっとも一般的。
- **傍観者型**:主人公のそばにいる別の人物が語る。『グレート・ギャツビー』のニック、シャーロック・ホームズもののワトソン、夏目漱石『こころ』の上・中の「私」。
  - 利点:主人公の内面を書かずに済むので、主人公を謎のまま保てる。読者は語り手と一緒に主人公を観察する。
  - 隠れた本筋:傍観者型では、**語り手自身がひそかに変化していく**のが物語のもう一本の線になることが多い。

## 2. 一人称代名詞

日本語の一人称代名詞は、それだけで人物の性別・年齢・育ち・自己像を伝える。選択は人物設定そのもの。

| 代名詞 | 伝わる印象の例 |
|---|---|
| 私(わたし) | 中立。性別を問わない。大人の語り、改まった語り |
| わたくし | 改まり、上品、またはよそ行きの仮面 |
| 僕 | 柔らかい男性、少年性、内省的 |
| 俺 | くだけた男性、粗さ、親しさ |
| あたし | くだけた女性、若さ |
| うち | 地域性(関西など)、若い女性 |
| 自分 | 体育会系、軍隊的、または自分を突き放した視線(太宰治『人間失格』の手記は「自分」) |
| わし/儂 | 高齢、方言 |

- **地の文と台詞で代名詞を変える**手もある。人前では「俺」と言い、地の文では「僕」と書く語り手は、それだけで内と外の差を背負う。
- 一度決めたら変えない。変えるなら、それ自体が物語上の事件(仮面が剥がれる瞬間)になる。

## 3. 語りの時点:語る私と、経験する私の距離

物語論のシュタンツェルは、一人称の語り手を2人に分けた。

- **経験する私**:その出来事を生きている私
- **語る私**:あとからそれを語っている私

同じ「私」でも、2人は時間も場所も知っていることも違う。この距離をどう取るかで、書けることが変わる。

| 型 | 距離 | 書けること | 書けないこと・注意 |
|---|---|---|---|
| 同時進行型 | ゼロ(現在形・実況) | 先がわからない緊張、臨場感 | 振り返り・意味づけができない。日本語では長く続けると不自然になりやすい |
| 直後型 | 数時間〜数日 | 生々しい感情と、少しの整理 | 日本語の過去形一人称小説の多くはこれが暗黙の設定 |
| 回想型 | 数年〜数十年 | 後知恵、皮肉、郷愁、「あの頃は知らなかった」 | 予告を使いすぎると緊張が死ぬ。語る私が出しゃばりすぎない |

ルール:
- どの型かを決め、作品の途中で勝手に変えない。型が決まると「語り手がこの時点で知っている情報の範囲」が決まる。
- 回想型でも、場面の最中は経験する私の目線に寄せて書く(結果を知っている語る私が、毎場面で答えを言ってしまわない)。語る私が顔を出すのは、効かせたい箇所だけ。

## 4. 誰に向けて語るのか(聞き手)

一人称の語りには、必ず暗黙の聞き手がいる。誰に向けているかで、語調・何を説明して何を省くかが変わる。

- 不特定の読者(もっとも一般的。ただし「読者」を意識しすぎると説明口調になる)
- 特定の「あなた」(手紙、遺書、恋文。「あなた」を誰にするかで全文の意味が変わる)
- 自分自身(日記・手記。説明が少なく、省略と自己弁護が多くなる)
- 裁く人(法廷・取り調べ・告解。弁明と隠蔽が混ざる)

ルール:
- 聞き手が知っていることは説明しない。語り手と聞き手の共有知識を決めておく。自分の家の間取りを、家族宛ての手紙で説明する人はいない。
- 「です・ます」で語るか「だ・である」で語るかも、聞き手との距離で決まる。

## 5. なぜ語るのか(動機)

人は理由なく自分の話をしない。告白、弁明、記録、自慢、整理、復讐、遺言。**動機があると語りに偏りが生まれ、その偏りが面白さになる。**

- 弁明のために語る語り手は、自分に不利な事実を後回しにする。
- 自慢のために語る語り手は、自分の失敗を小さく書く。
- 動機は作中で明示しなくてよいが、書き手は決めておく。終盤で動機が明かされる構成(実はこれは遺書だった)も強い。

## 6. 信頼性

| 型 | 中身 | 例 |
|---|---|---|
| 信頼できる語り手 | 事実も解釈もおおむね正しい | 多くの小説 |
| 解釈が歪む型 | 事実は正確に語るが、その意味を取り違える | カズオ・イシグロ『日の名残り』の執事スティーブンス。相手の反応は正確に書かれ、直後に誤読される |
| 理解できない型 | 子ども、異文化の人、特殊な環境で育った人。語り手には当たり前のことが、読者には異常に見える | イシグロ『わたしを離さないで』 |
| 隠す・嘘をつく型 | 意図的に重要な事実を伏せる | アガサ・クリスティー『アクロイド殺し』などの叙述トリック |

ルール:
- **いちばん使いやすく効果が高いのは「解釈が歪む型」**。事実は正直に書き、解釈だけをずらす。読者は語り手の枠を通しながら、枠の外の真実を見る。
- 信頼できない語り手には、読者が気づける「綻びの信号」を置く:他人の反応が語り手の解釈と合わない/語り手が同じことを何度も否定する/不自然に細かく覚えている/話題を急に変える。
- 嘘をつく型はフェアさが要る。真相がわかったあとで読み返して「嘘は書いていなかった(書かなかっただけ)」と言える形にする。

## 7. 心理的距離

作家ジョン・ガードナーは、語りと人物の心の距離を段階で示した。一人称でも距離は動く。一人称版に置き換えた例:

1. 遠い:「その年の冬、私は雪の多い町に住んでいた。」
2. 「雪は昔から、あまり好きではなかった。」
3. 「雪が嫌いだった。」
4. 「また雪だ。勘弁してほしい。」
5. 近い:「雪。襟の中に。靴の中に。」

ルール:
- 距離は場面の中で理由なく跳ばさない。急な跳躍は素人っぽく見える。
- 山場で近づき、余韻で離れる。場面の入りは少し遠め(状況がわかる距離)から始めると読者が迷わない。

## 8. 声(ヴォイス)

声は、語彙・文のリズム・口癖・何を面白がるか・何に腹を立てるか・何を見ないふりをするか、の総体。

ルール:
- 書き始める前に、**その語り手らしい地の文を3文**書いてみる。3文でその人だとわからなければ、声がまだない。
- 声のテスト:地の文の「私」を「彼女」に置き換えても違和感なく読めるなら、その文には語り手の主観がない。一人称で書く意味がない文が多すぎないか確かめる。
- 声は作品の最後まで保つ。変化させるなら、物語上の変化として意図的に(`01_面白さの原理.md` の原理8)。
