# 面白さの原理

ジャンルも人称も問わない土台。「面白い」とは、**読者が次の一文を読まずにいられない状態**のこと。その状態は偶然ではなく、以下の仕組みで作られる。各項目の末尾に、一人称で書くときの注意を添える。

## 原理1:読者の頭の中に、いつも問いが開いている

物語論のメイア・スタンバーグは、物語を読ませる力を3つに分けた。

- **サスペンス**:これからどうなるのか(未来への問い)
- **好奇心**:何があったのか、なぜそうなったのか(過去への問い)
- **驚き**:わかっていたつもりのことが組み替わる(理解の更新)

3つとも、**情報をどの順番で出し、何を伏せるか**で生まれる。

ルール:
- どの時点でも、読者の頭に最低1つ「答えを知りたい問い」が開いているようにする。問いを1つ閉じたら、すぐ次を開く。
- 問いは入れ子にする。作品全体の大きな問い(この二人は結ばれるのか)、章の問い(彼女は手紙を読むのか)、場面の問い(ドアの向こうに誰がいるのか)。
- サスペンスには、読者が「危険を知っている」ことが要る。テーブルの下の爆弾を観客だけが知っているから、ただの会話が緊張する。
- 驚きは、読み返すと「確かに書いてあった」と思える形にする。後出しの情報で驚かせない。

一人称では:語り手が知っていることを、語り手の判断で伏せたり先に言ったりできる。これは強力だが、**語り手が知っているのに理由なく隠す**と読者はずるいと感じる。隠すなら隠す理由(思い出したくない、まだ言う覚悟がない)を語り手に持たせる。

## 原理2:誰かが何かを欲しがり、何かが邪魔をする

- 欲求は具体的に。「幸せになりたい」ではなく「金曜までに四十万円」「母に一度だけ謝らせたい」。
- 邪魔するもの(障害)は、欲求と同じくらい具体的に。障害が弱いと勝っても面白くない。
- 賭け金(失敗したら何を失うか)を読者が理解していること。
- 外の欲求(手に入れたいもの)と内の欲求(本当に必要なもの)がずれていると、物語に奥行きが出る。

一人称では:語り手は自分の欲求を正確に言えなくてよい。むしろ**語り手が自分の本当の欲求に気づいていない**状態は、一人称でいちばん自然に書ける(原理を活かす技法は `04_一人称でしかできないこと.md`)。

## 原理3:期待と結果がずれる

脚本論のロバート・マッキーは、場面を動かすのは「期待と結果のずれ」だとした。人物が「こうすればこうなる」と思って行動する→結果が違う→もっと危険な行動を取る→またずれる。

ルール:
- 各場面の始めと終わりで、何かの値が反転しているか確かめる(希望→絶望、他人→味方、知らない→知っている)。反転していない場面は、削るか作り直す。
- ずれは毎回同じ方向にしない。悪化だけでなく、思いがけない好転も混ぜる。

一人称では:語り手の「期待」を地の文で先に書けるので、ずれがはっきり見える。「どうせ断られると思っていた」の後に承諾が来ると、承諾の意味が変わる。

## 原理4:「そして」ではなく「しかし」「だから」でつなぐ

『サウスパーク』の制作者が広めた考え方。出来事を「AがあってBがあってCがあった」と並べると、それは物語ではなく報告になる。出来事のあいだを「しかし」(邪魔が入る)か「だから」(前の出来事の結果として次が起きる)でつなげるようにする。

ルール:
- プロットの箇条書きを作ったら、各項目のあいだに「しかし」か「だから」が入るか試す。「そして」しか入らない箇所は、因果が切れている。

## 原理5:場面と余波を交互に置く

ドワイト・スウェインの場面構成論。

- **場面**:目標 → 衝突 → 挫折(または「はい、でも」という新たな問題)
- **余波**:反応(感情) → ジレンマ(どれを選んでも何かを失う) → 決断(次の場面の目標になる)

場面が続くと息切れし、余波が続くと停滞する。交互に置く。

一人称では:**余波(内面)が長くなりすぎる**のが最大の罠。一人称は内面を書きやすいので、反応とジレンマが何段落も続いて物語が止まる。目安として、外で何も起きない内面の段落が3つ続いたら、外の出来事(電話が鳴る、人が来る、自分が動く)を入れる。

## 原理6:具体性

一般論・抽象語・平均的な描写は読み流される。読者の目を止めるのは、**この話にしかない具体物**。

- 「古いアパート」より「郵便受けに前の住人の名前が残っているアパート」
- 「彼は怒っていた」より「彼は伝票を三回折りたたんだ」
- 数字・固有名詞・手触り・匂い・音。一場面に一つで十分。

一人称では:語り手が何に目を留めるかが、そのまま人物描写になる。同じ部屋に入っても、大工は床の傾きを、看護師は住人の顔色を、借金のある人は値札を見る。

## 原理7:人物が自分で選ぶ

- 出来事に反応するだけの主人公はつまらない。物語を動かす選択を主人公にさせる。
- 良い選択は代償を伴う。どちらを選んでも何かを失うジレンマが、読者を前のめりにさせる。

一人称では:語り手の選択の理由が地の文で読めるので、**理由と行動がずれている**(口では合理的な理由を言いながら、本当は別の理由で選んでいる)と、読者だけがそれに気づける。

## 原理8:最後に何かが変わっている

状況・関係・認識のどれかが、始まりと終わりで違っていること。全部が元に戻る話でも、語り手の認識だけは変わっている、という形がありうる。

一人称では:**語り手の声そのものが変化する**のが、一人称ならではの変化の見せ方。冒頭と結末で、語り手の語彙・リズム・他人の呼び方が少し変わっている。変化を地の文で宣言する(「私は変わった」)より強い。

## 原理9:感情の真実

読者が「わかる」と思うのは、平均的な感情ではなく、**具体的で少しずれた感情**に出会ったとき。

- 葬式で腹が鳴る。別れ話の最中に相手の歯に海苔がついているのが気になる。
- 大事な瞬間に、どうでもいいことを考えてしまう。
- 感情は遅れて来る。あとになって、関係ない場面で突然来る。

一人称では:語り手は自分の感情を誤解したり、名付け損なったりしてよい。**自分の感情を正確に分析できる語り手は、人間らしく見えない。**

## 原理10:緩急

緊張と弛緩、速い場面と遅い場面、長い文と短い文、笑いと痛み。同じ調子が続くと、どんなに上手い文でも読者は眠くなる。

- 緊張の山の直前に、小さな弛緩(笑い、日常)を置くと山が高く見える。
- 退屈な部分(移動、手続き)は飛ばす。「三日後。」の一行でいい。

## 面白くないときの診断表

| 症状 | 疑う原理 |
|---|---|
| 読者が先を気にしない | 原理1:開いている問いがない/問いがぼやけている |
| 主人公を応援できない | 原理2・7:欲求が曖昧/自分で選んでいない |
| 場面が平板 | 原理3:値が反転していない |
| 出来事が並んでいるだけ | 原理4:因果が切れている |
| 中だるみ | 原理5:余波(内省)が長すぎる/場面が同じ質の繰り返し |
| 印象に残らない | 原理6・9:具体性がない/感情が平均的 |
| 読後感が薄い | 原理8:何も変わっていない |
| 上手いのに眠い | 原理10:緩急がない |
