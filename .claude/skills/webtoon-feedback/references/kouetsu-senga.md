# 線画校閲チェックリスト

先に `kouetsu-common.md` を読むこと(校閲の定義・コメントの書き方・共通規定)。
出典: 「校閲の流れ」「U-NEXT線画校閲」(Drive: `1k4biOEO6bm9cJjl9ur-W3X7Ak5eBpy5O_UOqtUG4QOM`)、校閲レクチャー会メモ。

## 流れ

1. 全ページをざっと見て大きな間違いを探す(気になる箇所に印)
2. 各ページを精査
3. ネームと見比べて相違確認
4. 衣装確認(キャラごとに追う)

## 1. 左右・反転・瞬間移動(最頻出)

- [ ] 持ち物・人がコマ前後で瞬間移動(左右逆に)していないか
- [ ] 右手・左手が逆になっていないか(カップ・小物をどちらの手で持っているか把握してから見る)
- [ ] 鏡: 鏡内の像が正しく**反転している**か(髪の分け目・ほくろの位置・和服の左前・ベルトの向きは特に間違いやすい)
- [ ] カメラアングルが変わったコマで、物の配置(食卓のナイフとフォーク等)・人物の位置関係が矛盾していないか

## 2. 衣装・装飾(キャラごとに全ページを縦に追う)

- [ ] 前話から続く衣装は前話と一致しているか(装飾漏れ・意図しない変更)
- [ ] 衣装デザイン画があるものはデザイン画と照合
- [ ] 装飾の数(ボタン・チェーン等)を数えて一致確認
- [ ] コマごとの多少の揺れは許容。「他コマにあるのにこのコマだけ無い/ある」を拾う
- ※薄い色・見づらい衣装は画像を拡大したり、明るさを変えて確認する

## 3. 作画の破綻

- [ ] 線の途切れ(消しゴムの消し残り/マスク起因かの切り分けはclip要確認として記載)
- [ ] 背景との大きなズレ(イスに座っているはずが座れていない等)
- [ ] 小物のサイズ違和感(明らかに大きすぎる手紙など)→ ■申し送り

## 4. ネームとの相違

- [ ] 構図がネームと大きく違っていないか
- [ ] ネームにある必要な小物が描かれているか
- [ ] 指示書に表情などの記載があれば合っているか
- ※違いがあった場合、前後の流れがおかしくなっていないかも併せて確認

## 5. 原稿規定

- ネームほど細かく見なくてよいが、ページ抜け・命名規則・明らかなセリフ消失は確認(`kouetsu-common.md`参照)
