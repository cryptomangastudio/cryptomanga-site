## コマの流れ・演出

- [ ] 縦スクロール(または横読み)で読んだ時に視線・話の流れが自然か
- [ ] 場面転換がわかりやすいか
- [ ] ロングショット・寄りの使い分けが効いているか
- [ ] 見せ場のコマに十分なサイズ・タメがあるか

## 演技・キャラ

- [ ] 表情・ポーズがセリフと感情に合っているか
- [ ] キャラらしさを外れていないか(照れさせすぎ・乙女感が出すぎ等)
- [ ] 同ポーズが近いコマで連続していないか
- [ ] 視線: 誰が誰を見ているかが演出意図と合っているか

## フキダシ・セリフ

- [ ] 話者がわかるか(フキダシの位置・しっぽ)
- [ ] 同形状のフキダシ連続で紛れていないか
- [ ] セリフのテンポ(長ゼリフの分割余地)

## 構成

- [ ] シナリオ(構成案)の意図から大きく逸脱していないか(言い回しの調整はネーム担当の裁量)
- [ ] 引き(話の終わり)が次話を読みたくなる形か

## 規定

- [ ] ロゴ位置の指定があるか(該当話数)
- [ ] 冒頭の空き・クレジット等の作品規定
