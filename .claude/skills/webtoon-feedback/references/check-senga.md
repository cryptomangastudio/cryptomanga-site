# 線画チェック(監修FB)の観点

クオリティ面のフィードバック。間違い探し(左右反転・衣装揺れ等)は線画校閲(`kouetsu-senga.md`)の担当なので、
このモードでは演技・印象・画面の質を中心に見る。文体は `fb-style-guide.md` に従う。

## 表情・演技

- [ ] 表情がシーンの感情を伝えられているか(ネームより情報が増える分、印象のズレが出やすい)
- [ ] キャラらしさを外れていないか(例: クールなキャラに乙女感が出てしまう、照れさせすぎ)
- [ ] 前後のコマと比較して印象が変わって見えないか(例: 意図せず卑下した表情に見える)
- [ ] 悪役・強キャラなどの「らしさ」が線の段階で出ているか

## ポーズ・体

- [ ] 同ポーズが近いコマで連続していないか(片方の手を下ろす等の変化を提案)
- [ ] 体のバランス、手の描写の自然さ
- [ ] 視線: 誰が誰を見ているかが演出意図と合っているか

## 画面

- [ ] 構図がネームの意図(ロングショットの引き、寄りの迫力)を再現できているか
- [ ] 主役のキャラに視線が行く画面になっているか

## 申し送り

- [ ] 線画では直せない問題(ネーム起因の構図・背景起因)は修正依頼にせず申し送りへ
- [ ] ネームから意図的に変更した点への申し送りがあるか確認
