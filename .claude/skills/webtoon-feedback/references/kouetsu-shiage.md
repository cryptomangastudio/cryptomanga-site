# 仕上げ校閲チェックリスト

先に `kouetsu-common.md` を読むこと(校閲の定義・コメントの書き方・文字まわり規定)。
出典: 「校閲の流れ」「U-NEXT仕上げ校閲」(Drive: `1Fx8uhGw4yaLxTIxIcjbS4uQPWv-kJTIi2ojJJZ1nwzE`)、校閲レクチャー会メモ。

## 流れ

1. 全ページをざっと見て大きな間違いを探す(シームレス・マスク抜け・ルビ)
2. 各ページを精査(ネームと比較して描き文字漏れ確認)
3. 文字まわり確認

## 1. シームレス(最重要・事故多発ポイント)

- [ ] 次ページとの繋がり: 前ページの末尾と次ページの冒頭で背景・加工が急に変わっていないか
      (例: 前ページ黒背景で終わり→次ページ白背景で始まる)
- [ ] コマ枠のない絵やグラデーションが途中で急に途切れていないか(ページ内・ページまたぎ両方)
- [ ] ページまたぎの加工は**連結画像で継ぎ目の色ズレを確認**する(縦タイル分割された画像は隣接タイルを連続で見る。スポイト感覚では見逃す)

## 2. 加工・マスク

- [ ] 加工のとぎれ・ズレがないか(加工が絵からずれて見える箇所)
- [ ] マスク抜け: 手に持っている物(カップ・扇など)、手前にくる背景、手がぶつかる位置のオブジェクトがマスクされているか
- [ ] 背景・静物の濃度(%)が低すぎて白飛びして見えないか
- [ ] フキダシ下の加工: フキダシの下まで加工・塗りがあるか(ローカライズでフキダシ形状が変わるため。PDFでは怪しい箇所の指摘に留め、clip確認事項として記載)

## 3. 描き文字・漫符

- [ ] ネームと比較して描き文字が抜けていないか
- [ ] 漫符の抜けがないか
- [ ] 背景に埋もれて見づらい描き文字・漫符は白フチ追加を指摘

## 4. 文字まわり(kouetsu-common.md の規定で確認)

- [ ] フォント規定・表記(「事⇒こと」「方⇒ほう」は毎回出る)、誤字脱字・表記ゆれ
- [ ] 名前の各話初出時ルビ(抜けていれば前後も確認)
- [ ] ⁉・‼・ダブルダッシュの字形

## 5. 全体流し見

- [ ] セリフが表示されていないコマがないか(非表示のまま書き出された事故)
- [ ] 衣装の再確認(仕上げ工程で崩れていないか)
- [ ] 修正済みだったはずの箇所が巻き戻っていないか(前稿のFB・校閲と比較できる場合)
