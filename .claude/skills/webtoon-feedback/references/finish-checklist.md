# 仕上げ監修チェックリスト(WithLinks基準)

WithLinksの「仕上げ制作マニュアル」(Drive: `10b7Xn6ohL2rxT6xKt9dPepCejxMaaViX`)と、
過去の仕上げ/監修FBデータから抽出した観点。PDFの各ページをこの順で確認する。

## 1. 色味・カラー
- [ ] 彩度・明度はシーンの感情に合っているか(「もう少し彩度を上げて明るい印象に」系の指摘が頻出)
- [ ] スマホの高輝度液晶で見た時に目にチラつく色がないか(PCモニタではOKでもiPhoneでNGのケースあり)
- [ ] 使用する色・効果はキャラの心情に合っているか
- [ ] カラープロファイルは sRGB IEC61966-2.1 前提の色作りか
- [ ] キャラ同士の色が競合していないか(隣接コマ・同一画面内)

## 2. セリフ・フキダシ
- [ ] セリフ/フキダシの色はシーンの温度感に合っているか(例: 暖かいシーンは暖色系へ変更指示)
- [ ] フキダシの装飾は「フキダシの下まで」描かれているか(翻訳時に形状変更されるため必須)
- [ ] セリフやフキダシのコピーを加工レイヤーに結合していないか
- [ ] 同形状のフキダシが連続して話者がわかりにくくなっていないか(色変えで対応するのが仕上げの役割)

## 3. 影・陰影
- [ ] 人物・背景の影つけ(落ち影含む)は入っているか
- [ ] 陰影でキャラの性格・役割を演出できているか(例: 悪役はもう少し影を落として悪役感を)
- [ ] 光源の方向が背景と人物で矛盾していないか

## 4. 装飾・漫符・描き文字・エフェクト
- [ ] ネームの指示通りに装飾が入っているか
- [ ] 感情表現の漫符が必要な箇所に入っているか(例: 手で払いのける動きに漫符追加依頼)
- [ ] 状況に合わせたエフェクトが入っているか
- [ ] セリフのみのコマ・余白が多い箇所・場面転換に、縦スクロールを意識した演出が入っているか

## 5. 情報量・視線誘導
- [ ] 背景の情報量が多すぎてキャラから視線を奪っていないか(例: 床の反射+模様で情報過多→薄める/一部排除)
- [ ] 読者の視線がキャラ・セリフに自然に流れるか

## 6. 破綻・描画ミス
- [ ] オブジェクト同士が不自然に合体・貫通していないか(例: トマトが合体→ペンで加筆依頼)
- [ ] マスク処理(背景・素材・人物)の漏れ・はみ出しがないか
- [ ] 塗り残し・塗りはみ出しがないか

## 7. コマ間・余白
- [ ] コマ同士の間はしっかり空いているか(コマ間の最終調整は仕上げの業務)
- [ ] 縦スクロールで読んだ時のテンポが適切か

## 8. ロゴ(該当話数のみ)
- [ ] ロゴの入れ忘れがないか
- [ ] ネームで指定された位置にあるか
- [ ] 白い用紙の上に直張りか(グラデーション・背景の上に貼るのはNG)

## 9. レイヤー・データ規則(clipデータを確認できる場合)
- [ ] 「セリフ」「フキダシ」「コマ枠」「描き文字」「人物」「背景」がレイヤー分けされているか
- [ ] 血しぶき・流血など血液表現は別レイヤーか(海外展開時に非表示にするため必須)
- [ ] ファイル名は `作品名_仕上げ_話数_●稿` 規則か(アンダーバー・数字は半角、クリエイター名は入れない)

## 10. 他工程への申し送り
- [ ] 仕上げでは対応できない問題(線画起因・背景起因)は、修正依頼ではなく「申し送り」として区別して記載する
  (例: 「本の中身は線画さんなどでの対応箇所で問題ないでしょうか?(申し送り入れていただけますと助かります)」)
