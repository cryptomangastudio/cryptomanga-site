# 背景チェック(監修FB)の観点

出典: 背景制作マニュアル(Drive: `1N1zeX7-0UMgyRYJVqcA3JlKKapK9VvR-`)+過去の背景FB・監修データ。
文体は `fb-style-guide.md` に従う。

## 場所の伝達

- [ ] その場所だとひと目でわかるか(例: 診療所ならベッドが画面内にあるとわかりやすい→アングル移動を提案)
- [ ] 場面転換後の新しい場所が読者に伝わるか

## 空間・動線の整合性

- [ ] キャラの移動方向と背景の空間が矛盾していないか(玄関に向かっているように見える/屋敷の奥に進むべき等。前後のコマも併せて確認)
- [ ] パース・スケール感が人物と合っているか
- [ ] 光源の方向がシーン設定と合っているか

## 情報量・視線誘導

- [ ] 背景の情報量が多すぎてキャラから視線を奪っていないか(床の反射+模様など→薄める/一部排除を提案)
- [ ] 質感(ツルツル/マット)がシーンの意図と合っているか

## 小物・置物

- [ ] 小物の置かれ方が自然か(積まれた物は量・高さ・崩れ感で生活感を出す)
- [ ] 作中で意味を持つ小物がきちんと描かれているか

## 申し送り

- [ ] 背景では直せない箇所(本の中身など線画側の対応物)は申し送りとして明示されているか確認・指摘
