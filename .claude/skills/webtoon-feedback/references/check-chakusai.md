# 着彩チェック(監修FB)の観点

出典: 着彩制作マニュアル(Drive: `1bj1qIeldywTmX7QLhEsrjK4jugYnlcrr` / 2025-07-09更新)
+ 着彩監修・FBデータ(理想陛下・時戻り・魔界聖女の人物着彩_監修フォルダ群)。
文体は `fb-style-guide.md` に従う。

## 着彩作家の担当範囲(ここ以外は指摘しない)

**範囲**: 人物 / 小物 / 描き文字 / フキダシ・描き文字に隠れた部分 / コマの繋ぎ部分

- 背景そのものの描き込み、線画の狂いは着彩の担当外 → 見つけたら申し送りへ
- **大ゴマは特に丁寧に、つなぎの小さいコマは簡略化してよい**というのが前提。
  小さいコマの簡略化を「手抜き」として指摘しないこと

## 1. 塗りのきれいさ(最頻出・最優先)

- [ ] 拡大したときに塗りの穴が空いていないか(下塗りがバケツ任せになっていると出る)
- [ ] 塗りのはみだしがないか
- [ ] **線の下が塗られているか**。線の下が空いていると微妙な隙間ができて粗く見える
      (線の透明度を下げて全体に塗り分けるのが推奨手順)

## 2. 色

- [ ] キャラクターデザインの指定色と一致しているか(**HEX指定があればそれが優先**、なければスポイト)
- [ ] 前のページ・前のコマと色が揺れていないか
- [ ] 実物をイメージしたときに違和感のある色・奇抜すぎる色になっていないか
- [ ] スマホの高輝度液晶で見た時に目にチラつく彩度になっていないか
      (PCモニタではOKでも、鮮やかな緑や高彩度色は要注意)
- ※キャラデザで指定のない部分は着彩作家の裁量。指定がないことを理由に指摘しない

## 3. 塗り分け

- [ ] 色味の異なるパーツの塗り分けが不十分な箇所はないか
- [ ] 単色塗り・グラデのみの手抜きに見える着色になっていないか
- [ ] モブをグラデのみで済ませていないか
      ※例外: シルエット線画のみのモブ、演出として適している場合はOK

## 4. 光源・陰影

- [ ] 光源を意識した塗りになっているか。光の向きが画面内で矛盾していないか
- [ ] 影の落ち方が不自然でないか
- ※**演出的な逆光は仕上げ工程で足すこともある**ため、無い場合でも強く指摘しない

## 5. 塗りのタッチ

- [ ] キャラクターデザイン・共有資料・参考作品の作風とクオリティに合っているか
      (着彩作家個人の塗り方ではなく、その作品の作風に合わせるのが原則)

## 6. マスク処理

- [ ] 背景と照らし合わせたマスク処理ができているか
- [ ] **フキダシ・描き文字に隠れた部分まで塗られているか**(隠れた部分の塗り漏れは頻出)

## クリスタ上で要確認(PDFからは判定できない)

- カラープロファイルが `sRGB IEC61966-2.1` になっているか
- レイヤー構成(肌・髪・その他顔パーツのレイヤー順が規定どおりか)
- 一枚のレイヤーで全体を塗りクリッピングで分ける方式になっていないか(マニュアル上NG)
- レイヤーカラー・サブカラーの指定とレイヤー名
- 色味の異なるパーツのレイヤー分け
- ファイル名の命名規則(`作品名_人物着彩_話数_◯稿`)・cmc形式での提出

## 注意

着彩に**校閲モードは存在しない**(校閲が入るのはネーム・線画・仕上げの3工程のみ)。
着彩は常に監修FB(■修正依頼/■相談/■参考)として扱う。
