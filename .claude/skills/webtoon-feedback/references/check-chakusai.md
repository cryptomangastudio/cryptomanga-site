# 着彩チェック(監修FB)の観点

出典: 着彩FBデータ(例: 時戻り_キービジュアル1_着彩仕上げ_クリエイター様FB
Drive: `16wHYJqFUVokSWJTHLqLH9R_P37zHjSzCQDyk9b9zxsI`)+仕上げFBの色関連指摘。
※着彩専用の蓄積データはまだ少ないため、運用しながらこのリストを拡充すること。
文体は `fb-style-guide.md` に従う。

## ベースカラーの正確性

- [ ] キャラの髪・瞳・肌・衣装の色がキャラ設定(トンマナシート・カラーデザイン)と一致しているか
- [ ] 前話・前コマと色が揺れていないか

## 塗りの品質

- [ ] 塗り残し・はみ出しがないか
- [ ] 塗り分け(パーツ境界)が正しいか(隣接パーツの色混ざり)

## 色設計

- [ ] 彩度・明度がシーンの感情に合っているか
- [ ] キャラ同士・キャラと背景の色が競合していないか(隣接コマ・同一画面内)
- [ ] キャラのイメージと色調が合っているか(例: 高貴な男性=紺で締める、変えるなら微調整程度)
- [ ] **スマホの高輝度液晶(iPhone等)で見た時に目にチラつく色がないか**(PCモニタではOKでもNGのケースあり。鮮やかな緑・高彩度色は特に注意)

## 検討の出し方

- 色調変更を提案する場合は「どのキャラ/箇所を」「どの方向に」(例: パープル/ピンク/ホワイト×ゴールド等の案出し)を具体的に
- 大きく変えるべきものと微調整で済むものを区別して書く
