# 男性にも読める女性向け作品の設計

中川様の方針（2026-09-27）：
「女性向けの企画ではあるけれど、男性が読んでも面白い作品を作りたい。恋愛要素だけでなく、バトル要素があったり。バトルといっても本当に戦うことじゃなくてよくて、ミステリーが入ったりとか」

作品の実データは `data/works.csv`、市場の数字は `data/market-snapshot.md` にある。
**この文書の原則は、そこに載っている事実から導いたものに限る。** 根拠の強さを各項に書いてある。

---

## なぜこの方針が当社のルートに合うか

| 場所 | 読者 |
|---|---|
| カクヨム（数字を作る場所） | **男性66.4%／女性33.6%** |
| めちゃコミック（売り先） | 女性約8割 |
| ピッコマ（売り先） | 男女ほぼ半々、35〜49歳女性が最多 |

女性だけに向けた作品は、カクヨムでは3割の読者を奪い合う。男性にも読める作品なら、カクヨムの残り7割にも届く。そのうえで売り先では女性が買う。
**男女両方に読めることは、当社のルートを最短にする条件である。**

### 狙う比率は「女7：男3」

『薬屋のひとりごと』のアニメのファン層は**女性7：男性3**（日経エンタ）。これが男女両読の最大の成功例の実際の比率である。
**半々を狙わない。** 女性が主客であることを崩すと、めちゃコミやピッコマで弱くなる。男性は「読める」「面白い」で足りる。

---

## 「バトル」の7つの型

戦わなくてよい。**毎話、勝ち負けが決まる単位**があればよい。

| 型 | 毎話の勝ち負け | 実例（`works.csv`） |
|---|---|---|
| 1. 謎解き | 事件が解ける／解けない | 薬屋、後宮の烏、後宮の検屍女官、ミステリと言う勿れ |
| 2. 頭脳戦 | 駆け引きに勝つ／読み負ける | かぐや様、ティアムーン、茉莉花官吏伝 |
| 3. 勝負 | 試合・試験に勝つ | ちはやふる、茉莉花官吏伝（登用試験） |
| 4. 職能 | 作れた／治せた／売れた | 魔導具師ダリヤ、聖女の魔力は万能です、外科医エリーゼ、本好き |
| 5. 物理 | 殴った／守れた | 最後にひとつだけ、わたしの幸せな結婚、ホタルの嫁入り |
| 6. 潜入・偽装 | 正体を守れた／ばれかけた | SPY×FAMILY、ホタルの嫁入り（契約結婚） |
| 7. 経営・成り上がり | 地位・資産が増えた | 本好き、ティアムーン |

**型は2つまで組み合わせてよい。** 3つ以上は焦点がぼける。
例：薬屋＝謎解き＋職能。ホタルの嫁入り＝物理＋偽装。

## 原則

### 原則1　ヒロインの視線は「謎・仕事・勝負」に向け、恋はヒーローの側から来させる

**根拠：強い**
- 薬屋：猫猫は恋愛感情がほぼゼロで、壬氏を「毛虫を見るような目」で見る。恋は壬氏の側からの一方通行。この構図が「男性にも読みやすい」理由として繰り返し挙げられている
- 茉莉花官吏伝：ヒロインの視線は試験と政務。皇帝が見初める側
- ふつつか：恋愛は後ろに置き、ヒロインは逆境の突破に集中する

男性読者はヒロインの恋心に視点を預けなくて済む。女性読者はヒーローの執着を外から眺めて楽しめる。
**これは社内の「ヒーローの内面を地の文に書かない」（情報の非対称）とそのまま両立する。** 追加の設定は要らない。

### 原則2　毎話ひとつ、勝ち負けが決まる単位を置く

**根拠：強い**
- 薬屋は1話で1つの毒・1つの事件が片付く
- ちはやふるは1試合ごとに勝敗が出る
- ダリヤは1話で1つの魔導具ができる

男性読者は1話単位の決着で満足する。恋愛だけの回は、決着がないまま終わりやすい。

### 原則3　恋愛主軸のままでは、掲載場所を男性向けにしても男性は来ない

**根拠：強い（反例）**
- 『来世は他人がいい』はアフタヌーン（男性誌）連載で極道の抗争もあるが、アニメの視聴は女性（F1〜F3）に寄り、男性は低い（REGZA 67万サンプル）
- 『わたしの幸せな結婚』は異能バトルがあるが、恋愛主軸で女性寄り

**男性読者を呼ぶのは掲載場所でも戦闘シーンの有無でもなく、物語の主軸が恋愛以外にあるかどうかである。**

### 原則4　謎解きを主軸にした版のほうが売れた例がある

**根拠：中（他の要因を除けない）**
『薬屋』のコミカライズは2系統ある。
- 恋愛寄りの構成：ビッグガンガン版 850万部（2023年6月）
- **謎解き主軸の構成：サンデーGX版 1,770万部（2024年9月）**

時点がずれており、絵・版元・配信の差もあるので、軸だけが原因とは言えない。ただし「謎解きを前に出しても女性読者は逃げなかった」ことは確かである。

### 原則5　ヒロインの武器は、チートより専門知識にする

**根拠：中**
- 薬屋は「謎解き」と「お仕事論」でビジネスパーソンにも刺さったと分析されている
- ダリヤ（魔導具）、聖女（ポーション）、エリーゼ（外科）、茉莉花（記憶力と政務）はいずれも専門性で勝つ
- 男性向けレーベル（MFブックス、ヒーロー文庫、TOブックス）が女性主人公のお仕事ものを出している

専門知識の開陳は、男性読者にとって恋愛描写の代わりになる読みどころである。
**ただし知識は作中で必ず「事件を解く」「人を救う」に使う。** 知識の説明だけの段落は、女性読者を逃がす。

### 原則6　恋愛と謎・勝負は、同じ出来事で同時に進める

**根拠：仮説（実例からの推論）**
恋愛回と事件回を分けると、男性読者は恋愛回で、女性読者は事件回で離脱する。
- 薬屋：壬氏が猫猫に事件を持ち込む → 事件を解く過程で二人の距離が動く
- かぐや様：告白させる駆け引きそのものが頭脳戦

**1つの出来事が、謎（または勝負）と恋愛の両方を1歩ずつ進めるように組む。**
接点（社内D軸）を「ヒーローが事件・依頼を持ち込む」にすると、自然にこうなる。

### 原則7　疑似家族と子どもは、男女どちらにも効く

**根拠：中**
- SPY×FAMILY は単行本購入が男女ほぼ同数という調査がある
- 社内のロマファン6分類で在庫ゼロの①（幼女×家族愛）と⑥（ママです）に当たる

ただし『SPY×FAMILY』の型（偽装家族×各自の秘密）をそのまま使うと既視感が強い。**子どもが持つ「秘密」の中身を変える**必要がある。

## 補助軸F：男女両読

社内のA〜E（20点満点）は変えない。**Fは別枠で0〜4点をつけ、合計には入れずに併記する。**
社内の基準を当社が勝手に書き換えないためである。

| 点 | 条件 |
|---|---|
| 0 | 恋愛以外の軸がない |
| 1 | 軸はあるが背景にとどまる（職業の設定があるだけ） |
| 2 | 軸が毎話動くが、恋愛とは別の出来事として走る |
| 3 | 軸が毎話勝ち負けを持ち、恋愛と同じ出来事で進む（原則2・6） |
| 4 | 3に加えて、ヒロインの視線が恋でなく軸に向き、恋はヒーロー側から来る（原則1、薬屋型） |

**F＝4の企画を最優先にする。** A〜Eが同点なら、Fで順位を決める。

### Fを採点するときの確認

- [ ] 第1話の最後に、恋愛以外の決着（または決着の予告）があるか
- [ ] 30話のうち、恋愛以外の勝ち負けがない回が5話を超えていないか
- [ ] ヒロインの一人称の地の文で、恋心の独白が1話に3段落を超えていないか
- [ ] ヒーローが事件・依頼・勝負を「持ち込む」側になっているか

## やってはいけないこと

1. **男性向けに寄せすぎて、女性の主客を崩す。** 狙いは女7：男3
2. **戦闘シーンを足せば男性が来ると考える。** 原則3の反例がある
3. **専門知識の説明を、事件と切り離して書く。** 教科書になる
4. **恋愛回と事件回を交互に並べる。** 両方の読者が交互に離脱する
5. **男性キャラクターの内面を地の文に書いて、男性読者に寄せる。** 社内の情報の非対称が崩れる
6. **男性読者を意識して、恋の場面そのものを減らす。**（2026-09-28 の失敗）
   「ヒロインが恋に鈍い」と「恋の場面が少ない」は別物である。『薬屋』でも壬氏の執着は毎話はっきり描かれる。
   **ヒロインの視線を謎に向けるなら、そのぶんヒーローの執着を行動で毎話見せる。** 恋を出来事で書き、ヒロインの独白で書かない
