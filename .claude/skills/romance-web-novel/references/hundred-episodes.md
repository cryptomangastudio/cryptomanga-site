# 100話の長編にするときの作り方（2026-10-02、『錠前』で作った手順）

中川様の指示「100話にして」で作った。30話で完結する物語を、3倍に引き延ばさず、**三部構成にして、第二部と第三部を足した。** 引き延ばすと、中盤の錠（事件）の回が増えるだけになり、読者が飽きる。

## 三部構成の作り方

| 部 | 縦の謎 | 錠（作品の核になる装置）の意味 |
|---|---|---|
| 第一部（1〜30話） | 元の企画の縦の謎 | 元の意味（例：開けると誤解がほどける） |
| 第二部（31〜65話） | **第一部の解決が生んだ新しい問い**（例：返した思い出が、脅迫の材料にされる） | **意味を反転させる**（例：開けたものが刃になる） |
| 第三部（66〜100話） | **主人公の名や、父の仕事に関わる問い** | **意味を完成させる**（例：開けて人を救う） |

- 第一部の最後で、**完結に見せない。** 第二部の火種（消えた証拠、噂）を、第一部の最後か、巻の区切りに入れる
- **三部を貫く主題を1つ決める**（例：「名」）。部ごとに、主題の別の面を回収する
- 第二部の黒幕は、**第一部で味方として出した人物**が効く（第一部の一言が、後から意味を持つ）

## 作るときの決まり

1. **100話を、一覧表と曲線の図にする。** 図は、パートごとの一行見出し／感情の山谷／タグ（謎・恋・情・名・敵）の帯。`event-map.md` と同じ読み方。**同じ高さが3話続かない**ことを、プログラムで確かめる
2. **巻割りの案を出す。** 約10話ごとに1巻。**巻末は、引きで切る**（第一部の完結に見える所で切らず、第二部の火種まで入れる）
3. **型崩しを、約10話ごとに入れる**（失敗回、倒叙・幕間、錠で解く訪問回、恋愛比重の高い回、大型回）
4. **恋の場面が、10話以上空かない。** 第二部は、敵退治に寄りやすい
5. **毎話の錠で解く回が、全体の2〜3割以上あること。** 縦の謎が、人間関係の推理だけにならない
6. **ヒーローが、第二部・第三部でも、自分で動く場面を持つ。** 受け身になりやすい
7. **歴史上の大事件（震災など）を使うときは、主人公の「めでたし」のために使わない。** 死は描かず、救助に焦点を当て、全員無事にはしない。結婚などの幸福は、事件の後にずらす。時刻・地名は、調べてから書く

## 点検の手順（独立した査読者5名）

1. **整合性の査読者**：第一部との矛盾、時間の流れ、誰が何を知っているか
2. **女性向け恋愛作品の読者役**：中だるみ、恋の空白、ヒーローの魅力、結末で泣けるか
3. **ミステリー好きの男性読者役**：謎の質、犯人が読めるか、錠の回が足りているか
4. **コミカライズ担当の編集者役**：連載として続くか、巻割り、映える場面
5. **先読み役**：第30話までだけ読ませて、第31話以降を予想させる（`subvert-expectations.md`）

## 2026-09〜10月の実例で見つかった教訓

1. **敵の受益者が分かると、黒幕が早く読まれる。** 要求の中身は、受益者を指さないようにする（身代わりを立てる）。「誰が得をするか」を、読者が自分で解く謎にする（今回は、票を持つ家＝脅された四軒）
2. **謎の種は、答えまで書く。** 「四軒だけ」と書いて、答えを出さないと、一番良い種が死ぬ
3. **敵の罪を、増やさない。** 第一部で情を回収した敵に、第三部で新しい罪を足すと、情が消耗する。別の悪役を立てる
4. **「見せる」倒叙は、読者がすでに知っていることを見せても効かない。** 顔を見せない、中身と理由を隠す、などで、幕間に「分からない部分」を残す
5. **100話の設計は、足すより単純にする。** 5名の査読で、直し方の多くは「削る」「固定する」「呼称を揃える」だった
