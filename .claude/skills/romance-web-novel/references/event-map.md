## 書き方（中川様が示した形式）

**出来事の見出し（位置）**と、その**次の行に、具体的な一場面**を書く。2行で1出来事。

中川様が示した例：

```
・ヒーローと契約
◯◯◯◯◯◯◯◯◯◯◯◯◯◯◯◯

・ヒール役が◯◯を仕掛けてくる
◯◯◯◯◯◯◯◯◯◯◯◯◯◯◯◯

・偽装婚約を始める（中盤）
恋人らしく見せる練習で「愛している、と言ってくれ」と頼まれる

・ヒールの悪事を暴く
◯◯◯◯◯◯◯◯◯◯◯◯◯◯◯◯

・真実を知り結婚
◯◯◯◯◯◯◯◯◯◯◯◯◯◯◯◯
```

### 守ること

1. **1行目は、出来事を短く言い切る。** 「関係が深まる」のような状態ではなく、「偽装婚約を始める」のような出来事にする
2. **2行目は、誰が何を言う・する・持つかで書く。** 台詞、行動、小道具のどれかが入っていること。「絆が深まる」「距離が縮まる」のような抽象語で終わらせない
3. **位置は（序盤）（中盤）（終盤）で書く。** 話数は書かない
4. **2行目の台詞と小道具は案である**と、末尾に注記する
5. 恋の出来事は、**ヒーローが先に動く形**で書く（`crossover.md`）

## 一覧表（図の感情曲線とタグの列に当たるもの）

出来事の一覧の後に、次の表を付ける。

| 列 | 書くこと |
|---|---|
| 番号・位置 | 出来事の番号と序盤／中盤／終盤 |
| 感情 | ＋＋（最高）／＋／±／−／−−（最低）の5段階 |
| タグ | 作品ごとに決めた3〜6個。出す場所と回収する場所の両方を書く |

## 出す前に確かめる

1. 2行目は、すべて具体的か（誰が何を言う・する・持つか）
2. あらすじ・企画書の設計表と矛盾していないか。**新しく足した設定がないか**（あれば「案」と注記する）
3. **山と谷が交互に来ているか。** 同じ高さが3つ続いていないか
4. **最高点の直後に、落差（谷）があるか**
5. タグごとに、**出す場所と回収する場所**があるか。間隔が空きすぎていないか
6. 中盤に、型を崩す大きな出来事（複数話にまたがるもの）があるか
7. 終盤（決着）が、1出来事に詰め込まれていないか。**開く・真実・対峙・ざまぁ・結び**を別々の出来事にする
8. 恋の出来事が、序盤・中盤・終盤にそれぞれあるか
