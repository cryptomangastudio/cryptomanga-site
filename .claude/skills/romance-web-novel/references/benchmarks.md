# ベンチマーク

**状態：2026-09-27 確定（中川様承認「オッケー」）。メイン『薬屋のひとりごと』、サブ『わたしの幸せな結婚』。棚は大正・和風。**
ベンチマークを決めるのは中川様であって、こちらではない。こちらは基準を示して候補を絞る。

企画立案の前にベンチマークを固める（中川様の指示、2026-09-27）。
ベンチマークが揺れると、企画ごとに物差しが変わり、採点が比べられなくなるため。

---

## 絞る基準

1. **同じルートを通った作品である。** WEB小説発 → 書籍 → コミカライズ。当社のルート（カクヨム → コミカライズ）の実証になる
2. **最新の数字がある。** 部数・順位・映像化の時点が分かる
3. **当社の方針に合う。** 女性が主客で、恋愛以外の軸がある（`crossover.md` の補助軸F）
4. **借りるものを1文で言える。** 「構造」「棚」「情緒」のどれを借りるかが明確
5. **2作で役割が重ならない。** 同じものを借りる2作は、片方でよい

**数は2作に絞る。** 3作以上になると、どれに合わせるかで企画が迷う。

## 確定：メイン1作・サブ1作

### メイン（構造を借りる）：『薬屋のひとりごと』

| 基準 | 結果 |
|---|---|
| ルート | なろう → ヒーロー文庫 → コミカライズ2系統（どちらも青年誌）→ アニメ・劇場版 |
| 数字 | 全世界5,700万部（2026年8月）。ebookjapan少女・女性1位3年連続、BOOK☆WALKER同部門4連覇 |
| 方針 | ファン男女比 女7：男3。男女両読の最大の実例 |

**借りるもの（物語の骨格）**
1. **ヒロインは恋に無関心で、恋はヒーローの側から来る。** 男性読者は恋に視点を預けずに済み、女性読者はヒーローの執着を外から楽しめる
2. **1つの話で1つの事件を、ヒロインの専門知識で解く。** 毎話に決着がある
3. **無関係に見えた事件が、実は1本の陰謀に繋がっていた。** 後宮編では、食糧庫のボヤ・官僚の食中毒・彫金細工師の遺言が、壬氏の暗殺計画の準備だったと分かる。横の事件が縦の謎に合流する
4. **身分の低い場所の技能を、上の身分の男が必要とする。** 薬屋の娘の知識に、宮廷の実力者が頼る。接点が職務で説明できる

**借りないもの**
中華後宮、毒と薬の知識、宦官の設定。ここを借りると「二番煎じ」と言われる。

### サブ（棚と情緒を借りる）：『わたしの幸せな結婚』

| 基準 | 結果 |
|---|---|
| ルート | なろう → 富士見L文庫 → ガンガンONLINEでコミカライズ → アニメ2期・実写映画 |
| 数字 | 1,000万部（2026年5月、コミック・電子含む）。特別篇アニメが2026年10月25日放送 |
| 方針 | 女性が主客。異能バトルはあるが恋愛が主軸で、男性読者の根拠は弱い（ここは薬屋で補う） |

**借りるもの（読者が買う理由）**
1. **明治・大正を思わせる帝都と、華族の家。** 社内に在庫がなく、めちゃコミ×LScomicのコンテストの部門に「大正ロマンス」が明示されている棚
2. **虐げられてきた娘が、初めて一人の男に大事にされる。** 女性読者が買う感情の核。薬屋はここが乾いているので、サブで足す
3. **ヒロインの自己評価の低さが、少しずつ上がっていく。** 巻をまたぐ成長の線

**借りないもの**
異能（当社は職能で戦う）、「冷酷と噂の軍人」という看板、婚約から始まる導入。そのまま借りると衝突する。

### 2作を合わせた一行

> **『薬屋』の骨格（謎を解く・恋はヒーローから・横の事件が縦に合流）を、『わたしの幸せな結婚』の棚と情緒（大正の帝都・虐げられた娘が初めて大事にされる）に載せる。**

### メイン：『ふつつかな悪女ではございますが ～雛宮蝶鼠とりかえ伝～』

中村颯希・著／ゆき哉・イラスト。一迅社ノベルス。コミカライズは尾羊英。2026年7月からテレビアニメ放送。
中川様からピッコマのURLで指定された。

**話の骨格**
黄家の雛女・玲琳は、宮中一の嫌われ者である朱家の雛女・慧月に体を入れ替えられ、牢に入れられる。
入れ替わりは話せない。己を害した罪に問われ、死を目前にする。
ところが玲琳は病弱で、ずっと死と隣り合わせで生きてきた。**健康な体を手に入れたことを喜んでしまう。**

### 取るもの（3つ）

1. **逆境が、本人にはご褒美になっている。**
   周りが同情するほど本人は嬉しい。このズレが笑いと引きを同時に作る。
   → 本作では「壊れる役目に売られたのに、鈴は食べられて幸せ」がこれに当たる。

2. **鋼のメンタルのヒロイン。**
   泣かない、恨まない、へこたれない。読者は守りたくなるのではなく、応援したくなる。
   → 鈴は自分を不幸だと思っていない。読者だけが不幸だと知っている。

3. **恋愛を主軸に置かない。**
   主軸は役目の場での勝ち上がり。恋愛は薄く、長く、後ろに置く。
   → 中川様の指摘：「ベンチマークはあまり恋愛について重きを置いていない」。ここは崩さない。

### 取らないもの

中華後宮、入れ替わり、雛女選び。**中華は競合が厚すぎる**ため和風に振ると決めた（中川様の判断）。

### サブ：『鬼の花嫁』

クレハ・著／白谷ゆう・イラスト。スターツ出版文庫、2020年10月刊行開始。
2025年6月時点でシリーズ累計580万部。コミカライズあり。中川様から指定された。

**話の骨格**
人間とあやかしが共生する日本。あやかしの花嫁に選ばれることは名誉とされる。
平凡な高校生・柚子は、妖狐の花嫁になった妹と比べられ、家族にないがしろにされて育った。
あやかしの頂点に立つ鬼・鬼龍院玲夜に見初められ、全身全霊の愛を注がれる。柚子は家族から逃れ、居場所を見つける。

### 取るもの（3つ）

1. **人ならざる強大な存在が、ただ一人の娘を選び、全身全霊で愛する。**
   → 千年消えかけている山の神が、鈴にだけ毎晩「何が食べたい」と聞く。

2. **家族が居場所を奪っている。逃れて新しい居場所を得る話である。**
   → 本作では血縁ではなく「娘を買い続けてきた家」が同じ位置に立つ。

3. **「選ばれることは名誉」という社会通念そのものが、ヒロインを縛る。**
   → 村は、娘が供物を食べる役目を名誉だと思っている。誰も悪意がない。これが逃げ道をふさぐ。

### 取らないもの

現代の学園、あやかし財閥、一目惚れの出会い。

### 社内ベンチマーク：『ミス・ペンドルトンの恋』

実コメント26,838件の分析は `house-rubric.md` にある。本作に効くのは一点だけ。

**「悪役が悪役らしくない」が×5.97倍。身近な人物に本物の悪人を置かない。**
→ ヘイト役のとめは演技をしていない。本気で鈴を憐れみ、本気でおいしいものを食べさせたい。
→ 本物の悪役（娘を買い続けてきた家の側）は終盤にだけ出す。

### 回避対象：『生贄乙女の婚礼 龍神様に食べられたいのに愛されています。』

唐澤和希。カクヨム発 → 富士見L文庫 → フロースコミックでコミカライズ済み。

和風・神がヒーロー・娘が捧げられる・食べる／食べられる・毒、の5点が重なる。
中身は違っても、**企画書の1枚目とログライン1行がほぼ同じ絵になる。**

### 守ること

- **タイトルとキャッチに「毒見」「生贄」「食べられる」を出さない**
- 「娘が食べる」側に立てる。「娘が食べられる」側には立てない
- 婚礼・花嫁を看板にしない
