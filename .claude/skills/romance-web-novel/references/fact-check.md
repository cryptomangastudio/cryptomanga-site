# 事実確認の手順

作品の中で「実際にそうである」ものとして書くことは、書く前に調べる。
調べずに書いたものは、編集者や読者に一度見抜かれると、作品全体の信頼が落ちる。社内の企画シートにも「LINE様提案の場で指摘されると企画全体の信頼を落とすリスクがある」という記述がある。

## 調べる対象

次のものを作品に書くときは、書く前に調べる。例外はない。

| 種類 | 例 | 何を確認するか |
|---|---|---|
| 歴史上の制度・役職 | 毒味役、鬼取役、女中、書生、華族、爵位 | 実在したか。呼称、設置時期、人数、実際の作法 |
| 法律 | 家督相続、認知、庶子と私生児、婚姻、借財 | 当時の法律での扱い。現代の法律と混同しない |
| 医学・症状 | 中毒、失明、失声、記憶喪失、手の震え | その症状が実際に起きるか。起きない症状を書かない |
| 物質・道具 | 毒物、薬、機械、通信手段 | 当時入手できたか。名称と成分 |
| 時代の出来事 | 事件、流行病、災害、物価、月給 | 年と内容。前後関係 |
| 数量 | 金額、日数、人数、距離、摂取量 | 計算が合うか（→ `logic-audit.md` と併せて） |

## 手順

1. **書く前に、その記述が「事実」か「創作」かを自分で区別する。**
   区別できない状態で書き始めてはいけない。
2. **事実として書くなら、検索して一次情報に近いものを当たる。**
   Wikipedia、国立国会図書館のレファレンス協同データベース、官公庁のページ、学術的な解説を優先する。個人ブログは裏取りに使う程度にとどめる。
3. **調べた結果を、企画書または原稿の脚注に残す。** 出典のURLを書く。あとで編集者に聞かれる。
4. **調べて「記録がない」と分かったものは、創作として扱う。**
   そのうえで、作中では「この家だけが残している習わし」のように、例外であることを示す形にする。
5. **調べても分からなかったものは「要確認」と明記して出す。** 分からないまま断定してはいけない。

## 過去の失敗

### 2026年9月：史実を確認せずに設定の中心に置いた

「毒味役は三年で舌を失う」と書き、それを前提にタイトル・キャッチ・あらすじまで作った。
実際に調べた結果は次のとおりで、「任期で舌が死ぬ」という記録はなかった。

- 慶長19年（1614年）、大坂の役の折に茶臼山で伊達政宗が進言し、徳川家康が設置した
- 寛永・寛文年間までは「鬼取役」と呼ばれた。「毒見役」「膳奉行」「御膳奉行」は同じ役職で、将軍が食事をとる場所によって名称が違った
- 人数は時期により3〜5人。御膳所には料理番を含めて130人程度いた
- 1回の食事につき3〜4人が順に毒味し、しばらく待って異常がないか互いに確認した
- その結果、将軍は一生冷や飯を食べていた

出典: [膳奉行 - Wikipedia](https://ja.wikipedia.org/wiki/膳奉行) / [レファレンス協同データベース](https://crd.ndl.go.jp/reference/detail?page=ref_view&id=1000258685) / [Japaaan](https://mag.japaaan.com/archives/117038)

**教訓**：設定の中心に置く事実は、最初に調べる。あとから調べると、企画全体を作り直すことになる。

### 2026年9月：症状を確認せずに「味覚を失う」と書いた

慢性砒素中毒で味覚を失うと書いたが、調べた症状は次のとおりで、味覚障害は確認できなかった。

- 皮膚の色素沈着、白斑、角化
- 末梢神経障害（神経痛に似た疼痛、しびれ）
- 手足の感覚異常、頭痛、吐き気、筋力低下、貧血
- 肝障害、呼吸器障害、皮膚がん・肺がん

出典: [メディカルドック](https://medicaldoc.jp/cyclopedia/disease/d_other/di2122/) / [EICネット](https://www.eic.or.jp/ecoterm/?act=view&serial=2495) / [厚生労働省の資料](https://www.mhlw.go.jp/shingi/2008/06/dl/s0603-6g.pdf)

**教訓**：症状を変えると、むしろ良くなることがある。「手の感覚と爪の色」に変えた結果、絵になるモチーフになり、触れる描写の理由にもなった。事実に合わせることは制約ではなく、素材が増えること。

### 石見銀山ねずみ取り（猫いらず）
江戸時代、石見国笹ヶ谷銅山で銅とともに採掘された硫砒鉄鉱を焼成して作った殺鼠剤。主成分は亜砒酸。「石見銀山」「猫いらず」とも呼ばれた。明治以降も笹ヶ谷鉱山で亜ヒ酸の生産が断続的に続いた。
**毎日少量ずつ飲ませると、原因が分からないまま弱って死んでいくので「密室の殺人」に向く**と言われた。落語・歌舞伎・怪談にも登場するほど、江戸から大正期にかけて広く知られた毒薬。
出典: [石見銀山ねずみ捕り - Wikipedia](https://ja.wikipedia.org/wiki/石見銀山ねずみ捕り) / [アジア砒素ネットワーク](https://www.asia-arsenic.jp/pollution/health-damage)

### 脚気（大正期に慢性砒素中毒と混同しうる病）
ビタミンB1の欠乏で起きる。末梢神経が障害され、**手足のしびれ・痛み、感覚の低下、筋力低下**が現れる。神経と筋肉に異常が出る「乾性脚気」と、心血管系に影響する「湿性脚気」がある。
症状が慢性砒素中毒と酷似するため、**誤診の理由として使える**。
出典: [大正製薬 大正健康ナビ](https://www.taisho-kenko.com/disease/662/) / [MEDLEY](https://medley.life/diseases/54f919706ef458c93885cdb7/)

### 明治民法の家督相続順位
親等が同じ場合、**①嫡出子（嫡妻の子）②庶子（父が認知した子）③私生児（認知されない子）**の順。女であっても嫡出子・庶子が私生児より優先された。
認知の方法は、生前の任意認知、調停・審判による強制認知、遺言認知の3つ（遺言認知は遺言執行者が就職の日から10日以内に届出）。
**ただし遺言認知が明治民法下で同じ形で存在したかは未確認。** 作中で使う場合は要確認。
出典: [明治民法](https://law-platform.jp/acts/129089d) / [旧民法における養子縁組・継親子・嫡母庶子](https://www.daigo-shihousyoshi.com/2019/02/18/旧民法における養子縁組-継親子-嫡母庶子/)

### スペイン風邪（日本）
1918年（大正7年）8月下旬に流行が始まり、11月に全国的な大流行となった。
第2波は1919年9月〜1920年7月で、患者241万2千人、死者12万8千人（致死率5.3%）。1921年7月までの3年間で人口の約半数（2,380万人）が罹患し、38万8,727人が死亡した。首相の原敬も大正7年10月に罹患している。
**大正期に登場人物を病死させる理由として使える。**
出典: [内閣感染症危機管理統括庁](https://www.caicm.go.jp/houdou/article/feature/backnumber/kako_02.html) / [総務省統計研究研修所](https://www.stat.go.jp/library/pdf/minitopics30.pdf)

### 砒素の検出
マーシュ試験は1836年に確立している。大正期には砒素の検出が可能。
→ **「疑えば分かるのに、誰も疑わない」状態を作るには、別の理由（誤診など）が必要。**
