# カクヨムのルビ記法（コピペ用の版を作るとき）

2026-10-05、中川様の指示「読みにくい漢字は、カクヨムのルールを調べて、コピペできるようにルビをつけてほしい」。出典：[カクヨムヘルプセンター「ルビや傍点を付ける」](https://kakuyomu.jp/help/entry/notation)（検索結果の要約を確認。画面で最終確認はしていない）。

| 場合 | 書き方 | 例 |
|---|---|---|
| 漢字だけの語 | `漢字《かんじ》` | `暖簾《のれん》` |
| かなが混ざる語 | `｜語《ご》`（縦棒は全角か半角） | `｜襟巻き《えりまき》` |
| 《》をそのまま表示したいとき | 前に `｜` を付ける | `｜《` |

- ルビは、改行をまたぐと無効になる
- ルビと傍点は、同時に付けられない
- 付ける語は、各話の**初出**だけにする。人名・家名・時代語・専門語・読みにくい漢字
- 作り方：本文（ルビなし）を `drafts/jomae/本文/第XX話_vN.md` に置き、ルビ付き版を `第XX話_vN_カクヨム用.md` に作る。Driveにも別の文書で保存する
