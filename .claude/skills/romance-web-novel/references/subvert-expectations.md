# 読者の予想を裏切る手順（中川様の指示、2026-09-29）

話を考えるとき、**読者が考えそうな展開を10個出し、それを避ける。** 面白さは、読者の予想を、フェアに、感情の必然を保ったまま外すところから生まれる。

## 手順

1. **予想は、別の目で出す。** 自分で考えた話の予想を自分で出すと、自分の案を予想してしまう。**独立した読者役（別のエージェント）に、あらすじの一部だけを渡し、「この先の展開を10個予想」させる。** 渡す文章以外は読ませない（ファイルを読ませない）
2. **段階を分けて、2回以上出させる。**
   - 導入〜中盤の入口まで渡す → 「この先の展開」と「結末（恋の着地、悪役の末路、鍵になる物）」を当てさせる
   - 真相の直前まで渡す → 「犯人と動機」「隠された物」「主人公の秘密」「金庫・箱の中身」など、真相そのものを当てさせる
3. **各予想を、企画の実際の展開と照らして判定する。** 「当たり（そのまま）」「半分」「外れ」の3つ。表にして残す（予想／当たり外れ／対応）
4. **当たりの予想は、次のどれかにする。**
   - **避ける**（別の展開に差し替える）
   - **わざと予想させて、ずらす**（ミスリードとして使う。フェアであること）
   - **予想どおりで残す**（ジャンルのお約束。下の「残してよいもの」）
5. 差し替えたら、**あらすじ・イベントマップ・タグ表を更新し、もう一度、予想役に出させる。** 当たりが減ったか確かめる

## 残してよいもの（お約束）

裏切ってはいけない。読者が求めているから。
- 恋の最終的な着地（結ばれる）
- 悪役が報いを受ける（ざまぁ）
- 主人公の努力や才能が、最後に認められる

**裏切るのは「過程」と「理由」と「順番」。** 結末そのものを裏切ると、読者が離れる。

## 気をつけること

- **意外なだけでは面白くない。** 裏切ったあとに、「なるほど」と納得できる伏線があること（`mystery-writing` のフェアプレイ）
- **感情の必然が残っているか。** 予想を避けるために、登場人物が不自然な行動をしていないか
- **全部を避けようとしない。** 10個すべてを避けると、話が散らかる。当たりのうち、**読者が「そうなるだろう」と思って退屈する所**だけを外す
- 予想役には、作者を褒めさせない。当てにいかせる
