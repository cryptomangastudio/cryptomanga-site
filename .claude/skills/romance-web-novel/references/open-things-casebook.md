## 2. 感情の型と、作り方

| 型 | 作り方（調べたことの要約） | 『錠前』での使い方 |
|---|---|---|
| 感動（泣ける） | 感情の**落差**を大きく。①落差の起点②転換の一打（小さな行動や一言）③着地の温度。回想は、**本筋で使う意味**を明確にする。ありがちなので、型に頼りすぎない（[榎本メソッド](https://enomotomethod.jp/column/sad-story/)） | 開けた中身→回想→志乃の小さな行動 |
| 悲しい | 喪失と、幸福な時期の対比。助言より、行動で終わらせる | 間に合わなかった手紙、遺書。志乃は「届け先を探す」「開けずに返す」 |
| 胸クソ | **中身**か**依頼人**で出す。志乃の行動で、読者の怒りが解ける形にする（そのまま終わらせない） | 中身が裏切りの証拠、など |
| スカッと（カタルシス） | **溜め→解放**。①理不尽を具体的に②段階的に追い詰めても**灯火**を残す③逆転の材料は**事前に伏線**④悪役は自分の行いで崩れる⑤解放の**後**まで少し描く。主人公が過剰に報復すると、読者が冷める（[うずしお](https://uzusiox.hateblo.jp/entry/2020/08/11/230836)、[ざまぁ系の構造](https://tomenovel.com/blog/ja/zamaa-kei-to-wa-nanika)） | 悪徳錠前屋・押し売りを暴く、傲慢な客、偽物を見抜く |
| 脱力・ほっこり | 期待と違う中身（所さん型）。謎の錠剤1錠、など | 箱の中身が意外にささやか |

配分の目安（案）：感動・温かい 5割／悲しい 1.5割／スカッと 2割／胸クソ 1割（スカッとにつなげる）／脱力 0.5割。

## 4. ご指定の展開の型

## 4-3. 重い題材の扱い（中川様の決定 2026-10-09：「一部は正面から扱う」）

- 正面から扱う話は、**全30話のうち数話に絞る**。山場は「戦死・病死の手紙」など、遺された物から届く形にする
- 描写の注意は私が付ける：暴力・虐待の場面は直接描かず、**結果と、その後の人の動き**を書く
- 座敷牢は、引きこもりの話に結びつけない。扱うなら、独立した一話にして、「外から閉じ込める」ことを志乃がはっきり拒む話にする（要確認）
- 重い話の直後は、軽い話か、スカッとの話を置く
