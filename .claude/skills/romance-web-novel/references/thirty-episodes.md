# 30話構成の作り方（2026-09-29、『錠前』で作った手順）

イベントマップ（`event-map.md`）の次に作る。**中川様の許可を得てから進める。** 出来事（31）を、話（30）に割り振る。

## 書き方

1話を「**冒頭／山場／ヒキ**」の3つで書く。話ごとに、題、出来事の番号、錠（勝ち負け）、感情（＋＋〜−−）、ヒキの型を、一覧表にも載せる。

| 項目 | 決まり |
|---|---|
| 1話の字数 | 2,300〜2,400字、セリフ約60本（`prose-profile.md`） |
| ヒキ | 5〜10字の短い反応（疑問形、独白）。**決め台詞で締めるのは10話に1回程度**（30話で3回まで） |
| 恋愛以外の勝ち負けがない回 | **30話のうち5話まで**（`crossover.md`）。第1話は、決着の予告があれば数えない |
| 山場の位置 | 3分の1（山場1）、中盤の山、3分の2（山場2・最高点）、最低点（対峙）、泣き所と結び |
| 型崩し | 失敗回・倒叙回・恋愛比重の高い回・複数話の大型回を、**4種とも配置する** |
| 1話目 | 引きは、「嘘をつく」「秘密を隠す」場面に置く。静かな導入（刻印、命日）は、冒頭に2〜3行で圧縮する |
| 終盤 | 「開く／真実／引き出し／対峙／ざまぁ／返却／結び」を、別々の話に分ける。1話に詰めない |

## 割り振りのやり方

1. 出来事を並べ、**1出来事＝1話**を基本にする。短い出来事は、1話にまとめる（2つまで）。大型の出来事は、2話に分ける
2. 30話に足りなければ、**中盤に、新しい型の話を足す**（別の錠の回、恋愛比重の高い回）。同じ型の錠を増やすだけにしない
3. 一覧表で、**感情が山谷交互**か、同じ高さが3つ続いていないかを確かめる
4. **消えた物と傷を、出す話ごとに置く。** 初出の話に、消えた物の「気配」（破れ跡など）を一行入れる。返却の話が唐突にならない

## 出す前に、独立した目で確かめる

1. **予想役**に、途中まで（第18話まで）の流れだけを渡し、その先を10個予想させる（`subvert-expectations.md`）。当たった所は、避ける・ずらす・残す、を決める
2. **整合性の査読者**に、「話の順序で、誰が何を知っているか」を確かめさせる。企画書の既存設定の穴探しは、含めない

## 2026-09-29の実例で見つかった教訓

1. **主人公視点の断定文が、その時点で嘘になる。** 「親方を疑う理由は一つも見つからない」と書いたが、その時点で主人公には、疑う根拠が2つあった。**「疑う理由はある。疑いたくなかった」**のように、心理を正しく書く
2. **悪役が、動かない期間を作らない。** 主人公が悪役の目的の場所（金庫）へ向かうとき、悪役がなぜ止めないか、なぜ逃げないかを、幕間か台詞で見せる（第21話の幕間）
3. **見つかる場面は、読者に予想される。** 悪役が**自分から**見せる形にずらすと、動機を語らせる場にもなる（第24話）
4. **閉じ込められる主人公は、職能で出る見せ場にする。** 錠前師なら、閉じ込めの錠を、自分の技で開ける。読者は期待している（第17〜19話）
5. **金庫や箱の中身は、ほぼ当てられる。** 中身に、予想外の1つ（幼い日の最初の作品と、父が刻んだ名）を足す
6. **場所と動線を、話ごとに確かめる。** 「門の前で鉤を見せる」のに「屋敷を出る」、「外に出さない」のに「自由に行き来する」といった食い違いが出る
