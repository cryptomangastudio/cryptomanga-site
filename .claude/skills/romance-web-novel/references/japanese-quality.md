# 日本語の検査

**本文だけでなく、企画書・説明文・チャットの返答もすべて対象。**
2026年9月、中川様から「まず日本語がおかしい。全然意味わからん」という指摘を受けた。小説の文体以前に、説明の日本語が通じていなかった。

出す直前にこれを通す。音読するのが一番早い。

---

## 1. 主語と述語を対応させる

一文の中で、主語と述語が噛み合っているかを確かめる。

### 過去の失敗

**「書く力より、出す前に自分を疑う手順がない。」**
「〜より、〜がない」という構文は成り立たない。比較の形で始めて、否定で終わっている。
→ 「書く力の問題ではありません。出す前に自分で確かめる手順がないことが問題です。」

**「今回の失敗7件が手元にある今が、記憶が最も新しい。」**
「〜今が」と「〜記憶が」で主語が二重になっている。
→ 「今回の失敗を覚えているうちにやるべきだからです。」

### 確認の方法
長い文を見つけたら、**主語と述語だけを抜き出して並べる。** それだけで意味が通るか見る。通らなければ文を割る。

---

## 2. 一文は一つのことだけ言う

読点で三つ以上つなげた文は、必ず割れる。

- 読点が3つ以上ある文を探す
- 「〜して、〜で、〜が、〜ので」と接続が続く文を探す
- 割ったほうが読みやすいなら、必ず割る

---

## 3. 体言止めを並べない

一つだけなら効く。並べると文章が崩れ、敬体と混ざると読めなくなる。

### 過去の失敗
**「指標は一発OK率。」「私の推奨は独立。」**
敬体で書いている文章の中に体言止めを混ぜた。しかも複数箇所で。
→ 「指標は一発でOKが出る割合です。」「私としては独立させたいと考えています。」

### 規則
- 説明文・企画書・チャットの返答では、**体言止めを使わない**
- 本文（小説）では、強調のために使ってよい。ただし1話に2回まで
- 箇条書きの項目は体言止めでよい（文ではないため）

---

## 4. 文を途中で放置しない

「〜か、〜か。」で終わっている文は、文として完成していない。

### 過去の失敗
**「ドライブの `14_精読コーパス` に本文テキストを置いていただくか、環境の許可リストに `kakuyomu.jp` を追加していただくか。」**
選択肢を並べただけで、何をしてほしいのかが書かれていない。
→ 「〜置いていただくか、〜追加していただければ読めます。どちらかをご検討ください。」

### 確認の方法
各文の最後を見る。**「か。」「が。」「けど。」で終わっている文**を探して、述語を足す。

---

## 5. 分析めいた言葉を混ぜない

`creative-writing/references/anti-ai-tells.md` が禁じているのと同じ問題。**自分で書いた禁止事項を、自分が破っていた。**

### 使ってはいけない言葉（説明文・企画書・本文のすべてで）
担保する、機能する、構造、エンジン、装置、実体、プロトコル、項目化、充填、最適化、検査工程、カタルシスを供給、トリガー

### 言い換え
| 使わない | 使う |
|---|---|
| 検査工程 | 確認の手順 |
| プロトコル | 手順 |
| 項目化する | 一覧にする |
| 〜が機能する | 〜が効く／〜がうまくいく |
| 〜を担保する | 〜を確かにする |
| 実体 | 中身／実際にやること |
| 〜という構造 | （多くの場合、削れる） |

**社内の企画シートに書く検討メモは例外。** そこは分析の言葉で書いてよい。納品物と外向けの文章では使わない。

---

## 6. 敬体と常体を混ぜない

一つの文書の中で統一する。

| 文書 | 文体 |
|---|---|
| 中川様・クライアントへの説明、チャットの返答 | 敬体（です・ます） |
| 企画書・構成案 | 常体（だ・である）。箇条書き中心でよい |
| スキルの文書（この文書など） | 常体 |
| 小説の本文 | 常体（`21_執筆スタイルガイド` に従う） |

---

## 7. 比喩を引っ張らない

一つの比喩で文章全体を説明しようとすると、読みにくくなる。

### 過去の失敗
自分の問題を「診断」「症状」という医療の比喩で説明し、表の見出しまで「症状」にした。比喩が長く続いて、何の話か分かりにくくなった。
→ 比喩は1回使ったら離れる。二度目からは普通の言葉で言う。

---

## 8. カタカナ語を減らす

ジャンル名や固有名詞（ロマンスファンタジー、コミカライズ、カクヨム）は使う。
それ以外のカタカナ語は、日本語に置き換えられるなら置き換える。

| 使わない | 使う |
|---|---|
| コスト | 手間／費用 |
| リスク | 危険／おそれ |
| ロジック | 筋道／仕組み |
| フック | 引き／掴み |
| クリフハンガー | 引き |

ただし社内で定着している言葉（ヘイト役、ざまぁ、見せ場、字コンテ、ネーム）はそのまま使う。

---

## 出す前の最終確認

音読して、次を確かめる。

- [ ] 主語と述語が噛み合っているか（長い文は主語と述語だけ抜き出す）
- [ ] 読点が3つ以上ある文が残っていないか
- [ ] 体言止めを並べていないか
- [ ] 「か。」「が。」で終わって放置された文がないか
- [ ] 分析めいた言葉が混ざっていないか
- [ ] 敬体と常体が混ざっていないか
- [ ] 同じ比喩を引っ張っていないか
- [ ] 日本語に直せるカタカナ語が残っていないか
- [ ] 読み上げて、息が続かない文がないか
