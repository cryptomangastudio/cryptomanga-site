# 文体の数値記録

**現在、この文書はほぼ空である。** 人気作の本文を一本も読めていないため。

この環境からは小説投稿サイトに接続できない（`fact-check.md` の「この環境での制約」を参照）。
本文のテキストがドライブの `10_リサーチ/14_精読コーパス` に置かれたら、下の手順で実測して、この文書に書き込む。

**実測値が入るまでは、文体の判断は `21_執筆スタイルガイド`（ドライブ）と一般的な作法に頼るしかない。** その前提を忘れないこと。読まずに書いた文体論は精度が落ちる。

---

## 測り方

1作品につき、連続する5話を対象にする。1話だけでは偏る。

### 測る項目

| 項目 | 測り方 |
|---|---|
| 1話の字数 | 5話の平均と、最小・最大 |
| 1文の平均字数 | 句点で区切って平均 |
| 1段落の行数 | 平均と最大 |
| 台詞と地の文の比率 | 鍵括弧の中の字数 ÷ 全体の字数 |
| 空行の頻度 | 何行ごとに1回入るか |
| 会話の往復数 | 地の文を挟まずに続く台詞の最大往復数 |
| 三点リーダの使用 | 2個単位か。1話に何回出るか |
| ダッシュの使用 | 2個単位か。何に使っているか（転換・断絶・言い換え） |
| 比喩の数 | 1話に何個 |
| 決め台詞の数 | 1話に何個 |
| 冒頭3行の型 | `22_書き出しパターン集`（ドライブ）のどの型か |
| ヒキの型 | 見てしまった／言われてしまった／決めてしまった／その他 |
| ヒーローの内面 | 地の文に出ているか。出ているならどの頻度で |
| 一人称の自己否認 | ヒロインが自分の感情を否定する描写が1話に何回出るか |

### 測ったら書くこと

数値だけでは使えない。**自分の文章に移せる形**に変換して書く。

- この作品と自分の書き方の差はどこか
- 真似すべき技法は何か（3つまで。多いと実行できない）
- 真似してはいけないところはどこか

## 実測値（作品ごとに追記する）

### 実測1：『時戻りの令嬢は2度目の運命を処方します』字コンテ（社内・コミカライズ連載中）

2026-09-14 測定。全30話・約183万字のスプレッドシートから集計した。
**当社が納品し、実際に連載されている作品の実数値。** 外部のノウハウ記事より優先する。

| 項目 | 実測値 |
|---|---|
| 1話の文字数 | 平均 2,365字 / 中央 2,349字 / 範囲 1,605〜2,968字 |
| 1話のセリフ数 | 平均 59.5本 / 中央 58本 / 範囲 50〜77本 |
| 1セリフの文字数 | 平均 16.6字 / 中央 15字 |
| 吹き出し内で改行するセリフ | 34.0%（全角スペースで改行位置を指示） |

セリフの長さの分布（全7,039本）：

| 長さ | 割合 |
|---|---|
| 1〜5字 | 16.9% |
| 6〜10字 | 19.6% |
| 11〜15字 | 16.4% |
| 16〜20字 | 13.1% |
| 21〜30字 | 23.7% |
| 31〜50字 | 9.5% |
| 51字以上 | **0.8%** |

**使える規則**

1. **1話は2,300〜2,400字、セリフ約60本。** シナリオ欄の指定が「2〜3000文字程度」で、実際にその範囲に収まっている
2. **セリフは15字が基準。** 半分強（52.9%）が15字以下
3. **51字を超えるセリフは全体の0.8%。** 書いてしまったらほぼ間違いと考えてよい
4. **長いセリフは全角スペースで割る。** 3本に1本は吹き出し内で改行している

**心の声の書き方（出現数）**

| 書き方 | 回数 |
|---|---|
| （心の声） | 1,940 |
| キャラ名M「」 | 293 |

→ **括弧の心の声が、M「」表記の6.6倍。** 心の声は括弧が主流で、M「」は限定的に使う。

**記号の作法（重要な発見）**

| 記号 | 回数 |
|---|---|
| 三点リーダ1個「…」 | 3,143 |
| 三点リーダ2個「……」 | 92 |
| ダッシュ | 95 |
| ！？ | 149 |

→ **マンガ原作の字コンテでは三点リーダは1個が圧倒的（97%）。** 小説の作法（必ず2個単位）と真逆である。
**媒体で作法が違う。小説を書くときは2個、字コンテを書くときは1個。混ぜない。**

**ヒキの実例（各話の最終セリフ・10話分）**

「わぁ」／「目に見えないもの」／「突然倒れたと思ったら　ずっと意識が戻らなくて心配したんだよ！」／「苦悶の表情」／「事業失敗？」／「なんと答えよう」／「あなたは死なないわ　私が守るもの」／「怪しまれてる？」／「父上の前で俺に恥をかかせたこと　必ず後悔させてやる」／「できることから　やっていかないとね！」

→ **ヒキは長い決め台詞ではない。** 短い一言、疑問形、独白が多い。
「わぁ」「事業失敗？」「なんと答えよう」のように、**5〜10字の反応で切る**のが基本。決め台詞で締めるのは10話に1回程度。

## 暫定の目安（実測値が入るまで使う）

一般的な作法として確認できている数値。**これは実測ではない。** 置き換えられたら置き換える。

| 項目 | 目安 | 根拠 |
|---|---|---|
| 1話の字数 | 2,000〜3,000字 | スマホで3〜6分で読み切れる長さ。5,000字を超えると「あとで読む」に流れて離脱する |
| 序盤3話 | 3,000〜4,000字 | 掴みと世界観のために厚くする |
| 1段落 | 3行以内 | 4行を超えたら割る |
| 空行 | 5〜10行に1回 | 過剰な空白を避けつつ読みやすさを保つ |
| 台詞と地の文 | 4：6 | 会話劇に寄せすぎると薄く、地の文に寄せすぎると読まれない |
| 会話の往復 | 3往復まで | 4往復目の前に地の文を挟む |
| 三点リーダ | 必ず2個単位 | 1個は使わない |
| 比喩 | 1話2つまで | 全部が詩的だと体温が消える |
| 決め台詞 | 1話1つ | 2つ以上置くと両方が安くなる |

出典：のべまが [1話の文字数](https://novelmore.jp/blog/write/web-novel-episode-length/) / [セリフ改行ルール](https://novelmore.jp/blog/write/novel-serif-kaigyou/) / [基本ルール](https://novelmore.jp/blog/write/novel-writing-base/)
