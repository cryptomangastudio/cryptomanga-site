# ほっこり連作の型（『錠前』2026-10-08の方針転換から）

中川様の指示：「ミステリー・サスペンスが軸になりつつあり、自分でコントロールする自信がない。扉を開けて、中から出てきた物で、ハートフルな思い出につながる話がやりたい。ミステリーは2〜3割。主人公が最後にアクションして、引き立つ話にしたい」。

## 型
1話＝依頼 → 錠の前の主人公 → 開ける → 中身（大切な物／見たくない物）→ 回想 → 主人公の行動 → 余韻。
- 主人公の行動は、助言ではなく行動（鍵を作り直して渡す／開けずに返す）
- 大切な物7割、見たくない物3割。見たくない物の回は、主人公の行動で心が軽くなる終わりにする
- 錠の仕組み・手順は書かず、結果と音だけを書く
- 事件・敵対者・黒幕は置かない。縦糸（2〜3割）は「主人公の名／失くした鍵／恋」の三本に絞り、答えは優しいものにする

## 調べたこと（検索結果の要約。出典のある数字ではない）
- 連作は、一話完結の横糸を主にして、全体の縦糸を少しずつ見せる。縦糸が強いと長編に寄り、完結させにくい（[榎本メソッド](https://enomotomethod.jp/column/series-of-short-stories/)、[縦糸・横糸構造](https://ameblo.jp/takaryu57/entry-11842337908.html)）
- 近い型の前例：『ビブリア古書堂の事件手帖』（物から人の想いを読む、人が死なない謎）、『ツナグ』、『阪急電車』
- 「縦糸2〜3割」は目安。読者の反応を見て調整する

## 過去の失敗
- 2026-10-08：企画がミステリー・復讐に寄りすぎ、作者が制御できなくなった。**企画の段階で、軸（ほっこりか、謎か）と縦糸の割合を決める**。謎を足して面白くしようとすると、軸がずれる
- 2026-10-13：第1話の冒頭1行と最後の2行に「失くした鍵」の謎の引きを入れたところ、中川様から「ノイズ。全体に予定調和」と指摘された。原因は3つ。①感動の山の直後に別の謎が乗り、余韻が薄れた　②箱の錠が父の作で、しかも失くした鍵が若様の手の中、という偶然の二重　③ほっこり連作の引きは「続きが見たい」なのに、謎の引きを置いた。さらに、型（依頼→開ける→中身→回想→行動）の順番どおりに書くと、読者が毎場面で先を当てられる。**第1話の引きは「次も読みたい理由」だけにする。縦糸の謎は、第6話以降に初めて見せる。型の順番は、第1話から崩す**（結果から始める、境遇の説明は山のあとに置く、中身を裏切る）。
