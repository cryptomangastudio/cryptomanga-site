# 企画をゼロから立ち上げる手順

女性向けロマンス企画の立ち上げで実際に使った手順と、そこで踏んだ失敗の記録。
**次に同じことをやるとき、失敗のほうを先に読むこと。**

---

# 第一部:失敗パターン(先に読む)

実際にやらかしたもの。どれも一度ずつ企画を止めた。

## 1|依頼者の原案から離れる ← 最悪の失敗

原案に「従者と一緒に」「婚約者を探す旅」「溺愛執着」が入っていたのに、
提案を重ねるうちに全部落として別の話にすり替えていた。

**対策**:原案を一言一句ひかえて、提案のたびに突き合わせる。
落とす要素があるなら、**落としたことを明示して理由を言う**。黙って落とさない。

## 2|制度を作りすぎる

ディストピアだからと、感情の申告制、発話語数の配給、幸福度スコア……と
「説明が要る設定」を量産した。読者が最初に知りたいのは
**「この二人が見たい」**であって、制度ではない。

**対策**:設定は一行で言える分だけ。ロマンスは人で読ませる。

## 3|理屈は通っているが、字面が美味しくない

「腐らせない」は論理的には正しいが、読者は美味しさも幸せも感じない。
「浄化する」「泥水が透きとおる」「温かいスープになる」でなければ、
拠点の生活に憧れてもらえない。

**対策**:**設定の理屈と、読者の快楽は別物。**
理屈が通っていても、字面が美味しくなければ書き直す。

## 4|サンプルを内容の仕様と取り違える

書式の見本として渡されたものを、必須要素のリストだと誤読し、
職業・夢・陰謀・自立の着地を全案に足して膨らませた。

**対策**:サンプルが来たら「**書式ですか、中身ですか**」を先に聞く。

## 5|長くするときに複雑にする

500字・1000字版を書くとき、同じ話を丁寧に書くのではなく、
話そのものを複雑にしてしまった。

**対策**:長さを変えても**話は同じ**。増やすのは描写と間だけ。

## 6|構造だけ分解して、面白さを分解しない

ベンチマークを「口癖は盾」「物理と精神の両方で失う」と分析したが、
**なぜ見ていて楽しいか**は一度も分析していなかった。作りが分かっても面白さは出てこない。

**対策**:ベンチマークは必ず**二重に分解**する。構造(どう作られているか)と、
面白さ(なぜ楽しいか)は別の作業。

## 7|SF考証に寄りすぎる

日射が落ちているからキノコ、と考証を優先して、
「毎日キノコばかり食べている拠点」という地味な絵を作ってしまった。
遺物の育成灯を持たせて**真っ赤なトマト**にすれば、視覚のコントラストが出る。

**対策**:考証は背景に置く。前景は常に**絵の強さ**で決める。

## 8|ベンチマークの構造を、前提条件を確認せずに移植する

『となりの怪物くん』の帯「やっかいだ。この怪物も、恋した私も。」の構造
(**後半で自分も同じカテゴリに入れて、もう落ちていることを白状する**)を
そのまま本作に持ってきた。

だが、あの作品のヒロインは**自覚している**。だから白状できる。
本作のヒロインは**無自覚**が売りなので、同じことをさせると
「温度差」という最大の魅力が死ぬ。

**対策**:構造を借りる前に、**キャラの前提条件が一致しているか**を照合する。
- 自覚している / していない
- 優位に立っている / 立っていない
- 相手の感情を認識している / していない

ここが違うと、同じ型が正反対に働く。

### 語彙も同じ落とし穴を踏む

「患者」という語を使ったが、ヒロインは医療従事者ではない(水の管理一族)。
一語で**ジャンルの空気が変わってしまい**(急に本格医療もの)、
「ただ洗っただけ」という手軽なチート感が消える。

**対策**:キャッチに入れる語は、**そのキャラが実際に使う語**か確認する。

## 9|出力形式が読みにくい

見出しと引用符を過剰に使い、短い断言で文を切り続けた結果、
「提案」ではなく「自分の設定のプレゼン」になっていた。
指摘を受けて全部消したら、今度はただの文字の壁になった。

**対策**:**適度に改行し、要点だけ箇条書き。** 極端に振らない。
「〜が生きます」「〜で埋まりました」のような自己完結した言い回しを避ける。

# 第二部:進める順番

## 0|原案を一行で固定する

依頼者の言葉のまま書き写す。ここが全工程の基準になる。

## 1|ジャンルの作法を調べる

- そのジャンルのお約束(読者が求めて来るもの)
- **落とし穴**(そのジャンル特有の失敗。例:捕縛ものの「なぜ逃げないの?」)
- 現代の読者が嫌うもの(例:受け身のヒロイン)

## 2|市場の空白を確認する

似た組み合わせの作品があるか。無いなら**なぜ無いのか**まで調べる。
構造的に難しいなら、その難しさを自分がどう解いているかが強みになる。

## 3|ベンチマークを二段で置く

| | 何を借りるか |
|---|---|
| **第一幕用** | 導入の型(例:Falloutの「地下から地上へ出る」) |
| **エンジン用** | 第二幕以降、何が話を回すか(例:薬屋の「閉鎖世界+一話完結」) |

さらに必要なら、トーンの手本、主人公の効き方の手本を別に立てる。
**一本のベンチマークで全部をまかなおうとしない。**

ベンチマークは成功だけでなく**失敗も採る**。
(例:Fallout第1話の三本並行は批評家に「初回でいちばん不可解」と名指しされている)

## 4|三分類で棚卸しする

| | 扱い方 | 目標量 |
|---|---|---|
| **鉄板** | 読者がそれを求めて来る。**最大化する** | 7割 |
| **ただの既視感** | 何も運ばない重り。**削るか格上げ** | **0割** |
| **新規性** | 予想を裏切る一点。**位置を選んで刺す** | 2〜3割 |

判定は三問:
1. 削ったら読者が来た理由が消えるか → 鉄板
2. 読者の予想を裏切るか → 新規性
3. どちらもNOか → ただの既視感

## 5|人 → 世界の順で作る

主人公の立場・性格・目的を先に決める。世界はそれを成立させる分だけ作る。
**逆順にすると、世界に合わせて人を作ることになり、誰の話か分からなくなる。**

## 6|制作ルールを3つ以内で明文化する

書いている途中でブレたとき、ここに戻る。実際に立てたもの:

- 殺伐(世界観)3割 : 甘さ(ロマンス)7割
- 拠点の中は常に甘く、安全に。荒野の殺伐はそれを引き立てるスパイス
- 設定の理屈より、字面の美味しさ

## 7|パッケージを固める

**書き始める前に**、この順で。ここがブレると執筆中に迷子になる。

1. タイトル
2. キャッチコピー
3. ログライン(1〜2行)
4. あらすじ(数行 → 300字 → 必要なら500字)
5. 世界観(100字以内)

## 8|キャラクター造形

ヒロインから。四つの軸:

- **立場**(能力と身分を一つで繋ぐと設定が減る)
- **性格のギャップ**(普段はこう、でも一点だけ譲らない)
- **脇役の配置**(ツッコミ役・解説役・人質になる役)
- **相手役への感情**(恋愛の障害になるなら義務感にしておく)

## 9|第1話のビート表 → 執筆

# 第三部:パッケージを作るときの実務

## タイトルとキャッチは役割を分ける

**タイトルが状況を説明しているなら、キャッチで状況を繰り返さない。**
キャッチが足すのは、情報ではなく**笑いか感情**。

チェック:タイトルに入っている語をキャッチで使っていないか。一語ずつ照合する。

## キャッチはヒロインのぼやきで書く

女性向けヒット作28件(悪役令嬢・ロマンスファンタジー・TL)の
実タイトルを集めて照合したところ、共通点は六つ。

- **ヒロインが喋っている。** 三人称の状況説明は一つもない
- **「されています/されてます」の受動形**。望んでいないのに、されている
- **驚きの語が必ず入る**。「なぜか」「意外と」「〜はずの」「〜なのに」「ただの」
- **困惑・不本意の表明**。「逃げたい」「囚われて」「舐めていた」
- **相手を軽く扱う語**。「ラスボスを飼ってみました」「気絶させたら」
- **「!?」「!」で終わるものが非常に多い**。断定せず、驚いたまま終わる

状況の説明で終わっているキャッチは、ジャンルの記号が抜けているので
**棚に並べたときに同ジャンルに見えない**。

### ただし「揺れ」を入れるかは、ヒロインの型による

自覚型のヒロイン(『となりの怪物くん』)なら、
「恋した私も」と白状させることで「もう落ちている」が伝わり、強い。

**無自覚型のヒロインなら、揺れを入れてはいけない。**
本人が事務的に困っているだけ、という温度差が最大の売りだから。
コピーの段階で「愛」「好き」「懐かれて」のような、
**彼女が相手の感情を認識している語**を使うと、その魅力が消える。

## キャッチの字数

帯の標準は**30字程度**。20字以内に抑えるなら、説明は物理的に不可能になるので、
理屈を詰め込もうとせず、ギャップか感情の一点に絞る。

## 飛躍が気になるときの処理

「なぜその行為で執着するのか」が飛んでいると読者が引っかかる。
これを「彼が狂っているから」で埋めるのは**逃げ**であり、
しかもジャンルエラー(甘い話のアオリがサイコサスペンスになる)。

正しくは、**行為ではなく結果**に置き換える。
「傷を洗った」(行為・地味・他人事)ではなく「痛くない」(結果・本人の体感)。

# 第四部:リサーチの作法

- **数が集まらなかったときは、集まらなかったと言う。** 記憶から並べて数を合わせない
- 出典の取れた数字と、推定を**分けて書く**
  (例:Fallout第1話が74分・冒頭7分は出典あり。各ブロックの内部の分数は推定)
- ベンチマークは**批判記事も読む**。失敗の指摘が一番役に立つ
- 先行作の確認を怠らない。**「発見した」と思ったものは、たいてい誰かがやっている**
  (今回:万博×終末×カルトは『20世紀少年』、意味を知らずに継承する宗教は『黙示録3174年』)

# 第五部:相手とのやりとり

- 提案のたびに、**原案のどこを残しどこを変えたか**を言う
- 自分が足した要素は「足しました」と明示して、要るか要らないかを聞く
- 質問は一度に二つまで。三つ以上は相手が答えきれない
- 迷っている点は隠さずに「ここは好みが分かれると思う」と言う
- **相手が既に決めたことを、勝手に作り直さない**
