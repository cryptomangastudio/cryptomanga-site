# 視覚的物語術・人物描写(映像/絵に起こせる原作を書くための技術)

縦型ショートドラマ原作(将来マンガ化・実写化される素材)を、**「絵に起こせる・演出に落とせる」状態**で書くための技術リファレンス。英語圏の定評ある脚本術ソース＋中国の爆款方法論を統合。冒頭フック・毎話の引きの設計は `vertical-drama.md` が正。本ファイルは「人物をどう出すか」「内面をどう外在化するか」「作画/キャストにどう渡すか」を扱う。

> **本ファイルの背骨となる一文**: 原作は「頭の中で映像が再生できる」状態でなければ、作画にもキャストにも渡せない。心情・設定・性格は**地の文で説明する前に、動作・表情・小道具・立ち位置**という「カメラに写るもの」に変換する。CryptoManga縦型原作は小説形式(1話約2,000字)だが、その2,000字の中身は**「カメラが写せる情報」で満たす**のが原則。

---

## 1. キャラクターの初登場(character introduction)

### 1-1. なぜ初登場が決定的か
読者・作画・キャスト・演出は、そのキャラを**最初の数行で「こういう人だ」と固定**する。ここが弱いと以降ずっとキャラが立たない。縦型では特に、視聴者は3秒で人物を記憶できる形を求める(中国短剧の実務では人設は「符号化」して1つの識別点に絞るのが定石)。

### 1-2. 脚本の作法(原作小説に翻案しても効く核)
英語圏脚本の初登場には確立した型がある。原作小説でもこの「情報の順序」を踏襲すると映像化しやすい。

- **名前は初出のみ大文字化**(例: `JANE DOE`)。以降は通常表記。→ 読み手・制作が「新キャラ登場」を一目で把握するための業界標準。原作小説では「初出の人名を太字/フルネーム」で代替できる。
- **年齢(帯)を添える**: `(30s)` `(17)` のように概数で。実写キャスティングと作画年齢の指針になる。
- **描写は短く(目安3〜4行以内)**、かつ**「一撃で性格が分かる」1点**を入れる。全身を上から下まで説明しない。
- **動作で見せる(show through action)**: そのキャラが「何をしているか」でキャラを出す。プロフィール文で説明しない。

### 1-3. 「一撃で性格が分かる1点」の作り方
良い初登場は、外見の網羅ではなく**行動・所作・選択が滲む具体1点**を選ぶ。

- 悪い例(一般化・非視覚): 「ジョン、29歳、背が高く痩せている」「メアリー(40代半ば)、魅力的なブルネット」→ 何のイメージも湧かず、性格情報ゼロ。作画は描けるがキャラは立たない。
- 良い例(所作で人物が滲む): 「気弱そうな中年男。痩せた体に、2サイズ大きい90年代風のダサいジーンズと、絶望的に平凡な緑のポロシャツ」→ 喋る前から性格が漏れている。
- 良い例(動作で見せる): 「高そうな革靴に付いた血を、彼女は丁寧に拭き取っている」→ 説明ゼロで「冷静・裕福・何かをやった」が全部伝わる。
- 映画の古典(参考): 『レイダース』のインディは、後ろ姿→帽子→鞭→毒矢を拾う手、と**顔を見せる前に「過去の遺物に取り憑かれた・戦える・冷静な男」を動作だけで確立**する。原作でも「顔・名前より先に、象徴的な所作を1つ見せる」を真似できる。

### 1-4. 対比で立たせる
初登場は**単体より対比配置**で記憶に残る。『パルプ・フィクション』のヴィンセントとジュールスは「肌の色以外そっくり」な陰陽として置かれる。縦型でも「主人公 vs 加害者」を初場面で並べ、価値観の差を所作で対比させると人設が一発で立つ。

### 1-5. 原作小説(2,000字)への落とし込み
- キャラ初登場の段落は、**プロフィール羅列を禁止**。「今この人物が何をしているか」の現在進行の1シーンに乗せて出す。
- 1キャラにつき**識別点は1〜2個**(所作・持ち物・口癖のどれか)。3個以上盛ると符号として弱くなる。
- 縦型の初場面は3人以内(`vertical-drama.md` 参照)。3人を出すなら、3人の識別点が**互いに被らない**ように設計する。

## 2. 視覚的物語術・アクションライン(show, don't tell)

### 2-1. 原則:内面を「カメラに写るもの」に変換する
「show, don't tell」は縦型の鉄則(無音でも伝わる)と完全に一致する。感情・思考・設定は、地の文の説明ではなく**動作・表情・小道具・視線**に外在化する。

- 悪い例: 「部屋は酷い臭いだった」→ 良い例: 「彼は鼻を手で覆った」。
- 悪い例: 「彼は子供時代を思い出していた」→ 良い例: 「彼は子供の頃の写真立てに目をやった」。
- 悪い例: 「彼女は怒っていた」→ 良い例: 「彼女はマグカップを流しに叩きつけた」。

### 2-2. 現在形・能動態・強い動詞
アクションラインは「ページ上のカメラ」。**今この瞬間に起きていること**を、能動態・具体動詞で書く。

- 弱い: 「彼は引き出しを静かに閉めた」→ 強い: 「彼は引き出しを叩き閉める」。
- 弱い: 「〜されていた」の受動・状態描写の連続 → 強い: 主語が具体動作をする文に直す。
- 原作小説でも、心情の説明文を1つ削るごとに、**代わりに動作の文を1つ足す**という交換を癖にする。

### 2-3. 内面の外在化ツールキット(小道具・所作・表情)
「見えない感情」を「見える物」に翻訳する常套手段:

- **小道具**: 握りしめる・落とす・拭く・隠す・投げる(例: 婚約指輪を外してポケットに入れる=決別)。
- **身体反応**: 手が震える・生唾を飲む・後ずさる・拳を握る(微細すぎる指定は避ける。§4参照)。
- **視線と沈黙**: 目を逸らす・凝視する・答えない。「言わないこと」も演技になる。
- **環境との接触**: ドアを蹴る・壁に手をつく・雨に濡れるまま動かない。

### 2-4. ブロッキング(立ち位置・動線・視線)を必要な分だけ書く
画面/コマの中で「誰がどこにいて、どこを見て、どう動くか」は演出の核。ただし**過剰指定は禁物**——プロットや性格に効く動きだけを書く。

- **書くべき動き**: 「彼はナイフをカウンターの陰に隠す」「彼女は彼の行く手を塞ぐ」のように、意味のある位置・動線。
- **書かなくていい動き**: 意味のない移動・カメラ指定(§4)。
- **高低差=力関係**: 階段の上・立っている側が強者に読める。対立場面で高低差を付けると権力関係が絵で伝わる。
- **視線が観客の視線を導く**: 誰かが見る方向に読者の注意も向く。重要な小道具・人物へ登場人物の視線を先に振る。
- **三角配置**: 3人を三角に置くと、同盟・裏切り・序列の移り変わりを視線の切り替えだけで描ける。縦型の会話劇でも「2対1」の構図は緊張を生む。

### 2-5. 簡潔さ(ホワイトスペース)
アクション段落は**1ブロック3〜4行以内**。詰め込むほど「映像的な一瞬」が埋もれる。少ない語数で1カットを立てるほうが、かえってシネマティックに読める。原作小説では「1段落=1カット」を意識し、段落を短く割る。

## 3. マンガ/WEBTOON/縦型原作での人物ビジュアルの受け渡し

原作(小説・シナリオ)から**作画・キャスティングへ人物を渡す**ときの記述作法。目的は「作画/演出が迷わず、かつ読者が識別できる」こと。

### 3-1. シルエット・テスト(識別点の設計)
キャラ設計の定番則:**輪郭(シルエット)だけで誰か分かるか**。群衆シーンでも主要人物が形だけで識別できるのが理想。

- 差別化は**髪型・体型・服のシルエット**で作る(色は白黒や暗所で消えるため、形で差をつける)。
- 「奇異・特異なものほど記憶されやすい(distinctiveness効果)」——1人1つ、突出した形の特徴を与える。
- 原作からの指定は、色名より**形容できる形**で: 「肩まである直毛の黒髪」より「片側だけ刈り上げた非対称ボブ」のほうが作画・実写どちらにも通る。

### 3-2. 記憶点(identifying feature)は1人1個に絞る
短尺・縦型では「3分で1キャラ覚える」必要がある。ポパイのセーラー服のように、**1キャラ=1アイコン**(髪・服・持ち物のいずれか)を固定する。

- アーク中は基本その衣装/髪を変えない(読者の識別と感情移入を維持)。転機で意図的に変えると「変化」の演出になる。
- 記憶点は**動作にも紐づける**と強い(例: 常に飴を舐めている、片手を必ずポケットに入れる)。作画のコマ量産にも、実写の所作演出にも効く。

### 3-3. 対比配置(silhouette contrast)
主要人物同士は**互いに被らない形**にする。長身×小柄、直線×曲線、装飾過多×ミニマル。並んだ1コマで即座に「別人だ」と分かる差を設計する。

### 3-4. 原作→作画/キャストへの人物ビジュアル記述テンプレ
1話2,000字の本文とは別に、**人物ビジュアル指定シート**を添えると制作がスムーズ。

- 名前/年齢帯/立場
- シルエットの一言(例: 「長身・撫で肩・常に猫背」)
- 記憶点1個(髪・服・持ち物のどれか、形で書く)
- 対になるキャラと、そのビジュアル対比
- 「一撃で性格が分かる」初登場の所作(§1-3)
- 感情の出方の癖(怒ると黙る/困ると笑う 等=作画の表情・実写の芝居の指針)
- 禁則(このキャラが絶対にしない所作)

### 3-5. 縦画面・コマ特有の注意
- 縦スクロール/縦画面は**1画面に1〜2人**が基本。大人数の群像は縦では潰れる。初場面3人以内の原則(§1-5)と一致。
- 顔のアップで感情を運ぶ比率が高い→ 記憶点は**顔まわり(髪型・目・アクセサリ)に置く**と縦で効きやすい。
- 位置関係は上下でも表現できる(画面上=優位/未来、下=劣位/過去 の含意)。

## 4. 初心者がやりがちな基礎ミスと是正

| ミス | 何が問題か | 是正 |
|---|---|---|
| **アクションの過剰描写** | 1シーンを長大な段落で細密描写。映像的な一瞬が埋もれる。 | 1ブロック3〜4行。1段落=1カット。 |
| **カメラ指定の乱用** | `CLOSE UP` `PAN TO` `CUT TO` を多用。あなたは撮影監督ではない。 | 「ジョンの手がハンドルの上で震える」と**描写でアングルを暗示**。 |
| **マイクロディレクション(演技の指定過多)** | 「一筋の涙が頬を伝う」等、俳優/作画の仕事まで書く。 | 状況を作り、感情の**結果**は演者・作画に委ねる。 |
| **説明的セリフ(on-the-nose)** | 感情・動機・背景をセリフで直接言う。※縦型は説明セリフを一部許容するが乱用は別問題。 | サブテキスト。核心を避けて話す。挨拶・別れの定型は削る。声に出して不自然を潰す。 |
| **tellの地の文** | 「彼女は悲しかった」と感情を名指し。 | 動作・小道具・視線に外在化(§2)。 |
| **初登場のプロフィール羅列** | 年齢・身長・容姿を網羅。性格が出ない。 | 現在進行のシーンに乗せ、性格の出る1所作で出す(§1)。 |
| **キャラのシルエットが被る** | 主要人物が形で見分けられない。作画も読者も混乱。 | シルエット・テストと対比配置(§3)。 |
| **名前が似ている** | サトウ/サイトウ/カトウ等。音・文字数の混同。 | 頭音・字数・響きを主要キャラ間で分散(`character-craft.md` §7)。 |
| **無音で成立しない冒頭** | フックがセリフ依存。ミュート視聴で崩れる。 | 冒頭フックは視覚的事件にする(`vertical-drama.md`)。 |
| **遅い登場・遅い事件** | 主人公や対立が出るのが遅い。 | 縦型は最初の数秒で人物と対立を提示(`vertical-drama.md`)。 |

## 5. 実務チェックリスト(原作1話を書いたら通す)

**人物の出し方**
- [ ] 主要キャラの初登場に「一撃で性格が分かる」所作が1つあるか
- [ ] 初登場でプロフィール羅列をしていないか(現在進行のシーンに乗っているか)
- [ ] 初場面の人物は3人以内か。3人の識別点は互いに被っていないか
- [ ] 主要キャラはシルエット/記憶点で描き分けられるか(1人1アイコン)
- [ ] 主人公と対になるキャラをビジュアル・価値観で対比配置したか

**視覚化(show, don't tell)**
- [ ] 「〜は悲しかった/怒っていた」等の感情名指しを、動作・小道具・視線に置き換えたか
- [ ] 心情説明の文と同数以上、カメラに写る動作の文があるか
- [ ] 各段落が「1カット」として頭の中で再生できるか
- [ ] 意味のあるブロッキング(位置・動線・視線・高低差)だけを書き、不要な移動やカメラ指定を書いていないか
- [ ] 冒頭フックは無音でも成立するか(セリフに依存していないか)

**渡せる状態か**
- [ ] この原稿だけで作画は絵を、キャストは芝居を起こせるか(曖昧な形容に逃げていないか)
- [ ] 人物ビジュアル指定シート(§3-4)を添えたか

## 6. よくある初心者ミス早見(一言版)

1. 感情を地の文で名指しする(tell)→ 動作に変換。
2. 初登場を容姿カタログにする → 所作1点で出す。
3. アクション段落が長すぎる → 3〜4行、1段落1カット。
4. `CLOSE UP` などカメラを指定する → 描写でアングルを暗示。
5. 演技(涙・眉の動き)まで指定する → 状況を作り結果は委ねる。
6. セリフで設定・感情を全部言う → サブテキスト化(縦型でも乱用は禁)。
7. キャラのシルエットが似る → 形で描き分け・対比配置。
8. 名前が似て混同する → 頭音・字数を分散。
9. 主人公/対立の登場が遅い → 冒頭で提示。
10. フックがセリフ頼み → 視覚的事件にする。

## 補足:このリファレンスの確度について

- **確度が高い**部分: 脚本の初登場作法(名前大文字化・年齢・所作で見せる)、show don't tell、アクションラインの現在形/能動態/3〜4行、カメラ指定やマイクロディレクションの回避——いずれも英語圏の複数の脚本教育ソースで一致しており定説。
- **やや薄い/一次資料に当たり切れていない**部分: 具体的な名作台本の原文引用は検索スニペット由来のため、実際の台本原文で裏取りするのが望ましい(『レイダース』『パルプ・フィクション』『ターミネーター』の初登場は方向性の参考として提示)。WEBTOON実務の「シルエット・テスト」はアニメ/コミック設計論として広く共有されているが、縦型ショートドラマ(実写)への転用は本ファイルでの橋渡し解釈を含む。
- 中国短剧の人設「符号化」「反差感」「黄金三秒」は複数の中国語実務記事で一致。詳細な数値・型は `vertical-drama.md` と `shortdrama/docs/research/` が正。
