# キャラクターシート(フォーマット)

主要人物を作るときに埋める。脇役は A・D・E だけでよい。
ロマンスでは **H(引力)** を必ず埋める。

**注意**:埋めること自体が目的ではない。
**「この項目を削ったら、この人物の選択は変わるか」**で要不要を判断する。

---

## A|一言

- **コンセプト3語**(視覚と内面を先にこの3語へ落とす。デザインはここから肉付けする)
- **一行紹介**

## B|基本

- 名前(呼び名 / 正式名 / 他人からの呼ばれ方)
- 年齢 / 立場 / 所属

## C|内面 ── 物語を動かす部分

- **行動原理**:何を見ると、手や足が勝手に動くか
- **Want**:自覚している目的
- **Need**:自覚していない、本当に必要なもの
- **Wound**:Needが生まれた過去(重くしすぎない。コメディが死ぬ)
- **禁則**:この人物が絶対にしないこと。プロットの都合でここを曲げない
- **コダワリ(主義)**:本筋と無関係でよい。書き手が詰まったとき、これが助けになる
- **アーク**:ポジティブ / フラット / ネガティブ と、その到達点

## D|声

- **一人称 / 二人称**(最重要。必ず最初に決めて、いつでも参照できる場所に置く)
- 敬体か常体か
- 口癖ではなく、**価値観・話す速度・省略の仕方・比喩の選び方**で差をつける
- **同じ内容の言い分け**:「危ない、逃げろ」を他の主要人物と並べて書き分ける
- **言わないこと**:沈黙する場面、話題を逸らす場面

## E|見た目 ── シルエットから作る

順番が大事。**シルエット → 記号 → 細部**。

- **シルエット**:背の高低、体型、髪の量とかたち。**他の主要人物と並べて影だけで見分けられるか**
- **記号**:一目で「この人だ」と分かる要素を1〜3個(眼鏡、髪飾り、持ち物、服の形)
- **色**:多くて3色。理由をつける
- **細部**:手、歯、肌、爪など。**身分や職業がにじむ部位**を選ぶ
- **服**:なぜそれを着ているか。**行動原理と矛盾していないか必ず照合する**

## F|癖

- **意味のある癖**:感情や過去とつながるもの。1つ
- **意味のない癖**:伏線でも象徴でもない、ただの癖。1つ
  (全部に意味がある人物は嘘くさい)

## G|関係

- 主要人物それぞれとの関係と、それがどう変わるか
- **主人公としか繋がっていない人物がいないか**確認する

## H|引力 ── 相手と並んだときにだけ出るもの(**ロマンスでは必須**)

単体でどう魅力的かより、**相手と並んだとき、どう欠落を埋め合うか**が主役になる。
ここが空欄のロマンスは、ジャンルの機能を果たしていない。

- **相手の欠落を、この人物の何が埋めるか**
- **この人物の欠落を、相手の何が埋めるか**
- **相手と並んだときにだけ出る顔**(一人のときには見せないもの)
- **埋め合わない点**。全部が噛み合うと平板になる。**ひとつ反発を残す**

## I|「その人物だから見られる姿」← いちばん重要

属性(おっとり、クール、不器用)は、それだけでは記号の集合でしかない。

> **属性の先に「この人物だから見られる姿」があるとき、
> 単なる属性の集合ではなく、愛される一人の人物になる。**

その一場面を、先に言語化しておく。誰も見ていないところで何をしているか、が効く。

---

# 作るときの順番

1. **コンセプト3語**を決める
2. **行動原理**を一文で書く(何を見ると手が出るか)
3. Want / Need / Wound を出す
4. **シルエット**を決める(内面が決まってから。逆順にすると記号の寄せ集めになる)
5. 記号 → 細部 → 服
6. 一人称・二人称・口調
7. 癖(意味のあるもの1つ、ないもの1つ)
8. **H(引力)と I を書く**。ここが書けないなら、まだ人物になっていない

# 服を決めたら必ずやること

**行動原理と照合する。**

衛生に厳しい人物が、不衛生な服を着ていないか。
無口な人物が、目立つ服を着ていないか。
矛盾があるなら、**服を変えるか、着ている理由を作る**。理由づけが苦しいなら服を捨てる。

# 深掘りが要るとき

「好きな食べ物は?」のような平凡な質問でよい。大事なのは答えそのものではなく、
**「なぜそう答えたのか」を追うこと**。そこに無意識に決めていた過去や性格が出る。

既成の100問リストを使うなら、**自分で10問足す**。作り手の熱がそこに出る。
