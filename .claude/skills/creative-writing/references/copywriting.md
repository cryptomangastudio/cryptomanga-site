# コピー・タイトル・ログラインの作り方

企画を通す仕事は、面白い話を作る力と、**一行で掴む力**が別々に要る。ここは後者。
散文のAI臭対策は `anti-ai-tells.md` と `kindle/docs/09_脱AI文体ルール.md`(散文編)にある。
このファイルは**短い文**——タイトル・惹句・ログライン・キャラ紹介の一行——を扱う。

---

## 0. まず、3つを混ぜない

| 種類 | 目的 | 読む人 | 長さ |
|---|---|---|---|
| **タイトル** | 一目で「自分向けか」を判別させる | 読者(スクロール中) | プラットフォーム依存 |
| **キャッチコピー(惹句)** | 感情を動かす。読みたくさせる | 読者(作品ページ) | 1行 |
| **ログライン** | 構造が破綻していないことを示す | 編集・審査員 | 1〜2文 |

同じ文で全部を兼ねようとすると、どれにも効かないものができる。**先に用途を決める。**

## 1. タイトル

### 原則: タイトルはUIへの適応であって、美学ではない

日本のWeb小説でタイトルが長文化したのは、作者の趣味ではない。
スマホのランキング画面ではあらすじが折りたたまれ、クリックしないと見えない。
だから**あらすじの役割がタイトルに移った**。紙のライトノベルの時代は20字程度で足りていた。

→ **まず、その作品が並ぶ画面で何文字まで表示されるかを調べる。** そこが上限。
プラットフォームを見ずにタイトルを考えるのは順序が違う。

### 韓国ウェブトゥーン/ウェブ小説の実勢

- タイトルに**ジャンル・大まかな筋・主人公の性格**まで圧縮し、読者がタイトルだけで
  自分の好みか判断できるようにする
- **一人称・主人公視点**の文章型が没入を早める(「〜します」「〜になった」)。
  第三者が筋を説明する形より強い
- 例として挙がる型: 「継母だけど、娘が可愛すぎる」「財閥3世、天才俳優になった」

### 実務手順

1. その作品の**売り**を単語で3つ書き出す(立場・関係・仕掛け)
2. 主人公の一人称で言い直す
3. 表示可能文字数に収める
4. **20本作る**。3本で止めない

## 2. キャッチコピー(惹句)

### 順番を守る

表現から入らない。**Why(目的) → Who(誰に) → What to say(何を言うか) → How to say(どう言うか)**。
「どう言うか」から始めると、うまいだけで刺さらない文になる。

### イメージ型とセールス型は別物

- **イメージ型**: 作品の空気を伝える。ブランドを作る。抽象でよい
- **セールス型**: 読む理由を作る。具体・利得・切迫が要る

新連載の1話目に必要なのは**セールス型**。空気を伝えている場合ではない。

### 数を出す

プロは1案件に**100本**持っていくことがある。
切り口を変えて数を出し、その中から選ぶ。**1本目を採用しない**を規律にする。

## 3. ログライン

**誰が / どんな皮肉な状況で / どうなるか** の3つを1行に収める。

- 「皮肉」が入っていないものは、まだログラインではなく設定の説明
- 企画を売り込む第一声。ここで転けたら中身は読まれない
- 結末を隠さない。審査員は結末の設計力を見ている

## 4. キャラクター紹介の一行

企画書のキャラ欄は、**性格の要約を書く場所ではない**。

- ✗ 「心優しく芯の強い少女」→ 誰のことでも言える
- ◎ **その人物にしか起きない一場面**を書く

### 二段で書く
1. **具体的な一場面**(その人物の行動。読み手の頭に絵が浮かぶもの)
2. **読み手に渡す感情**(選考者が拾いやすい言葉)

①だけだと審査員が評価語に翻訳できず、②だけだと誰のことでも言える文になる。
①を先に置き、②は短く添える。

## 5. 短文のAI臭 ─ 実際に出た症状

散文のAI臭(`kindle/docs/09`)とは別の症状が出る。短い文は逃げ場がないぶん、型が露出しやすい。

### 症状1: 対句への逃避【最頻出】
「Aなのに、Bない」「Aな男と、Bな女」。一度なら効くが、**同じ構文を複数の対象に使うと即座に型が見える。**
人間の書き手が二人分のキャラ紹介を書けば、片方は熱が入って長くなり、片方は素っ気なくなる。
- **処方**: 対句は資料全体で1回まで。2つ以上並ぶときは、**片方をわざと崩して長さを変える。**

### 症状2: コピーによる自己解説
企画の狙いをコピーの中で説明してしまう。「人が読めるのに自分の望みが読めない」のような文は、
**読者が読み終えて感じること**であって、企画書で先に言うと「わかってる感」の披露になる。
- **処方**: 狙いを説明している文を消し、その狙いが生まれる**場面**に差し替える。

### 症状3: 決めゼリフの過剰配給
全部の見出し・全部の欄が決まっている。効かせたい1箇所のために、**残りを日常の言葉に沈める。**
- **処方**: 決めゼリフは1話1つまで。数えて超えていたら削る。

### 症状4: 体言止めと三点セット
「静けさ。孤独。そして、選択。」型。読点で刻む三連は型として消費済み。
3つ並んだら1つ削るか、1つだけ質を変える。

### 症状5: 分析語彙の混入
「〜という構造」「カタルシスを担保する」「関係のエンジン」「機能する」。
検討メモではよいが、**納品物に入れると評論家の文章になる**。普通の日本語に開く。

### 症状6: 抽象度が一定
全文が同じ高さで書かれている。人間は、思い入れのある箇所だけ急に細かくなる。
- **処方**: 1箇所だけ、具体的すぎるほど具体的な描写を入れる。バランスを崩す。

## 6. 提出前チェック

- [ ] タイトル・惹句・ログラインの用途を分けたか
- [ ] タイトルは表示可能文字数を調べた上で作ったか
- [ ] 案を20本以上出したか。1本目を採用していないか
- [ ] 対句が2つ以上ないか
- [ ] コピーで企画の狙いを自分で説明していないか
- [ ] 決めゼリフが1話1つに収まっているか

- [ ] 分析語彙が残っていないか
- [ ] 音読して、うますぎて空々しい箇所はないか
