# 日本語のセリフを自然にして、温度を出す

「AIっぽい」「温度を感じない」「文章としておかしい」と言われたセリフを直すときに読む。`dialogue-and-depth.md`(会話の構造・説明セリフ・厚み)の姉妹編で、こちらは**一行ごとの言葉の手触り**を扱う。

## この資料の根拠について(先に正直に書く)

- 公開されている創作論の検索では、**日本語のセリフの語尾・口語化・体言止め**を体系的に扱った資料は、ほとんど見つからなかった。見つかったのは、国立国語研究所の論文(創作会話と自然会話の差)、役割語の研究(金水敏)、公募ガイド・ブログの断片、英語圏のセリフ論(サブテキスト、バンター、ツンデレ型の気遣い表現)。
- したがって、この資料の**具体的な直し方の多くは、この企画で実際に指摘された失敗(第1話の字コンテ)を分析して作った実務ルール**であり、検証された定説ではない。使うときは、**必ず音読して確かめる**こと。

---

## 1. 日本語セリフの「おかしさ」の4種類

### 1.1 文法・語法のずれ(文章としておかしい)

書いた本人は気づきにくいが、読者は引っかかる。この企画で実際に出たもの:

| 悪い例 | 何がおかしいか | 直した例 |
|---|---|---|
| 「診なくていいから、あんたが帰るの」 | 「帰るの」は、状態の説明にも命令にも聞こえる。命令の形が曖昧 | 「診なくていいって。あんたこそ帰んなさいよ」 |
| 「それはあんたの分! 全部食べるの!」 | 「全部食べるの」は、行為の予定のように聞こえる。叱る言い方なら命令形 | 「それはあんたの! 半分こなんかしてないで、まるごと食べな」 |
| 「庶民のひと月の稼ぎでも、足りないのよ」 | 「でも」の使い方が不自然。何を比べているか不明 | 「銀貨三枚。八百屋のおじさんが、ひと月まるごと働いても届かないのよ」 |
| 「ここにいていいなら、起きなくちゃ」 | 条件の関係が逆。「いていい」は許可で、義務の理由にならない | 「ここにいていいって言われたんだ。遅刻なんて、できない」 |

**チェック方法:** 文を「主語・述語・結び」に分けて、意味が通るか確認する。命令・依頼・説明のどれなのか、文末だけで分かるか確認する。

### 1.2 整いすぎ(完結した一文の連続)

- すべてのセリフが、主語・述語が揃った完結文で、情報が過不足なく収まっている。実際の話し言葉は、**省略、倒置、言いかけ、言い直し、言いよどみ**が混ざる。
- 国立国語研究所の論文は、創作会話は自然会話から「正常な非流暢さ」(言いよどみ、言い直し)を除いて作られがちで、その分だけ整った理想的な会話になる、と指摘している。
- ただし、**言いよどみを足しすぎると読みにくくなる**。足すのは、感情が動いたセリフに限り、1場面に数か所まで。
- 直し方:
  - 主語を落とす(「あなたは疲れている」→「疲れてるでしょ」)。
  - 語順を崩す(「帰りなさいよ、もう」「いるの? まだ」)。
  - 言いかけて止める(「あんたね、……いや、いいわ」)。
  - 数や名前を、切れ目で入れる(「何人やったっけ。……数えるのやめたんだった」)。

### 1.3 役割語・語尾の過剰

- 「〜わよ」「〜のよ」「〜だわ」を連発すると、キャラが記号になる。語尾は、**感情が乗る箇所だけ**に使い、普段は断定の「〜だよ」「〜でしょ」「〜じゃない」や、語尾なしの言い切りで流す。
- 役割語(特定の人物像を連想させる言葉遣い)は、書き分けに便利だが、現実の話し方ではなく、読者のステレオタイプで機能する(金水敏)。役割語だけに頼らず、**性格や関係性から口調を決める**。
- 書き分けの手がかり(研究での整理):一人称・二人称、文末表現(終助詞、キャラ語尾、丁寧さ、断定の強さ)、感動詞、速度・なめらかさ。

### 1.4 温度がない

- 全セリフが、**正しく、きれいで、誰が言っても通る**。具体物、固有の言い回し、体の感覚、相手の癖、共有の過去がない。
- 「優しい」「心配」を言葉で宣言している(「心配してるのよ」)。
- 温度の出し方は§3。

## 2. セリフを話し言葉にする手順

1. **一文に一つの内容。** 説明を二つ詰め込まない。
2. **主語を省く。** 毎回主語を言うと、翻訳調に聞こえる。
3. **名前を呼ぶのは、感情が動くときだけ。** 毎行「ゼニア、」で始めない。
4. **「、」は呼吸の位置。** 文法上の区切りではなく、息継ぎの場所で打つ。ト書きでも、動作の連続に「、」を多用しすぎない。
5. **終助詞を使い分ける。** 「よ」(知らせる)、「ね」(確かめる)、「な」(つぶやく)、「さ」(軽く流す)、「の」(柔らかい断定・疑問)。キャラごとに、よく使うものを一つか二つに決める。
6. **発話動詞(「言った」「答えた」)に頼らない。** 誰が言ったかは、内容と行動で分かる形にする。
7. **吹き出し1つ=1〜2文。** 長いセリフは、息継ぎの位置で割り、間に動作のコマを挟む。
8. **質問への答えは、まず質問の中身。** 温度や皮肉は、そのあとに載せる(`dialogue-and-depth.md` 1.2)。

## 3. 温度を出す方法

### 3.1 気遣いは、「文句+具体的な行動」で出す

- ツンデレ型の気遣い(英語圏の解説でも、日本語の解説でも共通):**心配を、文句の形に包んで言う。そして、具体的な行動を添える。**
  - 弱い:「心配してるのよ」「無理しないで」
  - 強い:「また食べてないんでしょ。ほら、これ。……べつに、余っただけだから」
- 本心が**小さく漏れる瞬間**を作る(言い損じ、照れ、手が先に出る)。仮面が、一瞬だけ外れる。
- **きつさが強すぎると嫌われる。** 心配の文句は、怒りよりも、照れ・あきれ・ため息が伝わる形に調整する。毎回、「でも、見ているから」という証拠(相手の癖や変化を覚えている)を添える。

### 3.2 見ている証拠を入れる

- 相手のことを細かく見ていることが分かる一言は、温度の最短ルート。
  - 「さっきから、右足かばってるでしょ」
  - 「あんた、嘘つくとき、袖いじる癖あるよね」
- ゼニア側も同じ:数字は見ないが、**人のことは見ている**(右腕の震え、名前、孫の誕生)。

### 3.3 共有の歴史を匂わせる

- 内輪の言い回し、あだ名、過去の出来事への一言参照。説明はしない。読者が全部分からなくてもよい。
- 内輪ネタには、**由来**を決めておく(書かなくてよい)。

### 3.4 具体物と体の感覚

- 食べ物、匂い、温度、重さ、音。セリフの中でも、ト書きでも。
- 例:「あったかいうちに食べな」より「冷めてる。……まあ、食べられるけど」。

### 3.5 自分の弱さを少し開示する

- 完璧な人は温度が低い。ペニーなら、食い意地、怖がり、ぼやき。
- ぼやきは、**温度が高く、説明が少なく、世界観の情報を運べる**(「お給金も出ないのに、朝から晩までよ」)。

## 4. 「AIっぽい」セリフの見分け方

次のうち3つ以上当てはまったら、書き直す。

1. 全セリフが、完結した一文で、論理が通りすぎている
2. 感情を言葉で宣言している(「悲しい」「心配」「ありがたい」)
3. 一般語でまとめている(「優しい」「頑張る」「大切」)
4. 同じ語尾が3回以上続く
5. 呼びかけ(名前)が毎回ある
6. 皮肉・テーマを、セリフで自分で説明している
7. 受け答えが、毎回きれいに決まる(ツッコミが外れない)
8. 具体物・固有名詞・数字がない
9. 音読すると、息継ぎの位置が分からない
10. 他のキャラに入れ替えても通る

(`anti-ai-tells.md` の全般的な症状リストと併用する)

## 5. キャラ別の声の作り方(この企画の例)

| キャラ | 声の設計 |
|---|---|
| ゼニア(今世) | 丁寧語だが、完璧ではない。「あの、」「えっと」で始まる。謝罪が先に出る。心の声は、友達に話す素の声(「〜よね」「〜かあ」)。体の感覚で語る |
| ペニー | 下町寄りのくだけた口調。早口。言いかけ・言い直しが多い。食べ物と体の感覚の言葉が多い。ぼやく。サンクスの前では急に黙るか、敬語になる |
| サンクス | 穏やかな敬語。質問・提案の形で命令する。否定語を使わない。「〜しましょう」「〜なさい」。声は柔らかく、中身は重い |
| 母親(庶民) | 素朴な敬語。感情が先に出て、言葉が追いつかない。言いかけて止まる |

---

## 6. 直し方の手順(まとめ)

1. 全セリフを**音読**する。引っかかった箇所に印をつける。
2. 印をつけた箇所を、**4種類(文法、整いすぎ、語尾の過剰、温度)**に分類する。
3. 文法 → 語尾 → 整いすぎ → 温度の順に直す。
4. 直したあと、もう一度音読する。
5. 各セリフに「このキャラが、この場面で、この相手に言う理由があるか」を問う。
