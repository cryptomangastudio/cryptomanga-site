# 場面が死ぬ理由 ── 「情報のやり取りで、何も起きていない」の恒久対策

**この失敗を、一つの企画の中で三回やった。** 再発するので、機構を特定してルールにする。

---

## 1|実際にやった失敗

| # | 書いたもの | 何が起きていたか |
|---|---|---|
| 1 | サヤ「捨ててきたんですよ。家も、水も、全部!」 | 二人とも知っている事実の復唱。読者への説明 |
| 2 | ミナ「腹を下した者の数を教えてください」 | 記録のない世界で答えが返らない質問 |
| 3 | ミナ「子供は、何人いますか」の一連11行 | **情報の交換。誰も何も得ようとしていない** |

いずれも**「読者にこの設定を伝えなければ」という動機から生まれている。**

---

## 2|なぜそうなるのか(機構)

### 四段で悪化する

1. **設計を先に完成させる。** 世界と人物を緻密に作る。作った情報は「正しい」ので届けたくなる
2. **届ける責任を感じる。** 「これを知らないと読者が分からない」と判断する
   (この判断自体は正しいこともある。動機に関わる情報は実際に必要)
3. **説明を台詞の形に変換して、解決したと錯覚する** ← **ここが核心**
   - 地の文で説明するのは悪い、と知っている
   - だから二人に分けて喋らせる
   - **分けても講義は講義。**「説明台詞を避けた」のではなく「**説明を二人に分担させた**」だけ
4. **その場面には、他のエンジンがない。** 誰も何も欲しがっていないので、場面が動かない

### 悪化させる二つの癖

- **賢い人物に質問させ、答えを受け取り、意味ありげに黙らせる型**を使う
  → 作者が読者より賢い位置に立つ型。退屈で、しかも鼻につく
- **山場の直前に置く**。設定の仕込みが「終わった」と感じる場所がそこだから
  → **一番速度が要る場所を減速させる**

### 裏づけ(Robert McKee)

- 場面の初めと終わりで**人物の状況の価値が変わっていなければ、何も起きていない**。
  活動はあるが、価値が動いていない
- **場面に価値の転換がないなら、その正体はほぼ必ず説明である。**
  説明が場面の唯一の存在理由なら、規律ある書き手はそれを捨て、情報は別の場所に織り込む
- **説明を弾薬に変えろ。** 人物が、知っていることを**欲しいものを得るために使う**形にする

## 3|五つのテスト(書いた直後に通す)

### テストA|**ト書きテスト** ← 三秒で終わる。まずこれ

**台詞を全部消して、`【 】`だけ残す。何か起きているか。**

| | 台詞を消した残り | 判定 |
|---|---|---|
| 子供の件 | **(何もない)** | **削除** |
| 毒味の場面 | 【ボス、立ち上がる】【桶を取る】【飲み干す】【ミナを見る】 | 合格 |

**台詞オンリー稿を書く工程と完全に噛み合う。** 毎回やる。

#### ただし、例外が一つある

**ヒット作の実例で反証が出た**(『公女殿下の家庭教師』第1話)。
あの話はまるごと移動であり、台詞を消せば何も残らない。**だが面白い。**

理由は、**読者だけが知らない情報があり、登場人物は気づいていて、言わないから**。
道中ずっとズレが続き、最終行で開く。

> **追加条件:何も起きない場面が許されるのは、**
> **読者と登場人物のあいだに情報の落差があるとき。**
> **落差がなければ、やはりただの移動である。**

削除した「子供は何人いますか」には、この落差もなかった。**削除は正しい。**

#### さらに大きな例外|物語の駆動原理が違う場合

『朝起きたら探索者になっていた』(469話完結・書籍化・コミカライズ)は、
第1〜3話が**自己紹介 / 買い物 / 一体倒して400円**である。
事件も秘密も反転もない。作者自身が地の文で「何も起きないな」と書いている。

**それでも読める。快楽が物語ではなく「数字が動くこと」だから。**

| | 読者の状態 |
|---|---|
| **反転型** | **次を知らない。だから見たい**(謎・秘密・認識の反転) |
| **積み上げ型** | **次を知っている。それでも見たい**(数字が増える・階層が深くなる) |

> **テストAは反転型にしか効かない。**
> **書く前に、自分の企画がどちらの駆動原理かを決めること。**
> 一つの作品の中で、幕ごとに使い分けてもよい。

### テストB|価値の転換

**場面の頭と終わりで、人物の状況が正→負 か 負→正 に振れているか。**

- 子供の件:振れない → 削除
- 毒味:彼女の水が「毒かもしれないもの」→「頭が飲んだもの」=**承認された** → 合格

### テストC|弾薬テスト

**その情報を、誰かが何かを得るために使っているか。**
ただ渡しているだけなら、それは場面ではなく**配達**である。

- 旧「捨ててきたんですよ」:誰も何も得ようとしていない → 削除
- 新「帰る井戸もないのに、基準値出してどうするんですか!」:
  **サヤはミナを止めるためにその事実を使っている** → 合格

### テストD|隠したい人テスト

**情報が出る場面に、それを言いたくない人物が一人いるか。**
誰も隠していない情報は、交換ではなく配達になる。

### テストE|配置テスト

**山場の手前は加速だけ。説明を山場の直前に置かない。**
仕込みが終わった開放感で、一番悪い場所に置きたくなる。

---

## 4|予防の原則(書く前に効く)

> **情報は、それを使って誰かが何かをする瞬間に出す。**

| 伝えたい設定 | ×配達 | ○事件 |
|---|---|---|
| 汚い水で子供が死ぬ | 「子供は何人いますか」 | **拠点で子供が増え、副官が黙って数えている** |
| 彼は奪うことしか知らない | 「処理不能に陥っている」 | **差し出された水を、彼が黙って飲み干す** |
| 婚約は血統の割り当て | 制度の説明 | **二人が何度もしてきた口論の中で出す** |
| 彼女は自分を勘定に入れない | 独白 | **従者が水の量を問い詰め、嘘をつけずに白状する** |

---

## 5|三秒版(これだけ覚える)

> **台詞を消しても、何か起きているか。**
> **起きていないなら、それは場面ではなく、設計図の配達である。**
