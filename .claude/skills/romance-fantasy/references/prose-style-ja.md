# 日本語ロマファンの文体・口調・呼称・表記

`creative-writing/prose-and-dialogue.md`(視点の固定、Show don't tell、サブテキスト、リズム)の一般技術を前提に、このジャンルの日本語本文で判断に迷う点を扱う。

## 1. 人称と視点

### 一人称(私/わたくし)

令嬢ものの主流の一つ。**外面の言葉と内心の言葉のギャップ**がこのジャンルの大きな武器になる。

- 転生令嬢(中身が現代人):台詞は「ごきげんよう」、地の文の内心は「うわ、来た」。この落差がコメディの源になる。ただし内心を全部ネットスラングにすると安っぽくなる。現代語は使ってよいが、崩しすぎない。
- 非転生の令嬢:内心も、その世界で育った人間の語彙にする。現代の若者言葉は使わない。内心の方が台詞より少しだけ率直、くらいの距離感。
- 地の文の一人称は「私」が読みやすい。台詞で「わたくし」を使うキャラでも、地の文では「私」にする作品が多い(作品内で統一する)。

### 三人称一元+男主人公視点の挿入

章の間に「side ○○」「◆」などで男主人公視点の短い話を挟む構成は、このジャンルの定番。

- 効果:ヒロインが知らない男主人公の本心(溺愛・後悔・独占欲)を**読者にだけ**見せる。ヒロインが「どうせ契約だから」と思い込んでいる横で、読者は答えを知っている——このズレ自体が甘さになる。
- 注意:男主人公視点は短めにする。本編で積み上げている緊張を、答え合わせで全部解消しない。本心をすべて明かさず、「彼にも言えない事情がある」ことを匂わせる程度にとどめる回を混ぜる。
- 視点の切り替えは必ず記号か改章で明示する。同一場面内で視点を滑らせない。

## 2. 口調と役割語

**口調の差がそのままキャラの差になる。**全員が同じ敬語の水準で話すと、誰が話しているかわからなくなり、AIっぽさも増す。

### お嬢様言葉の濃さを調整する

- 「〜ですわ」の連打は、読者が違和感を持つ代表例。お嬢様言葉の源流とされる山の手言葉には、「〜ですの」「〜かしら」「〜てよ」「〜ですこと」「ごきげんよう」「存じませんわ」など語尾の種類が多い。散らす。
- 「ありがとうございますわ」「おはようございますわ」は不自然に聞こえやすい。「ございます」の後にさらに「わ」を付けない方が自然。
- **公的な場では濃く、私的な場では薄く**。気を許した相手の前で語尾が崩れる、感情が高ぶって地が出る——崩れた瞬間が本音の記号になる。
- 全員に「ですわ」を使わせない。お嬢様言葉を使うのは主人公だけ/悪役令嬢だけ、など役割を絞ると、口調で人物が立つ。

### その他の人物

- 男主人公:断定調(「〜だ」「〜か」)が基本。王族の「余」は強い記号なので使うなら意図的に。無口型は台詞を短く、語尾より間(沈黙)で人物を出す。
- 騎士:丁寧だが軍人口調。「〜であります」は現代の軍隊っぽさが強いので使いどころを選ぶ。
- 使用人・侍女:丁寧語+呼称(お嬢様/奥様/旦那様)。ベテランの侍女頭と新人の侍女で語彙を変えると生活感が出る。
- 加害者側(継母・異母妹・元婚約者):口調で悪役だと分かるほど記号的にしない。表向きは丁寧で、言葉の選び方に棘がある方が怖い。

## 3. 敬称と呼称

### 敬称の目安(Web小説で一般的な使い分け)

| 敬称 | 対象 |
|---|---|
| 陛下 | 国王・皇帝とその配偶者 |
| 殿下 | 王子・王女などの王族(王族出身の公爵を含むことがある) |
| 閣下 | 大臣・将軍・大使など高位の役職者、高位の貴族当主 |
| 猊下 | 高位の聖職者(教皇・大司教など) |
| 卿 | 騎士、および貴族男性 |
| 様/嬢/夫人 | 一般的な敬称。「◯◯嬢」は未婚の令嬢、「◯◯夫人」は既婚女性 |

貴族当主同士では、格上には「爵位+閣下」、同格以下には「殿」を使う、といった作品内ルールを決めておくと揃う。**史実どおりである必要はないが、作品内では必ず一貫させる。**キャラクターバイブルに「誰が誰をどう呼ぶか」の表を作っておく。

### 呼び方の変化は関係の節目

「カッセル伯爵令嬢」→「カッセル嬢」→「イルゼ嬢」→「イルゼ」→愛称、という呼び方の変化は、告白や口づけに次ぐ強い進展の記号になる。

- 変化の瞬間を一度だけ意識して描く(呼ばれた側が気づく、一拍遅れて反応する)。
- 一度変えた呼び方を理由なく戻さない。戻すなら、それ自体を事件として書く(喧嘩・公の場での使い分け)。

## 4. 世界観と語彙の整合

- **外来語・現代語**:転生ヒロインの内心なら現代語はむしろ個性になる。一方、異世界の住人の台詞や三人称の地の文では、「ストレス」「メリット」「プライベート」「オッケー」などは避ける。ただし「分」「時間」などの単位まで異世界語に置き換える必要はない(読みにくくなるだけ)。どこまで許すかを作品ごとに決める。
- **比喩の出どころ**:その世界に存在しないもの(電車・写真・スマホ・映画)で比喩しない。転生者の内心は例外だが、多用すると世界への没入が切れる。
- **手触りの語彙**:1場面に1つ、身体に触れるものを入れると実在感が出る——コルセットの締め付け、手袋を外す指、扇の骨の音、ドレスの裾が踏まれる感触、燭台の蝋の匂い、馬車の揺れ、封蝋の割れる音、紅茶が冷めていく時間。詰め込むとカタログになるので、1つずつ。
- **時代考証の程度**:厳密な中世ヨーロッパの再現は不要だが、作品内の贅沢の水準(砂糖・入浴・ガラス窓・紙)は揃える。ある場面で庶民が気軽に砂糖を使い、別の場面で砂糖が貴重品、という揺れは読者に気づかれる。

## 5. Web小説の表記とレイアウト

- 三点リーダーは「……」(2つ重ね)、ダッシュは「——」(2つ重ね)が一般的な作法。
- 「!」「?」の後に文が続くときは全角スペースを1つ空ける(「えっ!? 今なんと」)。閉じ括弧の直前には入れない。
- 段落頭の字下げ:なろう系では字下げしない作品も多いが、書籍化を想定するなら字下げする。作品内で統一する。
- 横書きのスマホで読まれる前提で、段落は短め、会話の前後に空行を入れることが多い。ただし空行だらけで地の文が痩せると状況が見えなくなる。
- 形式名詞・補助動詞はひらがなに開くのが一般的(こと/もの/とき/〜ていく/〜てくる)。作品内で統一する。
- ルビ(なろう形式:`|漢字《かんじ》`)は固有名詞・造語の初出に使う。多用しない。

## 6. 地の文とセリフのバランス

- Web小説は会話の比率が高い。ただし台詞だけのラリーを長く続けると、誰がどこで何をしているか見えなくなる。3〜5往復に1回は、地の文で仕草・周囲の反応・内心を挟んで「間」を作る。
- 令嬢もののコメディでは、内心のツッコミ(地の文)がテンポを作る。台詞(外面)→内心(本音)→台詞、の交互運動が基本のリズム。
- 退屈な移動・準備・手続きは大胆に飛ばす(「三日後。」の一行でよい)。全場面を同じ密度で書くのは、人間の書き手はやらない。
