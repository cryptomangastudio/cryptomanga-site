# ロマファン特有のAI臭を抜く

**前提**:`creative-writing/anti-ai-tells.md` を先に読んでいること。あちらの一般原則(過剰な対称性、意味の過剰、決めゼリフ過多、メタ語彙、AI頻出圏の名前、テーマの自己解説、感情の平均値化、リスト化の過剰整形)は、このジャンルでも当然すべて適用される。ここでは**このジャンルだからこそ起きやすい固有の症状**だけを追加する。

## ロマファン特有のAI臭リスト

1. **執着・溺愛セリフのテンプレ配給過多**:「お前は俺のものだ」「絶対に離さない」のような決め台詞を、ほぼ毎話・複数キャラで反復させる。人間の書き手は、キャラごとに愛情表現の語彙・沈黙の使い方を変える。同じ言い回しが別の男主人公からも出てくると、キャラの区別がつかず量産感が強まる。
2. **心理描写の均質化**:ヒロインが驚いたとき・照れたとき・怒ったときの反応がテンプレ通り(「頬が熱くなるのを感じた」「心臓が跳ねた」)で、どのヒロインも同じ驚き方をする。実在の人物は同じ感情でも表出の仕方が偏っていて一貫性がない(照れると早口になる/黙り込む/関係ない話を始める、など個体差をつける)。
3. **爵位・名前のテンプレ量産感**:「レオンハルト」「エリザベート」「ヴィオレット」のような、いかにもロマファン的な西洋風の名前を無批判に並べると、既視感の塊になる。名づけには一段の固有性(その家門の由来、時代・地域による偏り、あだ名の存在)を混ぜる。爵位・領地名も、地理・歴史との整合を1つだけでも仕込むと実在感が出る。
4. **対比構造が綺麗すぎる**:悪役令嬢とヒロイン(聖女)、暴君の顔と素顔、身分の高さと孤独、といった対比があまりに整いすぎて図式的になる。片方の対比要素をわざと歪ませる(聖女にも打算がある、悪役令嬢にも本当に意地悪な瞬間が1つある、など)。
5. **感情描写の紋切り型比喩の多用**:「胸が締め付けられるように痛んだ」「心臓が高鳴った」「頭が真っ白になった」といった、ジャンル内で使い古された比喩をそのまま使う。1シーンにつき1箇所だけ、その主人公固有の身体感覚・記憶に紐づいた具体的な比喩に置き換える。
6. **회빙환の内的独白の反復**:「生き延びなければ」「今度こそ後悔しないように」のようなモノローグが、話をまたいでほぼ同じ文言で繰り返される。同じ決意でも、状況ごとに違う角度・違う言葉で表現し直す。
7. **専門知識の底が浅い**:未来知識で流行や商売を仕掛ける展開で、「なぜかそれっぽく成功する」だけで具体的な手順・障壁・失敗の可能性が描かれない。実際の商売・技術には必ず固有の手間とコストがある——そこを1つでも書き込むと嘘くささが消える(`creative-writing/anti-ai-tells.md`の「固有の解像度で嘘をつく」の応用)。
8. **決着のさせ方が予定調和すぎる**:断罪・ざまぁの場面で、加害者側の反応・崩れ方が判で押したように同じパターン(絶叫して膝から崩れ落ちる、など)になる。加害者にもキャラごとの違う崩れ方(開き直る/黙り込む/言い訳を重ねる)を用意する。

## 処方(ロマファン版)

- **決めゼリフの配給制を男主人公にも適用する**:1人の男主人公につき「効かせたい決め台詞」は物語全体で1〜2箇所までとし、それ以外の愛情表現は言いよどみ・不器用な行動・沈黙に置き換える。
- **心理描写に個体差の「クセ」を1つずつ与える**:感情が高ぶったときにキャラごとに違う行動パターン(貧乏ゆすり、早口になる、視線をそらす、関係ない話をし出す)を1つ設定し、感情描写のたびにそこへ立ち返る。
- **固有名詞は「実在の由来」を仮でもいいので考えてから使う**:名前・領地名・爵位を決めるとき、なぜその名前なのか(家系・地方色・親の願い)を一言でも想像してから使う。全キャラに均等な労力をかける必要はない——主要人物1〜2人にだけ濃くやるので十分。
- **専門性の解像度を1箇所だけ深く掘る**:流行や商売の挿話を書くなら、その業界・技術の具体的な障壁やコストを最低1つ、取材した風の固有性で書く(事実確認が必要な場合はその旨を注記する)。
- **対比構造を1箇所だけ歪める**:綺麗に対になっている人物・場面のペアを見つけたら、片方だけ意図的にズラす(善玉に見える聖女に小さなエゴを1つ持たせる、悪役令嬢に本物の悪意の瞬間を1つ持たせる)。

## セルフチェックリスト(ロマファン版・納品前に一周)

- [ ] `creative-writing/anti-ai-tells.md` の一般チェックリストを一周したか
- [ ] 男主人公の決めゼリフは配給制(全体で1〜2箇所)を守っているか
- [ ] ヒロイン/女性キャラの感情表現が全員同じ紋切り型比喩に頼っていないか
- [ ] 名前・爵位・領地名に、最低1人分でも固有の由来を想像したか
- [ ] 회빙환の内的独白(「生き延びなければ」等)が話をまたいで同じ文言の繰り返しになっていないか

- [ ] 断罪・ざまぁの場面で、加害者の崩れ方がテンプレ通りになっていないか
- [ ] 綺麗に対になりすぎているキャラ・場面のペアを、どこか1箇所歪めたか
