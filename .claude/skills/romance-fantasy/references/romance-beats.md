# 恋愛の感情曲線と第1話の型

`creative-writing/story-structure.md` の三幕構成は外側の事件の骨組み。ロマンスでは、それとは別に**二人の関係の曲線**を引き、外側の事件をそこへ編み込む(逆ではない)。ここでは欧米ロマンスの定番構成論を土台に、日本の異世界恋愛向けに調整した型を示す。

## 下敷き:Romancing the Beat(Gwen Hayes)

欧米ロマンス作家に広く使われる構成論。4フェーズ・20ビートで、恋の始まりから結ばれるまでの感情の段階を並べる。

1. **出会いと設定**:主人公①の紹介/主人公②の紹介/出会い(Meet Cute)/「ありえない」その1(惹かれない理由)/**離れられない状況**(Adhesion:二人を一緒にいさせる外的な縛り)
2. **恋に落ちる**:「ありえない」その2/惹かれの兆し/深まる惹かれ/「うまくいくかも」/**恋の中間点**(初めて本当に心が通う、または関係が一段進む)
3. **恋から退く**:疑いの兆し/深まる疑い/退却/心の防御/**決裂**
4. **恋のために戦う**:魂の暗夜/目覚め(何が本当に大事か気づく)/**大いなる行動**(Grand Gesture)/心からの結びつき/エピローグ

使いどころ:Adhesion(離れられない状況)と中間点、決裂、大いなる行動の4点を先に決めると、恋愛の芯がぶれない。

## 日本の異世界恋愛向けの調整

欧米型をそのまま当てると、日本の女性向けWeb小説では合わない箇所がある。

### 1. 溺愛ものでは「ありえない」は女性側にだけある

溺愛ものの男主人公は、早い段階(第1章内)で好意を示すのが主流。「彼が振り向くか」の緊張は使わない。代わりに「ありえない」はヒロイン側の内面に置く:

- 「私なんかが」(ドアマット系の自己評価の低さ)
- 「これは契約だから」「演技に決まっている」(契約結婚・偽装婚約)
- 「原作では彼は聖女と結ばれる」(悪役令嬢転生の原作知識)

恋愛の曲線は「距離が縮まる」より「**ヒロインが受け取れるようになる**」曲線として引く。

### 2. 「決裂」は外圧に置き換える

読者はストレスに敏感で、二人が本気で仲違いする長い区間を嫌う。第3フェーズは、二人の間の決裂よりも**外からの圧力**で作る方が主流:

- 元の家族・元婚約者が連れ戻しに来る/復縁を迫る
- 陰謀・冤罪で引き離される
- ヒロインが「彼の立場のために」自分から身を引こうとする(自己評価の低さの再燃)

誤解やすれ違いを使うなら、**「話せば解けるのに話せない理由」**(立場・契約の条項・呪い・第三者の妨害)を必ず用意し、長くても3〜4話以内で解く。「言えばいいのに」と思われた時点で読者は離れる。

### 3. 「大いなる行動」と「ざまぁ」は同じ場面で重ねる

日本の異世界恋愛の終盤の定石は、**公の場(夜会・裁判・謁見)で男主人公がヒロインを選び、守り、同時に加害者側の不正が暴かれる**場面。Grand Gestureとざまぁを1つの場面に束ねると、恋愛のカタルシスと逆転のカタルシスが同時に来る。ここで重要なのは、ヒロイン自身も一言でいいから自分の言葉で加害者に向き合うこと(守られるだけで終わらせない)。

### 4. エピローグは長めでよい

結ばれた後の甘い日常・後日談は、読者にとっての報酬。欧米型より長めに取ってよく、番外編として別枠で書き足されることも多い。

## 書籍1巻(約10万字/約33話)への配置例

| 区間 | 話数の目安 | 関係の段階 | 外側の事件の例(ドアマット×白い結婚の場合) |
|---|---|---|---|
| 第1フェーズ | 1〜5話 | 出会い・離れられない状況 | 家を追われるように嫁がされる/「愛するつもりはない」宣言/屋敷での生活開始 |
| 第2フェーズ | 6〜16話 | 惹かれの兆し→中間点 | 屋敷の問題を彼女の知識で解決/夫が彼女の有能さと人柄に気づく/初めて本音で話す夜(中間点) |
| 第3フェーズ | 17〜25話 | 外圧・退却 | 実家が彼女を連れ戻そうとする/彼女は夫の迷惑になるまいと離縁を申し出る |
| 第4フェーズ | 26〜31話 | 大いなる行動・結びつき | 夜会で夫が公に彼女を選ぶ+実家の不正が暴かれる/彼女が自分の言葉で実家と決別 |
| エピローグ | 32〜33話 | 報酬 | 白い結婚の終わり(=本当の夫婦へ)/穏やかな後日談 |

比率は目安。第1フェーズを長く取りすぎない(第1話の時点で「離れられない状況」の入口まで来ているのが理想)。

## 甘さの配分:関係の段階を1段ずつ上る

恋愛の進展は段階を踏むほど効く。段階を理由なく飛ばすと、甘さが安くなる。

視線が合う → 気遣いに気づく → **呼び方が変わる** → 手が触れる → かばわれる/守られる → 本音を話す → 抱きしめる → 想いを告げる → 口づけ

- **毎話、最低1ミリは進める**(`creative-writing/genre-playbook.md` のラブコメの原則と同じ)。事件回・説明回でも、二人の間の小さな変化を1つ入れる。
- 呼び方の変化は、関係の節目として非常に強い記号になる(`prose-style-ja.md` の呼称の項参照)。
- 一番大きな段階(告白・口づけ)は、それぞれ作品全体で1回ずつ、最も効く位置に置く。

## 第1話の型

第1話(約3,000〜5,000字)で最低限やること:**ヒロインの「声」(地の文の人格)を確立する/不遇を1場面で見せる/転機を起こす/男主人公を登場させる(顔見せだけでもよい)/引きで終える**。

### 型A:断罪・婚約破棄の場面から入る

もっとも一般的。冒頭300字以内に宣言を置く。

- 0〜500字:宣言と衆目
- 500〜1,500字:**ヒロインの反応**。ここで作品の個性が決まる。泣く/怒るという予想通りの反応ではなく、その人らしいズレた反応を書く
- 1,500〜2,500字:退出、または男主人公の介入
- 2,500字〜:引き(求婚/意外な申し出/記憶の覚醒など)

### 型B:虐げの日常の一場面 → 転機

ドアマット系。虐げは**1つの象徴的な場面**で見せる(長く続けない)。食卓に彼女の席だけない、妹の誕生日の飾り付けを徹夜でやらされた翌朝に自分の誕生日を誰も覚えていない、など。第1話の後半で必ず転機(縁談・追放)まで行く。

### 型C:前世の記憶が戻る

悪役令嬢転生の定番だが、最も使い古されている。覚醒(頭を打つ/熱を出す)の場面は短く済ませ、**覚醒後の最初の選択**を早く見せる。「ここは乙女ゲームの世界で……」という状況説明を長々と地の文で続けない。説明は必要になった場面で小出しにする。

### 型D:契約の場面から入る

白い結婚・契約結婚。「君を愛するつもりはない」の宣言、または契約書への署名の場面から入る。宣言に対するヒロインの返しが作品の声を決める(型Aと同じ)。

### どの型でも避けること

- 目覚め・天気・世界観の説明から入る
- ヒロインの容姿の説明(鏡を見て自分の姿を描写する、など)を第1話の前半に置く
- 第1話の最後を「——これが、すべての始まりだった。」のような総括の一文で閉じる(`human-voice-for-ro-fan.md` 参照)
