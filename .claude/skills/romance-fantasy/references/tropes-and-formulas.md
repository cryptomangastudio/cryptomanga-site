# 王道トロープと構造

`creative-writing/genre-playbook.md` の大原則(「予想は裏切り、期待は裏切らない」「基本は満たしつつ1〜2点だけ外す」)をこのジャンルの語彙で具体化する。

## 회빙환:先読み優位性の設計

회귀(回帰)・빙의(憑依)・환생(換生)はいずれも「主人公だけがこの先の展開を知っている」状態を作る装置。仕組みの違いと使い分け:

- **회귀(回帰)**:同一人物が同じ人生をやり直す。読者への説得力は「前回の人生で何を失敗し、何を悔いていたか」の解像度に依存する。処刑ループ(処刑される直前で時間が巻き戻る)は回帰の中でも特に人気の高い変奏。
- **빙의(憑依)**:現代人の意識が、自分が読んでいた小説・プレイしていた乙女ゲームの中の脇役(多くは悪役令嬢)に入り込む。「原作知識」というチート情報を持つ代わりに、身体・立場・人間関係は他人のもの。ギャップ(中身は現代人、器は貴族令嬢)がコメディと緊張の両方の資源になる。
- **환생(換生/転生)**:死後、別の世界・別人として生まれ変わる。前世の記憶をいつ・どう思い出すかが構成上の分岐点になる(幼少期から/婚約破棄の瞬間に/など)。

**設計原則**:先読み優位性そのものは前提条件にすぎない。「なぜこの運命だけは変えたいのか」という主人公の切実さと、「知っているのに変えられない/知っているからこそ選べる」というジレンマを必ず用意する。ただの答え合わせゲームにしない。

### エピソード単位の定番パターン(頻出だが要注意)

- **流行の先取り**:未来知識でファッション・商売・技術の流行を先読みし、名声や資金を得る挿話。使い古されているため、専門性の解像度(具体的にどんな技術・商材か)で差別化しないと既視感が強い。
- **「生存」というモノローグ**:憑依直後のヒロインが独白で繰り返す生存戦略への言及。使いすぎると内面描写が単調化する(`human-voice-for-ro-fan.md` 参照)。
- **「男主人公(攻略対象)だけは避けよう」という決意とその崩壊**:意図的に距離を取ろうとするほど関係が深まる、というロマンスの基本メカニズム。この決意の理由づけが薄いと、単なる様式のなぞりになる。

## 悪役令嬢もの:基本フォーマットと変奏

基本形:前世の記憶(または原作知識)を思い出した主人公が、自分が乙女ゲーム/小説内の「悪役令嬢」であることに気づき、原作通りの破滅(処刑・断罪・追放・婚約破棄)を回避すべく行動する。行動していくうちに、原作にはなかった人間関係・展開が生まれる。

- **変奏の軸**:①どの段階で気づくか(幼少期/断罪の瞬間/処刑直前)、②回避の手段(実力で覆す/退場して距離を置く/原作のヒロインを助けて信頼を得る)、③原作のヒロイン・攻略対象との関係(敵対のまま/協力関係に転換/恋愛対象にすり替わる)。
- **外し方の例**(genre-playbook.md の大原則に基づく):「破滅を回避すること」自体をゴールにせず、回避した先で主人公が何を望むようになるか(自己実現・専門性の追求・新しい人間関係)に着地させる。断罪回避後の「その後」を丁寧に描く作品は差別化になりやすい。

## 婚約破棄 → 偽装婚約/契約結婚のチェーン

頻出の連鎖構造:①婚約破棄される(または自ら破棄する)→②何らかの事情で別の相手と偽装婚約・契約結婚を結ぶ→③打算の関係から本物の感情が生まれる。

- **婚約破棄の質**:「誤解」による破棄より、「価値観・立場の本質的な衝突」による破棄の方が、その後の関係修復にドラマが生まれる(genre-playbook.mdの少女マンガ系の注意点と共通)。
- **偽装/契約婚約の駆動力**:利害が一致する明確な理由(政治的必要・呪いを解く条件・爵位存続の条件など)を先に固める。理由が曖昧だと「なぜ結婚しているのか」がぼやけ、関係性の緊張が薄まる。
- **感情が生まれる転換点**:打算だったはずの関係が変わる「きっかけの場面」は1つに絞り、そこに至る伏線(小さな気遣い・意外な素顔の目撃)を複数話に薄く仕込む。

## ざまぁ/追放:カタルシス構造の設計原則

「ざまぁ」(加害者への報復・自業自得の描写)と「追放」(不当に組織を追われた主人公が新天地で正しく評価される)は、抑圧された不満の解消というカタルシスの基本形。

- **カタルシスの強度は「抑圧の大きさ×解放の落差」で決まる**。不当な扱いの理不尽さを十分に描かないまま報復だけ描くと、カタルシスが薄い。
- **加害者側の自滅には「組織的・構造的な必然性」を用意する**。加害者を単に愚かに描くと安っぽく見える。なぜ主人公の価値に誰も気づけなかったのか(評価基準の歪み・情報の非対称性・利害関係)を設計しておくと、自滅が説得力を持つ。
- **「追放されて去ること自体が最大の報復」という型**は、主人公が積極的に復讐を計画しない分、後味がクリーンになりやすく、悪役令嬢もの・キャラクターの気品を保ちたい企画と相性がよい。
- **溜め(ストレス)と解放(カタルシス)の間隔**:`genre-playbook.md`の異世界転生ものの注意点と同様、理不尽な展開を長引かせすぎない。特にロマファン読者は「ストレスの少なさ」への感度が高い傾向がある。

## ドアマットヒロイン/虐げられ令嬢

家族(継母・異母妹が定番)や婚約者に長年踏みつけられてきた令嬢が、ある転機(婚約破棄・家からの放逐・政略結婚の押し付け)で外へ出され、そこで初めて正当に扱われ、溺愛される。

- **読者が受け取っているもの**:恋愛のときめき以上に「**自分の価値を認めてもらえる**」ことの回復。男主人公の溺愛は、その承認を届ける手段という側面が強い。
- **構造の核心**:恋の障害は「彼が振り向くか」ではなく、「彼女が自分は愛されてよいと信じられるか」。男主人公は序盤から好意を示してよい(むしろ示す方が主流)。緊張は彼女の自己評価の低さと、過去の加害者の再接近から生まれる。
- **虐げパートの長さ**:冒頭で虐げを長々と描くと離脱される。第1話の中で「虐げの日常」→「転機」まで到達させるのが安全。虐げの具体性は、量ではなく**1つの象徴的な場面の鋭さ**で出す(食事の席に彼女の皿だけない、など)。
- **注意**:ヒロインが最後まで受け身のままだと、救済が他人任せに見える。救い出された後、彼女自身が一度は自分の意志で何かを拒否する/選ぶ場面を必ず置く。『ドアマットヒロインは速攻終了いたします!』のように、型そのものをメタに崩す作品も出ている。

## 白い結婚

「夫婦間に肉体関係のない結婚」を指す。契約結婚と重なることが多いが軸が違う。契約結婚=**結婚の目的と期限**の話、白い結婚=**関係の中身**の話。

- 定番の型:「君を愛するつもりはない」と初夜に宣言される→形式上の妻として淡々と役目をこなす→夫が彼女の有能さ・人柄に気づいて態度を変えるが、彼女の方はもう期待していない(後悔男との組み合わせ)。
- 「白い結婚が一定期間続けば離縁できる」という架空の法制度を置く作品も多い。**離縁までの期限=作品全体の時計**になり、緊張を作りやすい。
- 夫側の「愛するつもりはない」宣言の理由(別に想い人がいる/呪い/過去の裏切り)が薄いと、ただの無礼な男になる。宣言の理由は物語の中盤で反転させる材料として取っておく。

## 聖女追放/偽聖女

「偽物の聖女」とされて(あるいは新しい聖女の登場で用済みとされて)国や神殿から追放された主人公が、隣国などで本来の力を正当に評価される。追放した側は、彼女が陰で担っていた役割(結界の維持など)を失って困窮する。

- ざまぁの型としては「去ること自体が報復」の典型。主人公に復讐心がない方が後味がよくなる。
- 追放した側の崩壊は、**主人公の不在が具体的にどの仕組みを止めたのか**を描くと説得力が出る(結界が薄れる→魔物が出る→物流が止まる、のように連鎖で)。

## 身代わり花嫁

姉・妹・主人の代わりに、恐ろしいと噂の相手(冷酷公爵・呪われた辺境伯など)へ嫁がされる。噂と実像のギャップ、正体露見の緊張の2つが駆動力。露見のタイミングは中盤の大きな山場に置くのが定石。

## 組み合わせ設計のチェックリスト

新規プロットを立てるときは、以下を1つずつ明確に言語化できるか確認する:

- [ ] 先読み優位性(회빙환)の種類と、それが機能する具体的な仕組み
- [ ] 主人公が変えたい運命は何で、なぜそれが「変えたい」ほど切実なのか
- [ ] 婚約破棄/契約結婚を使うなら、その契約が成立する具体的な利害関係
- [ ] ざまぁ/追放を使うなら、加害者側が自滅する構造的な必然性
- [ ] このジャンルの代表的な型のうち、どの1点をあえて外して差別化するか(`genre-deep-dive.md` の市場動向も参照)
