# romance-fantasy スキルの使い方(コピペ用)

別のセッションで、下のプロンプトの `【】` の部分だけ書き換えて貼り付ける。

## 前提:スキルが見えているか

このスキルが `main` ブランチにマージ済みなら、cryptomanga-site リポジトリで開いた新しいセッションは自動的にこのスキルを認識する。プロンプトの冒頭に `/romance-fantasy` と書けば確実に呼び出せる。

**まだマージしていない場合**は、どのプロンプトの先頭にも次の1行を足す:

```
まず git fetch origin claude/blissful-goodall-we5b73 を実行し、git checkout origin/claude/blissful-goodall-we5b73 -- .claude/skills/romance-fantasy .claude/skills/creative-writing でスキルを取り込んでから、.claude/skills/romance-fantasy/SKILL.md を読んで作業して。
```

---

## 1. 新作の長編を一から書く

```
/romance-fantasy
ロマンスファンタジーの長編を一から書いてほしい。
references/independent-writing-workflow.md の手順どおりに進めて。

- 作品フォルダ: novels/【作品名】/
- 想定媒体: 【なろう異世界恋愛の連載/書籍1巻分(約10万字)/短編】
- 使いたい型: 【例:白い結婚×ドアマットヒロイン/おまかせ】
- 入れたい要素・避けたい要素: 【例:ヒロインは薬師、ざまぁは控えめ/特になし】

Step 1〜4(企画・キャラ・世界観・プロット)ができたら、いったん見せて止まって。
OKを出したら第1話から書き始めて。1話書くごとに .claude/skills/romance-fantasy/scripts/ai_tell_scan.py を回して、
04_進捗メモ.md を更新し、コミットしてプッシュして。
```

## 2. 前のセッションの続きを書く

```
/romance-fantasy
novels/【作品名】/ の続きを書いて。
まず 04_進捗メモ.md、01_キャラクター.md(呼称表)、03_プロット.md を読んでから、
第【◯】話から第【◯】話まで書いて。
1話ごとに .claude/skills/romance-fantasy/scripts/ai_tell_scan.py で確認し、04_進捗メモ.md を更新して、コミットしてプッシュして。
```

## 3. 短編を1本書く(企画のテストにも使える)

```
/romance-fantasy
なろう異世界恋愛向けの短編を1本書いて(【8,000〜12,000】字くらい)。
型は【例:婚約破棄の場面から始まる/おまかせ】。
references/romance-beats.md の第1話の型と、references/sample-scenes.md を読んでから書くこと。
タイトル案3つとあらすじ(200〜300字)もつけて。
保存先は novels/【作品名】/本文/短編.md。書き終えたら .claude/skills/romance-fantasy/scripts/ai_tell_scan.py を回して、
要確認の箇所を直してからコミットしてプッシュして。
```

## 4. 既存の原稿のAIっぽさを抜く

```
/romance-fantasy
【ファイルのパス】の原稿を、references/human-voice-for-ro-fan.md と references/sample-scenes.md の基準で推敲して。
先に .claude/skills/romance-fantasy/scripts/ai_tell_scan.py を回して結果を見せ、そのあと直した版を同じファイルに上書きして。
何をどう直したかを、主な箇所だけ箇条書きで教えて。
```

## 5. 企画だけ相談する

```
/romance-fantasy
ロマンスファンタジーの企画を【3】案出して。
各案に、ログライン・型・男女主人公のアーキタイプ・差別化ポイント(1つ)・タイトル案・あらすじ(200字)をつけて。
本文はまだ書かなくていい。
```
