# 真相と手がかりの設計

## 真相から逆算する

- **先に推理で導く答えを作り、その答えにたどり着けるヒントを考える**
- 次に、**そのヒントだけでは他の可能性を否定できないかを考え、その可能性も潰せるヒントを追加していく**
- 「なんとなく犯人が分かった」では読者は納得しない。どの情報・証拠から、どう推理したかを段階を追って示す

出典：[インディーズ小説家マニュアル 名推理シーンの作り方](https://ganap-akira1.com/syousetsukouza/syousetsu-mystery008/)、[専門学校デジタルアーツ東京](https://www.dat.ac.jp/course/novels/become_novelist/writemystery/)

### 設計表（本文を書く前に作る）

| 項目 | 書くこと |
|---|---|
| 真相 | 1文で |
| 推理の筋道 | 手がかりA＋B → 結論 |
| 手がかり | 各手がかりを、何話のどの場面で、どう見せるか |
| 潰す可能性 | 真相以外にありうる答えと、それを消す手がかり |
| ミスリード | 読者を誤らせる情報と、その本当の理由 |
| 動機 | なぜそうしたか。序盤のどこに痛みの種を置くか |

## 手がかりの隠し方

**大原則：隠さずに見せる。ただし目立たせない。**
手がかりを最初から目の見える場所に置き、1〜2回さりげなく触れて、探偵と読者が意味に気づくまで背景に置いておく。

| 技法 | やり方 |
|---|---|
| 目の前に置く | さりげなく1〜2回触れ、背景に置いたままにする |
| 並べて埋める | 物の列挙の中に入れる（「机には書類の束、飲みかけの湯呑み、ペーパーナイフ、ペンが三本、枯れかけた鉢」） |
| 挟む | 手がかりを、より派手な情報2つの間に置く。読者は派手なほうを覚え、手がかりは読み流す |
| 感情で覆う | 強い感情が場面を満たすと細部は消える。そこに手がかりを滑り込ませる |
| 生活に溶かす | 説明で強調せず、人物がその手がかりを「使って暮らす」場面にする |
| 文の主題を変える | 手がかりが入っている文の主題を別のことにし、手がかりは添えるだけにする |
| 目立つ情報の直後に置く | 読者の注意が前の情報に向いている間に置く |

出典：[The Write Practice](https://thewritepractice.com/mystery-clues/)、[Career Authors](https://careerauthors.com/how-to-bury-clues-in-your-mystery-novel/)、[Writing Academy](https://blog.writingacademy.com/the-best-place-to-hide-a-clue-is-in-plain-sight/)、`creative-writing/references/genre-playbook.md`

### 心理的な盲点（チェスタトンの逆説）
- 「落葉を隠すなら森」「最も目にしているものこそ見えない」
- 短編「見えない男」の犯人は、**見えないことにされている人物**（心理的に視界から外れている人）
- 人の思い込みを突く心理トリック。**物理的な仕掛けや専門知識が要らない**ので、当社の方針（専門性を濁す）と相性が良い

出典：[BOOKSとらじ ブラウン神父の童心](https://books-toraji.com/entry/chesterton1-1/theinnocenceoffatherbrown)、[蒼ざめた犬](https://kamiyamautou.hatenablog.com/entry/2022/08/14/132332)

→ 大正ものでは、女中・書生・出入りの職人など「いて当たり前で、誰も見ていない人」が、この盲点になる（仮説）。**小春自身も、世間から見えていない職人である。**

## ミスリード（レッドヘリング）

- 読者（や人物）を、大事な真実から逸らす情報
- **地の文で嘘をつくのはアンフェアなので、心理的な誘導で読者を誤らせる**
- **疑わしく見せたものには、必ず本当の理由を用意する。** 疑われる根拠は現実のものでなければならない

出典：[Story Grid Red Herrings](https://storygrid.com/red-herrings/)、[Koubo ミステリーの技法](https://note.com/kouboguide/n/na48806ce31b0)

### ミスリードの型（当社で使いやすいもの）
1. **思い込みを使う**：人物が信じていることを、読者も信じる（一人称の語り手の誤解）
2. **怪しい人物に、別の秘密を持たせる**：疑われる理由は本物だが、事件とは別の秘密
3. **分かりやすい答えを先に出す**：探偵以外の人物が、もっともらしい推理を先に言う

## 伏線の距離

- 伏線は**「気づかれない程度に早く、忘れられない程度に近く」**置く。回収の3〜7話前が記憶に残りやすい
- 長い伏線は、中盤で1回「思い出させる」描写を挟む

出典：`creative-writing/references/story-structure.md`

## 動機（ホワイダニット）

- **動機は真相の半分。** 仕掛けが解けても「なぜそこまでしたのか」に感情の説得力がないと、読後感が軽くなる（`creative-writing/references/genre-playbook.md`）
- **序盤で痛みの種を置き、繰り返し思い出させる**と、読者の共感は増す
- 動機の型の例：復讐／仕事・職務／私利私欲／正当防衛／保身／衝動／**大切な人を守る**／世のため人のため

出典：[インディーズ小説家マニュアル 犯行動機9種](https://ganap-akira1.com/syousetsukouza/syousetsu-mystery002/)、[掃除プロの知恵袋 ミステリー動機](https://wiple-service.com/column/mystery-motive-whydunit-guide/)

### 日常の謎の動機は「人の事情」
日常の謎では、謎を起こした人の多くは悪人ではない。**解けたとき、誰かの隠れた優しさ・恥・ためらいが見える**形が、女性向けの感情の軸と重なる。
例（『錠前』）：「母は娘を捨てた」→ 錠の内側の擦れ →「母は毎晩この箱を開けていた」
