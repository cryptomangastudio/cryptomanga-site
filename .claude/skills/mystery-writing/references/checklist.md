# 出す前の確認

## 設計（本文を書く前）
- [ ] 真相を1文で言えるか
- [ ] 謎の型（誰が／どうやって／なぜ）の主が決まっているか。女性向け作品ではホワイダニットが主か
- [ ] 推理の筋道が「手がかりA＋B → 結論」の形で書けるか
- [ ] 真相以外にありうる答えを洗い出し、それを消す手がかりを用意したか
- [ ] ミスリードの一つ一つに、本当の理由があるか
- [ ] **「知っているはずのないことを知っていた」型の手がかりは、その人物が正当に知りうる経路をすべて潰したか**（2026-09-28、『錠前』v3で、親方が表立って金庫に挑んだ設定のまま失言を手がかりにしかけた）
- [ ] **犯人役に「ヘイト役」などのラベルを付けていないか。付けるなら「恩人」など善人側の呼び方にし、執筆メモで「序盤〜中盤は善人として描くこと」と明記したか**（2026-09-28）
- [ ] **手がかりが「言及されていないこと（沈黙）」だけに依存していないか。** 不在を手がかりにするときは、誰かが名指しで言明する場面を作ったか（2026-09-28）
- [ ] ヒロイン（探偵役）自身を含め、疑いうる全員を機械的に除外する根拠が設計表にあるか
- [ ] 動機の重さとジャンルの温度（コージーか本格か）が合っているか
- [ ] **推理の根拠が、専門知識ではなく読者も分かる事実か**
- [ ] 動機の痛みの種を、序盤のどこに置くか決まっているか

## フェア（真相を知ったうえで読み直す）
- [ ] 推理に使う手がかりが、すべて解決編より前に出ているか
- [ ] 地の文に嘘がないか
- [ ] 一人称の語り手が知っている事実を、隠したり偽ったりしていないか
- [ ] 「読者への挑戦」を入れても恥ずかしくない状態か

## 隠し方
- [ ] 手がかりを、その話の主題にしていないか（文の主題を別のことにしているか）
- [ ] 手がかりの直後に、読者の目を引く出来事があるか
- [ ] 伏線は「気づかれない程度に早く、忘れられない程度に近く」置けているか

## 解決編
- [ ] 論理の山場（真相）と感情の山場（動機・着地）を分けたか
- [ ] 解決編で新しい情報を出していないか
- [ ] 着地で、誰かの事情や痛みが見えるか。「すっきり」だけで終わっていないか

## 連作・恋愛・マンガ化
- [ ] 各話の謎がその話で解けているか
- [ ] 各話に、縦の謎の痕跡が1つだけ残っているか
- [ ] 謎の持ち込みがヒーローの口実になっているか
- [ ] 恋の一歩が、謎の着地と同じ場面にあるか
- [ ] 手がかりが「絵にできる物」か
- [ ] 真相を感想欄で当てられても、動機と着地の感情で読ませられるか

## 追加項目（2026-09-28、錠前の企画で見つかったもの）

- [ ] **「手元にある物を、なぜ試さなかったのか」に答えられるか。** 鍵・暗号・手がかりを持っている人物が、それを使ってみない（または使ってみて失敗した）理由が書かれているか。試した結果、何が分かって何が残ったのかまで書く
- [ ] **総当たり・力ずくで解決できないか。** 桁数の少ない暗証、壊せば開く箱などは、読者が「全部試せばいい」と思う。試行回数の制限、壊すと中身が失われる、などの「試せない理由」を作中の事実にする
- [ ] **手がかりの「読み手の限定」が本当に成り立っているか。** 「あの人にしか読めない符丁」にするなら、他の人には模様にしか見えないこと、その人が過去に教わった経緯があることを書く。普通の文字として刻んだら、持ち主は読んで試している
- [ ] **道具・鍵の作り手が、設計表と本文とタイトル・キャッチで一致しているか**
