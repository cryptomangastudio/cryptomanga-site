# 解決編の書き方

## 目標

謎が明かされたとき、読者が**「ああ、そういうことだったのか」**と感じ、読み終えたあとにもう一度最初から読んで**「ここに伏線があったのか」**と納得できること。

出典：[小説家情報局 ミステリー小説の書き方](https://www.amgakuin.co.jp/contents/novels/column/how-to-writing-mystery/)、[専門学校デジタルアーツ東京](https://www.dat.ac.jp/course/novels/become_novelist/writemystery/)

## 論理を段階で示す

- 探偵役が、**どの情報・証拠から、どういう推理をして**真相にたどり着いたかを、段階を追って明らかにする
- 「なんとなく分かった」は不可

出典：[専門学校デジタルアーツ東京](https://www.dat.ac.jp/course/novels/become_novelist/writemystery/)

## 解決編の組み立て（当社の型）

以下は調査で直接の出典が見つからなかった部分を、上の原則から組み立てたもの（**仮説**）。書いてみて調整する。

| 順 | 何をするか | 注意 |
|---|---|---|
| 1. 引き金 | 探偵役が「分かった」と気づく瞬間。小さな一言や物がきっかけ | ワトソン役の何気ない一言がきっかけになると、二人の関係が進む |
| 2. 手がかりの再提示 | 解決に使う手がかりを、**前の場面の言葉をそのまま引いて**見せ直す | 新しい情報を出さない（後出しになる） |
| 3. 可能性を消す | 真相以外の答えを1つずつ消す | ミスリードに使った情報の本当の理由もここで明かす |
| 4. 真相 | 1文で言い切る | 長い説明の途中に埋めない |
| 5. 動機 | なぜそうしたか。回想を使ってよい | **ここが感情の山場。** 論理の山場（4）と分ける |
| 6. 着地 | 日常に戻る。関わった人の関係が少し変わる | 恋の一歩をここに置く（`serial-and-romance.md`） |

### 長さの目安（仮説）
- 論理（2〜4）は短く。読者は手がかりを一度読んでいるので、思い出させれば足りる
- 感情（5〜6）に紙幅を使う
- 1話の中で解決まで行く連作なら、**解決編は1話の3分の1以下**

## 日常の謎の着地

- 日常の謎は、**非日常の象徴である謎を解いて、元の日常へ戻す**型である（`types-and-structures.md`）
- 代表例の『氷菓』は、掛け合いのおかしさと、**読後のほろ苦さ**が同居すると評される
- → 着地を「すっきり」だけにしない。**解けたことで、誰かの事情や痛みが見える**。女性向けの感情の山場はここに置く

出典：[ブクログ通信 米澤穂信](https://booklog.jp/hon/recommend/yonezawahonobu-0326)、[プラスアルファの本棚 氷菓](https://purasuarufainburogu.hatenablog.com/entry/2025/09/09/%E5%B0%8F%E8%AA%AC%E3%80%8E%E6%B0%B7%E8%8F%93%E3%80%8F%E3%83%AC%E3%83%93%E3%83%A5%E3%83%BC%EF%BD%9C%E7%B1%B3%E6%BE%A4%E7%A9%82%E4%BF%A1%E3%81%8C%E6%8F%8F%E3%81%8F%E6%97%A5%E5%B8%B8%E3%81%AE)

## 専門知識を使った解決の書き方

当社の方針（専門性を濁す）に合わせる。

| しない | する |
|---|---|
| 専門知識で推理の筋道を作る | 読者も分かる事実で筋道を作る |
| 部品・手順・数値を解決編で並べる | 探偵役がそれに**気づく速さ**と**手つき**で専門家らしさを見せる |
| 「専門家なら常識だが」と説明する | ワトソン役が驚く。説明は読者が分かる言葉に置き換える |
