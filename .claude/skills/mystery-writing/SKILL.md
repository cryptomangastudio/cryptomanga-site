# ミステリーの書き方スキル

中川様の依頼（2026-09-28）：「ミステリー作品を書くことにもなると思うので、ミステリーパートに備えて、ミステリーの書き方を徹底的にリサーチしてスキルに入れ込むこと」

最初の適用先は企画『錠前』（`drafts/jomae/`）。ただし一般のスキルとして書く。

---

## 作業の順番

1. **謎の型を決める**（`references/types-and-structures.md`）：誰が／どうやって／なぜ のどれを主にするか。日常の謎か、連作短編か
2. **真相を先に決める**（`references/clue-craft.md`）：答えから逆算する。真相が決まらないまま書き始めない
3. **手がかりを設計する**：答えにたどり着くヒント → そのヒントだけでは消せない別の可能性 → それを消すヒント、の順に足す
4. **ミスリードを設計する**：疑わしく見せたことには、必ず本当の理由を用意する
5. **配置する**：手がかりの隠し方の技法を使う。後出しをしない
6. **解決編を書く**（`references/solution-scene.md`）：論理を段階で示し、感情に着地させる
7. **フェアを検査する**（`references/fair-play.md`、`references/checklist.md`）：真相を知ったうえで最初から読み直し、嘘がないかを確かめる

2〜5は、本文を書く前に表で作る。書きながら考えない。

## 絶対に守ること

1. **地の文で嘘をつかない。** 一人称の語り手が思い込んでいることは書いてよい。地の文が事実として嘘を書くのは不可
2. **推理に使う手がかりは、解決編より前に必ず読者に見せる。** 後出しは読者の信頼を失う
3. **真相を先に決める。** 書きながら犯人や仕掛けを決めない
4. **疑わしく見せたものには、本当の理由を用意する。** ミスリードの投げっぱなしは不可
5. **動機を軽くしない。** 仕掛けが解けても「なぜそこまでしたか」に説得力がなければ読後感が軽くなる

## 当社の方針との接続

### 専門性を濁す方針とフェアプレイは、同じ方向を向いている
中川様の方針（2026-09-28）は「専門性は濁す。監修が要る細部は書かない」（`romance-web-novel/SKILL.md`）。
ミステリーのフェアプレイは「読者が推理できる材料で解ける」こと。**専門知識がないと解けない謎は、読者には推理できないのでアンフェアになる。**

→ **手がかりは、読者も知っている日常の知識で組む。専門知識は、解く場面の演出（手つき、雰囲気）にだけ使い、推理の根拠にしない。**

例（『錠前』）：
- 不可：「このレバーの摩耗は三年以上の使用を示す。だから犯人は旧知の者だ」（専門知識が根拠）
- 可：「錠の内側だけが艶々している。毎晩、内側から開けていた人がいる」（読者も分かる事実が根拠。錠前師の目は、それに気づく速さとして描く）

### 男女両読の方針との接続
`romance-web-novel/references/crossover.md` の原則6「恋と謎を同じ出来事で進める」を、このスキルの `serial-and-romance.md` で具体化している。
