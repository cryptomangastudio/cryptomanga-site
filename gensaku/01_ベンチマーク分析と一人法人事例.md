# 原作紹介事業：ベンチマーク分析と一人法人の事例

作成：2026-09-24 / 対象：CryptoManga Studios 合同会社（代表1名）
テーマ：「マンガの原作を集めて、紹介する」事業を始めるなら何をするか

---

## 0. 結論（先に）

1. **「原作を集めて紹介する」ビジネスには5つの型がある。** このうち、一人法人でも成立した実例があるのは **③マーケットプレイス／リスティング型の“初期”** と **④スカウト・キュレーション型** だけ。①投稿プラットフォーム型と②大型エージェント型は資本も人も要る。
2. **一人で成立した代表例は海外に集中している。** The Black List（最初は1人が75人にメールで送ったアンケート）、Publishers Lunch（長いあいだ創業者1人で運営、月25ドル）、Bo-sco（2026年5月開始、小説家が作ったプロデューサー向け月額スカウトレポート）など。「紹介する側が、**原作を探す側（買い手）からお金をもらう**」という点が共通している。
3. **日本の漫画・縦読み領域には、ここがほぼ空いている。** 縦読みスタジオやコミカライズ編集部は原作を常に探しているが、プロデューサー向けの「原作発掘サービス」は検索では見つからなかった。海外向けの大きな場（TIFFCOM の Tokyo IP Market）は KADOKAWA・東映などの大手の権利者しか出ていない。
4. **CryptoManga Studios が狙うべき形**は次の3段階。
   - **Phase 1：** 「原作スカウトレポート」。B2B の月額制で、コミカライズ権が空いている Web 小説や原作を目利きして届ける。
   - **Phase 2：** 成約したときに紹介手数料をもらう、エージェント型への拡張。
   - **Phase 3：** 自社の縦読み制作・キャスティングと組み合わせ、原作を自社 IP 化する。
   いまの事業（シナリオ・編集・制作進行・キャスティング・WEBTOON）がそのまま出口として使えるので、「紹介して終わり」ではなく「紹介→制作→権利」までつなげられる。これが他社にない強み。

## 1. 事業の型の整理（5類型）

| 型 | 何をするか | 誰からお金をもらうか | 代表例 | 一人法人でできるか |
|---|---|---|---|---|
| ① 投稿プラットフォーム型 | 誰でも投稿できる場を作り、人気作を出版・映像化に回す | 読者課金、広告、出版・版権収入 | エブリスタ、アルファポリス、テラーノベル、Wattpad、Inkitt、note創作大賞 | ✕（開発・集客・資本が必要） |
| ② エージェント型 | 作家と契約し、作品の編集・権利の窓口・メディア展開を担う | 作家の収入からの手数料、共同プロデュース収益 | コルク、ストレートエッジ、ナンバーナイン、Wattpad WEBTOON Studios | △（小さく始めることはできるが、作家からの信頼と実績が要る） |
| ③ マーケットプレイス／リスティング型 | 原作や脚本を一覧に載せ、買い手に検索・閲覧してもらう | 掲載する側（書き手）の月額料金、評価料 | The Black List、InkTip、Tokyo IP Market、韓国コンテンツIPマーケット | ○（最初期なら。規模を広げるには開発が要る） |
| ④ スカウト・キュレーション型 | 目利きが「映像化・漫画化できる原作」を選び、買い手にレポートで届ける | 買い手（プロデューサー、編集部、スタジオ）の月額・契約料 | Bo-sco、The Optionist、The IP Scout、Publishers Lunch、リテイナー型の文芸スカウト | ◎（一人で成立した例が複数ある） |
| ⑤ 読者向け紹介メディア型 | 読者におすすめの漫画を紹介する | アフィリエイト、広告、PR案件 | マンバ、マンガ大賞、漫画アフィリエイトブログ、漫画紹介 YouTube | ○（ただし単価が低く、B2B に比べ収益性は弱い） |

## 2. ベンチマーク企業の詳細分析

### ① 投稿プラットフォーム型（参考にはなるが、真似はしない）

**エブリスタ（メディアドゥ子会社）**
- 小説投稿サイトを運営し、書籍化・コミカライズ・映像化をプロデュースしている。2021年にメディアドゥの子会社になった。
- 収益は、月額の有料会員、広告、コンテンツプロデュース（出版社や映像会社への提案）の3本。
- 出版社への提案には3つのパターンがある。自社から出版社におすすめする、編集者がサイト上で見つける、コンテストで受賞作を出版する。
- 2017年の記事の見出しは「プラットフォームからエージェントへ」。**投稿サイトでさえ、最終的な価値は“紹介・仲介機能”にある**と自ら認めている。
- 学び：「集める」より「出版社・映像会社に売り込む」機能が利益の源泉になっている。

**アルファポリス（東証グロース 9467）**
- 2026年3月期の連結決算は、売上高166.1億円、営業利益34.56億円。漫画売上は125億円を超えた。
- 投稿サイトの広告収益を作者に還元する「投稿インセンティブ」で原作を集め、人気作をライトノベル化・コミカライズ・アニメ化している。
- 学び：**「Web小説 → コミカライズ」は日本でいちばん太い原作供給ルート**。一方で大手が作品を囲い込むので、人気上位の作品は取りにいけない。狙い目は中位以下の埋もれた作品。

**テラーノベル**
- 登録作家90万人以上、作品数1,000万以上。2025年3月に10億円を調達し、縦型ショートドラマに参入した。
- 学び：**原作の出口が「漫画」から「縦型ショートドラマ」へ広がっている**。原作を紹介する先として映像（ショートドラマ）の制作会社も含めるべき。

**note 創作大賞**
- 2025年は応募約7万件、協賛38媒体（出版社、テレビ局、漫画アプリなど）。過去4回で応募は約17万件、メディア化は32件。
- 仕組みは、**場を作る note と、選んで引き取る各媒体の分業**。媒体ごとに賞を出し、担当者がつく。
- 学び：買い手（媒体）を集められれば、原作は勝手に集まる。**先に買い手を押さえることが大事**。

**Wattpad／Wattpad WEBTOON Studios（海外）**
- ユーザーは約1.7億人。作家に出版契約を仲介するとき、**文芸エージェント並みの手数料**を取っていると報じられている。
- 読了率、コメントの感情、投票の推移などのデータからヒット作を予測している。
- 学び：「データ＋目利き」で**原作のリスクを下げること**が、買い手にとっての価値になる。

**Inkitt／Galatea（海外）**
- 累計1.2億ドル超を調達。1,200項目以上の読者行動データからベストセラー候補を選んでいる。
- 学び：選定をデータで行うこと自体が差別化になる。一人法人なら、公開されている指標（ブックマーク数、評価の伸び、ランキングの推移）を手作業や簡単なスクリプトで追うだけでも十分に真似できる。

### ② エージェント型（Phase 2 以降のお手本）

**コルク（佐渡島庸平、2012年〜）**
- 講談社で『宇宙兄弟』『ドラゴン桜』などを担当した編集者が独立して作った会社。作家とエージェント契約を結び、編集、著作権管理、ファンコミュニティの運営を行う。現在は縦スクロール漫画のプロデュースに力を入れている。
- 学び：**編集者1人の実績と信頼が、そのまま作家を集める力になる**。最初は少人数で始まった。

**ストレートエッジ（三木一馬、元電撃文庫編集長）**
- 作家をマネジメントし、小説からコミック、ゲーム、アニメまで一つの IP を媒体に縛られずにプロデュースしている。2025年には「ストレートエッジコミック」も始めた。
- 学び：**「原作の窓口」を握れば、コミカライズ以降の展開をすべて主導できる**。

**ナンバーナイン（2016年〜）**
- 最初は**単月売上26万円**。3年半で単月1億円に成長した（同社の Wantedly 記事による）。
- 漫画家2,000人以上、1万作品以上の電子配信を代行している。自社の Studio No.9 が作った『神血の救世主』は、LINEマンガで月間販売額1.2億円を突破した。
- 2024年にカヤックから1億円、2025年に WEBTOON Entertainment から出資を受けた。
- 公開されている縦読みの原作料は、**プロット原作が1話2.5万〜5万円、ネームが1話5万〜7.5万円**。
- 学び：**小さな代行・仲介から始めて、自社制作と IP へ垂直に統合していく**のは、CryptoManga Studios が目指す形にいちばん近い。

**ソラジマ**
- オリジナルの縦読み漫画を制作し、アニメ化・ドラマ化を実現した。ただし2025年3月期は最終損失7,400万円で、**自社制作は資金を大きく食う**。
- 学び：一人法人が制作リスクを全部背負うのは危険。**原作の紹介・仲介のような軽い事業で現金を作ってから制作に回す**順番が正しい。

### ③ マーケットプレイス／リスティング型

**The Black List（米国、Franklin Leonard）** ★一人から始まった事例
- 2005年、DiCaprio の制作会社で開発担当をしていた Leonard が、**同業者約75人にメールで「今年読んだ未映像化脚本のベスト10」を聞いたのが始まり**。
- 2012年から有料サイトを運営している。**脚本の掲載料は月30ドル、プロの評価は1本100ドル**（2026年5月時点）。
- このリストに載った脚本のうち400本以上が映画化された。
- 注意点：書き手から掲載料を取る「pay-to-play」には批判も多い。
- 学び：**最初はお金も開発も要らない。「業界人の推薦を集めて公開する」だけで権威が生まれた。**

**InkTip（米国、Jerrol LeBaron、2000年〜）**
- 脚本のリスティングサービス。**買い手（プロデューサー）は無料、書き手は月32.5ドル（Pro）**。週6件以上の「募集案件」ニュースレターを出している。
- 実績は、映画化400本以上、オプション契約4,000本以上。
- 学び：**買い手を無料にして集めるのが鉄則**。買い手の募集要項（どんな原作を探しているか）を書き手に流すニュースレターは、一人でも回せる。

**Coverfly（米国）** ★失敗例
- 脚本家のポートフォリオとコンテストの集約サイト。親会社の事業整理で2025年8月1日に閉鎖され、姉妹サイトもまとめて閉じた。
- 学び：**書き手側の集客だけでは収益が安定しない**。買い手からの売上を持たないプラットフォームは弱い。

**TIFFCOM「Tokyo IP Market」（ユニジャパン）**
- 2023年に「Tokyo Story Market」として始まった、漫画・小説の映像化権と海外プロデューサーの商談会。2026年は10月28〜30日開催で、参加する権利者は KADOKAWA、松竹、東映、スクウェア・エニックスなど8社。
- 学び：**国の支援を受けた場があるのに、参加しているのは大手の権利者だけ**。中小の出版社や個人作家の原作を代わりに持ち込む「代理人」の席が空いている。

**韓国「コンテンツIPマーケット」**
- ウェブトゥーン作家と映像制作会社・消費財企業の二次利用をつなぐ B2B 商談会が毎年開かれている。
- 学び：韓国ではウェブトゥーンやウェブ小説の映像化が年50本規模。**原作仲介は政策的にも産業化されている**。

### ④ スカウト・キュレーション型（★一人法人の本命）

**Bo-sco（英国、Arianna Reiche、2026年5月開始）**
- 小説家でメディアリサーチャーの Reiche が始めた。**毎月1回、まだ開発担当者に届いていない「オプション契約が取れる文芸作品」を7本選んでレポートにする。**
- 料金は**月39.99ポンド、または429.99ポンド**（報道による。年額または法人向けの上位プランとみられる）。beehiiv（ニュースレター配信サービス）で配信している。
- 顧客はプロデューサーや開発担当が中心で、エージェントやマネージャーにも広げる。**「専属スカウトを雇うよりはるかに安い」**というのが売り文句。
- 体制は創業者1人と数名のリサーチャー。欧州、中南米、広東語圏には地域の協力者がいる。
- 学び：**CryptoManga Studios の Phase 1 とほぼ同じ形**。規模は小さく、中心になる目利きは1人で、道具はニュースレターだけ。

**The Optionist／The IP Scout／The Book Report（米国のニュースレター）**
- いずれも週刊のニュースレターで、書籍、記事、ポッドキャストなどから「映像化できる未契約の IP」を選んでハリウッド向けに紹介している。Substack 系の個人運営が中心とみられる（※運営人数と料金は、ページを取得できず未確認）。
- 学び：**「IPスカウト×ニュースレター」はすでに一つのジャンルとして成り立っている**。ただし日本の漫画や Web 小説に特化したものは見つからなかった。

**Publishers Lunch／Publishers Marketplace（米国、Michael Cader）** ★一人法人の成功例
- 2000年にメールニュースレターとして開始し、2001年にサイト化した。**初期の長い期間は Cader 1人で運営していた。**
- 料金は月25ドル。出版契約（誰がどの本の権利をいくらで買ったか）のデータベースが業界の基盤になった。
- 学び：**「取引情報を集約する」だけで、業界の必需品になれる**。日本の「コミカライズ決定情報」や「映像化決定情報」の集約・分析は、一人でも始められる。

**リテイナー型の文芸スカウト（米国、ニューヨーク）**
- 映画会社やスタジオと月額のリテイナー（固定報酬）で契約し、映像化向きの本を探す。**成功報酬ではなく固定報酬にすることで、推薦の中立性を保つ**。フリーランスなら1冊500〜2,000ドルでレポートを作る例もある。
- 学び：**日本の縦読みスタジオや映像制作会社と「月額の原作探し顧問」契約を結ぶ**のは、そのまま転用できる。

**Seven Seas の読者アンケート（米国の出版社）**
- 毎月、読者から「英語版を出してほしい漫画」を募り、ライセンス取得の参考にしている。
- 学び：**海外の出版社も「どの未翻訳作品を取るべきか」の情報を欲しがっている**。海外向けに日本の原作を紹介するルートも成り立ちうる。

### ⑤ 読者向け紹介メディア型（集客と実績づくりの補助）

**マンガ大賞（実行委員会、2008年〜）**
- 発起人はニッポン放送アナウンサーの吉田尚記。**書店員などの有志が手弁当で選考する**。「友達に勧めたくなる漫画」を選ぶ賞で、社会的な影響力は大きい。
- 学び：**お金をかけなくても「推薦の権威」は作れる**。CryptoManga Studios 版にするなら「漫画化してほしい原作大賞」のような企画がありうる。

**マンガ新聞（堀江貴文・佐渡島庸平らが2015年に設立、メディアドゥが買収、のちに解散）**
- 学び：**読者向けの漫画紹介メディア単体では、有名人と大手資本がついても続かなかった**。紹介メディアは事業の柱ではなく、集客とポートフォリオとして使うべき。

**漫画アフィリエイト、漫画紹介 YouTube**
- 電子書籍ストアの初回登録で数百円〜2,000円程度の報酬が出る。書籍紹介 YouTube の「積読チャンネル」は、年83本の動画で13,542冊を売った。
- 学び：個人でも収益化はできるが、**単価が低く、B2B の月額レポートに比べると効率が悪い**。

## 3. 一人法人で成立した事例のまとめ

| 事例 | 始めたときの体制 | 最初に作ったもの | お金をくれた相手 | 料金 |
|---|---|---|---|---|
| The Black List | 開発担当者1人（本業の傍ら） | 業界人75人へのメールアンケート | （当初は無収益 → 7年後に書き手課金） | 掲載料 月30ドル、評価 1本100ドル |
| Publishers Lunch | 創業者1人 | 業界ニュースのメール | 業界人（買い手と売り手の両方） | 月25ドル |
| Bo-sco | 創業者と数名のリサーチャー | 月1回の IP スカウトレポート | プロデューサー、開発担当 | 月39.99ポンド〜 |
| IP ニュースレター群 | 個人運営が中心（推定） | 週刊の IP 紹介 | プロデューサー | 有料購読 |
| リテイナー型スカウト | 個人事務所 | 担当スタジオ向けのレポート | 映画会社、スタジオ | 月額固定、または1冊500〜2,000ドル |
| InkTip | 創業者が起業（小規模） | 脚本の一覧サイト | 書き手（買い手は無料） | 月32.5ドル |
| ナンバーナイン | 小規模スタート | 漫画の電子配信代行 | 漫画家（配信手数料） | 単月26万円から開始 |
| マンガ大賞 | 有志（手弁当） | 推薦アンケート | （非営利） | — |

**共通点（ここから導く原則）**
1. **最初は「リスト」または「レポート」だけで、システムは作らない。** メールやニュースレターから始めている。
2. **お金は、原作を探している側（買い手）からもらう。** 書き手から取るモデルは批判されやすく、Coverfly のように不安定にもなる。
3. **推薦の中立性と目利きが商品そのもの。** リテイナー型スカウトが成功報酬を避けるのはこのため。
4. **量より「まだ誰も見つけていない」ことに価値がある。** Bo-sco の「開発担当者にまだ届いていない7本」がその例。

## 4. 日本市場での空白地帯（CryptoManga Studios の勝ち筋）

| 買い手の困りごと | いま存在するもの | 空いているところ |
|---|---|---|
| 縦読みスタジオは毎月、原作を大量に必要としている（原作募集の一覧サイトが作られるほど多い） | 各スタジオが個別に公募している | **スタジオ向けに原作を横断的に選んで届けるサービスがない** |
| コミカライズ担当は「この作品を描きたくても、権利を持つ出版社とつながれない」 | 編集部の人脈頼み | **権利の窓口を調べて紹介する役がいない** |
| 映像・ショートドラマの制作会社は検証済みの IP を探している | TIFFCOM（大手のみ）、テラードラマ（自社の原作のみ） | **中小出版社や個人作家の原作を代わりに持ち込む役がいない** |
| 海外のプロデューサーや出版社は未翻訳・未映像化の日本作品を探している | Seven Seas の読者アンケート、Tokyo IP Market | **英語の「日本の原作スカウトレポート」がない** |

※「日本のプロデューサー向け原作発掘サービス」を検索しても、該当するサービスは出てこなかった（2026年9月時点）。

## 5. CryptoManga Studios がやること（推奨プラン）

### Phase 1（0〜3か月）：原作スカウトレポート

- **商品：** 月1回の「コミカライズ・映像化向き原作レポート」。1号あたり5〜10作品。
  - 収録する項目：あらすじ、なぜ今この作品か（数字の伸び、読者層）、縦読みにしたときのフック、キャラクターの強さ、想定する媒体、**権利の状況（書籍化済みか、コミカライズ済みか、連絡先の窓口）**、CryptoManga Studios のシナリオ担当としての所見。
  - 探す元：なろう、カクヨム、アルファポリス、エブリスタ、テラーノベル、note、pixiv、同人・インディーズ漫画。**ランキング上位ではなく、「伸び率は高いが、まだ書籍化されていない」作品**を狙う。
- **顧客：** 縦読みスタジオ、コミカライズ編集部、ショートドラマ制作会社、アニメや映像のプロデューサー。
- **料金の仮説：** 無料版（note や X に月1〜2作品だけ抜粋）と有料 B2B 版（月3万〜5万円程度）。Bo-sco の月40〜430ポンドや、リテイナー型スカウトの相場を参考にした。
- **一人で回す体制：** 毎週の定点観測は、公開ランキングの推移を記録する簡単なスクリプトで取り、1日1〜2時間で精読して目利きする。既存のシナリオ制作の知見がそのまま差別化になる。
- **最初の10社：** 公募している縦読みスタジオの一覧（ノベルポータルや Koubo 掲載の各社）に、サンプル号を無料で送る。

### Phase 2（3〜12か月）：成約手数料と原作者の窓口

- レポートから成約した場合は、**原作者の同意を得たうえで紹介料**を受け取る（原作料の10〜20%程度を想定し、個別に交渉）。
- 原作者側には「持ち込み・売り込み代行」を用意する。**書き手からの掲載料は取らない**方針にし、Black List のような pay-to-play への批判を避ける。
- 実績が出たら、Tokyo IP Market や韓国の IP マーケットに中小の権利者の代理として参加する。
- **法務の注意：** 作家の代わりに利用料の条件を決めて許諾する「一任型」の管理を複数の権利者について事業として行うと、著作権等管理事業法の登録が必要になる可能性がある。最初は「条件は作家本人が決める」非一任型の紹介・代理にとどめ、契約書のひな形は弁護士に確認してもらう（**要専門家確認**）。

### Phase 3（12か月〜）：自社制作・自社 IP 化

- 紹介した原作のうち筋の良いものを、自社でシナリオ化・縦読み化し、キャスティングで作画担当を編成する。ナンバーナインが「代行」から「制作・IP」へ進んだのと同じ流れ。
- 原作者との共同著作や収益分配（原作と作画の印税比率は4:6〜5:5が一般的）を契約で設計する。
- Web3 の選択肢：Story Protocol のようなオンチェーンの IP ライセンス基盤もある（2025年2月にメインネット公開）。ただし**買い手（スタジオや編集部）が使っていない以上、主軸にはしない**。社名にある「Crypto」は、将来の実験枠として残しておくのが妥当。

## 6. 判断基準と撤退ライン（事前に決めておく）

| 指標 | 3か月時点の目安 | 撤退・方針転換のライン |
|---|---|---|
| 無料版の購読者（業界関係者） | 100人 | 50人未満なら、媒体を X とnote から直接営業に切り替える |
| 有料の B2B 契約社数 | 3社 | 0社なら、月額制をやめて1件ごとのリサーチ受託に変える |
| レポートから出た商談の数 | 累計5件 | 0件なら、選定基準（ジャンルや作品の成熟度）を見直す |
| 作業時間 | 週10時間以内 | 超える場合は、定点観測の自動化を進めるかリサーチャーを外注する |

## 7. リスク

- **著作権：** 紹介のために本文や画像を引用するときは、引用の要件（主従関係、出典の明示）を守る。有料レポートでも本文の転載はしない。
- **権利の誤認：** すでに出版社が権利を持っている作品を「空いている」と紹介しないよう、書籍化やコミカライズの有無を必ず確認する。
- **推薦の中立性：** 成約手数料を大きくしすぎると推薦が偏って見える。月額の収益を主にし、成約手数料は従にする。
- **プラットフォームへの依存：** 投稿サイトの規約が変わり、ランキングデータを取れなくなる可能性がある。
- **紹介メディアの収益性：** マンガ新聞の解散が示すとおり、読者向けメディア単体では続かない。

## 8. 最初の30日のアクション

1. 1週目：スタジオ・編集部の原作募集要項を30社分集め、「欲しい原作の条件」を一覧にする（＝買い手のニーズ表）。
2. 2週目：Web 小説サイト5つの定点観測を始める。伸び率が高く、まだ書籍化されていない作品を50本リストアップする。
3. 3週目：サンプル号（5作品）を作り、note で無料公開する。同時に10社へ直接送る。
4. 4週目：反応を集計し、料金と形式（月額か都度か）を決める。原作者に連絡するときの定型文と紹介の同意書のひな形を作る。
