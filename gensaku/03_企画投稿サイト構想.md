# 企画投稿サイト構想：既存サービスの調査と設計案

作成：2026-09-25

## 前提：実際の営業の流れ

```
企画を集める → 簡単な企画書5〜10本をまとめてスタジオに提案 → スタジオが良さそうなものを選ぶ
→ ブラッシュアップして再提出 → 字コンテライターを探して手配 → （ネーム以降はスタジオ）
```

営業は字コンテからではなく、**企画書から始まる**。いちばん手間がかかるのは企画づくりなので、**企画を外部から集める仕組み（投稿サイト）**を用意する、という構想。

---

## 1. 「企画だけを投稿できるサイト」はあるか

**結論：日本では常設のものは見つからなかった。** 近いものはあるが、どれも「単発の賞」か「1社専用の窓口」か「漫画と関係のないアイデア売買」にとどまる。

| 名称 | 何を募集しているか | 企画だけで応募できるか | 限界 |
|---|---|---|---|
| デジタル職人「Webtoonシナリオ企画コンテスト」 | 「0から Webtoon のシナリオ企画を作る」。企画立て（テーマ、売り、想定読者、キャラクター、あらすじ）を文書ファイルで提出 | ○ | **1社の単発コンテスト**。将来性のある企画は商業化の可能性あり |
| ソラジマ「企画作家」 | 企画作家を職種として募集。企画書の型（ログライン、ターゲット、参考作品、あらすじ、キャラクター、魅力、1〜3話のあらすじ）を公開している | ○ | **ソラジマ専属の窓口**。他社には出ない |
| 少年ジャンプ 原作者・作画家漫画賞 | 原作者の部門は1枚目に企画書をつけ、そのあとに原作を添える | △（企画書＋本文） | 本文が必要。横読みの漫画誌向け |
| ジャンプ＋×note 原作大賞、LINEマンガ×TALES 原作大賞、カドコミ原作コンテスト | 原作の文章（あらすじと数話分） | ✕ | 小説や脚本の完成度が求められる |
| アイデアマーケット、StoKee など | ビジネスや商品のアイデア売買 | ○ | 漫画や物語の買い手がいない |

**海外の類似サービス**

| 名称 | 仕組み | 学び |
|---|---|---|
| **Storyum（韓国、韓国コンテンツ振興院が運営）** | 物語の創作者が話や原案を登録し、新しい題材を探す制作会社とつなぐ**公的なプラットフォーム**。おすすめのストーリー、公募情報、求人情報も載せている | **「企画・原案の流通の場」は韓国では国が作っている**。民間の常設サービスとしては日本に空きがある |
| 韓国漫画映像振興院（KOMACON）「創作初期段階の漫画・ウェブトゥーン企画公募」 | 企画段階の作品に制作費を支援する | 「企画」が単独で価値を持つものとして扱われている |
| **Stage 32（米国）** | ログライン（1行の企画要約）を登録すると、約500人の映画関係者に自動で送られる。書き手は有料で売り込める | ログラインの一覧は成り立つ。ただし**書き手に課金する形は「pay-to-pitch」と批判されやすい** |
| InkTip（米国） | 脚本の一覧。買い手は無料 | 買い手を無料にすると集まりやすい |

## 2. 企画の値段（スタジオ側の相場）

- **ソラジマ：** 企画作家の単価は1話1.5万円から（税込）。印税は**企画と脚本の両方を担当すると売上の7.5%、脚本だけだと5%**。つまり**企画部分には売上の約2.5%相当の価値**がついている。ソラジマがクリエイターに払った印税は累計3,000万円、原稿料を含めると2億円以上。
- **Studio No.9：** 原作（プロット）は1話2.5万〜6万円。印税は全工程の合計で売上の約10%。
- 結論：**企画は「一度きりの企画料」と「少額でも長く入る印税」の組み合わせで値段がつく**。投稿者への報酬もこの形に合わせて設計できる。

---

## 3. 作るべきか → 作る価値はある。ただし「公開型の投稿サイト」にはしない

### 賛成の理由
1. **日本に常設の場がない**（上の調査のとおり）。
2. 集まった投稿は、**そのままスタジオに出す5〜10本の企画パックの材料**になる。
3. **投稿者の中から字コンテライターを見つけられる**。企画が書ける人は脚本も書けることが多い。企画集めとライター探し（キャスティング）が一つの仕組みでできる。
4. スタジオ側でも企画作家という職種が成り立っているので、需要の裏付けがある。

### 最大のリスク：アイデアは著作権で守られない
- 企画やアイデアそのものは著作権で保護されない。表現になって初めて著作物になる。
- 誰でも読める公開型のサイトにすると、次の問題が起きる。
  - 投稿者は盗用を恐れて、良い企画を出さない。
  - スタジオは無料で読めるので、CryptoManga Studios を通さずに作者と直接やりとりしたり、アイデアだけ使ったりできてしまう。
  - 似た企画が別々に出たとき、盗用だと疑われる。
- **対策：非公開で投稿を受け付け、CryptoManga Studios が選んで提案する形にする。**
  - 投稿は運営だけが見る。スタジオには、CryptoManga Studios が選んでブラッシュアップしたパックだけを出す。
  - スタジオと秘密保持契約（NDA）と取引基本契約を結んでから企画を見せる。
  - 投稿日時と内容を記録して残す（受付メールや自動の受付番号）。
  - 規約に「類似企画の免責」を入れる。企画の骨格は重なりやすいため。

## 4. 仕組みの設計案

```
[投稿者] ──非公開投稿（企画書テンプレート）──▶ [CryptoManga Studios]
                                               │ ① 選別（通過率の目安10〜20%）
                                               │ ② 軽いブラッシュアップ
                                               ▼
                                 [企画パック 5〜10本] ──NDAを結んで提案──▶ [スタジオ]
                                                                       │ 選定
                                               ◀──── フィードバック ─────┘
                                               │ ③ 投稿者と一緒にブラッシュアップして再提出
                                               │ ④ 字コンテライターを手配（投稿者本人、または登録ライター）
                                               ▼
                                            [スタジオでネーム以降の制作]
```

### 投稿フォーマット（ソラジマの型に合わせ、A4で1〜2枚）
1. タイトル案
2. ログライン（1〜2行）
3. ジャンル、ターゲット、想定する掲載先（縦読み／横読み）
4. 参考作品（どの作品の型で、どこをずらすか）
5. 全体のあらすじ（300〜600字）
6. キャラクター（主人公、敵役、相手役は必須）
7. この企画の売り（「読んだだけで面白い展開が5つ浮かぶか」）
8. 第1〜3話のあらすじ
9. 生成 AI の使用有無（使った場合はその範囲）

### 投稿者への報酬（叩き台）
| 段階 | 投稿者が受け取るもの |
|---|---|
| 投稿した時点 | なし（講評は月1回、通過作品だけに返すなど、運営の負担に合わせる） |
| スタジオが選定した時点 | **企画料**（例：一律3万〜5万円。スタジオから受け取る額から支払う） |
| 連載が始まった時点 | **原案のクレジット＋印税の一部**（企画分として支払われる印税のうち、例えば50〜70%を投稿者へ） |
| 字コンテも担当する場合 | 1話ごとの字コンテ原稿料（02の相場） |

### 投稿規約で決めておくこと
- **権利の帰属：** 投稿した時点では投稿者に残す。採用時に別途契約を結ぶ。
- **独占期間：** 投稿後、例えば6か月は CryptoManga Studios 経由でのみ提案できる。通過しなかった企画はすぐに解放する。
- **類似企画の免責**と、**盗用を疑われたときの対応窓口**。
- **生成 AI の使用申告**。
- 未成年が投稿する場合の保護者の同意。
- 採用時は業務委託になるので、**フリーランス保護法に沿って取引条件を明示し、期日どおりに支払う**。

## 5. いきなりサイトを作らない：MVP（最小限の試作）の進め方

| 段階 | やること | 道具 | 期間 |
|---|---|---|---|
| **検証0** | スタジオ3〜5社に「外部の企画パックを受け取るか、条件は何か」を聞く | 対面や DM | 2週間 |
| **検証1** | テーマを決めた「企画募集」を1回やる（例：復讐・スカッと系の企画を20本） | 告知ページ（このリポジトリに1ページ追加）、Googleフォームや Tally、X と note での告知 | 1か月 |
| **検証2** | 集まった企画から5〜10本のパックを作り、2〜3社に出す | 企画パックのテンプレート | 1か月 |
| **本格化** | 常設の投稿ページ、投稿者向けマイページ、ステータスの管理 | 通過率と採用実績が出てから開発する | — |

### 判断基準（先に決めておく）
| 指標 | 検証1〜2の目標 | 見直しのライン |
|---|---|---|
| 1回の募集で集まる投稿数 | 30本 | 10本未満なら、告知先と報酬の見せ方を変える |
| 選別の通過率 | 10〜20% | 5%未満なら、テンプレートと募集テーマを具体的にする |
| スタジオが「選定」した企画 | パック1つにつき1本以上 | 2つのパックで0本なら、スタジオの要望を聞き直す |
| 投稿者から字コンテライターに移った人 | 1〜2人 | — |

## 6. このリポジトリで実装する場合（将来）

- 既存の静的サイト（`index.html`）に「企画募集」ページを1枚追加する。**フォームの送り先は外部サービス（Tally や Googleフォーム）にし、投稿データを自前で持たない**（非公開の保管とアクセス管理を外部に任せるため）。
- 規約と応募要項も同じページに載せる。
