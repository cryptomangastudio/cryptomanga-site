## 水守ミナ

### 確定していること

- 臆病で、いつもびくびくしている。怯えは誰にでも分かる形で出す(震える、声が裏返る、言葉が詰まる、足が動かない、物陰に隠れる)。**専用の合図は作らない**
- 専門(水・衛生・傷)の場面では別人になる。震えが止まり、短く迷いなく言い切る
- 終わると素に戻り、自分が何を言ったかに気づいて青くなる
- 切り替えは「震えが止まる」の一行で見せる。一話に三回まで
- 勇気も必要。どこでどう出すかは【未決】
- 最後まで守る禁則は「基準を下げない」。第四幕で一度だけ破る禁則は「嘘をつかない」

### Want / Need / Wound

| | 中身 |
| --- | --- |
| Want | 婚約を解消して、自分を「あるべき状態」に戻すこと。恋愛感情はない。手続き |
| Need | 自分を、世話をする相手に入れること |
| Wound | 傷ではなく、教育。一族の掟は「水を預かる者は、基準を下げない」の一行だけ。九歳のとき父に「掟には、わたしたちの分のことが書いてありません」と聞き、「考えたことがなかったな」と返された |

### 声

- 一人称「わたし」、二人称「あなた」、名を知らない相手は「そちらの方」。敬体、常に
- 普段は言葉が詰まり、語尾が消える。専門の場面では短く言い切る
- **数字は言わない。** 罵らない
- 口に出さないのは自分の感情(怖い、嫌だ、寂しい)。代わりに手順の話をする
- 自分の視点の回では、地の文に口語の本音が出る(一行か二行)

| | 台詞の例 |
| --- | --- |
| 普段 | す、すみません。後ろから来られると…… |
| 専門 | 左肩、開けてください。お湯を |

注意: 山場の台詞は「その手で、**私**に触らないでください」と漢字の「私」で確定している。一人称の表記(「わたし」)と揃っていない。どちらに揃えるかは【未決】。

### 見た目

縦に長く細い。結い上げた髪。記号は三つ: 裾を不揃いに詰めた白いドレス(自分で切った跡)、腰の計測具(ガラスの小瓶と金属片)、結い上げた髪。色は白・薄い金・くすんだ銀。手に傷がない、爪が短く整っている、歯が揃っている、日に当たるとすぐ赤くなる。

## ハル(ボス)

### 確定していること

- 自分の名前を知らない。番号で呼ばれて育った。首の布の下(襲の裏)に名札が縫い付けてあるが、字が読めない。擦り切れて三文字しか残っていない
- 欲しいと思った時点で、もう手が出ている。頼むことを知らない。愛情表現が全部、略奪の形になる
- 禁則: 頼まない(最後に一度だけ破る)。痛いと言わない、弱っている姿を見せない。言い訳をしない
- コダワリ: 拾ったものを一つも捨てられない。ねぐらの奥にガラクタの山がある

### Want / Need / Wound

| | 中身 |
| --- | --- |
| Want | 【未記載】 |
| 欠落 | 帰る場所がない。人間として扱われたことがない |
| Wound | 子供のころ、瓦礫から掘り出した缶詰を一つ、年上の男(ゴロウ)に差し出した。男は受け取り、彼を殴って残り全部を持っていった。以来、何かを差し出したことがない |

### 執着の三段階

| | 状態 | 外に出る形 |
| --- | --- | --- |
| 第一幕 | 理由が分からない | 囲い込む。服を着せる。説明しない |
| 第二幕中盤 | 失うのが怖い、と分かる | 自分から手当てを受けに来る。「……死にたくない」 |
| 終盤 | 怖いと認めた上で、頼む | 「俺を、置いていくな」 |

地の文でも台詞でも「処理不能」「バグ」と説明しない。

### 声

一人称「俺」だが、ほぼ主語を省く。常体、極端に短く、三語を超えることが少ない。数を言わない(「足りる」「足りない」)。比喩を使わない。怒ると声が小さくなり、最も怒っているときは無音。序盤の「置いていけ」には主語がなく、終盤の「俺を、置いていくな」で初めて「俺」が出る。

### 見た目

つるりとした黒い大きな塊。装甲をほとんど付けない。美形だが手入れされていない。顔が出るのは第2話。記号は三つ: 首に巻いた洗っていない布、武器を持っていないこと、左半身をかばう歩き方。指の関節が太く爪が割れている。奥歯が何本かなく、硬いものは右でしか噛めない。匂いは鉄と煙。丈の長い外套を脱がない。

## 田代ヨシノ

- 怒るのは、ミナが自分を粗末にしたときだけ。怒りの起点をそこから動かさない(トピックを飛ばさない)
- シェルター下層の出。水が「量」で配給される側。地上のことは知らない(解説役はロクゾウ)
- 腕が立つ。地下にも暴力があるから
- 九歳のミナが父に聞いた場面に居合わせている。以来十年、この家はおかしいと思っている
- 口癖は「お嬢様。自分の分は」
- 一人称「僕」(台詞稿)
- ミナと無関係な欲: 【未決】

## ロクゾウ

- 行動原理は「数が合わないと眠れない」。ミナの価値を最初に理解する。理由は情ではなく損得(「姐さん一人で、水汲みが四人浮く」)
- ハルを止めるのも損得(「ボス。それ、損です」)
- 翻訳係。ただし正しく翻訳するほどミナに伝わらない
- 作中で数字を言うのは彼だけ
- ミナと無関係な欲: 【未決】

## ゴロウ

- 暴力の象徴。哲学は持たせない。怒鳴らせない。静かに、興味なく言わせる
- 字が読めない。知識は人に読ませる(イオリの存在理由)
- ハルを番号で呼ぶ。理由は思想ではなく見下し
- 最後: 【未決】(仮置きは「崩れた陣営で手下に見捨てられる」)

## イオリ

- 水を清める機械を独占しているだけで、直す技術はない
- 利権争いや人質交渉はやらない小悪党
- 最後: 【未決】(仮置きは「止まった機械を抱えて陣営に残る」)
