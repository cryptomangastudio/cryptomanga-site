# Webtoon原稿チェックツール(ブラウザ版)

原稿PDFをドラッグ&ドロップすると、WithLinks基準でチェックしてレポートを出します。
GitHub Pages に置いた静的ページなので、サーバーの用意もインストールも不要です。

## モード

| モード | 種別 | 見るもの | 2枚目に入れるPDF |
|---|---|---|---|
| 仕上げ校閲 | 校閲(間違い探し) | シームレス・マスク抜け・描き文字の抜け・誤字・左右反転 | ネーム |
| 着彩チェック | 監修FB | 塗りの穴・線の下の塗り・色の一致・塗り分け・光源・マスク | キャラデザ/設定資料 |

**校閲と監修FBは別物です。** 校閲は間違い探しに徹してクオリティに触れず、タグは
「指摘 / 要確認 / 申し送り」。監修FBはクオリティを上げるための提案で、タグは
「修正依頼 / 相談 / 参考」。モードを切り替えると観点・文体・タグ・レポートの見出しが
すべて連動して変わります。

なお**着彩に校閲モードはありません**(校閲が入るのはネーム・線画・仕上げの3工程のみ)。

## 使い方

1. ページを開く(公開後のURL: `https://<Pagesのドメイン>/kouetsu/`)
2. モードを選ぶ
3. Anthropic の APIキーを入れる(初回だけ。ブラウザに保存されます)
4. **本稿PDF** を入れる。あれば **2枚目のPDF**(モードによって内容が変わる)も一緒に入れる
5. 「校閲を開始」/「チェックを開始」

PDFを入れた時点で、画面下部の**原稿ビューア**に本稿とネームが並んで表示されます
(スクロールは同期します。ページの高さが違っても「同じページの同じ割合の位置」で合わせます)。
校閲後は、指摘カードをクリックすると該当ページにジャンプし、指摘のあるページには件数バッジが付きます。

原稿ファイルはこの端末の外に出ません。ページを画像化して Claude API にだけ送信します。

## APIキーについて

- [Anthropic Console](https://console.anthropic.com/) で発行します。
- キーはブラウザの localStorage にのみ保存され、どこにも送信されません。
- 共用PCで使った場合は、使用後に「キーを消去」を押してください。

## コストの目安

1話(15ページ前後)で **$2〜3程度**(Claude Opus 5・思考の深さ「高」の場合)。
コストを下げたい場合は、モデルを Sonnet 5 にする、思考の深さを「中」にする、
解像度を「低」にする、のいずれかで半分程度まで下がります。

## できること / できないこと

**仕上げ校閲でできること**
- 加工のズレ・マスク抜け
- 描き文字・漫符の抜け(ネームPDFを入れた場合)
- 誤字脱字・表記ゆれ・閉じ開き(「事⇒こと」「方⇒ほう」など)
- 左右反転・鏡像の間違い
- ページ境界のシームレス破綻(前ページ下端と次ページ上端を実際に連結して確認します)

**着彩チェックでできること**
- 塗りの穴・はみだし、線の下の塗り漏れ
- キャラデザ指定色との一致(キャラデザPDFを入れた場合。HEX指定が優先)
- 塗り分けの不足、単色・グラデのみの手抜き着色
- 光源の矛盾、フキダシ・描き文字に隠れた部分の塗り漏れ

**できないこと(レポートに「クリスタ上で要確認」として出ます)**
- 仕上げ: フォント種別・サイズ・アンチエイリアス、フキダシの線幅、フキダシ下の塗り、レイヤー分け
- 着彩: カラープロファイル、レイヤー構成・レイヤー順、レイヤーカラー/サブカラーの指定

いずれもPDFの見た目からは判定できないため、クリスタ上での確認が必要です。

## 観点を育てる

チェックリストや校閲の定義は `knowledge.js` にまとまっています。
このファイルだけを編集すれば、アプリ本体を触らずに観点を追加・修正できます。

元になっている社内資料は `.claude/skills/webtoon-feedback/references/kouetsu-*.md` にあります
(校閲の流れ / 校閲レクチャー会 / U-NEXT仕上げ校閲 / U-NEXT校閲 文字まわり から抽出)。

## 注意

生成されるレポートは**ドラフト**です。クリエイターに送る前に、校閲担当が必ず目を通してください。

## 構成

大きな原稿でもメモリを圧迫しないよう、ページは帯単位で描画して即JPEG化し、
描画用のcanvasはその場で解放しています(フルページのcanvasは一度も作りません)。
画面に近づいたページだけを遅延描画します。

| ファイル | 中身 |
|---|---|
| `index.html` | 画面とアプリ本体 |
| `knowledge.js` | 校閲の定義とチェックリスト(ここを編集して観点を育てる) |
| `vendor/pdf.min.js` | PDF.js 4.10.38(PDFをブラウザ内で画像化する。Apache-2.0) |
| `vendor/pdf.worker.min.js` | 同上のワーカー |
