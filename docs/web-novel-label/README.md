## 結論（要点だけ）

### 最短ルートは二本立て
- **ルートA（本線）**: カクヨムで★とPVを作った原作を、既存のLINEマンガ様／めちゃコミ様の提案チャネルに添付する。新しい仕組みが不要なので最短。
- **ルートB（保険）**: カクヨムのコミカライズ系コンテスト。本命は **めちゃコミック×LScomic×カクヨム漫画原作コンテスト**（大賞＝コミカライズ確約。第2回は2026/1/27〜3/27、第3回は2027年1月頃と推定）。部門は①王道恋愛（年の差／ハイスペック男子／大正ロマンス／ギャップ男子）②禁断の関係 ③裏切りと復讐。

### AI利用（2026年9月時点）
- カクヨム: 投稿可。タグ付け推奨（`AI本文利用` / `AI本文一部利用` / `AI補助利用`）。2026/5/27ガイドライン改定。**ただしコンテスト個別に全面禁止の例がある**
- なろう: 開示必須化（新規2026/6/9、既存2026/9/1）。**加筆修正のない全編AI生成は禁止**
- note: 可。全編AIそのままは不可。**AI学習データ提供プログラムが初期値ON → OFFにする**
- アルファポリス: AI生成作品のコンテスト参加・出版申請を禁止 → 使わない

運用: **Claudeが下書き、人間が作家。** 人間の加筆・推敲を必ず通す。タグは正直に付ける。

### 社内ルーブリック（企画判定）
A ヒーローの執着 / B 時限爆弾 / C 呪縛とヘイト役 / D 接点ロジック / E 画面の強さ。各0〜4点、減点0〜−3。
18〜20＝最優先、15〜17＝有望、12〜14＝差別化不足、9〜11＝要ブラッシュアップ、0〜8＝見送り。
**Aが1点以下は合計8点で打ち切り。**

### 市場の最重要発見
カクヨム／なろうのランキング嗜好（ざまぁ＋領地経営＋無自覚チート）と、LINEマンガ／めちゃコミの嗜好（溺愛・執着・不倫・復讐）は**別の読者層**。
当社のゴールはコミカライズなので後者に最適化し、**ランキング1位は狙わない**。ただしタグ設計で層②に確実に届ける。
