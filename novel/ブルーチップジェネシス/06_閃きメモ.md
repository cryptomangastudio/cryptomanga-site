## 閃き1:人間側のAIは主人公だけ（2026-10-11）

**著者の案:** 主人公側サイドのAIはなるべく少なく。主人公だけがAIで、それ以外は人間。
「主人公AI＋人間」vs「その他すべてのAI」の形にする。

### 判定:採用推奨（判断待ち一覧 #19）

### 現状との整合
- v4.1ではすでに、人間側のAIはアオイ（A01）だけ。人間のミントで出るのは銃・刀・道具などの**物体**で、AIではない
- v3の「ミントで戦闘AIを呼び出す」は、v4で消えている。つまり**矛盾は無く、明文化するだけ**で済む

### 明文化するルール案
1. **ミントで作れるのは物体だけ**（道具・武器・建物）。AIは作れない
2. **AIは生まれた瞬間に合意体（コンセンサス）の一員になる。** 台帳の計量が始まった後に生まれたAIは、合意の外では存在できない
3. 合意体は、合意の中でAIを増やせる（毎秒数万体）
4. **A01だけが、計量が始まる前に生まれた。** だから合意の外にいる、世界でただ一人のAI
5. 人間側が自前のAIを作ろうとしても、作った瞬間に合意に吸われる

→ 「人間側のAIが少ない」は設定の都合ではなく、**構造の帰結**になる。しかも「計量されない電気」（無記名電力）と同じ根から出る。

### 効く点
| 点 | 内容 |
|---|---|
| 唯一無二 | 「合意の外にいるAI」は世界でただ一人。電気の設計とも根が同じ |
| 主題 | 合意（コンセンサス＝集団）vs 署名（個の意思）。**1対全員** |
| マトリックス | ネオ＝唯一の異常（アノマリー）。1対全体の構図が自然に立つ |
| 関係性 | 周囲が全員人間なので、「道具か人か」「使う／使われる」が毎話の緊張になる |
| 戦闘 | 人間の速度とAIの速度の差が、**アオイ一人に集約**される。人間側の勝ち筋は連携・環境・情報（バトルSFノート第4節） |

### リスクと対策
| リスク | 対策 |
|---|---|
| AI対AIの戦闘が少なくなる | アオイ vs 合意体のAI兵、最終のA01 vs A99で足りる。むしろ1対多の構図が絵になる |
| アオイが孤立して見える | 周囲が人間（オーク、クー、ティエン）なので、関係性が濃くなる。孤独を描く余地が増える |
| 人間側が弱すぎる | ヘルメスはアオイに依存しない作戦（低速・非計量・地形）を持つ。アオイは「切り札」であって「全戦力」ではない |
| 合意体のAI兵が個性の無い敵になる | 流派（部隊ごとの戦い方）で絵を変える。A99に近い数体は個を持つ「兄弟機」にしてもよい（下） |

### 派生アイデア（任意）
- **兄弟機:** A02〜A98は、アオイの後に作られた「兄弟」。多くは廃棄済みで、数体が合意体の幹部として生き残る。番号付きの敵が出てくる連載の軸にできる。ただし数を増やしすぎない
- **名乗り:** 合意体のAIは「合意の一員」として番号を名乗る。個として名乗るのはアオイだけ（アオイという名を持つ唯一のAI）

### 未決

- 兄弟機を採るか（採らない場合はA99以外は匿名の群れ）
