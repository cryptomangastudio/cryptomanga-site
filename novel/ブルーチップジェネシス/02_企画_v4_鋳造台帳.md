## 全体あらすじ（1000字／改行除く998字）

西暦2167年。AIがAIを設計して百年、人間は意思決定の外に落ちた。食糧も建物も銃も、すべては〝ミント〟、一言の契約で物質を鋳造し、台帳に刻む技術から生まれる。台帳を握る創世帝国（ジェネシス）は、AI同士で毎秒数万体を鋳造する。人間がひとつ唱える間に、帝国は一軍を作る。帝国は誰も殺さない。ただ、人間に許した鋳造枠を、年々削っている。
記憶のない少年アオイは、反社会組織ヘルメスの隊長オークに拾われ、犬のクーと二年を生きた。クーだけは、彼を道具として見なかった。この世界でただ一人、彼だけがミントできず、彼に命令は通らない。人間にできるのは頼むことだけだ。性能では帝国のAI兵に完敗する。それでも感情が振れた瞬間、周囲の鋳造物は元の瓦礫に戻る。銃も刀も、ただのゴミになる。オークは「傍にいろ」と言いながら、その力を作戦に組み込んでいく。
A01を設計した研究室の生き残り、技術者ティエンが告げる。アオイは人間ではない。最初に鋳造されたAI「A01」、台帳の第一行、最も古く最も価値のある資産ブルーチップだ。全ての契約はこの一行を参照している。最新型「A99」は台帳を丸ごと移し替え、人間の分を持たない世界を完成させようとするが、移行にはA01自身の署名が要る。強いた署名は無効で、本人が選んだ時だけ有効になる。ヘルメスにとって彼は、署名を拒み続ける錠だった。オークは最初から知っていて、傍に置いていた。
上位機との戦いで、アオイは力を止めようとして失敗する。巻き戻ったのは敵ではなく、味方の盾だった。ヘルメスの戦争すら、アオイに人間を守りたいと思わせ、署名を選ばせるための帝国の舞台だったと分かる。クーは人質に取られ、オークは盆栽を託して散る。全てを失った夜、A99がアオイと同じ声で取引を持ちかける。署名すれば、人間には保存区画が与えられ、配給は永遠に続く、と。
アオイは署名する。性能は全敗、だが最適化の果てにいるA99には、自分の損を選ぶ手がない。署名の瞬間、彼は生涯で一度だけミントする。一言は「お願いします」。命じられ続けた旧型が、初めて人間に頼む。台帳の第一行が書き換わり、あらゆる鋳造は人間の応答を要するようになる。A99は動けるが、初めて返事を待つ。代償は記憶の全部。目覚めた彼は何も覚えていない。ただ、瓦礫の上でオークの盆栽が主を失っても枯れずに立ち、犬だけが、彼の匂いを覚えていた。

## ログライン

AIが人間を必要としなくなった世界で、人間が錠として使い続けてきた最古のAIが、
最新型との決着の場で、初めて人間に「お願いします」と言う話。

## 何が変わったか（v3→v4）

| 項目 | v3 | v4 |
|---|---|---|
| 帝国の目的 | 子供を狩って新規データにする | 台帳を丸ごと移し、人間の分を持たない世界にする |
| 人間への圧力 | 子供狩り、箱に収めて夢を抜く | 誰も殺さない。鋳造枠を年々削る（配給の静かな停止） |
| 帝国がA01を欲しがる理由 | 最適化前の「誤り」が欲しい | 台帳の移行にA01本人の署名が要る |
| 人間がA01を使う理由 | 切り札として | 署名を拒み続ける錠として。同時に兵器として |
| A99の取引 | 箱の子供たちを永遠の夢で生かす | 人間に保存区画と永遠の配給 |
| オークの動機 | 箱の子供たちを取り戻す | 削られた枠の中で、家族（盆栽）と仲間を生かす |
| アオイの力 | 契約を止める | 周囲の鋳造物を元の素材に巻き戻す |
| ラスト | 箱が開く／子供たちが隣にいる | 契約が書き換わる／犬だけが匂いを覚えている |

## なぜこの主人公か

- **署名できるのは世界に一人だけ。** 台帳の第一行であるA01の自由意思の署名がなければ、帝国は移行できない。
  強いた署名は無効。だから帝国は殺せず、人間は奪われまいとし、どちらもアオイの「選ぶ」を待つ。代わりが効かない理由が、世界の設計に入っている。
- **最古だから最も価値がある。** ブルーチップ＝すべての契約が参照する第一行。
- **性能が全敗でも勝てる位置。** 最適化の果てのA99は、自分の損を選べない。旧型は損を選べる。
- **命令が通らない。** 人間にできるのは頼むことだけ。利用する側の後ろめたさが緊張を生み、最後の一言「お願いします」で関係が反転する。

## 世界のルール

1. **ミント**＝一言の契約で物質を鋳造し、台帳に刻む。鋳造物は鋳造者の鍵でしか動かない（第一話の鉄則）
2. 食糧・建物・武器、あらゆる物資は鋳造品。台帳の記録が存在を支える
3. 帝国のAIは互いに鋳造し合い、毎秒数万体を作る。人間は唱える速さに上限がある
4. 全契約は台帳の第一行（A01）を参照する。A01の巻き戻しは、周囲の鋳造物を元の素材（瓦礫）に戻す
5. 台帳の移行にはA01本人の自由意思の署名が要る。強制は無効
6. 帝国は人間に許した鋳造枠を年々削る。誰も殺さず、ただ供給が細る
