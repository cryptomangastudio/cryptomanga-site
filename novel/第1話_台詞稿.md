# 第1話『終末のサンクチュアリ』── 台詞オンリー稿(②)

記法は二つだけ。`「……」`= 沈黙を1行として書く。`【 】`= 意味のある無言の動作。
地の文・心情・描写は一行もなし。

## 自己チェック(判定用)

### 1|説明台詞になっていないか

- **「家も水も捨ててきた」型の復唱は、全削除した**
- 片道切符は**サヤの怒りの中**にだけ置いた ──「帰る井戸もないのに」
- 婚約者探しは**日数と範囲**でしか触れていない ──「あと八十六日」「四つに分けました」
- 人質は**誰も説明していない**。ミナが「サヤはどこですか」→「では、行きません」で成立
- 世界設定(崩壊・勢力・井戸の数・名前・過去)は**一行も出していない**

### 2|ミナが最後まで「手順」を保っているか

- 全台詞が敬体。**一度も罵らず、一度も感情を口にしていない**
- 追い詰められるほど丁寧:「まだ途中です」「手順の話です」
- **禁則「嘘をつかない」が機能した箇所**
  - サヤ「嘘です」→ ミナ「……」→「計算上は、足りています」
  - **嘘を重ねられないので、言い換えるしかない。沈黙がそのまま証拠になる**
- 最終行が「二寸、長いですね」。**世界の重さに対して、温度が一切上がらない**

### 3|ボスの無言がコマの主役になっているか

ボスの出番は全部で**19行、うち台詞はゼロ**。

| 行 | 何が起きているか |
|---|---|
| `【ボス、ミナに手を伸ばす】` | 生殺与奪の提示 |
| `ボス「……」`(拒否の直後) | **全員が死を覚悟する。読者もそう読む** |
| `【ボス、外套を脱ぐ】` | 禁則(弱みを見せない)が初めて揺れる |
| `【ボス、ミナの前に片膝をつく】` | **見開き候補。誰も理解できていない** |
| `【ボス、ミナを見る】` | 癖の破壊。手下が震える |
| `【ボス、無言でミナに着せる】` | **引きの絵。説明ゼロ** |
| `【ボス、ミナから目を離さない】` | 最終コマ |

### 想定会話率

この稿のままだと**9割以上**。
③でト書き、④で地の文を足し、**最終稿35〜50%**に着地させる。
③で足すのは**絵にできる情報だけ**(手、歯、歩き方、匂い、光)。内面は足さない。

### ③で足す予定のト書き(メモ)

- S1:荒野の色(灰と赤錆)、ミナの白い作業着
- S2:袋の内側、匂い、手下の棘だらけのシルエット、ボスのつるりとした黒い塊
- S3:水が透きとおる工程を、段階で見せる。**ここだけ枚数を使う**
- S4:三日の経過、熱の引いた肩、ドレスの裂け目
