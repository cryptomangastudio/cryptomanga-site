# 水の徹底リサーチ ── 本当にその世界になったら何が起きるか

出典はスニペット経由(本文への直接アクセスは今回も遮断)。数字を対外資料に使うなら要確認。

## 1|人は、乾いて死ぬのではない。汚い水を飲んで死ぬ

**これが本作で一番重要な発見。**

| 数字 | 出典 |
|---|---|
| 下痢性疾患で死ぬ**5歳未満 443,832人/年**、5〜9歳 50,851人/年 | WHO |
| 下痢性疾患は**全世界のDALYの4.1%**、年**180万人**の死因 | WHO |
| **水系感染症の88%**が、安全でない水と衛生に起因 | WHO |
| コレラ 2024年:患者 560,823人、**死者6,028人(前年比+50%)** | WHO |
| コレラ推定:年130〜400万人発症、21,000〜143,000人死亡 | 研究者推計 |

> **だから「水がない」は脅威ではない。「水はあるが汚い」が脅威である。**

そしてこれが、**ミナの「腹を下した者の数を教えてください」を、この世界で最も正しい質問にする**。
ロクゾウが「数えたことねえ」と答えるのは、**数えれば恐ろしい数字が出るから**である。

### 本作への反映

- 荒野の死因の一位は暴力ではなく**下痢**にする(グロに寄らず、殺伐が出る)
- 特に**子供が死ぬ**。第二幕で拠点に子供が増えるのは、そこだけ子供が死なないから
- 手下の軟膏を否定した場面と同じ構造で、**「その水は飲めません」が何度も効く**

## 2|必要量と、死ぬまでの時間

| 項目 | 数字 |
|---|---|
| 生活活動レベル低 | **2.3〜2.5L/日** |
| 生活活動レベル高(荒野の労働者はこちら) | **3.3〜3.5L/日** |
| 飲料水として最低限 | 1.2L/日 |
| 防災の目安 | 3L/日 |
| 一滴も飲めない場合 | **2〜3日で生命維持困難**(別説4〜5日) |
| 体水分 **1%減** | のどの渇き |
| 体水分 **2%減** | **めまい、吐き気、食欲減退** |

### 本作への反映(重要)

> **荒野の人間は、常に軽い脱水状態にある。**
> **体水分2%減で判断力と気分が落ちる。**
> **暴力が蔓延している生理学的な理由がこれで立つ。**

- 手下たちが短気なのは性格ではなく**脱水**である
- **拠点の水がまともになると、男たちが穏やかになる**
  → 第二幕の「飯で陥落」に医学的な裏づけが出る。**設定が感情の変化を支える**

## 3|水は重い ── 1リットル = 1キログラム

**これがレイダーという職業の物理的な根拠になる。**

- 群れ30人 × 3L = **90kg/日**。井戸がなければ、毎日90kgを奪って運ぶ
- 「水場を持たない」で三十人を食わせている、というロクゾウの台詞の重さがここで出る
- **だから略奪する。思想ではなく、運搬コストの問題である**

### 水汲み労働の実態(そのまま使える)

| 数字 | 内容 |
|---|---|
| **毎日2億時間** | 世界全体で水汲みに費やされている時間 |
| **18億人** | 自宅の敷地内で水を得られない人 |
| **10世帯中7世帯** | 水汲みを15歳以上の女性・女児が担っている |
| 片道1〜2時間を何往復 | 途上国の標準 |
| エチオピアの13歳 | 朝6時半出発、水場に10時半着、帰宅16時。**往復8時間** |
| サハラ以南24カ国 | 水汲みが30分超 = 子供336万人、女性1,354万人が担う |

### 本作への反映

- **水汲みは女と子供の仕事**にする。この世界でも同じ
- 第二幕で拠点の水が近くなったとき、**真っ先に解放されるのは女と子供**
  → 拠点が育つ描写の芯がここに立つ。「便利になった」ではなく「**誰かの一日が返ってきた**」

## 4|濾過だけでは飲めない(ミナの工程の根拠)

- 濾過の順序:**布/濾紙 → 活性炭 → 砂 → 小石**
- **濾過後の煮沸または消毒が必須**。濾しただけの水は生活用水にしかならない
- 煮沸:**海抜0mで最低1分**、標高300m上がるごとに1分追加
- 塩素消毒:漂白剤を数滴、よく混ぜて**30分静置**

### ミナの三段工程が、これで物理的に正しくなる

1. **漉す**(布で、複数回)
2. **沈める**(凝集剤。濁りが落ちていく。男たちには魔法に見える)
3. **煮る**

> **そして「待ちます」は演出ではなく、工程そのものである。**

## 5|燃料という第二の希少資源(ここが最大の収穫)

**煮沸には燃料が要る。**

水を作れる人間がいても、**焚くものがなければ水は作れない**。
つまりミナの能力には、はじめから上限がある。

### 制約の数値設計(仮)

| 項目 | 数値 |
|---|---|
| 群れの人数 | 30人 |
| 必要量 | 3L × 30 = **90L/日** |
| ミナが一人で作れる量 | **30〜50L/日**(鍋の容量と燃料の制約) |
| **差分** | **毎日40〜60L足りない** |

> **これがプロットの駆動力になる。**
> ミナ一人では、群れを賄えない。**だから拠点を作るしかない。**
> 井戸を掘り、雨を溜め、竈を増やし、人を訓練する。
> **第二幕の拠点開拓が、御都合主義ではなく必然になる。**

そして**ロクゾウが計算するのはこの差分**である。
「姐さん一人で水汲みが四人分」は、**満たされない分を数えている男の言葉**になる。

## 6|手押しポンプの物理的限界(涸れ井戸とイオリの根拠)

- 吸い上げは**大気圧が上限**。理論値10m、**実用7〜8m**
- それ以深は、水中にシリンダーを下ろす深井戸用の機構が要る

### 本作への反映

- **電気がないので、深い井戸は汲めない。だから涸れた井戸は涸れたままになる**
- 第1話の涸れ井戸で、ミナが「涸れていません。腐っているだけです」と言えるのもここ
- **イオリの「ポンプへの細工」に根拠が立つ**
  → 深井戸の機構は複雑で、読める者しか直せない。**字が読めない親父には永久に手が出ない**

## 7|水をめぐる争いは、実際に起きている

- 歴史上の水紛争は**200件以上**。**そのうち約半分が過去20年**(不足が進むほど増える)
- 江戸時代の**水論**:用水の幅と深さまで規定していたが、渇水になれば村同士が争い、
  領主や幕府を巻き込む訴訟に発展した

### 本作への反映

- **親父の支配は「奪う」だけではなく「配分する」形**にできる
  → 親父が押さえた水場から、どの集落に何杯配るかを決めている。**それが権力の実体**
- 配分表を握るのが**イオリ**(字が読める唯一の男)。二人の関係がここでも噛み合う
