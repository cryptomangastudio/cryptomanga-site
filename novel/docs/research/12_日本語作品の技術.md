# 日本語作品の技術 ──『ゴールデンカムイ』『ダンジョン飯』『葬送のフリーレン』

Falloutの笑いは英語の語法に依存している。日本語で同じことをやるための技術を、
三作から抜き出す。

**設計を変えるレベルの発見が二つあった。**(→ 第1節・第2節)

---

# 1. 最重要:笑いとシリアスは一方通行である

マンガの指導の現場で言われている法則。

> **ギャグ → シリアス は移行できる。しかも強い。**
> **シリアス → ギャグ は移行できない。**

特に、**ギャグ担当のキャラが死んだあとに笑いへ戻るのは、ほぼ不可能**とされる。

### 本作への影響

わたしの設計(09資料)は「笑いが途中から痛みに変わる」だった。
**方向としては正しい。** 一方通行の順路に沿っている。

だが同時に、こういう問題が出る。

> **中盤で笑えなくなったあと、作品に笑いが一切なくなる。**

手塚治虫の指摘がここに刺さる。

> どんなにシリアスな物語でも、場面の緊張を和らげ、
> 息切らさず次へ繋ぐために、笑いの要素は欠かせない。

読者が疲弊する。09資料の設計のままだと、後半が読めない。

### 解決:**笑いの担当を、人ごと移す**

これが『ゴールデンカムイ』のやり方だった。
杉元がシリアスを背負い、**白石が笑いを引き受ける**。
白石は戦闘能力が低く、専門技能(脱獄)だけがあり、**作中で最もいじられる**。

本作では:

- 前半 ── **トオルの礼儀正しさ**が笑いを出す
- 中盤(鍋を墓に置く場面)で、**トオル発の笑いが終わる**
- 後半 ── **アカネが笑いを引き受ける**

アカネの「ふーん。で?」は、すでにその素質がある。
彼女を**戦闘担当 兼 笑い担当**に確定する。

---

# 2. ライオス型の発見:主人公は「嫌がられる」べきである

『ダンジョン飯』のライオスについて言われていること。

- モンスターの話になると、**周りが引くほど**情熱的になる
- オタク気質を前面に出して**うっとうしがられる**
- 対人コミュニケーションが下手。人間相手でなくていいものにハマる
- キャラ造形の核は「**それは確かに合理的だが、倫理的・感情的に許し難い**」感覚
- **作中でも作品外でも嫌がられる。** それが見事だと評価されている
- **共感性羞恥**を誘発する

### わたしの見落とし

トオルを「善良で可笑しい」としか設計していなかった。
**うっとうしい、という軸がなかった。**

ルーシーは愛される。ライオスは嫌がられる。
**トオルは、その中間に置くべき。**

具体的には:

> 彼が「また明日」と言うのは、**優しさではなく、押しつけ**でもある。
> 明日死ぬかもしれない相手に、明日の話をするのは、**残酷**ですらある。

シラセの批判が、ここで正当性を持つ。
「あなたのそれは、優しさではありません。**無神経**です」

そして読者も、半分そう思っている。**これが効く。**

### リスク

ライオスは「苦手すぎて視聴を断念した」という反応も現に出ている。
**うっとうしさは、やりすぎると離脱に直結する。**

配分:**笑える(ルーシー)7 : うっとうしい(ライオス)3** くらい。

# 3. 各作品から抜くもの

## 3-1『ゴールデンカムイ』── グロを笑いで中和する

- 命を懸けた戦闘の**直後**に、変顔や下ネタを入れる
- **グロテスクな描写を、ギャグで中和している**
- 根底には重いテーマ(子の人生が親の期待・家柄・しきたりに左右される)がある
- それでも読者が疲弊しないよう、常にバランスを取り続けている

**本作で使う**:
この世界は人が簡単に死ぬ(平均寿命四十七歳、子の三割が五つまで)。
死そのものを重く書くと、読者が保たない。
**死の直後に、生活の間抜けさを一つ置く。**

例:村人が死ぬ。その夜、遺族が集まって、**故人が借りていた鍋の所有権で揉める。**
悲しいのだが、鍋である。

## 3-2『ダンジョン飯』── 硬い設定を、飄々と運ぶ

- 古典ファンタジーのモンスターを、**現実の調理法で料理する**
- モンスターの生態を論理的に考察したうえで、調理を主眼に置く
- 「食」と「生」への信頼が一切揺るがない
- 妹を救うという**強い一本のライン**があり、食を通して最後に回収される

**本作で使う**:
わたしは世界設定を実データで固めた。**それを深刻に語ると重い。**
ダンジョン飯方式は、**硬い設定を、当たり前のこととして飄々と扱う**。

例:キノコの菌床の管理を、真剣に、しかし深刻ぶらずに描く。
トオルが菌床の温度を気にする。**深刻な顔で、キノコの世話をしている。**

そして「妹を救う」に相当する一本の線が、本作では「**姉を探す**」。
これも最後に回収する。

## 3-3『葬送のフリーレン』── 感情は「間」に入れる

- **「間」が感情の器**である。沈黙を信じる。急がない
- ただし——**意図のある間は余白になり、意図のない間はただの退屈になる**
- 淡々とした語り口で、過剰な演出を避ける
- 勝利も成長も達成も描かない。「**終わったあとに何が残るか**」を問う
- 死を起点にして、生を描く

**本作で使う**:

トオルが「また明日」と言い、相手が一拍おいて「……息災で」と返す。

**この一拍が、この作品で最も重要な演出になる。**

説明しない。「相手は戸惑った」と書かない。
**間だけを置く。**

そして注意書きを自分に課す:
**意味のない間を置かない。** 沈黙は、置く理由があるときだけ置く。

# 4. 本作の笑いの配分(確定)

| 部 | 笑いの担当 | 笑いの質 |
|---|---|---|
| 第1部 前半 | **トオル** | 礼儀正しさと世界のズレ。声を出して笑える |
| 第1部 中盤 | トオル → 移行中 | 同じ行動が、痛くなり始める |
| **転換点** | ── | **鍋を墓の上に置いて帰る場面** |
| 第1部 後半 | **アカネ** | 乾いた軽口。緊張を緩める役 |
| 第2部以降 | アカネ中心 | トオル発の笑いは戻さない |

**一方通行の法則に従い、トオルの笑いは一度終わったら戻さない。**
戻すとしたら最終巻の最後の一行だけ。

---

# 5. これで書けるようになったこと

- 笑いの配置が、勘ではなく配分表で決まるようになった
- **トオルに「うっとうしさ」という欠点が入り、人物として立った**
- シラセの批判に正当性が生まれた(「それは無神経です」)
- アカネの役割が確定した(戦闘 + 後半の笑い)
- 「間」の使い方が決まった。**「息災で」の前の一拍**が本作の核になる
- 死の扱いが決まった(直後に生活の間抜けさを置く)

# 6. まだ足りないもの

- **第1話のビート表**(A-2。Falloutドラマ第1話を分単位で測る)
- **文体の決定**(A-3。人称・時制。試し書きで選ぶ)
- キャラの声の確定(B-3)
