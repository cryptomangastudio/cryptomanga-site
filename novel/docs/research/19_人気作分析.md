## 01|『世界最強の魔力持ちは平穏に暮らしたい!～何故か王太子殿下に執着されています～』

南雲いちよう / カクヨム / 全61話完結 / コミカライズ・書籍化済み
**第1話「過去」= 2,433文字**

### 数字(私の前提と食い違う)

| 項目 | 私が立てた前提 | この作品の実物 |
|---|---|---|
| 1話の文字数 | 3,500〜4,000字 | **2,433字** |
| 会話率 | 最終稿35〜50% | **目測20〜25%** |
| ヒロインの登場 | 1話で必ず | **一度も出てこない** |
| 視点 | ヒロイン | **ヒーローの三人称** |

**第1話にヒロインが出ない。** タイトルは「過去」で、中身はヒーローの暗殺未遂である。

### 構成(導入/山場/引きは守られている)

| | 中身 |
|---|---|
| **導入** | 現在・執務室。側近の報告。**謎の提示**「ある少女を十年探している」 |
| **山場** | 過去・避暑地の暗殺。信じていた護衛の裏切り |
| **引き** | **裏切り者が剣を抜いた瞬間**で切る |

### 最大の発見|説明は、謎とセットなら読める

第1話の前半は**完全な報告シーン**である。王妃の野望、母の出自、継承権、暗殺。
私のルール(情報のやり取りは削れ)なら、全部削除対象になる。

**だが読める。理由は、最初の台詞が謎だから。**

> 「例の件ですが…」
> 「**見つかったのか**」

**この二行で「何かを探している」という問いが走り出す。**
以降の説明は、その問いの答えを待つ間に読まされている。

- **説明そのものが悪いのではない。走っている問いがないのが悪い。**
- 我々が削った「子供は何人いますか」は、**走っている問いがなかった**。削除は正しい
- ただし**「情報のやり取りは常に削れ」は言い過ぎ**だった。条件を足す

> **修正:説明は、その前に謎が走っているなら成立する。**

### 文体の具体

- **一文が短い。** 読点で繋ぐ。体言止めや倒置はほぼ使わない
- **段落が短い。** 1〜4行
- **地の文に心情を直接書く**
  - 「内心では最近の仕事量に辟易しながらも」
  - 「子どもながらに安堵したのを覚えている」
  - 「心拍数が上昇しているのがわかる」
- **説明に照れがない。**「排除というのは、言い換えると暗殺だ。」と地の文が読者に直接言う
- **会話と地の文が一文に同居する**
  - 「と口を開くとレオフォードは『見つかったのか』と静かに訊く。」

### セリフの温度感(ここが一番使える)

ヒーローは**短く、静か**。

> 「見つかったのか」
> 「そうか、わかった。**ありがとう**」
> 「分かった。警備含めた準備は問題ないだろう」
> 「**ありがとう**」

**「ありがとう」を二回言っている。**
冷徹で感情を見せない王太子が、側近には礼を言う。**これが温度である。**

**裏切りは、温度の落差で描かれる。**

| | ササジ(裏切り者) |
|---|---|
| 最初 | 「**ご無事で!**」と**口角を上げる**。親しげ |
| 正体 | 「どうかされましたか」← **抑揚のないもの**。能面の表情 |

**同じ人物の同じ丁寧語が、温度だけ変わる。**

### 本作への示唆

| # | 示唆 | 判断 |
|---|---|---|
| 1 | 2,433字。3,500〜4,000は重いかもしれない | **他の作品で要検証** |
| 2 | 会話率20〜25%。35〜50%も見直し要 | **他の作品で要検証** |
| 3 | **地の文で心情を直接書いている** | **要検討。**下記 |
| 4 | 説明は謎とセットなら読める | **採用。**ルールに条件を追加 |
| 5 | **無口なヒーローにも一箇所だけ温かい言葉がある** | **採用** |

#### 3について(最重要)

私は「**地の文は計測値だけ。ミナの内面は書かない**」と決めた。
だがこの作品は**心情をそのまま地の文に書いている**。しかもヒット作である。

> **この読者層は、心情が書いてある文章に慣れている可能性が高い。**
> ミナの内面を完全に封じるのは、ジャンルの標準から外れているかもしれない。

ただし**一作では判断できない**。次の作品を見て、同じ書き方が続くかを確認する。

#### 5について(すぐ使える)

**ハルの「……」は温度ゼロだが、ゼロのままでは読者が入れない。**
この作品は、無口なヒーローに**側近への「ありがとう」だけ**を与えている。

- ハルにも、**一箇所だけ温度が出る場所**を作るべきかもしれない
- 候補:**ロクゾウに対してだけ、何か一つ**(頷く、分ける、名を呼ぶ)
- ただし**ミナに対してではない**。ミナに対する温度は終盤まで取っておく

### 第2話「かつての少女」= 3,466文字

第1話が2,433字、第2話が3,466字。**話ごとに千字以上ぶれる。**
1話の方が短い。**掴みは短く、山場の話は長い。**

### 第1〜2話で一ブロック

第1話が剣を抜いた瞬間で切れ、第2話で暗殺・救出・治癒・目覚めまでを一気に描く。
そして冒頭の問い(「見つかったのか」)に戻って閉じる。

**ブロックの仕事は「なぜ彼が十年、顔も知らない少女を探しているのか」の一点。**

- **ヒロインは第2話でもフードを被っていて顔が見えない**
- 第3話「平穏な日々」からヒロインの現在が始まる
- つまり**この作品はヒロインを三話まで出さない**

### 最大の発見|執着の起点は、一つの台詞である

レオフォードが十年探し続ける理由は、能力でも命の恩でもない。

> 「**生きること、諦めないで。大丈夫、大丈夫だよ**」

敵だらけの環境で笑顔を失った子供に、見ず知らずの子供が**温度のある言葉**をかけた。
それだけである。

**そして我々は、この型を意図的に外している。**

| | 執着の起点 |
|---|---|
| この作品 | **温かい言葉**「大丈夫だよ」 |
| 本作 | **何も要求しないこと**。ミナは温かい言葉をかけない |

ミナが言うのは「あなたの傷は、三日で塞がります」である。

> **判断:外していい。ただし代替が要る。**
> どちらも「彼が今まで受け取ったことのないもの」という点では同じ機能。
> ただし**我々の方が伝わりにくい**ので、**画で強く補う必要がある**。
> → **水を飲む場面**と**膝をついたまま立たない場面**が、その代替。

### 文体の新発見|ダッシュで心の声を独立させる

- 「**―ササジだけではない。**」
- 「**―あぁ、今日は月が美しい。**」
- 「**―逃げて**」
- 「**―その瞳は薄く緋色に光っている。**」

**心の声と、決定的な一行を、ダッシュで一行に独立させる。**
これは**マンガのモノローグ枠と同じ機能**であり、コミカライズ前提の作品では特に効く。

**本作でも使える。**地の文を計測値にする方針と両立する。

> ―男の歩幅が、左右で違う。

### 五感の細部で書く

- 「**口の中に砂利の味がする**」
- 「ドクドクと全身の血流を感じながら」
- 「生温い風が頬に触れる」(第1話)

**痛みや状況を、説明ではなく体の感覚で書く。**
これは「地の文=計測値」と完全に両立する。むしろ同じ方向。

### ヒロインの出し方(顔を見せずに)

- **第一声が行動**。「**逃げようっ…**」。説明ゼロ
- 「その声は**その場の誰よりも通っていて、その場の誰よりも存在感のあるもの**だった」
  → **声で登場させている**
- **手の温度を物理で書く**
  「少女の手は**とてもあたたかく、冷え切ったレオフォードのそれと対照的**だった」
- 台詞は全部で四つだけ。短く、幼く、**説明しない**
- **ヒロインが先に体を張る。**彼を突き飛ばして自分が斬られる

> **温度差を物理で書く**は、そのまま使える。
> ミナの手(傷がなく爪が短い)と、ハルの手(関節が太く爪が割れている)。
> **並べたカットが格差の説明になる**と既に設計済み。**触れたときの温度**を足せる。

## 02|『勇者刑に処す 懲罰勇者9004隊刑務記録』

ロケット商会 / カクヨム / 連載中154話 / 書籍化8巻

### 序 = 181文字

```
　勇者刑とは、もっとも重大な刑罰の名前である。
　少なくとも、連合行政室はそう定めている。
（中略）
　――そして、すべての魔王の根絶というのは夢物語でしかない。
```

**設定の説明そのものなのに、面白い。一文ずつ価値が反転しているから。**

| 行 | 価値 |
|---|---|
| 勇者刑とは、もっとも重大な刑罰の名前である | 定義(安定) |
| **少なくとも**、連合行政室はそう定めている | **四文字で疑義が立つ** |
| この罰に刑期はない | 絶望 |
| **唯一**、恩赦が規定されているのみだ | **希望** |
| ――**夢物語でしかない** | **希望を潰す** |

> **説明は、一文ずつ価値が反転していれば読める。**(「謎とセット」に続く第二の解)

**ミナと相性がいい。**彼女は事実を並べる人間なので、
**事実を並べながら価値を反転させれば、彼女の語りそのものがこの効果を持てる。**

### 第1話 = 5,465文字

181字の次が5,465字。**文字数の幅が全て。話の役割で決める。**

### 最大の発見|説明は「悪態」にすれば読める

**この第1話は、ほぼ全部が設定説明である。**
ドッタの罪状、勇者刑の仕組み、任務の内容、部隊の状況、《女神》の設定、主人公の聖印。
**私のルールなら壊滅的に削除対象。だが読める。**

理由は、**説明のたびに語り手が評価を下しているから**である。

> 「ドラゴンを盗んだ話を聞いたときは爆笑したが、左腕を食われたというくだりで真顔になった。
> **本当にどうかしている**」
> 「**控えめに言って、相当ふざけている。考えたやつを叩き殺したい**」
> 「人格は最低だが、**その部分だけは認めるしかない**」
> 「蘇生させられて戦う――**といえば良いことに聞こえるかもしれないが**、当然(略)無理だ」

**情報が事実として置かれていない。主人公の感情のフィルターを通って出てくる。**
だから**説明が人格描写を兼ねている**。

> **私は「情報を渡す」場面を書いていた。**
> **この作品は「情報について文句を言う」場面を書いている。**

### 会話が一度も噛み合っていない

ザイロは黙らせたい。ドッタは話したい。**全会話に対立がある。**

「蘇生がどの程度うまくいくかは、死体の状況による」は説明だが、
**ドッタを黙らせるための武器として出ている**。McKeeの「説明を弾薬にしろ」の実例。

### 引きが三段エスカレートする

棺桶 → 中に死体 → **《女神》** → **未起動の十三番目** → 魔王現象が襲来

**一話の中で三回上がる。**

### ヒロインの第一印象が「偉そう」

登場は最後の五分の一。第一声は寝ぼけた「――た、たかい?」。
そして起き上がった瞬間に、

> 「あなたが、私の、騎士ですね」
> 「**合格点を差し上げます**」
> 「敵を殲滅した暁には、この私を褒めたたえ、そして**頭を撫でなさい**」

**可憐でも健気でもない。偉そう。**

> **我々は既にこの型を使えている。**
> ミナの「**その手で、私に触らないでください**」がそれ。

## 03|『公女殿下の家庭教師』七野りく / カクヨム / 462話 / 23巻

一人称「僕」。地の文はほぼ全部が内心のツッコミで、**一行か二行で切れる**。

> 「反応に困る。」
> 「世の中、厳しい。」
> 「**残念だなー。**」
> 「……**あ、大丈夫だな、これは。**」
> 「……**なんか嫌な予感が。**」
> 「そんなに、にこやかな笑みを浮かべられましても……。」

### 設定説明を「なお、」で始めて「だよね」で閉じる

> 「**なお、**王国の四大公爵家には(略)尊称は特別に『殿下』が使われている。
> 他国だと普通は『閣下』**だよね**。」

**説明を一段落で済ませ、口語で崩して終える。**

> **基礎魔法すら使えない子を王立学校に首席入学させるまで後100日。**

- **何をするか**(首席入学させる)
- **どれだけ無理か**(基礎魔法すら使えない)
- **期限**(後100日)

**カウントダウンが始まる。**

> **我々は既に同じものを持っている。**「三ヶ月」「あと八十六日」。

> この作品は**プロローグの最終行として独立させている**。要検討。

そして直前に、**後日視点からの予告**を置いている。

> 「今から思えば……そう楽観的に考えていた自分に、**目を覚まして!** と言いたいところだけど」

**この先ひどい目に遭うことを保証する。これが引きになっている。**

### 第1〜3話(2,196 / 2,176 / 2,088字)

**この作品は、話ごとの文字数がほぼ一定である。**
プロローグ1,557、以降2,088〜2,196。**ぶれが100字程度。**

> **文字数は「作品内では一定、作品間では大きく違う」。**

### 最大の発見|毎話、最終行で読者の認識を反転させる

| 話 | 最終行で何がひっくり返るか |
|---|---|

### テストAが壊れた(条件を追加する)

第1話は**まるごと移動**である。駅で迎えられ、車に乗り、屋敷に着く。
**台詞を消したら何も残らない。私のテストAなら削除対象。**

だが面白い。理由は一つ。

> **読者だけが知らない情報があり、主人公は気づいていて、言わないから。**

道中ずっと「この子なんかおかしいな」というズレが続き、最終行で開く。

> **テストAへの追加条件:**
> **何も起きない場面が許されるのは、読者と登場人物のあいだに情報の落差があるとき。**
> 落差がなければ、やはりただの移動である。

### 我々の第1話の引きは、反転になっていない

| | 引き |
|---|---|
| この作品 | **認識が反転する**(メイド→公女殿下) |
| 本作(現行) | ロクゾウ「……終わった」= **状況の確認**。反転していない |

**反転させる案**:最終行を**ボスの反応**にする。

```
ミナ「その手で、私に触らないでください」
【誰も動かない】
【ボス、手を引く】
ロクゾウ「……は?」
```

**殺されると思ったのに、引いた。** これは反転であり、
「なぜ引いた」という問いが次話まで走る。☐ 要検討

だが本人は「**うちの研究室なら誰でも出来る魔法だ**」と思っている。

> **ミナと完全に同じ型。我々は既に持っている。**

- 敬語なのに距離が近い。「……やっぱりはめましたね?」「はは、なんのことかな?」
- **地の文のツッコミが、台詞より面白い**
  - 「いや、凄く嫌そうなんだけど」「**軽っ**」「**バレバレです**」
- **一語で切る**。「軽っ」の二文字が一番効いている

## 視点の宿題|答えが出た

> **「地の文は計測値だけ。ミナの内面は書かない」は、四篇すべてと逆行している。**

読者は**語り手の感情に乗って読んでいる**。
ミナには感情の言語がない。**だから彼女の視点だと、読者が乗る場所がない。**

### ただし、視点を変える必要はない

問題は「ミナ視点であること」ではなく、**私が彼女の内面をゼロにしたこと**だった。

> **ミナにも声を持たせる。ただし彼女の声は「感情」ではなく「手順への所感」。**

| 書かない(感傷) | 書く(所感) |
|---|---|
| 恐ろしかった | この人たちは、布を洗わないのだろうか |
| 悲しかった | 十日。いえ、九日かもしれない |
| 嬉しかった | 一度で落ちると思っていたのに |

**口語で、短く、一行か二行で切る。** 感傷にはならず、温度は出る。
**制作ルール5(感傷的な独白を書かせない)とも矛盾しない。**

### 案(採否)

| 案 | 判定 |
|---|---|
| 1 ミナ一元・内面ゼロ(旧) | **不採用。**四篇すべてと逆行 |
| 2 ロクゾウ一人称 | **保留(次善)。**悪態が使えるが、女性向けで**ヒロインの内面が読めない**のは重い |
| 3 話ごとに切り替え | 不採用。散らかる |
| **4 ミナ一元+手順への所感を口語で** | **採用。**温度が出て、感傷にならない |
