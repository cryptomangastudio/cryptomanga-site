# ライトノベル企画『あと四回の冬』(仮)

## 現在地

- **キャッチ**:誰も、引き算をしていなかった。
- **世界観**:太陽の異変を起点に文明が滅び、生き残った人類が再生した地球 ── の方向で確定済み
- **テーマ**:意味を失った継承と、警告は守られたときにだけ外れること
- **主人公**:トオル ── 読んで、**数える**。集落の余命を計算できる(06資料で確定)
- **舞台**:滅亡から約300年後の関西。旧万博記念公園一帯
- **媒体**:ライトノベル(小説。マンガ原作化は後で検討)
- **参考にする手触り**:Fallout(シェルター→地上、勢力の灰色、レトロフューチャー)
