# 05 方針再判定 — n8n GOの撤回と、最終提案〔2026-07〕

> 代表の「そもそも本当にGOでいい?」への回答。**n8n事業としてのGOは撤回を提案する。**

## n8nを撤回する理由(推敲で直しきれなかった穴2つ)

### 穴1: 動機の穴 — 狙う客は、n8nを必要としていない

docs/04で「書いて売る個人」に差別化したが、この差別化は自己矛盾を含んでいた:
- **n8nを欲しがる人** = ツールいじりが好きなAI層 → 先行3者が押さえている
- **うちが狙うと決めた人**(書いて売る個人) = 欲しいのは「結果」であってワークフローエンジンではない。
  Dockerの壁・$24/月・トークン管理を越えてまでn8nを動かす動機が薄い。彼らに合うのは完成品(SaaS/代行/もっと簡単な予約ツール)
- 段差商売(個別支援)は「どうしても越えたい人」がいて初めて成立する。**越える動機の総量を検証しないままGOと言っていた**

### 穴2: 運用適合 — この事業は、うちの体制と噛み合わない

- n8nテンプレはn8n本体(2.0破壊的変更)×Meta APIの**二重保守**。窓は12〜18ヶ月で、走り続ける前提の事業
- 一方でうちの実績: AffiForge・らくアフィは作ったが**クローズした**。完璧主義で作りかけが溜まる傾向も一次情報にある(kindle/企画/著者プロフィール)。
  保守が重く鮮度が命の事業は、**この体制が最も苦手とする型**
- 戦いに勝てるかの前に、「この戦いを18ヶ月続けられるか」で答えが出ていた

## らくスレについて(代表の見立てに同意)

**ニッチすぎて収益柱にはならない、はその通り。** Threadsユーザー×有料ツールの市場は小さく、ツール保守の負債も上と同じ構造。
ただし**捨てる必要はない**: 「自分の道具で自分の発信を回している」という実演素材・無料の集客装置としては働く。
位置づけ=収益柱ではなく**小道具**。開発投資は最小限に。

## 3回の調査が同じ答えを出し続けている(パターンの直視)

AIライティング(05-09)・Notionテンプレ(10-14)・横断12カテゴリ(15-19)・n8n(20-21)——**全部の調査で同じ法則が出た**:

1. フロントの形式(テンプレ/チェックリスト/ワークフロー)は何であれ**消耗品**。AIの進歩と同じ速度で陳腐化する
2. 稼いでいるのは例外なく「**ドメイン知識×読者(リスト)×後段の教育・コミュニティ**」
3. つまり「どの形式が狙い目か」を探し続けても答えは出ない。**決めるべきは形式ではなく、複製不能なドメイン知識をどれにするか**

うちが持っていて他人がAIで複製できないものは、結局1つしかない:
**編集・出版の現場でAIの原稿を商品になるまで直してきた実務**(Kindle6冊+脱AI文体ルール10本+制作パイプライン)+本人の物語。

## 最終提案

**主軸: 「AIで書いて売る個人のための編集者」(research/05の結論を、文体単品でなく編集全体で復活)**

- 対象: note・Kindle・ブログで「AIで書いて売りたいが品質で埋もれている個人」
  (note年間流通213億円・「AI活用」が公式急成長ジャンル・編集者権威が最も効く層 = research/09)
- フロント: 安くて保守ゼロの配布物。**第1弾(配布01・脱AI文体チェックリスト)は完成済み**
- 収益: 添削・個別支援(月1〜5万)→note有料(実用系1,842円帯)→メンバーシップ(1,980円×50人で月10万)。
  検証可能な中央値パス(research/09)
- n8n: **事業から素材に降格**。「半自動(作業はAIに、顔は人間に)」の実演を1本見せる小道具。Creator Hub申請などの投資はしない
- らくスレ: 同じく小道具(実演・無料配布)

### 「すぐ飽和しそう」への回答(前回この案を見送った理由に答える)

調べた全市場を並べると、飽和・崩壊が速い順に:
プロンプト単品(崩壊済み)>汎用printables(崩壊済み)>Notionテンプレ(AI侵食が時差なし)>n8nテンプレ(12-18ヶ月)>**編集・添削(最も遅い)**。
理由: 「AIで作る」側は供給が無限に増えるが、**「AIで作った物を商品品質に上げる」側は本物の編集経験者しか供給できず、構造的に増えない**。
research/08の結論も同じ(モデルが進歩しても編集判断・一次情報の価値は残る)。飽和が怖いなら、なおさら一番飽和しにくい場所に立つべき。
なお前回見送った「文体テクニック単品」は今回もやらない(それは実際にすぐ枯れる)。売るのは編集の判断と伴走。
