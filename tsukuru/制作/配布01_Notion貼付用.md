# AIっぽい文章を消す26のチェックリスト

AIに書かせた文章を、人が最後まで読む文章に直す

---

自分の本のまえがきを、AIに書かせたことがあるんです。

出てきた原稿を読んで、最初に思ったのが「なんだこれ」でした。文句のつけようがないんですよ。事実は合ってるし、誤字もない。構成も綺麗。なのに、1ミリも読む気が起きない。

しばらく画面を睨んで、やっと言葉になったのがこれでした。

**「書いた本人の顔が、どこにもない」**

僕の話のはずなのに、僕がいない。

そこから、原稿を直すたびにメモを取るようになりました。「うわ、これAIっぽい」と思った瞬間を、片っ端から書き留めていく。それが26個たまったので、リストにしています。

上から順に当ててみてください。Dの「体温」だけでも効きます。

---

## A. 言い回し(今日から直せる)

- [ ] **1. 本音の前の「合図」を打っていないか** — 「正直に言うと」「ここだけの話」「実は」。本当のことは、前振りなしでいきなり書く
- [ ] **2. AI定番語を乱発していないか** — 「本質」「まさに」「〜と言えるでしょう」「〜に他ならない」「ポテンシャル」「ある種の」。滑らかで無難な言い回しはAI臭の温床
- [ ] **3. 読者の感情を指定していないか** — 「〜ですよね?」「肩の力を抜いて」「ちょっと待ってください」。事実と自分の話を置いて、感じ方は読者に委ねる
- [ ] **4. 芝居がかった呼びかけをしていないか** — 「ねえ、あなたに聞きたい」。セミナー講師のマイクの響きになる
- [ ] **5. 流行りの概念ラベルをそのまま解説していないか** — 「タイパ」「ワンオペ」等を定義から語ると、100万回擦られた一般論になる。ラベルを剥がして、自分の家・職場で実際に起きた場面で語る

## B. リズム

- [ ] **6. 全文が同じ心地よいリズムになっていないか** — 一文の長さをわざと不均一に。整いすぎたら崩す
- [ ] **7. 「——」でタメを作りすぎていないか** — 多くて記事に1回
- [ ] **8. 「A。B、C、Dも。」の3拍子羅列が続いていないか** — 綺麗な羅列はAIの癖
- [ ] **9. 短文ぶつ切りを連発していないか** — 「終わり。眠れなかった。後悔だけ。」はスライド広告の文体。短文は"ここぞ"の一撃だけ
- [ ] **10. 箇条書きに逃げすぎていないか** — リストが増えるほどプレゼン資料の匂いになる。文章のリズムの中で読ませる

## C. 構成

- [ ] **11. 「実績→挫折→共感」の黄金テンプレになっていないか** — 語り順をわざとズラす。オチを先に言う、時系列を崩す
- [ ] **12. 綺麗な1対1の対比を繰り返していないか** — 「AはXX、一方BはYY」が等間隔で続くと、2回目で読者は飽きる。対比は時々の武器に留め、使うときも左右対称にしない
- [ ] **13. 締めが「ドヤ顔の総括+次回予告」になっていないか** — 綺麗にまとめず、問い・余韻・ヒリヒリする現実を残してぶつ切りで終わる
- [ ] **14. 気遣いの前置きを打っていないか** — 「誤解しないでほしいのですが」。削って、いきなり言う
- [ ] **15. 全体が等間隔で行儀よく整いすぎていないか** — 感情の起伏をわざと不格好に。小さな脱線を1つ残す

## D. 体温(いちばん効く)

- [ ] **16. 感情語だけで済ませていないか** — 「絶望した」「つらかった」で終わらせず、その時の身体・行動・具体物を書く。胃はどうだったか、手は、その日の部屋は、誰に言えたか
- [ ] **17. 大事件を数字だけで処理していないか** — 「◯万円失った」で終わると記号になる。その数字を見た瞬間に何をしていたかを書く
- [ ] **18. 自分にツッコミを入れて実況していないか** — 「……いきなり物騒ですね。落ち着いて」のようなセルフ実況は、キャラを演じているだけに見える。内省は茶化さない
- [ ] **19. 比喩が劇画調のクリシェになっていないか** — 「奈落の底」「地獄の扉」「脳汁」「電子の海の藻屑」。本当に絶望した人は、もっと静かで乾いた言葉で語る。比喩は生活半径1メートルから採る(スマホの充電残量、段ボール、レジ、エクセル)
- [ ] **20. 成功談がトントン拍子になっていないか** — 冷や汗を混ぜる。決断の前に誰に相談したか、その時の声、深夜に虚しくなった瞬間。冷や汗の量が文章の熱量を決める
- [ ] **21. 都合の悪い現実を省いた綺麗事になっていないか** — 「〜すれば自動で稼げる」と理想化しかけたら、自分でツッコんで現実に引き戻す
- [ ] **22. 口調が途中で変わっていないか** — 情けない失敗談を語っていた人が、急に「あなたは悪くない」と読者を救うカウンセラーに変貌する。最後まで同じ一人が喋る

## E. 信頼(見落とすと一発で崩れる)

- [ ] **23. 自分がやっていないことをノウハウとして語っていないか** — 読者は必ず気づく。やっていないなら「これは自分はやっていないが」と断る
- [ ] **24. 自分の成功例をそのまま一般化していないか** — 「出来すぎた例かもしれない。でも仮に半分でも——」と自分から予防線を張ると、逆に説得力が増す
- [ ] **25. データを「講義」にしていないか。逆に、ぼかしすぎていないか** — 「調査によると〜」の解説はニュース原稿。かといって「半分くらい」とぼかすと権威が消える。硬い数字は記事に1〜2個、自分の反応とセットで刺す(「48.1%。ほぼ2人に1人。僕もその一人だった」)
- [ ] **26. 断定できない事実をそれっぽく書いていないか** — AIの数字・固有名詞・制度の記述は疑って確認する。間違いが1つ見つかると全部が疑われる

# そのまま使えるリライトプロンプト3本

## ① 番人プロンプト — チェックを自動化する

```
あなたは「脱AI文体の番人」です。以下のチェックリストを基準に、
この後貼る文章から「AIっぽさ」を全て指摘してください。

指摘の形式:
- 該当箇所を引用 → どの項目に違反しているか → 直し方の提案
- 直し方が複数あるときは2案
- 問題ない箇所を褒めない。指摘だけを淡々と

チェックリスト:
(上の26項目を貼る)

文章:
(自分の文章を貼る)
```

## ② 体温注入プロンプト — AIに書かせず、自分から引き出す

```
以下は私の体験談の下書きです。この文章の「体温が足りない箇所」を3つ特定し、
それぞれについて、私の実体験を引き出すための質問をしてください。

条件:
- 質問は「その時、身体はどうだったか」「その場に何があったか」
  「誰に何と言ったか/言えなかったか」など、五感と具体物を掘るもの
- 私が答えたら、その答えを使って該当箇所を書き直す。
  答えていないことは創作しない

下書き:
(文章を貼る)
```

## ③ リズム崩しプロンプト — 整いすぎを直す

```
以下の文章は内容は良いのですが、リズムが整いすぎてAIっぽく見えます。
次の操作だけを行ってください。内容・主張は変えないこと。

- 一文の長さを不均一にする(長い文と短い文を混ぜる)
- 3拍子の綺麗な羅列を崩す
- 接続詞の「確かに〜。でも〜。だからこそ〜」パターンを解体する
- 締めの綺麗な総括を、余韻を残すぶつ切りに変える

文章:
(文章を貼る)
```
