# 配布01 投稿設計 — 脱AI文体チェックリストの配り方

> 〔2026-07〕`配布01_脱AI文体チェックリスト_v1.md`(承認済み)を配るための投稿設計。
> 方針は `../docs/01`、根拠は `../research/02〜04` と `../tracker/観測ログ.md`。

## 受け取り条件 〔推奨: ハードル最小型〕

**必須はコメントのみ。フォローもリポストも条件にしない。**

```
必須: この投稿に「文体」とコメント → 返信でURLを送ります
任意: 更新版も受け取りたい人はフォローだけしておいてください
```

### なぜ条件を盛らないか

| 論点 | 条件を盛る場合(界隈の標準) | 条件を最小にする場合(推奨) |
|---|---|---|
| フォロワー増 | 多い。ただし**配布目的のフォロワーは剥がれる**(research/02失敗1) | 少ないが、内容で納得した人だけが残る |
| 参加数 | 手順が多いほど脱落 | 最大化。**コメント数=Threadsの最重要拡散シグナル**(research/04) |
| ブランド | 煽り界隈と同じ見た目になる | 「条件を付けない人」として界隈で目立つ |

つくるの軸は「同じ一人が全部欲しがる実用物を配る人」。フォロワー数は副指標(`docs/01`)なので、
**条件を盛ってフォロワーを買いに行くより、コメント数を最大化して拡散とリストの入口を広げる方が方針と一致する**。

※検証したい場合は、第2弾(ネタ管理DB)で「フォロー+コメント」条件にして受け取り数を比較する。
1回の配布で条件を変えて比較はできないので、配布ごとに1条件だけ変える。

## Threads投稿文(本命)〔v3: 本人の口ぶりを注入。文体基準=`../docs/02`〕

> v2は「整っているがAI臭が抜けただけ」で、本人の声になっていなかった。
> `kindle/企画/第1巻_Kindle版_本文.md`(著者リライト稿)から口ぶりを抽出して反映:
> **「〜んです/〜んですよ」の説明形・内心をカギカッコでそのまま置く・自虐・体言止めのぶつ切り**。

> 注意: 本文に外部リンクを貼るとリーチが1/2〜1/4に落ちる(research/04)。**URLは返信で送る**。
> 【要確認】冒頭の「まえがきをAIに下書きさせて、読み返して駄目だと思った」が事実と合っているか。
> 元は`kindle/docs/09`の発端(第1巻まえがき初稿への批評「無難で綺麗なだけの副業本まえがき/
> 書いた本人の顔と体温が見えない」)。**体験の主語が違うなら直す。ここを作り話にしたら全部台無し**。

```
自分の本のまえがきを、AIに書かせたことがあるんです。

出てきた原稿を読んで、最初に思ったのが「なんだこれ」でした。
文句のつけようがないんですよ。事実は合ってるし、誤字もない。構成も綺麗。
なのに、1ミリも読む気が起きない。

しばらく画面を睨んで、やっと言葉になったのがこれでした。

「書いた本人の顔が、どこにもない」

僕の話のはずなのに、僕がいない。

そこから、原稿を直すたびにメモを取るようになりました。
「うわ、これAIっぽい」と思った瞬間を、片っ端から書き留めていく。

たとえば、こういうやつです。

・本音を言う前に「正直に言うと」って合図を打つ。本当のことは前振りなしで
　書けばいいのに、なぜか一拍置きたがる
・「絶望した」で終わらせる。その時に胃がどうだったのか、手元に何があったのかを
　書かないと、ただの記号なんですよ
・成功談がやたらトントン拍子。決断する前に妻へ相談したときの情けない声とか、
　深夜に「何やってんだろ」って虚しくなった瞬間が、きれいに消えている

これが26個たまりました。
言い回し、リズム、構成、体温、信頼の5つに分けてあります。

あと、この26項目で自分の文章を採点させるプロンプトも入れました。
毎回26個を目で追うなんて無理なので、AIに見張らせてます。

コメントに「文体」と書いてくれたら、返信でURLを送ります。
```

### v1(没)から何を変えたか

v1は自分の26項目に違反していた。**脱AI文体のリストを配る投稿がAIっぽいのは、それだけで終わり**なので全部書き直した。

| v1の問題 | 該当項目 | v2の対応 |
|---|---|---|
| 「3行で気づかれます」と根拠なく断定 | 26 | 削除。自分に起きたことだけ書く |
| 「問題提起→経験→リスト→CTA」の教科書構成 | 11 | 失敗の場面から始める。構成を崩す |
| A〜Eを均等に並べ「ほか2項目」で揃えた | 15 | カタログをやめ、実際の項目を3つだけ、長さもバラバラに見せる |
| 「ここが一番きつい」等のキメ短文 | 9 | 短文の一撃は「事実は合っている。誤字もない。」の1回だけ |
| 締めが「新しいAI臭を見つけるたびに足しています」 | 13 | 総括せず、受け取り方法で終える |
| 体温ゼロ(編集経験を語るだけで場面がない) | 16・23 | 実際のまえがきの場面から入る |

### 残っている設計意図

- **煽らない**: 締切なし・収益自慢なし・「消します」なし(観測ログ6)
- 全項目の列挙は**配布物側(Notionページ)でやる**。投稿では3つに絞る。
  観測ログ3の「見せ切る」は守りつつ、投稿がカタログになるのを避けるための分担
- 末尾で追加のフォロー誘導をしない。整った締めになるうえ、条件を増やす印象になる

## X版(同時投稿・チャネル比較用)

Xは長文が読まれにくいので圧縮し、リプ欄に全26項目をぶら下げる。
**チャネル比較のため受け取り経路は同じ「コメント→返信」に揃える**。条件が違うと比較にならない。

```

そこから原稿を直すたびに「うわ、これAIっぽい」をメモしていったら26個になりました。
言い回し、リズム、構成、体温、信頼の5つに分けてあります。
採点用のプロンプトも3本つけました。

コメントに「文体」と書いてくれたら、返信でURLを送ります。

(全26項目はリプ欄に)
```

## 配布物の置き場所 〔2026-07 再検討: 自サイト推奨に変更〕

当初Notionを前提にしていたが、**このチェックリストにNotionである必然性はない**(データベース機能を
使わないため)。`affiforge/` `rakuaffi/` と同じ形で**自サイトの1ページとして出す方が良い**。

| 論点 | Notionページ | 自サイトのページ(推奨) |
|---|---|---|
| 受け取りハードル | 閲覧は可。**書き込むには複製=ログインが必要** | アカウント不要で即読める。条件を最小にした方針と一貫 |
| 使えるか | 複製して初めて自分用になる | **チェック状態をlocalStorageで保存すれば、そのまま校正ツールになる** |
| 資産 | 滞在もトラフィックもNotion側 | 自分のドメインに貯まる。他の配布物・既存ツールへの導線を置ける |
| 権威性 | 匿名のページに見える | **編集・出版をやっている会社のサイトにある編集チェックリスト**という裏付けが効く |
| 更新 | 即反映 | 即反映(同じ) |
| 形式比較 | 01も02もNotionだと「置き場所」が交絡する | 01=Webページ / 02=Notion / 03=ミニツール で形式が綺麗に分かれる |
| コスト | 0 | 0(既存リポジトリに置くだけ) |

**線引き: Notionを使うのは「Notionの機能そのものが価値になるとき」だけ。**
第2弾のネタ管理DBはデータベース機能が要るのでNotionが正解。今回は違う。

- ページ末尾に、次の配布物の予告を1行だけ置く。ここが拡散層→顧客層の入口になる
- **リスト登録は求めない**(浅い配布のため)。LINE/メールの用意は第2弾までに準備すればよい
- PDFは作らない。更新できない形式は「永久無料+Ver1.xで改良」の方針と噛み合わない

> 留意点: 自サイトに置くと**つくる ↔ CryptoManga Studios が紐づく**。
> 権威性としてはプラスだが、`kindle`側のぼかし方針(社名・業種を出さない)との兼ね合いは要判断。
> チェックリスト本文に書名やブランド名は出していないので、現状は問題ない想定。

## 測定 〔`docs/01`のガードレール〕

| 指標 | 記録先 | 見方 |
|---|---|---|
| 主: 受け取り数(コメント数) | `../tracker/配布実績.md` | **インプの0.4%が目安**(観測ログ2)。1万インプで40人前後なら想定内 |
| 副1: インプレッション | 同上 | 入口の太さ。**主指標にしない** |
| 副2: フォロワー増 | 同上 | 条件にしていないので、増えたぶんは質が高いはず |
| 副3: Threads/X別の受け取り数 | 同上 | どちらが主戦場かを数字で決める。感覚で乗り換えない |

**停止ライン**: 拡散(インプ)は出るのに受け取りが0.1%を大きく下回る場合、配布物ではなく
「見せ方」の問題(中身の列挙が足りない/訴求がズレている)を疑って投稿文を作り直す。配布物自体はまだ捨てない。

## 返信テンプレ(コメントが来たとき)

手動返信で足りる想定。同じ文をコピペで使う。**売り込みを足さない**。

```
ありがとうございます。こちらです。
(URL)

Notionの右上から複製すれば、自分用に書き込めます。
```

伸びて手が回らなくなったら自動返信ツールを検討する。**先に自動化しない**
(非公式ツールはアカウント制限のリスクがある。research/02失敗4)。

## 公開当日の手順

1. Notionページを公開設定+複製可にして、URLを控える
2. Threadsに投稿(本文にURLを入れない)
3. Xに投稿 → **自分のリプに全26項目をぶら下げる**
4. コメントが来たら返信テンプレでURLを送る
5. 24時間後・1週間後に、インプ/コメント数/フォロワー増を`../tracker/配布実績.md`に記録
