# 05 AIライティング特化の是非 — 統合判断〔2026-07〕

> 4本の調査(`06`需要 / `07`競合 / `08`リスク / `09`買い手)の統合。詳細と出典は各ファイル。

## 結論(提案)

**「脱AI文体」単品への特化は×。「AIで書いて売る個人のための編集」への特化は条件付き○。**

同じに見えて違う。前者は文体テクニックが商品の本体で、後者は編集判断・企画・一次情報の引き出し方が本体。
文体テクニックは入口のフック(配布物)としては優秀だが、商品の本体に置くと1〜2年で陳腐化する。

## 判断の根拠(4調査の交差点)

### 1. 需要はあるが、訴求を間違えると空振りする(`06`)
- 書き手側の悩みとしての需要は本物: 文章作成は生成AI利用の最多用途(企業47〜60%)、個人利用率は1年で約3倍
- **ただし読者は「AIっぽさ」をそれほど嫌っていない**: 離脱要因の7位(17.1%)。1位は「結論不明瞭」44.8%
- → 刺さる訴求は「読者に嫌われる」ではなく「**埋もれる・売れない・規制で弾かれる**」

### 2. 金は動いている。ただし稼げる形式は限られる(`07`)
- 実売の実例: Brain教材59,800円×463部(≈2,770万円)、7,480円×レビュー214件、10万円超スクールが満席
- **プロンプト単体は無料公開が氾濫していて商品にならない**。稼ぐのは体系化教材・添削・コミュニティの上位帯
- 「出版編集の現場出身」を看板にするプレイヤーは**確認できず=ほぼ空席**。ただしフォレスト出版が2026/7にど真ん中の商業出版を刊行するなど、埋まり始めている。**窓は1年程度と見るべき**

### 3. 最大のリスクは陳腐化と買い手の退場(`08`)
- 最新モデルは「AIっぽさ」を大幅に軽減済み。**文体修正ノウハウは12〜18ヶ月周期で陳腐化しうる**
- **低単価Webライター層は市場から退場中**(Upworkライティング案件-32%、クラウドワークス純損失)。この層を買い手に想定してはいけない
- Google・KDP・読者調査のいずれも「AIか否か」より品質基準 → 「バレない技術」は売り物にならない
- 持続する側: アンチAI感情の高まり、"Made by Human"の商業価値化、**編集判断・一次情報の価値は残る**

### 4. 買い手は「AIで書いて売りたい個人」(`09`)
- note: 年間流通170億円・月間収益クリエイター4万人・**「AI活用」が公式発表の急成長ジャンル筆頭**。実用系の売れ筋平均1,842円
- KDP: 1日3冊規制が示す「AI量産→埋もれる」構造 = 編集ノウハウの痛点が構造化している
- **編集・出版出身の権威が最も効くのがこの層**(プロ編集者のKindle講座・小説講評が商品として成立している実例あり)
- Webライター初心者市場は最大だが、60.9%が月収3万円未満で単価耐性が低く、「稼げた実績」訴求のスクール大手と正面競合になる → 避ける

## 月10万円の現実ライン(中央値ベース・`09`)

無名の単発教材は月数部しか売れない。二段構成が実例と整合する:

- **フェーズ1(0〜6ヶ月)**: 添削・個別支援が主軸(添削8,000円×8件+有料note1,800円×15部+相談) ≈ 月10万
  - ゼロフォロワーならnoteは月3〜5部と見る(その場合月7万前後)
- **フェーズ2(6〜18ヶ月)**: ストック化(メンバーシップ1,980円×50人 または 教材9,800円×10部/月)
- 法人研修(半日30〜50万円)は書籍・実績が揃った後の上振れオプション

## 配布戦略への反映(docs/03 v3で確定させる事項)

1. **看板を変える**: 「脱AI文体の人」ではなく「**AIで書く個人のための編集者**」。文体は入口、編集が本体
2. **配布01(チェックリスト)は入口フックとして有効なまま**(競合薄・拡散向き・保守ゼロ)。公開してよい
3. **主ターゲット= Kindle個人出版者・note有料販売者**。Webライター初心者向けの見せ方をしない
4. **有料の出口を先に作る**: 初期は添削・個別(労働集約だが信頼と実例が貯まる)→ note有料/メンバーシップへ
5. **陳腐化時計(12〜18ヶ月)を前提に早く出す**。「文体の癖」依存の配布物は賞味期限を明記し、Ver更新を前提にする
6. 権威の見せ方: 「編集・出版の現場で原稿を直してきた」を明示する(詐欺疑義業者が多い市場で、本物の経歴がそのまま差別化になる)

## 残る不確実性(正直に)

- 検索ボリュームの一次データは取れていない(SEO記事の量産という間接証拠のみ)
- 「編集者権威×AIライティング」で実際に売った日本語圏の先行実例がない(空席=未検証でもある)
- noteのAI活用ジャンル成長が「AIで稼ぐ話」中心で、「AIの原稿を良くする話」が同様に売れるかは未実証
- → **小さく検証する設計は維持**(配布01の反応 → 添削の少数受注 → 有料note1本、の順で確かめる)
