# 配布物候補ワークシート

> リサーチ(`../research/00_リサーチ計画.md`)を終えた候補をここで採点し、最初の2〜3個を決める。
> 選定ルール: **形式をばらす**(同形式で複数選ばない)。合計点の高い順ではなく、形式ごとの最高点を選ぶ。

## 採点基準(各1〜5点)

| 基準 | 5点の状態 | 1点の状態 |
|---|---|---|
| **悩みの頻度** | Step2で何度も観測した悩みに刺さる | 思いつきで悩みの実在が未確認 |
| **観測の裏付け** | 類似形式の配布がXで反応率高く伸びていた | 類似の配布事例を見ていない |
| **制作の速さ** | 既存資産の切り出しで数日で出せる | ゼロから数週間かかる |
| **保守の軽さ** | 配りきり(テンプレ/PDF/チェックリスト) | 動作環境依存で問い合わせが来る(プラグイン等) |
| **有料版への地続き** | Pro版・自動化版が自然に想像できる | 無料で完結し上位版が作れない |
| **軸との一致** | 「発信・副業の面倒を楽に」のど真ん中 | ペルソナがずれる(バズ狙い) |
