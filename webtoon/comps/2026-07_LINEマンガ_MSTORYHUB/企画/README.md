# 企画の中身はここに置かない(意図的)

本リポジトリ `cryptomangastudio/cryptomanga-site` は **public** である。
企画の中身(ログライン・プロット・シノプシス・キャラクター設定・台本)を締切前に公開すると、
競合の応募者に読まれる。応募規約に違反はしないが、戦術上の不利になる。

**したがって、このディレクトリの中身は `webtoon/.gitignore` でコミット対象から外している。**

---

## 運用ルール

| 対象 | 置き場所 |
|---|---|
| 要項・リスク分析・ロードマップ・ベンチマーク等の**調査と分析** | リポジトリ(公開してよい) |
| **企画の中身**(ログライン以降のすべて) | **ローカル管理** — コミットしない |
| 公式配布の企画書フォーマット(.docx) | **ローカル管理** — 第三者の配布物のため再配布しない |

### 重要: 作業環境は一時コンテナ
Claude Code の実行環境はセッション終了後に破棄される。
**コミットしないファイルは、この環境に置いたままだと消える。**

そのため企画ファイルは、生成のつど**本人のローカル環境へ受け渡す**運用とする。
セッションを跨ぐときは、直近のファイルを再アップロードして作業を再開する。

### 解禁のタイミング
2026年10月16日(結果通知期限)を過ぎ、かつ本企画で採用されなかった場合は、
公開しても戦術上の不利は消える。その時点でコミットするかを再判断する。
採用された場合は、契約上の秘密保持の有無を確認するまで非公開を維持する。
