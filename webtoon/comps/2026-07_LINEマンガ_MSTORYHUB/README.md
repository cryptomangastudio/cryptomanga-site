## 攻略の中心(これだけは外さない)

**「3話トライアル制作」が企画設計を規定する。**

採用企画は1〜3話だけ作られ、LINEマンガ インディーズで無料公開され、**読者の反応で連載可否が決まる**。
審査で問われているのは壮大な長期構想ではなく、**最初の3話で読者を掴めるか**。
長期プロットは破綻していないことを示せれば十分で、**紙幅は冒頭3話に寄せる**。

そして査読するのはMSTORYHUB。日本の少女マンガの呼吸ではなく、
韓国ロマファンの「**剥奪 → 選択 → 奪還**」を正面から満たしにいく。
虐げの描写は燃料であって目的ではない。**虐げの尺より、反撃の一手の切れ味。**

## フォーマットから判明した勝負どころ

公式フォーマット(Word・全11項目)は入手済み。**記入例が最大の情報源**だった。

1. **記入例は韓国語からの機械翻訳**(「家門」が「家紋」、「令嬢」が「英愛」等の誤訳が残る)。
   → 査読者は韓国語話者。**日本語の巧拙より構造の明快さで評価される**。翻訳耐性の高い短文で書く。
2. **記入例のストーリー自体が本テーマの模範解答**(虐待された令嬢＋治癒能力／竜王＋略奪婚)。
   → 全応募者が同じ見本を見ている。**同じ部品で組むと埋もれる。**
3. **求められる感情語が明示されている**:
   救済叙事 / サイダー(溜飲) / 成長型ヒロイン / 保護本能 / カタルシス / エキゾチックなスケール。
4. **プロット欄(500字)はセリフを入れてよい** — 記入例が掛け合い主体。要約に使うのは損。
5. **1話コンテは任意提出** — 出せば完成度で差がつく。当方はスタジオ実務者なので優位。

詳細 → `企画書フォーマット分析.md`
