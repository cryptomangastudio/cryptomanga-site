# 企画書フォーマット分析

> 原本: `MSTORYHUB企画脚本コンペ_応募作品の題名.docx`(公式配布、Word)
> ファイル名の「応募作品の題名」部分を自作のタイトルに差し替えて提出する想定。
> **項目の改変は不可。** 冒頭に「企画書内にはお名前、経歴以外の個人情報(電話番号、メールアドレス等)を
> 記載しないでください」と明記あり。
> 最終更新: 2026-07-29

---

## 1. 項目一覧(全11項目)

| # | 項目 | 制約・要求 |
|---|---|---|
| 1 | 作品タイトル | — |
| 2 | 予想読者(ターゲット) | 例示は年代＋性別の粒度 |
| 3 | 想定全話数 | 例示は100話 → **長編前提** |
| 4 | ログライン(一行紹介) | 1文 |
| 5 | プロット | **500文字以内**(唯一の明示的な字数制限) |
| 6 | 作品の見どころ/アピール要素 | **3つ**、各1文 |
| 7 | キャラクター紹介 | ヒロイン・ヒーロー・ヴィラン・その他主要人物 |
| 8 | 世界観 | **主要人物の関係性に直接影響する設定がある場合のみ**記載 |
| 9 | シノプシス | **起承転結をすべて含むこと** |
| 10 | 1〜3話構成及びエンディングポイント | 1話・2話・3話それぞれ |
| 11 | 1話コンテ | **任意**・自由形式 |

### 項目7(キャラクター紹介)の要求が細かい
公式の指示文が求めているのは以下。ここは手を抜けない。

- 主要人物(ヒロイン/ヒーロー/ヴィラン/その他、作中の面白さのために設定した人物)を挙げる
- メインの2人は **名前・年齢・設定** に加えて
  - **後半に変わる設定や成長ルート**
  - **互いに反発する(対立する)きっかけ**
  を詳細に書く
- 記入例には **「キャラクターチャーム」** という独自欄がある(その人物の魅力を一言で定義する欄)

> **読み取り**: 静的なプロフィールではなく、**変化の軌跡と関係の力学**を書けという指示。
> 「〜な性格」で終わる紹介文は要求を満たしていない。

### 項目10の内部構造(記入例が示す型)
1話の記入例が `＜導入＞ → ＜展開＞ → ＜危機＞ → ＜1話ポイント＞` の4段で書かれている。

- ＜導入＞は**過去時点の場面**(ヒロインとヒーローの最初の出会い)から入っている＝**回想のコールドオープン**
- ＜1話ポイント＞は、その話が読者を掴む理由を書く欄(あらすじではなく**設計意図の説明**)

この型に沿って書くのが安全。自己流の分割にする理由がない。

## 2. 記入例から読み取れること(ここが本題)

配布フォーマットの記入例は、**韓国語から機械翻訳された日本語**である。誤訳が多数残っている。

| 例文の表記 | 本来の意味 |
|---|---|
| 家紋 | 家門(一族) |
| 英愛 | 令嬢(영애) |
| ヨジュ / ナムジュ | 女主 / 男主(ヒロイン/ヒーロー) |
| サイダー | 溜飲が下がる展開(사이다) |
| 救い書士 | 救済叙事(救済の物語) |
| 弱奪婚 | 略奪婚 |
| 定価 | 代価 |
| 神性能力 / 神聖な癒し能力 | 神聖な治癒能力 |

### 読み取り① 審査は韓国語話者が行う
日本語の文章の巧拙より、**構造とトロープの正しさ**で評価される可能性が高い。
→ 凝った日本語表現に投資せず、**構造の明快さ・図式の分かりやすさ**に投資する。
→ 一文を短く。修飾を減らす。関係と変化を明示的に書く。翻訳されても崩れない文にする。

### 読み取り② 記入例のストーリー自体が、今回のテーマの模範解答
記入例の中身は「一族に虐待された私生児の令嬢(治癒能力持ち)が、ドラゴンの王に略奪婚で奪われ、
未知の地で初めて安全を得て成長する救済ロマンス」——**まさに「傷ついたヒロイン×野獣ヒーロー」**。

> **最重要の含意**: 全応募者がこの見本を見ている。
> **見本と同じ部品(虐待された令嬢・治癒能力・獣/竜の王・略奪婚・一族への復讐)で組むと確実に埋もれる。**
> 大枠(剥奪→選択→奪還、救済ロマンス)は守りつつ、**部品を変える**必要がある。

### 読み取り③ 求められている感情語が明示されている
記入例に繰り返し現れるキーワード:

**救済叙事 / サイダー(溜飲) / 成長型ヒロイン / 保護本能を刺激 / カタルシス / エキゾチックなスケール**

企画がこの6語を満たしているか、提出前にチェックする。

### 読み取り④ プロット欄はセリフを入れてよい
記入例のプロット(500字以内)は、地の文の要約ではなく **ヒーローとヒロインの短い掛け合いを軸**に
書かれている。つまり**あらすじの圧縮ではなく、一番おいしい場面を見せる欄**として使ってよい。
→ 500字を要約に使うのは損。**掛け合い＋状況＋フックの構成**にする。

### 読み取り⑤ 「1話コンテ(任意)」は差がつく場所
任意提出だが、当方はシナリオ制作スタジオの実務者である。
**ここを出せば提出物の完成度で明確に差がつく。**
ただし撤退ライン(企画書20時間)の範囲内で。本体が仕上がってから、残時間で判断する。

## 3. 制作方針への反映

| 決定 | 内容 |
|---|---|
| 想定話数 | 100話前後を置く(記入例に合わせる。長編耐性を示す) |
| ターゲット | 20〜30代女性を基本線に、企画の性質で調整 |
| 文体 | **短文・明快・図式的**。翻訳耐性を最優先。凝った比喩は使わない |
| 差別化 | 記入例の部品を避ける。大枠は守り、**ヒロインの動機の置き方**で差をつける |
| 紙幅配分 | 項目10(1〜3話)に最も時間を割く。トライアル3話で反応を測られるため |
| コンテ | 本体完成後、残時間があれば作成 |

### 避ける部品リスト(記入例と被るもの)
- 治癒・浄化系の能力をヒロインの武器にする
- 竜・獣人の王による略奪婚
- 私生児・庶子という出自の設定
- 一族(家門)への復讐を主筋にする
- 遊牧騎馬民族＋超自然的存在のエキゾチック世界観

> これらを**全部**避ける必要はない。1〜2個残すのは「テーマに乗っている」証明になる。
> だが**3つ以上重なったら作り直す。**

## 4. 提出前チェック(フォーマット規定)

- [ ] 公式Wordフォーマットを使用している(他形式は審査対象外)
- [ ] 項目を追加・削除・改変していない
- [ ] 記入例の文言を消して自作の内容に差し替えている
- [ ] 氏名・経歴**以外**の個人情報(電話番号・住所・メールアドレス)を書いていない
- [ ] プロットが500文字以内
- [ ] 見どころが3つある
- [ ] シノプシスに起・承・転・結が**4つとも**ある
- [ ] 1話・2話・3話それぞれにエンディングポイントがある
- [ ] ファイル名の「応募作品の題名」を自作タイトルに差し替えている
