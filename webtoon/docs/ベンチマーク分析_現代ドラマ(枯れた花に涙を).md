### ランキングの実績

## 3. 物語の骨格

### 前提として置かれている状況

紹介文が要約する「夫の不倫・借金・子どもの喪失」は、実際にはもっと入り組んでいる。

- 13年前に結婚。**まもなく子どもを失った。**
- その後、夫が借入を重ねて**巨額の借金**を作る。二人は**半地下**で暮らしている。
- 妻は夫を愛していたので許し、追い出さなかった。ただし**書類上はいったん離婚している。**
- 夫の借金を返すため、彼女は**花屋・焼肉屋・モーテル・コンビニ**を平日も週末もなく掛け持ちしている。
- そこへ、**毎日バラを買いに来る**年下の男が現れる。

### 1話で起きること

1話の時点では、**まだ不倫は起きていない。**

- 「配偶者の裏切りを見たら、もう元には戻れない」という、かつて聞いた言葉から入る
- 夫と若い女が体を重ねる**悪夢**にうなされる
- 仕事に追われる日常
- 一方、夫は職場の若い女性社員の好意に気づき、まんざらでもない様子を見せる

つまり1話は、**予感とヘイトだけで組まれている。** 快感は一切ない。
既存の `1話の型と尺.md` の結論「1話で謎かヘイトを溜める。快感は2話以降でよい」と完全に一致する。

### 「バラ」と呼ばれる男

年下の男は毎日バラを買いに来る。名乗らない。
花屋の同僚が彼を「バラ」と呼ぶようになり、**ヒロインも本名を知るまで彼を「バラ」と呼ぶ。**
彼が買うのは他のアルバイトからではなく、必ず彼女からである。
彼女は「私は結婚しているので」と断ろうとする。

> 名前を与えず、**自分の反復行動そのものを名前にしてしまう**。
> これは企画書のキャラ欄に「ミステリアスな年下」と書くのとは、まるで別の仕事である。

### 中盤の反転

物語の中盤で二つのことが明かされる。

1. 年下の男は、**かつてヒロインが家庭教師をしていた教え子**だった。
   偶然ではなく、学生時代からの執着で**全部を計画していた。**
2. 彼は**財閥の庶子**である。異母兄からは「妾腹」と呼ばれ、父(会長)は側近に彼の行動を報告させている。

以降、物語は恋愛だけでなく**財閥内の権力争い**(会長 対 男と側近)を軸に進む。
側近が二人を守って自己犠牲を選ぶ展開もある。

> 「純真で従順な年下」は**表の顔**にすぎない。実体は、権力と実行部隊を持った執着者である。

## 4. 【最重要】なぜ当たったのか ─ 5つの装置

### ① 「清潔な不倫」という設計

韓国側の批評に、この作品の中核を正面から言い当てているものがある。

> 不倫を夢見る人が求めているのは、道徳的にも法的にも完璧な「**清潔な不倫**」というファンタジーである。
> (配偶者が事故で急死して、主人公と恋人が晴れて幸せになる、というような)

本作は、ヒロインの恋を**三重に無罪化している**。

1. **書類上は既に離婚している**(同居はしているが、法的には他人)
2. **先に裏切ったのは夫のほう**である
3. 夫は借金でヒロインの人生を潰した側であり、**同情の余地を消してある**

その結果、「33歳の枯れた花が、10歳年下の裕福な美男に愛される」という願望を、
読者は**道徳的な引っかかりをまったく持たずに消費できる。**

> これが本作の最大の発明である。前回の分析はここを完全に落としていた。
> **大人の女性向け恋愛では、「感情の設計」より先に「無罪化の設計」がある。**

### ② 剥奪を、説明ではなく「労働」で可視化している

「不幸なヒロイン」を説明で処理していない。**職場の数**で見せている。
花屋、焼肉屋、モーテル、コンビニ。平日も週末もない。住まいは半地下。

`ベンチマーク分析.md` §4 の「傷を状態ではなく毎シーン発動する制約に翻訳する」の、
現代における最良の実装がこれである。**制約が仕事のシフトとして毎話画面に出てくる。**

### ③ 恋愛の約束を「反復」で作っている

現代ものには婚姻始まりという装置がない(`導入と命名の分布調査.md` §2)。
本作の解法は、**毎日同じ男が同じものを買いに来る**ことだった。

反復は、宣言よりも安全に機能する。宣言は一度きりだが、反復は**毎話出せる**。
そして反復が続くほど、読者は「これは何かある」と確信を強める。
名前を与えないことで、その確信に**回収されるべき謎**まで付いてくる。

> なお「大人の恋を教えてください」という一文は、**日本語版の宣伝コピー**として広く流通しているが、
> それが1話のどこで発話されるかは確認できていない。1話の実際の構成は上記(§3)のとおり、
> 夫の不倫の予兆で組まれている。**コピーと1話の設計は別物として扱うこと。**

### ④ 1話で快感を出していない

日本語圏の紹介文だけを読むと「年下男が現れて救う話」に見えるが、1話は違う。
悪夢と、夫の側の描写と、労働しかない。読者は**怒りだけを持って2話に行く。**

### ⑤ 年下の男に権力を持たせている

年下・格下の男では、身分差の落差が作れない。本作は男を**財閥の庶子**にすることで、
「年齢では下、資源では上」という**ねじれた落差**を作っている。
しかも庶子なので、彼の側にも剥奪がある。**救う側と救われる側が固定されない。**

## 5. 【最重要】失速の分析 ─ 何が壊れたか

ここが前回の分析に丸ごと欠けていた部分である。**この作品は既に崩れている。**

### 韓国での評価の推移

| 指標 | 序盤 | 現在 |
|---|---|---|
| 女性人気 | **1位** | 2位 |
| 総合人気 | 2〜3位 | **10位** |
| 星点 | 高得点を維持 | **7点台**へ低下 |
| 1話あたりのコメント数 | **1,000件超**(有料区間でも) | **約200件** |

### 挙げられている原因

- **80話以降は酷評が大多数。** 「竜頭蛇尾」「既に取り返しがつかないほど話が壊れた」という声が多数
- **100話出てもメインストーリーがほとんど進んでいない**
- **似たような独白と、不要で同じ展開の反復**
- **不快感を覚えるほどの不幸と、刺激的な内容**の積み増し
- 一日の朝・昼・晩がそれぞれ1話になるほどの引き延ばし

### 英語圏でも同じ批判が出ている

Goodreadsの平均は4.01(907件)。ただしレビュー本文では次が繰り返されている。

- 前回のおさらいが長く、実際の話が進まない
- **自己憐憫(self-pity)が読んでいて苛立つ水準**に達している
- **ヒロインの成長が描かれない**

> 「自己憐憫が苛立つ」は、`好かれるキャラの条件調査.md` §3 が
> 日本と韓国の両方の読者について記録していた最大の嫌悪点そのものである。
> **1位を取った作品ですら、100話かけてここに落ちる。**

### そして日本だけが1位を維持している

日本語版は2026年6月時点で100話。韓国で酷評が始まった80話台を、日本の読者も既に通過している。
それでも**2026上半期1位**であり、POP UPには200人が並び、グッズは初日に完売した。

説明を三つ立てておく。**どれも仮説であって、実測はできていない。**

1. **日本の読者は「進行」ではなく「関係の反復」に課金している。**
   POP UPの盛況(推し活化)は、物語の進行より**キャラクターへの愛着**が収益を支えている証拠になりうる
2. **課金の慣性。** 序盤で入った読者は、100話ぶんの投資があるので簡単には降りない
3. **ランキングの集計期間。** 2026上半期は1〜6月。序盤から積み上がった読者数・購入数が効いている

> 実務上の結論は、どの仮説を取っても同じになる。
> **学ぶのは序盤(1〜30話程度)の設計だけにする。中盤以降は反面教師として扱う。**

## 6. ロマファンとの構造比較

| | ロマファン(MSTORYHUB案件) | 現代ドラマ(本作) |
|---|---|---|
| 骨格 | 剥奪 → 選択 → 奪還 | **同じ** |
| 剥奪の中身 | 身分・家門・婚約 | 生活・金・家族・時間 |
| 剥奪の見せ方 | 追放・婚約破棄の場面 | **労働のシフト**(職場の数) |
| 世界観の説明コスト | 尺を取られる | ほぼゼロ |
| 落差の作り方 | 身分差 | **年齢差と資源の逆転**(年下だが財閥) |
| 恋愛の約束 | 婚姻・契約から始める | **反復**(毎日バラを買いに来る) |
| 道徳的な処理 | 不要(異世界なので) | **必須。無罪化の設計が要る** ← 現代固有 |
| サイダーの出所 | 知略・魔法・地位の奪取 | 職能・法・生活の技術 |

**骨は同じ。燃料と装置が違う。** そして現代には、ロマファンに無い工程が一つ増える ── 無罪化である。

## 7. ロマファンの作法を現代に移す変換表

既存docsの規則はすべてロマファンで較正されている。現代で企画を立てるなら、ここを翻訳する。

| 規則(出所) | ロマファンでの実装 | **現代ドラマでの実装** |
|---|---|---|
| **恋愛の約束を1話で作る**<br>`導入と命名の分布調査.md` §2 | 婚姻・婚約・契約から始める(13/40本) | **反復**(毎日来る)／回帰(私の夫と結婚して)／取引／再会。<br>反復は毎話出せるので、宣言より安い |
| **傷は毎シーン発動する制約に**<br>`ベンチマーク分析.md` §4 | 吃音(オークの樹の下) | **労働と生活の癖**。掛け持ちの数、住まい、食事の取り方 |
| **タイトルはジャンル記号を含む名詞句**<br>`タイトル分布調査.md` | 貴族称号(37%)＋女性の立場語(28%) | 現代に貴族称号はない。記号語は**生活と喪失の語**。<br>『枯れた花に涙を』は7字の情景型で筋を説明していない |
| **溺愛は差分で出す**<br>`溺愛の出し方調査.md` §4 | 全員に冷たい暴君が彼女にだけ違う | **彼が買うのは、必ず彼女からである**。第三者(同僚)が先に気づく |
| **命名**<br>`導入と命名の分布調査.md` §4-6 | K音・子音終わり／母音終わり | 日本名。**あだ名で呼ばせる手がある**(「バラ」)。<br>本名を伏せること自体が謎になる |
| **サイダーを供給する** | 知略・魔法・地位の奪取 | 職能・法・生活の技術 |
| **(現代固有)無罪化する** | — | **離婚済み／相手が先に裏切る／相手に同情の余地を残さない。**<br>この工程を飛ばすと、読者は恋を楽しめない |

### 注意 ── 「現代だから設定は要らない」は逆

世界観の説明が要らなくなった分、**読者は生活の細部の嘘に敏感になる。**
賃貸、相続、保険、介護、労災、離婚調停。ここを間違えると、爵位を間違えるより深く冷める。
読者の側が当事者だからである。

`世界観の裏取り.md` の「制度で縛るより、人の選択にしたほうが強い」は現代でも同じく効く。

## 8. 飽和マップ ─ 現代・大人向け女性枠

### 埋まっている

| 部品 | 埋めている作品 |
|---|---|
| **サレ妻＋若い女＋借金＋年下の救済者** | **枯れた花に涙を(1位が占有)** |
| サレ妻＋回帰・タイムリープによる復讐 | 私の夫と結婚して(LINEマンガ2022年間総合1位／グローバル5億回) |
| サレ妻＋転生して復讐 | 愛人転生 ほか多数 |
| 幼馴染がある日恋愛対象になる | 幼馴染コンプレックス(2026上半期3位) |
| 不倫の現場に踏み込む | 「スカッとマンガ」という呼称が既にあるほど飽和 |
| **年下＋財閥＋執着** | 枯れた花に涙を。加えてロマファン側の「わたしにだけ優しい暴君」の現代版でもある |

### 空いている

1. **剥奪を「不倫」以外の現代的喪失にする** ── 介護に費やした時間、親の借金、家業からの排除、
   不妊治療の終わり、キャリアの空白、保証人、二重生活の**死後**の発覚
2. **ヒロインの職能をサイダーの供給装置にする** ── 現代なら職業を与えるだけで、
   「恋愛が止まっても読者を繋ぐもう一本の線」が手に入る
3. **年下男を従順にしない** ── 本作の男は表面が従順型。ここを外す
4. **日本の地方・家業・季節を絵の売りにする** ── LINEマンガはグローバル配信を持つ。
   日本の現代劇は海外から見れば異国である
5. **相手を先に死なせる** ── 憎む相手が不在だと、物語は復讐ではなく別のもの(整理・引き受け)になる。
   同時に**無罪化(§4-①)が最初から完了している**という副次効果が大きい

- [ ] 剥奪が「不倫・借金」以外の現代的喪失になっているか
- [ ] **ヒロインの恋が無罪化されているか。**その工程を意識して設計したか
- [ ] 1話で「この二人は恋愛する」と読者に約束できているか。**それは反復で出せるか**
- [ ] 傷が、状態説明ではなく**労働と生活の癖**として毎話画面に出るか
- [ ] 1話に快感を置いていないか(予感とヘイトで足りているか)
- [ ] 相手役に、年齢や立場とは**逆向きの資源**があるか。相手役の側にも剥奪があるか
- [ ] ヒロインに職能があり、それが溜飲の供給装置になるか
- [ ] **ヒロインが自分で嘆いていないか**(1位の作品でも、ここで英語圏の評価が落ちた)
- [ ] 30話時点で、ヒロインが**開始時と違う人間**になっているか
- [ ] 生活の制度(相続・賃貸・保険・介護・雇用)に嘘がないか
- [ ] 企画書に**書いていない面白い場面を5つ**書き出せるか
- [ ] フルカラー縦読みで「絵になる場面」が3つあるか

## 11. 初版(2026-08-04午前)からの訂正

**同じ日に全面改訂した。初版は浅く、いくつか事実として誤っていた。**

| 初版の記述 | 訂正 |
|---|---|
| ヒロインは「32歳」 | **33歳。** 日韓の記述が一致している |
| 「男が1話で目的を口に出す」ことが恋愛の約束の装置 | **コピーと1話の設計を取り違えていた。**「大人の恋を教えてください」は日本語版の宣伝コピー。1話は夫の不倫の予兆で組まれている。実際の装置は**反復**(毎日バラを買いに来る) |
| 本質は「傷ついた魂の相互救済」 | それは日本語のレビュー記事の言葉。実体は**執着・計画・財閥の権力争いを含むラブサスペンス**で、男は財閥の庶子。側近もいる |
| 剥奪は「不倫・借金・子どもの喪失」 | 順序が逆。**子どもの喪失が13年前で先**にあり、その後に借金、書類上の離婚、そして不倫が来る |
| 現代枠の成功例として全面的に参照 | **韓国と英語圏では既に失速している。**女性人気1位→2位、総合2〜3位→10位、コメント1,000件超→約200件。参照してよいのは序盤だけ |
| 「清潔な不倫」の設計 | **初版には記述が一切なかった。**本作の最大の発明を落としていた |

失敗の形を一般化して残す(`CLAUDE.md`「失敗も残す」)。

> **日本語の紹介文だけで作品を分析した。**
> 紹介文は売るために書かれているので、設計の意図とは別物である。
> 原題を特定して韓国語で検索した瞬間に、話数、評価の推移、批判、設定の実体が一度に出てきた。
> **翻訳ものを分析するときは、まず原題を特定する。** これを最初にやらなかったのが原因。
