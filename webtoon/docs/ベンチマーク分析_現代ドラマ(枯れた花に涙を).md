## 1. なぜこの作品を見るのか

既存の `ベンチマーク分析.md` §2 に、企画着手時点で最も重い一行が残っている。

> 一次査読は **MSTORYHUB(韓国ロマファンの基準)**、配信先は **LINEマンガ(日本の読者)**。

MSTORYHUB案件は「韓国の文法で書く」制約があったので、この事実は脇に置いた。
**その制約が無い企画を立てるなら、ここが正面になる。**

日本のLINEマンガで一番読まれているのは、異世界の令嬢ではない。**32歳の主婦である。**

## 3. なぜ日本で1位なのか ─ 4つの分解

### ① 剥奪が「読者に起こりうるもの」である

ロマファンの剥奪(家門から追われる・婚約破棄・生贄に出される)は、読者の人生には起きない。
**不倫・借金・子どもの喪失は、隣の家で起きている。**

共感の5経路(`好かれるキャラの条件調査.md` §1)の①不当な苦境が、
**説明なしで、読者の実感として立ち上がる。** ロマファンが世界観の説明に払うコストが、ここでは0になる。

> これが現代ドラマ枠の最大の構造的優位。**1話の尺(60〜80コマ)を、丸ごと感情に使える。**

### ② 「保護される側 → 選ばれる側」の反転を、身分ではなく**年齢**で作っている

ロマファンは身分差(公爵と侍女)で落差を作る。現代にはその装置がない。
本作は**年齢**でそれをやっている。32歳と22歳。10歳の差。

そして反転の向きが重要で、**若く価値のある側が、価値を失ったと思っている側を選ぶ。**
「私にはもう何もない」と思っている女を、何でも選べる立場の男が選ぶ。
これは `溺愛の出し方調査.md` §4 の結論「**溺愛の正体は差分**」の、現代における最も安い実装である。

### ③ 男が1話で**目的を口に出す**

これが構造上いちばん効いている点だと見ている。

`導入と命名の分布調査.md` §2 の発見はこうだった:

> 婚姻・婚約から始めると、**1話目で「この二人は恋愛する」と読者に約束できる。**
> 仕える立場から始めるのは弱い。恋愛の約束にならない。

**現代ものには「婚姻始まり」という装置が無い。** ここが現代ドラマ枠の最大の技術的難所である。
本作の解法は、**男に宣言させること**だった。

> 「大人の恋を教えてください」

これは婚姻契約と同じ働きをする。1話で目的が宣言され、読者は「この二人は恋愛する」と確定できる。
しかも宣言者が男なので、**ヒロインは受け身のまま能動性を失わずに済む**(彼女は断る側に立てる)。

### ④ 嘆きを、ヒロイン以外が担当している

`好かれるキャラの条件調査.md` §3 の「**本人が嘆かないことが最大の防御**」に完全に一致する。
剥奪が三重に来ているのに、読者の側が代わりに怒れる構造になっている。
だから「悲劇のヒロイン気取り」に落ちない。

## 4. ロマファンとの構造比較 ─ 何が同じで、何が違うか

| | ロマファン(MSTORYHUB案件) | 現代ドラマ(本作) |
|---|---|---|
| 骨格 | **剥奪 → 選択 → 奪還** | **同じ** |
| 剥奪の中身 | 身分・家門・婚約 | 生活・金・家族・時間 |
| 説明コスト | 世界観に尺を取られる | **ほぼゼロ** |
| 落差の作り方 | 身分差 | **年齢差・立場差・生活力の差** |
| 恋愛の約束 | 婚姻・契約から始める | **男が目的を宣言する** |
| サイダーの出所 | 知略・魔法・地位の奪取 | **職能・法・生活の技術** |
| 読者 | 韓国ロマファン読者の文法 | **日本の30代以上の女性** |

> **結論**: 骨は同じ。**燃料と装置だけが違う。**
> 既存の `docs/` のナレッジ(3話構成の型・1話の尺・溺愛の差分・共感の5経路)は、
> ジャンルを変えても**そのまま使える**。書き換えが要るのは次章の6項目だけである。

## 5. 【最重要】ロマファンの作法を現代に移す変換表

既存docsの規則は、すべてロマファンで較正されている。**現代で企画を立てるなら、ここを翻訳する。**

| 規則(出所) | ロマファンでの実装 | **現代ドラマでの実装** |
|---|---|---|
| **恋愛の約束を1話で作る**<br>`導入と命名の分布調査.md` §2 | 婚姻・婚約・契約から始める(13/40本) | **男が1話で目的を口に出す**(枯れた花)<br>／回帰・時間遡行(私の夫と結婚して)<br>／取引・雇用契約<br>／再会(幼馴染コンプレックス) |
| **タイトルはジャンル記号を含む名詞句**<br>`タイトル分布調査.md` §3,§5 | 貴族称号(37%)＋女性の立場語(28%) | 現代に貴族称号は無い。**記号語は「妻・夫・母・部屋・最後・涙・花」など、生活と喪失の語**。<br>『枯れた花に涙を』は7字の**情景型**で、筋を一切説明していない |
| **命名**<br>`導入と命名の分布調査.md` §4-6 | ヒーローはK音・子音終わり／ヒロインは3〜4音・母音終わり | 日本名。**姓が階層を語る**(旧家か新興か)。<br>ヒロインは呼ばれ方が複数あるのを利用する(「奥さん」「お母さん」「名前」) |
| **溺愛は差分で出す**<br>`溺愛の出し方調査.md` §4,§6 | 全員に冷たい暴君が彼女にだけ違う | **全員に無礼な若い男が、彼女にだけ敬語**／誰の指示も聞かない男が彼女の指示にだけ従う。<br>**第三者に驚かせるのが最も安い**(規則は同じ) |
| **傷は毎シーン発動する制約に翻訳する**<br>`ベンチマーク分析.md` §4 | 吃音(オークの樹の下) | **生活の癖に落とす**。座って食事ができない／自分の名前に反応が遅れる／値札を先に見る／「私が言うことじゃないので」が口癖。<br>**現代もののほうがこの翻訳は易しい。読者が同じ癖を持っているから** |
| **サイダーを供給する**<br>`ベンチマーク分析.md` §3-④ | 知略・魔法・地位の奪取 | **ヒロインの職能**。専門技能で相手が隠したことを暴く。<br>ロマファン側で禁じ手だった「治癒能力=奉仕型」の逆で、**現代の職能は攻撃に使える** |

### 変換表を使ううえでの注意

**「現代だから設定を作らなくていい」は逆である。**
世界観の説明が要らなくなった分、**読者は生活の細部の嘘に敏感になる**。
賃貸契約、相続、保険、介護保険、労災、離婚調停 ── ここを間違えると、
ロマファンで爵位を間違えるより深く冷める。読者の側が当事者だからである。

`世界観の裏取り.md` の教訓「**制度で縛るより、人の選択にしたほうが強い**」は、現代でも同じく効く。

## 6. 飽和マップ ─ 現代・大人向け女性枠

### 埋まっている(避けるか、強い理由が要る)

| 部品 | 埋めている作品 |
|---|---|
| **サレ妻＋若い女＋借金** | **枯れた花に涙を(1位が占有)** |
| **サレ妻＋回帰・タイムリープによる復讐** | 私の夫と結婚して(LINEマンガ2022年間総合1位／グローバル5億回) |
| サレ妻＋転生して復讐 | 愛人転生 ―サレ妻は死んだ後に復讐する― ほか多数 |
| 従順で危険な年下男による救済 | **枯れた花に涙を** |
| 幼馴染がある日恋愛対象になる | 幼馴染コンプレックス(2026上半期3位) |
| 不倫の現場に踏み込んでスカッとする | ジャンルとして飽和。「スカッとマンガ」という呼称が既にある |

> **重要**: 「サレ妻」枠は**日本の現代女性向けで最も混んでいる場所**である。
> 1位も、歴代最大のグローバルヒットも、量産作も、すべてここにいる。
> **入るなら、剥奪の種類をずらすしかない。**

### 空いている(狙える方向)

1. **剥奪を「不倫」以外の現代的喪失にする**
   介護に費やした10年／親の借金／家業からの排除／不妊治療の終わり／キャリアの空白／
   保証人／実家の廃業／二重生活の**死後**の発覚。
   **どれも日本の30〜50代女性の現実にあり、まだWEBTOONの棚に少ない。**

2. **ヒロインの職能をサイダーの供給装置にする**
   韓国ロマファンの最新潮流(`ベンチマーク分析.md` §3-③「恋愛の遅延の見返りにキャリアの成長叙事を返す」)は、
   **現代ものでこそ自然に成立する。** 異世界で職能を持たせるのは設定が要るが、現代では職業を与えるだけでいい。
   **恋愛が停滞しても読者を繋ぐ「もう一本の線」**(提出前チェック)が、ほぼ無料で手に入る。

3. **年下男を「従順」にしない**
   枯れた花の蓮は従順型。ここを外す。
   **ヒロインより先に怒っている年下**にすると、`好かれるキャラの条件調査.md` §3 の
   「嘆きは読者にやらせる」がキャラクターとして実装される。

4. **日本の地方・家業・季節を絵の売りにする**
   LINEマンガはグローバル配信を持つ。**日本の現代ドラマは、海外から見れば異国である。**
   公式が求める「エキゾチックなスケール」を、異世界ではなく**日本の地方**で作れる。
   酒蔵・旅館・寺・港・雪 ── フルカラー縦読みで強い画になり、かつ他社が持っていない。

5. **復讐の相手を不在にする**
   サレ妻ものの推進力は「相手が生きていて憎める」ことにある。
   **相手が既に死んでいる**場合、物語は復讐ではなく別のもの(整理・仕分け・引き受け)になる。
   飽和した棚の中で、いちばん安く新品に見える一手。

## 7. 企画着手前の照合チェック(現代ドラマ版)

`ベンチマーク分析.md` §5 の現代版。企画を1本に絞る前に通す。

- [ ] 剥奪が「不倫・借金」以外の現代的喪失になっているか(サレ妻枠の直撃を避けたか)
- [ ] **1話のうちに「この二人は恋愛する」と読者に約束できているか**(現代には婚姻始まりが無い)
- [ ] ヒロインの傷が、状態説明ではなく**毎シーン発動する生活の癖**になっているか
- [ ] ヒロインに**職能**があり、それがサイダーの供給装置として機能するか
- [ ] ヒロイン自身が嘆いていないか(嘆きは読者と第三者に担当させる)
- [ ] 1話に甘さの拍が1つあるか。それは**差分**で出ているか(`溺愛の出し方調査.md`)
- [ ] 3話で一次解消し、同時により大きな扉が開くか(`3話構成の型.md`)
- [ ] 生活の制度(相続・賃貸・保険・介護・雇用)に嘘がないか ← **現代もの固有の落とし穴**
- [ ] 企画書に**書いていない面白い場面を5つ**書き出せるか(`3話構成の型.md` §4)
- [ ] フルカラー縦読みで「絵になる場面」が3つあるか
