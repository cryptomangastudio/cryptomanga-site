# ログラインとあらすじの分布調査

> 調査日: 2026-07-30 / サンプル: 紹介文の構造が読み取れた実在作品 **約65本**(日本語45・韓国語20)
> 目標100本には届かなかった。検索スニペットから構造が確認できたものだけを数え、水増しはしていない。
> 母集団は「おすすめ記事・作品ページに載る作品」に偏っており、無作為抽出ではない。
> 著作物なので本文は引用せず、**構造だけを記録する。**

---

## 1. ほぼ全作品が二段構造

観察した紹介文の圧倒的多数が、次の順で書かれている。

```
① ヒロインの窮状(不幸な事実)
② 男の出現、または男の異常な態度
```

①が先で②が後。**例外がほとんどない。** 男から書き始める紹介文は見つからなかった。

---

## 2. 【最重要】逆接マーカーが溺愛の中核構文

②の部分に、ほぼ必ず**時間差の逆接**が入る。

| マーカー | 意味 |
|---|---|
| **なぜか** | 理由が分からないまま態度が違う |
| **はずが／はずだった** | 予期と結果のずれ |
| **〜のに／〜と言ったのに** | 宣言と行動の矛盾 |
| **昨日まで〜／急に** | 態度が変わった時点の明示 |
| **話したこともない〜が** | 関係の薄さと関心の強さの落差 |

型にすると **「以前は◯◯だった男が、なぜか今は△△」**。
この落差そのものが溺愛の約束になっている。

> 溺愛系の紹介文の定型は「冷徹だと知られている男が、**彼女にだけ**違う」。
> 「〜にだけ」と「なぜか」が組み合わさると最も強い。

---

## 3. 冒頭は短い断定から入るものが強い

長い状況説明から始まる紹介文より、**最悪の事実を一文で叩きつける**ものが目を引く。

- 不幸な事実を短文で置く → 詳細 → 男の出現、の順
- 一文目が長いと、スマホの表示で切られて何の話か分からなくなる

---

## 4. 具体的な数字が高頻度で入る

「99番目の」「十分前に」「十年目の」「400年後に」「六ヶ月の契約」など、
**数えられるものが入っている紹介文が目立つ。**
数字は一目で異常さを伝え、かつ記憶に残る。

---

## 5. 末尾の型

| 型 | 内容 |
|---|---|
| **ジャンル名でのラベリング** | 「やり直し溺愛ファンタジー」「ラブコメディ」のように、最後に何の話かを名づける |
| 問いで止める | 「この運命から逃れられるのか」 |
| フックで止める | 状況を提示したまま切る |

ラベリングは審査員にも読者にも棚を伝えるので、企画書では有効。

---

## 6. 固有名詞の扱い

- **ヒロイン名は早い段階で出る**
- **ヒーロー名は出ないことが多い。**「公爵」「陛下」「殿下」など役職で呼ばれる
  → 役職のほうがジャンル記号として機能するため

---

## 7. 実務チェックリスト

- [ ] ①窮状 → ②男の異常、の順になっているか
- [ ] 逆接マーカー(なぜか／はずが／〜のに／昨日まで)が入っているか
- [ ] 一文目が短い断定か
- [ ] 数えられる数字が入っているか
- [ ] ヒロイン名が出ているか。ヒーローは役職で呼んでいるか
- [ ] 末尾で棚を名づけているか
