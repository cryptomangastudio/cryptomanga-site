# ベンチマーク分析 ─ 「傷ついたヒロイン×野獣ヒーロー」の先行作と韓国トレンド

> 目的: 企画の骨を組む前に、**何が既にやり尽くされていて、どこが空いているか**を特定する。
> 調査日: 2026-07-29
> 注記: 作業環境のネットワーク制限により一次サイトへの直接アクセス不可。検索経由の情報で構成。

## 1. 直撃ベンチマーク(必読の3作)

### ◎ オークの樹の下(Under the Oak Tree)— **最重要**

| | |
|---|---|
| ヒロイン | マクシミリアン。公爵令嬢。**吃音**を持ち、幼少期から父に虐待され、自己肯定感が壊れている |
| ヒーロー | リフタン。**貧しい生まれの下級騎士**から英雄へ。無骨で逞しい |
| 構造 | 政略結婚から始まる → ヒーローが一途に溺愛 → ヒロインが人々との交流を通じて成長・自立 |
| 実績 | 配信開始1ヶ月で1000万DL、売上3億円超 |

**本テーマの完成形が既に存在している**と考えるべき。「傷ついたヒロイン×野獣ヒーロー」で
企画を立てるとき、審査側の頭には確実にこの作品がある。

- 効いている点: ヒロインの傷が**具体的な障害(吃音)として可視化**されている。
  「虐げられた」という状態説明ではなく、毎シーンで発動する制約になっている。
- 効いている点: ヒーローが「結婚した以上、生涯守る」という**単純で揺るがない原理**で動く。
  読者は彼の心変わりを心配しなくていい。安心して溺愛を享受できる。
- **弱点(＝我々の空き地)**: 序盤のヒロインが受動的で、自虐が続く。
  韓国読者の言う「고구마(もどかしさ)」が溜まりやすい構造。**ここが差別化の入り口。**

### ○ 再婚承認を要求します(MSTORYHUB)

- 共催スタジオの看板作。**審査側の基準そのもの**と考えてよい。
- 効いている核: 夫の裏切りに対し、嘆願でも自滅でもなく「**離婚と同時に再婚の承認を要求する**」
  という能動的かつ理知的な一手。読者が快感を得るのは「可哀想」ではなく「**賢く、静かに、強い**」姿。
- 教訓: **虐げは燃料であって目的ではない。反撃の一手の切れ味に紙幅を割く。**

### ○ 贄姫と獣の王(日本・少女マンガ)

- 異形の眷属の王に捧げられた**99番目の生贄**の少女が、恐れられる王の真実を知り妃となる。
- 「野獣＝実は誠実」の型の日本側の代表例。アニメ化・ミュージカル化まで到達。
- 参照価値: ヒロインが**最初から運命を受け入れて自分の足で儀式に向かう**。
  受動的な被害者として始まらない設計。オークの樹の下と対照的で、こちらの方が現代的。

## 2. 周辺ベンチマーク(市場の実勢)

| 作品 | 位置づけ | 読み取り |
|---|---|---|
| **枯れた花に涙を**(Gae) | LINEマンガ **2026上半期 連載1位**(2025年間も1位) | ロマファンではなく**現代**。夫の不倫・借金・喪失を抱えた32歳女性と、22歳の年下男。**日本のLINEマンガ読者に最も刺さっているのは「大人の傷の物語」** |
| **お求めいただいた暴君陛下の悪女です** | タテ読みマンガアワード2025 国内1位 | 最強の悪女が魔法と知略で圧倒 → 冷酷な暴君が**強さに**惹かれる。**保護される側→惹きつける側への反転** |
| **今世は当主になります** | 同 海外1位 | 家督・立場の奪取。恋愛より**地位獲得の叙事** |
| **ずたぼろ令嬢は姉の元婚約者に溺愛される** | 虐げ→溺愛逆転の定番 | 型として完全に飽和済み |

> **重要な構造的緊張**: 一次査読は **MSTORYHUB(韓国ロマファンの基準)**、
> 配信先は **LINEマンガ(日本の読者)**。日本市場の1位は現代ドラマ系である。
> → 企画は**韓国ロマファンの文法で書き**、そこに**日本読者に効く要素を1つ**差す設計が最も強い。

## 3. 韓国ロマファンの現在地(トレンド)

韓国の読者コミュニティ・ジャンル論では、以下が共通認識になっている。

### ① クリシェの飽和は「批判」として明確に語られている
シノプシスを見ただけで8割の作品が2つのストーリーラインのどちらかに分類できる、という
批判が実際に存在する。**テンプレの再生産は、韓国側では既に飽きられている。**

### ② クリシェ捻り(비틀기)の累積 → ジャンルの拡張
- ノーマンス、ガールクラッシュがロマファンのクリシェとして併合された
- 武侠・ハンター物との融合が進行
- 中世風でない世界観、恋愛が中心でない叙事もロマファンとして受容されている

→ **「中世西洋風の貴族社会」から出ることは、もはや逸脱ではなく潮流。**

### ③ 最新の潮流: 恋愛の遅延の見返りに「キャリアの野心と成長叙事」を返す
恋愛の進展を焦らす代わりに、ヒロインが**職能・地位・目的**を獲得していく物語を並走させる。
読者は恋愛が停滞しても離脱しない。**これが今いちばん新しい部分。**

### ④ 사이다(溜飲) / 고구마(もどかしさ)の配置が生命線
- 사이다作品の共通点: 起承転結を圧縮し、キャラと感情線を単純化し、**読者に悩ませる要素を削り**、
  面白い展開を速く・継続的に供給して「この先も速く供給される」という**信頼**を与える。
- 고구마(理不尽・停滞)が続くと即離脱。**虐げの描写を長く引っ張るのは、韓国基準では明確な悪手。**

### ⑤ 冒頭3話がすべて
韓国のウェブ小説・ウェブトゥーン実務では「**起承転結を3話の中に詰め込め**」
「平板な回が3話以上続くと離脱が始まる」と語られる。

> **本コンペとの一致**: 採用作は**1〜3話のトライアル制作**で読者反応を測られる。
> 韓国側の実務常識と審査形式が完全に一致している。
> **3話で1つの物語が完結する感覚**を持たせる構成が、そのまま正解。

## 4. 飽和マップ ─ どこが埋まっていて、どこが空いているか

### 埋まっている(避けるか、強い理由が要る)

| 部品 | 埋めている作品 |
|---|---|
| 治癒・浄化能力を持つ虐げられた令嬢 | **公式記入例** |
| 竜/獣人の王による略奪婚 | **公式記入例** |
| 寡黙で巨躯の武人×自己肯定感の壊れた令嬢 | オークの樹の下 |
| 生贄として捧げられた少女×恐れられる異形の王 | 贄姫と獣の王 |
| 一族への復讐を主筋にする | 再婚承認を要求します 他多数 |
| 虐げ→溺愛による逆転 | ずたぼろ令嬢 他、飽和 |

### 空いている(狙える方向)

1. **ヒロインに早期の能動性を与える**
   オークの樹の下の弱点(序盤の受動性＝고구마)を正面から潰す。
   **1話のうちに、ヒロイン自身の選択で状況を1つ動かす。** テーマ文の「心を盗め」は
   ヒロインが**盗む側**である、という指定でもある。受け身のヒロインはテーマから外れている。

2. **野獣性を「治さない」**
   従来型は、野獣が愛によって飼い慣らされる。逆に、**ヒロインがその野獣性を必要とする**構造にする。
   荒々しさが欠点ではなく、彼女の目的に不可欠な資源として機能すれば、関係が対等になり
   「一方的に癒す自己犠牲ヒロイン」の古さを回避できる。

3. **恋愛と並走する「職能・目的」を持たせる**
   韓国の最新潮流に正面から乗る。ヒロインが恋愛とは別に達成したいものを持つ。
   ただし治癒能力のような「奉仕型の能力」は公式記入例と被るので避ける。

4. **中世西洋風の貴族社会から出る**
   もはや逸脱ではなく潮流。ただし**エキゾチックなスケール**は公式が求める感情語なので、
   「地味な世界」に振るのではなく「見たことのないスケール」に振る。

5. **傷を「状態」ではなく「毎シーン発動する制約」にする**
   オークの樹の下の吃音が最も効いている点。虐げの過去を説明するのではなく、
   **いま画面上で読者に見える障害**に翻訳する。
