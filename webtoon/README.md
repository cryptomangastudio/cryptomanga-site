## 運用ルール

1. **新しいコンペは `comps/YYYY-MM_名称/` を切る。** README・募集要項・リスク分析・ロードマップの4点セットから始める。
2. **募集要項には出典を明記する。** 一次ソース(公式LP)と二次ソース(報道)を区別し、
   転記由来の項目は `[LP転記]` を付す。食い違ったら常に公式が正。
3. **受ける前に撤退ラインを数字で決める。** 後から「ここまでやったんだから」で泥沼化するのを防ぐ。
4. **無償区間を必ず特定する。** WEBTOONのコンペは「採用候補→ブラッシュアップ」が無償契約外であることが多い。
   ここが実質的な最大コストになる。
5. 企画・脚本の作法は `.claude/skills/creative-writing/` を参照する。
   納品前には必ず `references/anti-ai-tells.md` のパスをかける。

## 前提として持っておく数字

- WEBTOON原作の原稿料は **1話 25,000円前後**が一つの水準(本コンペの正式報酬)。
  週刊ペースで月4話＝**月10万円**。**個人の原稿料としては成立するが、法人の制作原価は賄えない。**
- したがってコンペ応募は、原則として**収益ではなく実績・関係構築への投資**として評価する。
  金額目的で判断すると、ほぼ全てのコンペが「割に合わない」になる。
- 例外は賞金型(例: TALES原作大賞の最優秀賞300万円)。**賞金型と原稿料型は別物として扱う。**
