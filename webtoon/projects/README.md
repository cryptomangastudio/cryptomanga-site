# projects/ ─ 自社の本命企画

コンペ応募用ではなく、**CryptoManga Studios が自社で温存し、持ち込み・自主連載に育てる企画**を置く。
コンペ個別のものは `comps/` に置く。分けている理由は、コンペ企画には
「一定期間ほかに出せない」という拘束が付くのに対し、こちらには付かないため。

## 企画の中身はここに置かない(意図的)

`comps/*/企画/` と同じ扱い。本リポジトリ `cryptomangastudio/cryptomanga-site` は **public**。
ログライン・プロット・シノプシス・キャラクター設定・台本を公開すると、
持ち込み前の企画が他社に読まれる。

**`webtoon/.gitignore` で `projects/*/企画/*` をコミット対象から外している。**

| 対象 | 置き場所 |
|---|---|
| ベンチマーク分析・市場分析・作法 | リポジトリ(`webtoon/docs/`) |
| **企画の中身**(ログライン以降のすべて) | **ローカル管理** — コミットしない |

### 重要: 作業環境は一時コンテナ

Claude Code の実行環境はセッション終了後に破棄される。
**コミットしないファイルは、この環境に置いたままだと消える。**
企画ファイルは生成のつど本人のローカル環境へ受け渡し、
セッションを跨ぐときは再アップロードして作業を再開する。

### 解禁のタイミング

持ち込みが済み、掲載先が決まった時点で、公開してよいかを先方の条件に照らして再判断する。
