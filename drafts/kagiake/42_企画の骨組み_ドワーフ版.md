# 鍵開け放浪記 企画の骨組み（ドワーフ版、2026-10-18）

`22_シンプル版_企画の骨組み.md`（エルフ版）を、中川様の決定（2026-10-17）に合わせて直した版。**今後はこのドワーフ版を正とする。** 22番以前は、そのまま残してある。決定の経緯は、`33_` `34_` `36_` `37_` `40_` の文書にある。

## 一言で
元空き巣のドワーフの女性が、親方に命じられて盗んだ物を、持ち主に返して歩く。同行するのは、盗まれた家の孫。最後に、盗めなかった箱を、魔族に返す。

## 残した設定（これだけ）
| 項目 | 内容 |
|---|---|
| 題（暫定） | 『元空き巣ドワーフ、盗んだ物を返して回る。見張り役は、盗まれた家の孫。』（34字。100話、恋愛なし、男女どちらにも読める）。ランキング本体で確かめられていないので、確定ではない |
| 世界 | 魔法が生まれたばかりの時代。人間は生活魔法だけ。魔法の錠は新しい高級品。強い魔力を持つのは、魔族とドワーフ。魔法の仕組みは説明しない |
| 主人公 | **ドワーフの女性。** 背は孫の肩ほど。煤色の肌。髭はなし。**長い三つ編みに、十年ごとに紐を一本足す（三つ編みが時計）。** 寿命は約450年（人間の約5.6倍）。一人称は「私」 |
| 性格 | **図々しい、口が悪い、金にうるさい、魔力は使わない。** 金にうるさい理由は、弟子の頃、稼ぎを全部親方に取られていたこと（案） |
| 偏愛 | **「錠は、作った人の恐れの跡。私はそれを指で読むのが好き。」** 入口は手触り。戸の錠を見ると、持ち主の暮らしを言い当てる。作った人は必ず尊重する。開けていいかを先に聞く。題やキャッチで言わず、**本文の場面で見せる** |
| 親方（シーフ） | 人間。主人公の**錠前の師匠**で、腕を見込んで引き取った。字と数字と、錠の読み方を教えた。看病もした。同じ手で、翌朝また他人の戸を開けさせた。すでに死んでいる。死の床で「お前のせいじゃない。教えたのも、命じたのも俺だ」と言い、主人公は「私の手だった」と返す。**免罪には使わない** |
| 過去 | 親方の弟子として、**留守の家**に入る空き巣を12軒した（約20年間）。盗みの夜は、家に人がいなかった |
| 魔法の縛り | 主人公は強い魔法を使える。けれど使わない。理由は二つ：①盗みの道具にされた記憶がある ②魔法で開けると、作った人の恐れの跡を壊す。**孫の命がかかった時だけ使う** |
| 技 | 指で錠を読む。魔法の錠も同じ。戦いでは、同じ技で相手の守りを「開ける」 |
| 孫（同行者） | **被害者の孫、見張り役、計算が得意、鍵に怯えて育った。** 恋愛なし。祖父は、留守のあいだに入られたあの日から、毎晩、鍵を三度かけ直した。旅の終わりに、鍵をかけずに眠る |
| 魔族 | 敵。魔力が強い。親方が魔族の王の庫から盗んだ箱を探している。出てくるのは使いだけ |
| 縦糸 | 盗品の帳面（12行）。返せた9、返せなかった3。最後の箱 |
| 箱 | 親方にも、若い頃の主人公にも開けられなかった。返す意志のある者にだけ開く（作った者は、盗まれることを何より恐れていた）。中身は魔族の大切な物（最終話の直前に決める） |
| 毎話の型 | 町に着く、金がない、開かない扉、開ける、人の事情、主人公が動く、時間の差の一行。**事情の段で、錠の作り手を読む一言を入れる。** 余韻に共食 |
| 戦い | 100話のうち10話前後。暴走する試作錠と魔族。殺さず、守りを開けて終わる |
| 型崩し | 4種（結果から始める、返せない、悪党を暴く、**偏愛が人を傷つける**） |
| 配分 | 感動・温かい5割、悲しい1.5割、スカッと2割、胸クソ1割（必ずスカッとへ）、脱力0.5割 |
| 描写 | 暴力・虐待は直接描かない。被害の重さを先に描く。親方の情は免罪に使わない |

## 最終話の流れ
箱の前に立つ → 箱が開く（作った者の恐れを読んで、返す手に開く）→ 中身を魔族に返す → 魔族が引く → 帳面に新しい行（開けた扉）と三つ編みに紐を一本 → 孫が鍵をかけずに眠る最後の夜。

## 要確認
- 弟子になった経緯をどこまで書くか（錠前師の家の子で腕を見込まれた、など）
