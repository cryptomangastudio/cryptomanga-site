# 鍵開け放浪記 主人公の輪郭（2026-10-18）

外部の提案（身体性、五十年の空白、行動原理、孫との日常、名前）を受けて、中川様が決めたこと。反映先は、共有ドキュメント「企画書」の第3章と第4章。

## 決定事項

| 項目 | 決定 |
|---|---|
| 見た目 | 小柄・童顔・胸と腰は豊か。背は孫の肩ほど。太い骨格と筋力。丸い目、柔らかい頬、煤色の肌、髭なし。革の前掛けと袖まくり。成人（約145歳、人間なら二十代半ば）として描く。働く姿の可愛さと、口の悪さの落差を見せる |
| 手と力 | 手のひらと関節はヤスリのように硬い。指の腹だけは、軽石と油で柔らかく保つ。重い鉄の扉を持ち上げる怪力があるが、錠を開けるときは羽のような力だけを使う |
| 道具 | 親方から受け継いだ鍵開けの棒を、自分の指に合わせて根元を削り、革紐を巻き直して使う |
| 五十年の空白 | 盗みを完全にやめ、人里離れた町で、壊れた鍵の修繕と合鍵作りだけを請け負って暮らした。新しい錠は作らない（誰かの恐れを形にすることだから）。帳面は油紙に包み、仕事机の一番深い引き出しの底へ。訃報の夜に、五十年ぶりに出して埃を払う |
| 金の癖 | 物の値段を、金属の相場で測る（「真鍮の閂が二本買える」）。ただ働きを嫌う。開けた扉の奥の金品には触れず、手間賃だけを請求する。「私は泥棒じゃない、鍵開け職人だ」 |
| 口の悪さ | 二つの理由。（1）弟子の稼ぎを親方に取られた過去（金）、（2）人間は先に死ぬので、情を移さないための棘（防壁） |
| 呼び方 | 主人公が孫を「荷物持ち」と呼ぶ（孫の性別は決めていないので「小僧」は使わない）。孫は「あんた」「泥棒」→「ドワーフさん」→終盤に名前 |
| 日常の落差 | 短い足で小刻みに速く歩き、孫が息を切らす。孫が「来年また来ればいい」と言うと、顔をこわばらせて怒る。薄い粥に「病人食か」と毒づくが、夜中に胃を温めている |
| 弱点 | 相手が隠したい恐れまで、無自覚に読んで口にしてしまう（宿の女将の回） |
