# 鍵開け放浪記 紹介文（公開用）v2（2026-10-17）

## 紹介文

エルフの私は、人間のシーフの奴隷だった。
命じられるまま、十二軒の家に忍び込んで、物を盗んだ。

シーフは、私に文字と数字を教えてくれた。
熱を出した夜は、寝ずに看病してくれた。
その同じ手が、翌朝には、私に他人の戸を開けさせた。

シーフが死んで、数十年。
開けられなかった帳面を、私は今になって開いた。
盗んだ物と持ち主の名が、十二行。

「お前のせいじゃない」と、シーフは言った。
でも、鍵を開けたのは、私の手だ。

だから私は、盗んだ物を、持ち主に返しに行く。

最初の指輪は、白髪の老人の手に渡った。
「遅いんだよ」と、老人は笑った。

次の家では、孫に帳面を取り上げられた。
祖父は盗まれた夜から、毎晩、鍵を三度かけ直したという。
「全部返し終わるまで、私が見張る」
路銀の管理まで、取り上げられた。

今の私は、元空き巣のエルフ。図々しくて、口が悪くて、金にうるさい。
路銀が尽きたら、開かない扉を開けて稼ぐ。魔法の錠だって、耳と指で開けてみせる。
依頼された箱を、開けずに返したら、依頼人の偽の証文が暴かれたこともある。

帳面に載っていない箱が、一つだけある。
それを開ける日まで、この旅は終わらない。

## v1からの変更（読者役3名の採点を受けて）
読者役3名（男性、女性、漫画編集者）は、v1について、全員「第1話を読む（軽い『はい』、または『迷う』から『はい』寄り）」と答えた。強いのは前半（シーフの看病の手が、翌朝に戸を開けさせた）と、最後の「帳面に載っていない箱」。弱いのは後半の抽象3行（性格の羅列、「扉の向こうに事情」、「胸がすく」）。

| 指摘 | 直したこと |
|---|---|
| 後半が定型で抽象的（性格の羅列、「扉の向こうに事情」、「ときには胸がすく」） | 3名とも指摘。具体的な場面に置き換えた：「依頼された箱を、開けずに返したら、依頼人の偽の証文が暴かれたこともある」。魔法の錠を耳と指で開ける一文を足した |
| 「依頼人」が突然出てくる。「金に汚い」と「償い」が噛み合わない | 「路銀が尽きたら、開かない扉を開けて稼ぐ」を足し、依頼で路銀を稼ぐと分かるようにした |
| 孫の人物像、見張る理由が分からない | 「祖父は盗まれた夜から、毎晩、鍵を三度かけ直したという」を足した。路銀の管理を取り上げられる、も足した |
| 呼び名がばらばら（空き巣、泥棒、シーフ） | 「元空き巣のエルフ」に統一した。シーフは、人物の呼び名としてのみ使う |
| 語りが「私」から三人称のキャラ紹介に変わる | 「今の私は、元空き巣のエルフ。」と、一人称にそろえた |
| 「何年も」盗んだのに、帳面が十二行は少ない | 「十二軒の家に忍び込んで」とし、帳面は十二行と合わせた |
| なぜ数十年遅れたのか | 「開けられなかった帳面を、私は今になって開いた」を足した |
| 指輪の場面が説明で、泣けるか笑えるか分からない | 「『遅いんだよ』と、老人は笑った」と、場面にした（第1話の山場） |
| 「鍵開けの腕だけは本物」が定番 | 削った |
