## 縦糸
| 縦糸 | 中身 | 出し方 |
|---|---|---|
| 盗品台帳 | 空き巣時代に几帳面につけた台帳。品名、持ち主、町。返す先の持ち主は、老いている、亡くなって子孫がいる、家がなくなっている。件数は未定 | 数話に1回、台帳の一件を返す回を入れる。盗むために入った家に、返すために入る |
| 唯一開けられなかった箱 | 駆け出しの頃、一度だけ開けられず、盗めなかった箱。持ち主の町と家は覚えている | 序盤に存在を示し、中盤に手がかり、最終話で開ける |

台帳の答え（案）：全部は返せない。持ち主が亡くなり、子孫もいない物がある。返せなかった物をどうするかが、旅の終わりの意味になる。

唯一開けられなかった箱の中身（案、要判断）：
1. 空の箱。箱自体が持ち主の大切な形見だった
2. 持ち主が、泥棒が来る日を待って残した手紙。開けた者に宛てた言葉
3. 台帳の一件目の持ち主の、残したもの（相棒の祖父につながる）

時間の対比：エルフの数十年と、人間の一生の落差を、毎話の余韻に一行で添える。

## 毎話の型
| 段 | 何が起こるか |
|---|---|
| 1. 着く | 町に着く。路銀が尽きかけている |
| 2. 錠 | 開かない扉、箱、牢、金庫が出てくる。依頼（報酬）か、成り行き |
| 3. 開ける | 魔法錠か物理錠。耳と指で読む。結果と音だけを書く |
| 4. 中身 | 人の事情。大切な物、見たくない物、悪事の証拠、肩透かし |
| 5. 行動 | エルフが行動する。返す、開けずに去る、悪事を暴く |
| 6. 余韻 | 時間感覚の一行 |

台帳の回は、2と3が「返すために、持ち主の家に入る」に置き換わる。

### 型崩し（予定調和を避ける）
| 型崩し | 中身 |
|---|---|
| 結果から始める回 | 開けたあとの場面から始め、巻き戻す |
| 開けない・開けられない回 | 魔法錠に負ける。依頼人が「開けないでくれ」と言う |
| 返せない回 | 返す先が空き家、別人が住んでいる、持ち主が受け取りを拒む |
| 相棒が主役の回 | 相棒の機転で解決し、エルフは見ているだけ |
| 悪党を暴く回 | 依頼人が悪党で、開けた物で悪事が暴かれる（スカッと） |

配分（案、大正版からの引き継ぎ）：感動・温かい5割、悲しい1.5割、スカッと2割、胸クソ1割（必ずスカッとにつなげる）、脱力0.5割。
