# 鍵開け放浪記 世界の仕組みと箱の決定（2026-10-17）

イベントマップ v3 の再確認（`12_…`）で出た「世界側の謎が薄い」「箱の中身が未決」を受けて、中川様が決めた。

## 決定事項（2026-10-17、中川様）
| 項目 | 決定 |
|---|---|
| 魔族が魔法を教えた理由 | **貸した。いつか返してもらう日が来る。**人間の魔法は魔族からの借り物 |
| 最後の箱の中身 | **魔族の貸し台帳**（人間に貸した魔法の記録）。エルフの帳面と鏡写しになる |
| 箱が開く条件 | **返す意志のある者にだけ開く錠。**盗人のシーフにも、返す気のなかった若いエルフにも開かなかった。100話かけて返してきたエルフに開く |

予想役が挙げた方向（シーフの手紙、エルフ自身に関わる物、魔法の起源そのもの）は避けた。

## この決定で、つながるもの
| つながり | 内容 |
|---|---|
| 主題 | 「盗んだ物を持ち主に返す」が、世界の仕組みにも映る。人間は魔法を借りていて、魔族は返してもらう日を待っている |
| ギルドと魔族の取引 | 返済の先延ばし。ギルドの幹部は、魔族との取引で、返す日を遅らせてきた |
| 箱の出どころ | シーフが魔族の王の庫から盗んだ物。台帳に載っていない唯一の物 |
| 日記の断片 | 「魔族は我々に、火の灯し方を教えた。その理由は——」の破れた頁の答えが「貸した」 |
| 錠の仕組み | 返す意志のある者にだけ開く、という考え方だけを書く。仕組みと手順は書かない |

## 最終話のぶつかり（未決：エルフの選択）
箱が開くと、貸し台帳が出る。エルフは「盗んだ物は持ち主に返す」と決めて100話歩いてきた。台帳を魔族に返せば、魔族は人間から魔法を取り立てられる。返さなければ、エルフは盗人に戻る。

| 案 | エルフの選択 | 影響 |
|---|---|---|
| A | 返す。ただし、返し方を変える（取り立ての期限や、貸した相手を人間側に知らせるなど） | 主題を守りつつ、人間も守る。返し方の設計が要る |
| B | 返す。人間は魔法を返し、元の暮らしに戻る | 主題に最も忠実。魔法の黎明期の世界が終わる、苦い結末 |
| C | 返さない。盗人として背負う | エルフが償いを破る。主題とぶつかる |
| D | 魔族と交渉し、返済の形を人間と魔族で決め直す | 孫（計算が得意）が活きる。交渉の見せ場になる |

選択は、中川様の決定を待つ。

## 要確認
- 貸し台帳が出る場面で、魔族の王はいるか。王が出るなら、第三部のあらすじで決める
- 魔法が借り物だと、人間が知る場面を、どの出来事に置くか（ギルド幹部が暴かれる回の後が自然）
