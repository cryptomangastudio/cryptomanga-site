## 1. 鍵の歴史（物語の「時代」に使える部分）
| 年代 | 内容 | 区分 |
|---|---|---|
| 紀元前2000年ごろ | 古代エジプトの木製の錠。閂の穴にピンを落として固定し、ピンの入った木の鍵で持ち上げて開ける。ピンタンブラー錠の原型 | 【検索】 |
| ローマ | 南京錠の原型が作られたとされる | 【検索】（異説あり） |
| 中世ヨーロッパ | ウォード錠（鍵穴の内側の仕切りを避ける形の鍵で開ける）。仕切りに合わない鍵は回らない。仕切りを避ける「骨組み」の鍵で開くので、古い錠は開けやすい | 【一般知識】 |
| 1790〜 | ブラマーの錠（1790年から店先に「開けたら200ポンド」の挑戦錠を置いた）。1851年、ロンドンの万国博覧会の年に、米国の錠前師ホブスが約50時間（資料により51〜52時間、14〜16日）かけて開けた。賞金の扱いは争いになったとの記述もある | 【検索】 |
| 19世紀 | チャブの探知錠（不正に触ると固着して開かなくなる。ホブスは固着させて仕組みを知り、逆向きに戻して約25分で開けた。立会人11名）。※制作年は未確認 | 【検索】 |
| 1860年代 | 現在のピンタンブラー錠（イェール）。小さく、大量生産できる | 【検索】 |
| 日本 | 和錠は飛鳥時代からあり、江戸時代に発展。**注文の減った刀鍛冶が、副業として和錠を作った**。板バネ式（板バネ2〜6本）。複数の鍵を順に差す錠、鍵穴をからくりで隠す錠、解くと音の鳴る錠もあった。土佐錠、阿波錠、因幡錠、安芸錠など、地方色がある | 【検索】 |

物語に使える点：
- 「錠は、泥棒と錠前師の競争で進歩した」という歴史がある。エルフは、**錠の進歩を見てきた生き証人**にできる（錠が育つ時代を、数十年・数百年の目で見ている）。この作品の時代は「魔法の黎明期」で、魔法錠は新しい贅沢品。古い錠（機械錠）と新しい錠（魔法錠）が並ぶ。
- 「不正に触ると固着する」「挑戦錠が何十年も破られなかった」は、どちらも**時間の落差**と相性がよい。

## 2. 鍵の種類と、それぞれが「語る」こと【一般知識】
| 種類 | 仕組み | 弱さ | 物語での使い道 |
|---|---|---|---|
| ウォード錠（古い錠） | 仕切りを避ける鍵 | 骨組みの鍵で開く | 古い家、古い持ち主。最初の被害者の家の錠にできる |
| ピンタンブラー | 鍵の凹凸でピンを揃える | ピンを一本ずつ押し上げ、感触で順番を探る | **主人公の基本の技。指先の感触を書ける** |
| レバータンブラー | 板を一定の高さに上げる | 高さを探れば開く | 金庫、箱 |
| 板バネ（和錠） | 板バネを鍵で挟んで外す | 構造を知れば挟める | 和風の街の錠 |
| 南京錠 | 持ち運べる | 壊されやすい | 宿、納屋、馬小屋 |
| 組み合わせ（ダイヤル）錠 | 数字や順番 | 持ち主の癖（誕生日など）が弱点 | **持ち主を知るほど開く錠。人を読む話にできる** |
| 魔法錠（この作品の新しい錠） | 生活魔法で施錠する | 魔力の癖。作り手の癖 | 新しい贅沢品。「作り手の手癖が出る」 |
| 挑戦錠・探知錠 | 触れると固着、挑戦者に賞金 | 破られるまでに時間がかかる | 最後の箱を、これに近づける手もある |

## 3. 鍵の「危険性」（愛するほど、熟知してしまうこと）
【一般知識】が中心。

| # | 危険 | 意味 |
|---|---|---|
| 1 | **鍵は、信頼の形をしている。** 合鍵を持つ人が、その人を守る範囲にいる人 | 鍵が誰の手に何本あるかで、その家の人間関係が分かる |
| 2 | **錠は、正直な人を締め出すだけ。** 泥棒は、窓、壁、鍵を持つ人を通る | 「閉まっている」は「安全」ではない。主人公は、閉まっていることで人が安心しすぎる危うさを知っている |
| 3 | **鍵の形は、情報である。** 鍵の凹凸を見れば、錠の中身が分かる。写し取れば複製できる | 孫が「帳面の数字」を見て気づくのと同じ種類の目 |
| 4 | **錠は、作り手の癖が出る。** 手の癖、疲れ、焦りが寸法に出る | 主人公は「錠を作った人」を指先で読む。同じ作り手の錠は、次も開く |
| 5 | **開けられる技は、開けてはいけない扉も開ける。** 技は中立 | **物語の核**：愛した技が、シーフに盗みの道具として使われた |
| 6 | 鍵は、**持ち主の恐れ**を映す | 孫の祖父は、毎晩、鍵を三度かけ直した。三度かけ直すのは、錠の問題ではなく、人の不安の問題 |
| 7 | 鍵を失うと、**開けられない自分の物**ができる | 帳面にない箱、開けられなかった箱 |

愛好家の世界（ロックスポーツ）【検索】：
- 錠前は、**専門家が人を締め出すために設計したパズル**。愛好家は、設計の欠点を見つけて突破する達成感を楽しむ
- 指先の感触（ピンが設定される感触、テンションとクリック音）に没頭する
- 「自分の物でない錠は開けない」「使用中の錠は開けない」という倫理規範が強い（TOOOL）。ロックスポーツという言葉は、泥棒と区別するために生まれたとされる
- 錠前を、**中身を理解できる機械**として好む人がいる（デジタルの不透明さへの反動）
- 学んだ人は、**安全の見方が変わる**と言う（錠への敬意が増す）

→ 物語の使い道：主人公が愛する鍵と、シーフが使った鍵が、同じ技である。**ロックスポーツの倫理規範（自分の物でない錠は開けない）を、主人公は盗みで破らされてきた。** 償いの旅で、彼女は「許された扉だけを開ける」ことを、自分で選び直す。

## 4. 「鍵そのものが好きか、その先が好きか」の整理
| 好きの向き | 例 | 物語での強さ | 弱さ |
|---|---|---|---|
| A. 機構が好き（仕組み、感触、音） | ロックスポーツの愛好家、細工師 | 描写が具体的で、漫画の絵になる（錠の断面、ピンの動き） | 読者には「技自慢」に見えがち |
| B. 作った人の意図が好き（錠は手紙） | 「この錠を作った人は、何を恐れたか」を読む | **孫の祖父の話、被害者の話につながる**。人を読む話になる | 抽象的になりすぎる恐れ |
| C. 閉じられたものが好き（守られたもの） | 箱、金庫、宝の中身 | シーフの目線に近い（危うい。盗みの動機になりうる） | 主人公を「欲しがる人」に見せる |
| D. 開く瞬間が好き（解放、終わらない緊張の終わり） | カチリ、という音 | 毎話の山に使える（開く瞬間が見せ場） | 繰り返しで型になる |
| E. 開けた先の人が好き（人の暮らし、扉の内側の家） | 部屋の匂い、家具の置き方 | 盗みの罪の重さを知る。償いの旅に直結する | 説明的になる |

私の整理（仮説。議論で検証する）：
- 主人公の偏愛は、**A（感触）から入り、B（作った人の意図）で深まり、E（扉の内側の暮らし）で苦しくなる**。
- 若いころは A と D（開く瞬間）が好きで、そのままシーフに盗みの道具にされた。盗みのあと、E（開けた先の家の暮らし）を、自分の手で壊したと知った。
- 旅の中で、B と E を、別の形で好きになり直す。
- 最後の箱：C（閉じられたもの）が、いちばん危うい好き。「開けたい」という欲が試される。

## 5. 偏愛が出る場面の部品（本文に使える）
| 部品 | 例 |
|---|---|
| 癖 | 宿の戸の錠を、勝手に見る。値切りの最中でも、錠が気になって話を聞いていない |
| 口の悪さ | 「こんな錠、赤子の手より甘い」。ただし作り手の悪口は言わない。**作った人は、必ず尊重する** |
| 値切り | 錠の値段に厳しい（質の悪い錠は、安すぎる）。金にうるさいことと偏愛がつながる |
| 道具 | 針金の曲げ方に流派がある。シーフから教わった道具は、捨てずに、使い方だけ変えた |
| 沈黙 | 錠を前にした時だけ、口の悪さが止まる（孫が気づく） |
| 倫理 | 「開けていいか」を、最初に必ず聞く。聞かずに開けたら、帳面に書き足す |
| 危険を語る | 「閉まってるから安全、って言う奴が、一番先に盗まれる」（これは経験から） |
