## 1. 規格

### タイトル
**『名も刻めない女錠前師は、若様の金庫も恋もひらいてしまう』**
**〜大正十年、七年前に私が作った鍵で、あなたは私を見つけました〜**

| 検査 | 結果 |
|---|---|
| 誰の話か | 名も刻めない女錠前師 |
| 誰との話か | 若様（恋愛が起こることも「恋も」で分かる） |
| 何が起こるか | 金庫を開ける（ミステリー）、恋が始まる |
| 前半20字 | 「名も刻めない女錠前師は、若様の金庫も恋も」。前半だけで機能する |

### キャッチコピー（46字）
**「父の仇と信じていた家の子爵様が、七年間肌身離さず持っていたのは、十二歳の私が作った鍵でした。」**

- ヒロイン目線
- A（裏の顔）＝仇と信じていた家の当主が、実は…という反転
- B（行動）＝七年間肌身離さず持っていた、十二歳の私が作った鍵
- ジャンル語「子爵」が入り、検索・タグ流入に効く
- 真相（親方の犯行）は明かしていない。鍵の作り手（ヒロイン）は、タイトルとキャッチで先に約束として見せる。山場の驚きは、その鍵が七年間ヒーローの手にあったことに置く

### ログライン
名を刻まれない女錠前師が、恋した男の家を「父の仇の家」と信じ込んだまま、開かずの錠を開けるたびに人々の誤解をほどいていく。けれど本当の仇は、彼女を育てた恩人だった。

### 全体あらすじ（2472字）

大正十年、東京。女の錠前師など誰も聞いたことのない時代だ。下町の錠前屋に、どんな錠でも壊さずに開けてしまう十九歳の娘がいた。それがヒロインだ。腕のいい錠前師だった父を亡くし、父の弟子だった親方に育てられている。店の錠を実際に作り、開けているのはヒロインだが、女であるために、その仕事はすべて、町一番の錠前師と呼ばれる親方の名で世に出る。客先を回るのも親方の役目で、ヒロインは工房の中で、ひたすら錠と向き合ってきた。

ある日、店に子爵家の若い当主が訪ねてくる。これがヒーローだ。屋敷には、ヒーローの父で、七年前に亡くなった先代が遺した、誰にも開けられない金庫がある。金庫屋の職人にも、名うての錠前師にも開けられなかった。先代の遺言はただ一言、「壊すな。開けられる者が来るまで待て」。ヒーローは、店の奥から錠を抱えて出てきたヒロインの手つきをじっと見つめ、親方ではなくヒロイン本人に見てほしいと言い張った。この子爵家は、ヒロインが育ての親方から「自分の父は、ヒーローの父である先代に無理な仕事を急がされて死んだ」と聞かされてきた家でもある。それでも親方は「お前の腕が認められたんだ」と、優しく送り出す。

屋敷の書斎に通されて、ヒロインは息をのむ。七年前、父に連れられて一度だけ来た部屋だった。くの字に曲がった鍵穴を持つ金庫の中のからくりにも、見覚えがある。手の震えで細かい作業ができなくなったヒロインの父に代わり、十二歳の自分が組み上げたものだったのだ。ただし、からくりだけでは開かない。専用の鍵と、文字盤に合わせる三つの文字が要る。しかも文字を誤り続ければ、二度と開かなくなる。だが鍵は行方知れずで、鍵穴の形を見ても作り直せない造りだった。文字も、教わる前に父を亡くしたため、分からない。

ヒーローは、金庫は焦れば取り返しがつかないから、と言う。それより先に、開けてほしい錠があった。叔父が、家の帳簿に目を向け始めた当主を封じようと、「先代の死には裏がある」と根も葉もない噂を流し、家督の正当性を揺さぶっているのだ。味方を固めたいヒーローは、先代の代から屋敷に出入りしてきた旧家臣や縁戚の家々を、ヒロインを連れて回る。どの家にも、長年開けられずにいる錠があった。家の困りごとを解けば、その家は当主の味方になる。けれどヒーローには、まだヒロインに明かせない理由がもう一つあった。

たとえば、ある家の亡き母が遺した文箱。娘は、自分は母に疎まれていたのだと思い込んでいた。だがヒロインは、錠の内側だけが艶々と光っていることに気づく。母は毎晩こっそりこの箱を開けていたのだ。中から出てきたのは、会えない娘の背丈や好物を書き留めた帳面だった。錠を開けるたびに、持ち主が長年抱えてきた誤解がほどけていく。

ただ、どの家の錠にも見覚えのある合鍵の傷が残り、決まって、あったはずの物が一つだけ消えていた。工房にこもりきりだったヒロインが、初めて何軒もの家を渡り歩いて、ようやく気づいた符合だった。

錠のことなど何も分からないヒーローは、ヒロインが錠を読む手元にただ見入り、口実を作っては店に通ってくる。親方ではなくヒロイン自身に礼金を渡し、傷だらけの指を気遣い、誰も呼ばなかった彼女の名を呼ぶ。生まれて初めて大事にされ、ヒロインは彼に惹かれていく。

けれど二人の間には、壁がある。まず身分の違い。次に、家督をいまだに狙う叔父が進める、華族の令嬢との縁談。そして何より、金庫を開ければ、惹かれた人が父を死なせた家の息子だと、自分の手で確かめることになる。

そんなある日、親方がふと漏らす。「あのくの字の鍵穴は、厄介だろう」。だがヒロインは、その鍵穴のことを誰にも話していない。この屋敷に親方を呼んだことは一度もない、と家令からはっきり聞かされていたのに。

ある夜、ヒーローは初めて、七年間肌身離さず持っていたものをヒロインに見せる。くの字に曲がった、小さな鉄の鉤。七年前のあの日、書斎で十二歳の少女が取り落としたのを、当時十九だった自分が拾い、誰にも言わずに持ち帰ったのだという。鍵穴に差せば錠は回る。だが金庫は開かない。柄には、誰にも読めない刻みが並んでいた。刻みを見たヒロインの手が、止まる。それは七年前に自分が作った鍵で、刻みは、ヒロインの父が娘にだけ教えていた符丁だった。ヒロインにだけ、こう読める。「は」「る」「を」。

だがヒロインは、すぐには開けられない。屋敷を出ようとする彼女に、ヒーローは言う。「開けなくていい。君がいればいい」。それでもヒロインは、真実を選ぶ。

金庫が開く。中にあったのは、ヒロインの父の帳面と、先代が書き残した文だった。真実はこうだ。親方は長年、客先の家々にひそかに合鍵を残しては、金目の物ではなく、誰かの大事な思い出の品だけをそっと持ち去っていた。名を刻まれることのない職人が、せめて人の心の奥に触れて確かめる、ささやかな、それでいて許されない慰めだった。それに気づいたヒロインの父は先代にだけ打ち明け、証拠の帳面を金庫に託した。だがその直後、真夜中の工房で親方に問い詰められたヒロインの父は、もみ合ううちに倒れ、帰らぬ人となる。誰も見ていない夜のことだった。

先代もまた、余命わずかな体だった。公にする力も時間もないまま、せめてもの真実を金庫に封じ、後を追うように世を去った。二人の死が重なったあの年、真実を知る者は誰もいなくなっていたのだ。

すべてを知ったヒロインは、震えながらも親方の前に立つ。「父を、殺したんですね」。追い詰められた親方は最後にすべてを認め、静かに縄を受け入れる。その名は、生まれて初めて公に刻まれることになった。盗人としての名で。叔父の使い込みも、味方となった縁戚の家々が親族の席で帳簿の開示を求め、家令が洗い直して、明るみに出る。叔父は屋敷を去っていった。

すべての決着がついた夜、ヒーローは言う。「この家の錠は、これからすべて君が作ってくれ」。名を刻むことを許されなかった娘は、初めて自分の名を、店の看板に、そして錠に刻む。

### 舞台の理由（年・都市・大正である必要）（v5新設）

年と都市を「なんとなく」で置かない。次の理由で大正十年・東京とする。

| 理由 | 中身 |
|---|---|
| 一点物の錠 | 錠前がまだ一点ものの手仕事で、錠の艶・擦れ・傷に持ち主の暮らしが残る。量産品の時代には成り立たない（毎話の型の土台） |
| 合鍵は職人にしか作れない | 客先に残した合鍵が、複製できる職人の存在の証拠になる |
| 事故死が見逃される | 科学捜査が未発達で、ヒロインの父の死が「事故」のまま埋もれても不自然でない。現代では、警察と防犯カメラが7年間の空白を許さない |
| 女性が名を出せない | 職業婦人の調査（大正13年、十年の3年後）の対象は教師・タイピスト・事務員・店員・看護婦・交換手の6職種で、錠前師は入らない（`fact-check.md`）。十年の時点でも前例はごく少なかったと考えられる（要確認）。「名を刻まれない」の必然性がある |
| 華族と洋館 | 華族は東京居住が義務（明治4年の勅諭。検索要約で確認、条文の一次資料は未確認）。子爵家・洋館・蔵・金庫が揃う |
| 年の選び方 | 七年前が大正3年になり、華族の襲爵と後見（未成年でも襲爵でき、成年は二十歳）の設定が成り立つ。関東大震災（大正12年）の前で、洋館と下町が並ぶ東京が残る。**十年という数字自体に強い意味はない**（九〜十一年でも成り立つ） |

**新しさは舞台からではなく、「錠を開けるたびに人の誤解がほどける」×「名を刻まれない職人の恋と復讐」という組み合わせから出す。** 大正は棚が混んでいる（『わたしの幸せな結婚』以降、カクヨムにも大正の作品が多い）ので、舞台では差を付けない。現代・SFに移すなら、上の5行の理由がほとんど成り立たなくなるため、**別の企画として起こす**。

## 2. 企画の核

| 読みどころ | 誰に効くか | どこで出すか |
|---|---|---|
| 謎：錠を読み、なぜ閉められたかを解く | 男性読者 | 毎話の前半 |
| 感情：中から出た物で、長年の誤解がほどける | 女性読者 | 毎話の後半 |
| 恋：錠を知らない若様が、錠を読む娘に惹かれていく | 女性読者 | 毎話の最後の一歩 |
| 縦の謎：合鍵の主は誰か。金庫には何が入っているか | 両方 | 毎話に痕跡を1つ |

## 4. 因果の連鎖（壁打ちで作り直した核心）

### 4-1. 二つの死と、七年の空白

| 出来事 | 説明 |
|---|---|
| 父の発見 | 几帳面に帳簿をつける習慣のあった父が、親方が帳簿にない客先を私的に訪ねていたことに気づく。調べると、親方の作業場の鍵のかかった引き出しに、心当たりのない合鍵の束があった |
| 父の相談 | 証拠は父自身の手控えしかなく、名のある職人である親方を告発するには弱い。父は長年の得意先であり信頼する先代にだけ打ち明けた |
| 親方が鍵穴の形を知った経緯 | 父は工房の共有の作業台に、几帳面な癖で注文ごとの下書きを控えていた。親方は父の目を盗み、この金庫の下書き（くの字の鍵穴の図）を一度だけ盗み見ていた。全体の仕組みまでは分からなかったが、鍵穴の形だけは記憶に残っていた |
| 先代の判断 | 先代自身、余命わずかな病を抱えていた。公にする時間も力もないまま、**親方の合鍵では複製できない錠**を作ることだけを父に頼んだ |
| 父の症状 | 父の「手が利かなくなった」とは完全な麻痺ではなく、**重い震えと握力の低下**である。長時間の精密な組み立てはとても務まらず、その大半をヒロインに仕込ませた |
| 父の無理 | 鉤の本体を作ったのは、十二歳のヒロインである。ただし**一度きりで済む最後の仕上げ（文字盤への三つの文字の設定と、鉤の柄に符丁を刻むこと）だけは、震える手を押して父自身が渾身の力でやり遂げた**。刻んだのは、父がヒロインにだけ教えていた符丁である |
| 文字の伝達 | 三つの文字（ヒロインの愛称に由来する。仮）は、父がいずれヒロインに教えるつもりだった。教える前に亡くなったため、ヒロインは知らない。柄の符丁は、その備えだった |
| 据付の日 | 父は手の震えで最後の調整ができないため、ヒロインを連れて屋敷へ行き、書斎の金庫の据付と施錠をヒロインの手で行った。**ヒロインが屋敷へ行ったのは、後にも先にもこの一度きり** |
| 鉤の紛失 | 施錠のあと、父は鉤を「しばらく持っていなさい」とヒロインに預けた（手が震えて落としそうだったため）。その直後、先代が倒れて書斎が騒然となり、ヒロインは鉤を取り落とした。誰も気づかず、拾ったのは書斎に残っていた当時十九歳のヒーローだけだった。先代は、鉤は父の工房にあると思っていた |
| 父の死 | 先代への報告のあと、父は**師弟の情から、公にする前に本人の口から真意を聞きたい**と、ある夜ひとり親方を問い詰めた。もみ合いになり、無理がたたって弱っていた父は倒れ、そのまま帰らぬ人となった。目撃者のいない夜だった |
| 先代の死 | 先代も間もなく病で世を去った。**ヒロインを助ける時間は、最初から残っていなかった** |
| 空白の理由 | 真実を知る二人が、ほぼ同じ時期に相次いで世を去った。「7年間何もしなかった」のではなく、「行動する時間がなかった」 |

### 4-2. なぜ7年間、誰も盗みに気づかなかったか

- 親方が持ち去るのは**金目の物ではなく、誰かの思い出の品**。被害者は「なくした・しまい忘れた」と思い込み、盗難だと気づかない
- 客先を回るのは親方だけの役目で、**ヒロインは工房にこもりきりで、客先回りには一度も出たことがない**（外に出たのは、七年前に父に連れられて屋敷へ行った一度きり）。今回、ヒーローに何軒もの家へ連れ出されて初めて、複数の家の符合に気づいた

### 4-3. 先代の計画は、鉤がヒーローの手にあることを想定していない（壁打ちへの回答／v5.1で整合を取り直した）

先代と父は、いずれ父自身が金庫を開けて、親方を告発するつもりだった。それが叶わなかったとき、開けられる可能性があるのは、組んだヒロインだけだと先代は考えていた。文字は父がヒロインに教えるはずだったが、教える前に父は亡くなった。鉤の柄の符丁は、その備えである。先代は、鉤は父の工房にあると思っていた。
実際は、あの日ヒロインが書斎で取り落とした鉤を、当時十九だったヒーローが拾って持ち帰っていた。先代はそれを知らない。**先代の計画とは無関係な、ヒーロー個人の記憶と情**による。

**先代の遺言「壊すな。開けられる者が来るまで待て」は、「いつか必ず開けられる」という確信ではない。** 先代が本当に恐れていたのは、誰かが焦って金庫を壊し、証拠が失われるか、中身が誤って表沙汰になることだった。**鍵が見つかろうと見つかるまいと、急いで壊すことの危険のほうが大きい、という用心から出た遺言**であり、成功を保証するものではない。だからこそ、鉤が見つからなくても、金庫はいずれ壊すか、諦めて封じたままになったはずである。**ヒーローが鉤を偶然持っていたことは、先代の設計の一部ではなく、物語をきれいに閉じるための幸運として扱う。**

### 4-4. 親方の動機（壁打ちで重罪から過失致死へ調整）

親方は、師（ヒロインの父）の陰で腕はあっても名が出なかった職人だった。客先の合鍵を残す習慣は、**盗むためというより、名を刻まれない自分が唯一触れられる「人の心の奥」を確かめる、ささやかで許されない慰め**として始まった。父の死は計画的な殺人ではなく、**発覚を恐れた末のもみ合いの事故**である。

### 4-5. 金庫の仕掛けと、なぜ七年間開かなかったか（v5新設）

「鉤を持っていて、鍵穴の形も合うのに、なぜ七年間開けなかったのか」に答えるための設計。専門的な仕組みは書かず、次の因果だけを作中の事実とする。

| 疑問 | 答え |
|---|---|
| ヒーローは鉤を試さなかったのか | 試している。鍵穴に差せば錠は回る。だが金庫は開かない（文字盤が残っている） |
| 文字は分からなかったのか | 鉤の柄に刻みはあるが、ヒロインの父がヒロインにだけ教えていた符丁で、ヒーローには模様にしか見えない。読めるのはヒロインだけ |
| 総当たりで試さなかったのか | **文字を誤って合わせ続けると、内側の仕掛けが固まり、二度と開かなくなる。** 何度まで許されるか（三度まで）は、組んだヒロインだけが知っている。ヒーローは知らないので、当てずっぽうに試せない |
| ヒロインは鉤を作り直せないのか | 十二歳のヒロインは、父の指示どおりに作っただけで、細部の形を覚えていない。鍵穴の形を見ても作り直せない造り（複製できない錠）にしてあり、文字も原物の柄にしかない |
| ヒーローはなぜ七年間、ヒロインを探さなかったか | 金庫を組んだのが少女だとは知らなかった。金庫屋は「下請けの錠前屋の仕事」としか言わず、店の仕事はすべて親方の名で通っている（名を刻まれない、という主題そのもの）。先代の遺言は「待て」。叔父が屋敷と財産を握る中、家督を継いだばかりの十九歳に動く余裕がなかった。噂で切迫し、先代の代から出入りの店を七年ぶりに訪ねたところ、偶然、七年前の少女の手を見つけた |
| ヒーローはなぜ、ヒロインを指名したか | 店の奥から錠を抱えて出てきたヒロインの、錠を扱う手つきを見て、七年前の書斎で錠を組んでいた少女だと気づいたから |
| 親方はなぜ、ヒロインを送り出すか | 断れば子爵に怪しまれる。ヒロインには鍵も文字もないと見切っており、金庫の中身が気がかりで、ヒロインの近くで様子を見たい。表向きは、弟子の腕が認められたことを喜ぶ育ての親を演じる |
| 外の職人はなぜ開けられなかったか | 鍵を持たず、鍵穴を破ろうとしただけだから（複製できない錠なので、合鍵も作れない） |
| 叔父はなぜ壊して開けないのか | 先代の遺言「壊すな」があり、当主であるヒーローが許さない。中身が壊れる恐れもある |
| ヒーローはなぜ鉤を隠すのか | 金庫を狙う叔父の耳に入れば奪われかねない。ヒロインが誰の側か、序盤はまだ分からない。ヒロインが「父を死なせた家」を恨んでいると知れば、なおさら言い出せない |
| なぜヒロインは、金庫を先に開けようとしないのか | 鍵も文字も分からず、誤れば二度と開かなくなるので、急げない（ヒーローの頼みを先に受けるのは自然） |

※「誤ると固まる仕掛け」は創作であり、実在の機構に合わせる必要はない。ただし専門家に突っ込まれないよう、仕組みの説明は書かない（`錠前の知識.md` の方針どおり）。

## 5. ミステリーの設計

### 5-1. 謎の型

| 層 | 型 | 問い |
|---|---|---|
| 横（毎話） | 主にホワイダニット（一部の話にハウダニット要素を含む） | この錠は、なぜ閉められたのか |
| 縦（全話） | フーダニット＋ホワイダニット | 合鍵の主は誰か。金庫には何が遺されたのか |

作品の型：日常の謎 × 連作短編。殺人は毎話の中心にしない。父の死は過去の事件として縦の謎にだけ置く。

### 5-2. 縦の謎の設計表

| 項目 | 中身 |
|---|---|
| 真相（1文） | 客先に残した合鍵で思い出の品を持ち去り続け、気づいたヒロインの父を、問い詰められた末のもみ合いで死なせたのは、親方である |
| 推理の筋道 | 消えた物の家はすべて親方が客先回りをした家（A）＋毎回同じ合鍵の傷（B）＋一度も屋敷に呼ばれたことのない親方が、金庫の鍵穴の形を知っていた（C）→ 親方。Cは、父が下書きを工房の作業台に控えていたため、鍵穴の形を知りえたのは工房の人間（親方とヒロイン）だけ、という形で使う。そのうえでAにより、客先回りをしないヒロインが除外される |
| 対照 | ヒーローの母の宝石箱には傷がない。親方の客先ではなかったため（7章の表） |
| ヒロイン自身の除外 | ヒロインは客先回りに出たことが一度もない（外に出たのは七年前に一度、父に連れられて屋敷へ行っただけで、盗みの時期・場所とは無関係）。今回が客先の家々を回る初めて |
| 親方の機会（opportunity） | 客先回り・修理受付は親方の役目。据付や修理の折に合鍵を残す機会がある |
| 叔父の除外 | 叔父は錠前の心得が一切なく、自邸の鍵一つ直せず外の鍵屋を呼んだことがある（早い段階で示す） |

### 5-3. 手がかりの配置

| 時期 | 手がかり | 隠し方 |
|---|---|---|
| 序盤 | 家令かヒーローが「この屋敷は代々、錠前は先代の頃からずっと（父の）店に任せてきた。**親方さんにお願いしたことは一度もない**」と名指しで言う | 会話の中の一言。主題は先代の遺言 |
| 序盤 | 分業の説明：客先回りは親方、工房内はヒロイン | さりげない日常描写 |
| 序盤 | 金庫の鍵穴は「くの字」。別の場面で、ヒーローの手の中に「くの字の細い鉄」が一瞬見える | 文の主題は別のこと（火傷の痕など）にする |
| 序盤 | ヒロインの父は道具の柄に、ヒロインにだけ教えた符丁を刻む几帳面な癖があった（回想） | 父を懐かしむ感情の場面に置く |
| 序盤 | ヒロインの父は、注文ごとの下書きを工房の共有の作業台に控える癖があり、弟子（親方）もヒロインも、それを見られた（回想） | 父の几帳面さを語る場面に置く |
| 序盤〜中盤 | 毎話、錠に同じ合鍵の傷 | 読者だけが気づく回数を重ねる |
| 序盤〜中盤 | 毎話、依頼人が「この錠も、あの店で納めてもらった」と言う | 世間話の列挙の中に入れる |
| 中盤 | 「親方は屋敷に呼ばれたことがない」を、家令がもう一度思い出させる | 別の話題（叔父の噂など）のついでに |
| 中盤 | 毎話、中から「あったはずの物が一つだけ」消えている | 誤解がほどける感動の直後に置く |
| 中盤 | 親方が「あのくの字の鍵穴は厄介だろう」と口にする。ヒロインはまだ誰にも話していない | 親方が気遣う優しい場面の中に置く |
| 中盤 | 叔父が帳簿を執拗に確認させる。金の話になると不機嫌になる | 世間話の中に混ぜる |
| 中盤 | ヒーローの母の宝石箱：先代から母への手紙の束 | 恋の山場と同じ場面 |
| 終盤 | ヒーローが七年持ち歩いた鉤を見せる。ヒロインが自分の作った鍵だと気づく。符丁「はるを」 | 恋の告白と謎の発見が同じ出来事 |
| 終盤 | 金庫の中の、父の帳面と先代の文 | 縦の謎が閉じる瞬間 |

### 5-4. ミスリードと、その本当の理由

| 疑わしく見せるもの | 読者が疑うこと | 本当の理由 |
|---|---|---|
| 先代 | 父を死なせた（ヒロインの一人称の思い込み） | 先代は父を守ろうとしていた |
| 叔父 | 金庫の中身を狙い、先代の死にも関わった | 後見期間後も財産管理を任され続け、使い込んでいた。合鍵を作る技術も心得もない（早い段階で示す） |
| ヒーロー | ヒロインを利用しているだけ（序盤、冷たく見える） | 父を誤解したまま同じ冷たさを身につけていた。加えて、家督の正当性を揺るがす叔父の噂への対応に追われている（外的な切迫） |

### 5-5. 心理的な盲点

親方は、町の信用が厚い育ての親。いて当たり前で、誰も疑わない人である（チェスタトンの「見えない男」の型）。**執筆メモ：序盤〜中盤は徹底して善人・恩人として描くこと。犯人だと分かって書かない。**

### 5-6. フェアの検査

| 検査 | 結果 |
|---|---|
| 推理に使う手がかりが、解決より前に出ているか | 出ている。Cは序盤の名指しと中盤の思い出しの2段で成立する |
| 消去法（ヒロイン自身・叔父）が明記されているか | 明記した（5-2、5-4） |
| 地の文に嘘がないか | ヒロインの思い込みは伝聞として処理。全知的な記述はしない（執筆時の注意を9章に記載） |
| 専門知識で解いていないか | 傷の位置、消えた物、店の客、形の一致、失言。どれも読者に分かる |
| ミスリードに事前の手がかりがあるか | ある（5-4、5-3） |
| 悪役ラベルがトリックと矛盾していないか | 「恩人（もう一つの顔）」に変更し、執筆メモを付けた |

## 6. 毎話の型「開ける・出てくる・ほどける」

| 段 | 何が起こるか |
|---|---|
| 1. 持ち込み | ヒーローが、叔父の噂に対抗して味方を固めるため、旧家臣・縁戚の家の長年開かない錠を持ち込む（あるいはヒロインを連れて回る）。裏の理由は、彼女を手放したくないこと |
| 2. 錠を読む | 錠の艶・擦れ・傷・埃から推理する（読者も分かる事実で） |
| 3. 開ける | 開錠の手つき（専門性は手・耳・目の感覚だけで描く） |
| 4. 出てくる | 中から思い出の品 |
| 5. 回想 | 持ち主の回想 |
| 6. ほどける | 依頼人の長年の思い込みが誤解だったと分かる |
| 7. 一歩 | ヒーローがヒロインの推理に見入る。名を呼ぶ。手当てする |
| 8. 縦の糸 | 合鍵の傷と、消えた物が1つ |

### 型崩し回（仮説から確定事項へ）
1. **倒叙回**：先に「誰が、なぜ閉めたか」を読者に見せてから、ヒロインが解く回
2. **逡巡・失敗回**：開けてよいか迷う、または一度で開かない回
3. **恋愛比重の高い回**：錠の謎が背景に退き、二人の関係が前に出る回
4. **複数話の大型エピソード**：ヒーローの母の宝石箱の回を2話にまたがらせる。**終盤（金庫開扉・親方との対峙・叔父の失脚・求婚）も同様に複数話に分け、1話に詰め込まない**

## 7. 横の謎の例

| 錠 | 謎 | 読者にも分かる手がかり | 合鍵の傷の出し方 | ほどけ方 | 消えた物 |
|---|---|---|---|---|---|
| 母の形見の文箱 | 母はなぜ鍵を娘に残さなかったか | 錠の内側だけ艶がある＝毎晩開けていた | 錠前の内側に、他の錠と同じ小さな擦れ | 母は奉公先を出られず、毎晩娘の成長を書き留めていた | 帳面の最後の一枚 |

## 8. 恋の線

### 探偵役とワトソン役
- ヒロイン＝探偵役。視線は錠に向く。恋に鈍い
- ヒーロー＝ワトソン役。錠が分からず、ヒロインの推理に驚き見入る。その驚きと敬意が、そのまま執着になる

### ヒーローの執着の見せ方
口実を作って錠を持ち込む／給金をヒロインに直接払う／傷だらけの手を手当てする／名前を呼ぶのはヒーローだけ／表では冷たい当主、ヒロインの前でだけ不器用

### ヒーローが錠を持ち込む理由（二層／v5新設）

| 層 | 理由 |
|---|---|
| 表（ヒーロー自身が口にする） | 叔父の噂で家督の正当性が揺らいでいる。先代の代から屋敷に出入りしてきた旧家臣・縁戚の家々の「長年開かない錠」を解けば、その家は当主の味方になる。当主には「家の体面を保つ」務めがあり、家々の困りごとを預かるのは務めの内である |
| 裏（読者にだけ、後で分かる） | 七年前の少女を見つけた。手放したくない。鉤のことは明かせない。彼女が錠を読む姿を、もっと見ていたい |
| 家々が店の得意先でもある理由 | 屋敷が代々、錠を父の店に任せてきたため、屋敷に出入りする家々も同じ店を使ってきた。これが親方の客先回りと重なり、縦の謎（手がかりA）が成立する |

### ヒーローの外的な切迫（新設）
叔父が「先代の死には裏がある」という根も葉もない噂を流し、ヒーローの家督の正当性に疑いを持たせようとしている。**目的は、家の帳簿に目を向け始めた当主を封じ、自分の使い込みの発覚を防ぐこと。** ヒーローにとって金庫を開けることは、恋のためだけでなく、自分と家の名誉を守るための切迫した必要になる。**ただし、誤れば二度と開かないので焦れない。** その間に、味方を固めておく。

**使い込みが明るみに出る経路：** 味方となった旧家臣・縁戚の家々が、親族の席で帳簿の開示を求め、家令が洗い直す。味方固めの伏線が、そのまま回収される。

### 恋の障害（3つ）
1. 身分差：子爵家の当主と、名も出せない職人
2. 思い込み：ヒロインは先代が父を死なせたと信じている。惚れた男の家が仇の家
3. 縁談：叔父が急ぐ縁談

### 恋の山場

| 段階 | 出来事 |
|---|---|
| 出会い | 店の奥から錠を抱えて出てきたヒロインの手つきを見て、ヒーローが七年前の書斎の少女だと気づく。ヒロインは気づかない |
| 動き出し | 給金をヒロインに直接払われる |
| 近づく | ヒーローの母の宝石箱。ヒーローが初めて弱みを見せる |
| 引き離される | ヒロインが合鍵の傷に気づき始めた頃から、親方が「女の子を外に出すのは危ない」と、心配する親の顔で連れ戻そうとする（善人の顔のまま）。叔父が縁談を急ぐ |
| 告白 | ヒーローが鉤を見せる。ヒロインが自分の作った鍵だと気づく |
| 選ぶ | 仇同士になると思い、ヒロインは屋敷を出ようとする。ヒーロー「開けなくていい。君がいればいい」 |
| **対峙**（新設） | 金庫が開き、ヒロインが親方に「父を、殺したんですね」と問う。ヒロインの感情処理の場面 |
| 求婚 | 「この家の錠は、すべて君が作ってくれ」。ヒロインが自分の名を刻む |
