# 企画書『錠前』v1（2026-09-27）

企画在庫v3で2軍だったK5『錠前』を、中川様の判断で本命にした。
さらに中川様のアイデアを毎話の型として組み込んだ。

> 「開けた金庫の中から、いい思い出とか悪い思い出とかが毎回出てきて、その人たちの回想シーンが流れたりして、今まで思っていたことが実は誤解だったとか、そういうエモいエピソードを入れられるといい」

---

## 規格

### タイトル
**『華族様の開かずの金庫を組んだのは、十二歳の私でした』**
**〜大正錠前師の開錠帖〜**

| 検査 | 結果 |
|---|---|
| 誰の話か | 十二歳で金庫を組んだ娘（錠前師） |
| 誰との話か | 華族様 |
| 何が起こるか | 開かずの金庫をめぐる話。サブで、錠を開ける連作だと分かる |
| 作品固有の言葉 | 開かずの金庫、十二歳、錠前師、開錠帖 |
| ジャンルの言葉 | 華族、大正 |
| 前半20字 | 「華族様の開かずの金庫を組んだのは、十二歳の」 |

3つとも言える。サブの「開錠帖」で、1話ずつ錠を開けるお仕事ミステリーだと伝える（カクヨムコンのライト文芸部門の棚に合う）。

### キャッチコピー
**「若様が隠していたのは、父への恨みと、七年持ち歩いた私の錠前鉤でした。」**（35字）

- ヒロイン目線
- A（裏の顔）＝父への恨み。ヒーローの欠落でもある
- B（感情を行動で）＝七年持ち歩いた錠前鉤
- 恨みが誤解であることも、鉤の意味も明かしていない

### 全体あらすじ（309字）

大正十年。錠前屋の小春は、どんな錠でも開けられる。だが仕事はすべて親方の名でしてきた。

華族の若当主が、七年開かない亡父の金庫を開けてほしいと訪ねてくる。その錠を組んだのは、十二歳の小春だった。

若当主は、あの日書斎に落ちていた少女の鉤を、今も持ち歩いている。

番号を探す合間にも、開かずの錠が持ち込まれる。開けるたび思い出の品が出て、持ち主の長年の誤解がほどける。錠には必ず、同じ合鍵の傷があった。

小春は、先代が父を死なせたと聞かされて育った。金庫を開ければ、若当主とは敵になる。

合鍵を作っていたのは、小春を育てた親方だった。最後に金庫が開いたとき、ほどけたのは二人の誤解だった。小春は彼の隣で、初めて自分の名を錠に刻む。

## 毎話の型「開ける・出てくる・ほどける」（中川様の案）

| 段 | 何が起こるか | 誰の読みどころか |
|---|---|---|
| 1. 持ち込み | 開かない錠が届く。持ち主は死んだか、鍵をなくしたか、開けるのが怖いか | — |
| 2. 錠を読む | 小春が錠を調べ、**誰が、いつ、なぜ閉めたか**を錠の傷や擦れから推理する（内側からしか掛からない錠、毎晩開けられた跡、わざと折られた鍵） | 男性読者（謎解き・専門知識） |
| 3. 開ける | 開錠の手つき。マンガではここを見開きに使う | 男性読者（見せ場） |
| 4. 出てくる | 中から物が出る（手紙、写真、へその緒、借用書、壊れた懐中時計） | — |
| 5. 回想 | 持ち主の回想シーン | 女性読者（感情） |
| 6. ほどける | 依頼人がずっと思い込んでいたこと（捨てられた、憎まれていた、裏切られた）が反転する | 女性読者（感情）＋男性読者（どんでん返し） |
| 7. 一歩 | 同じ出来事で、小春と若当主の距離が一歩動く | 女性読者（恋） |
| 8. 縦の糸 | 錠か中身に、**同じ合鍵の傷**が残っている | 両方（引き） |

### この型がベンチマークに合う理由
- 【薬屋】1話1事件を専門知識で解く → 段2・3
- 【薬屋】横の事件が縦に合流 → 段8。毎話の合鍵の傷が、親方の盗みと小春の父の死に繋がる
- 【薬屋】恋はヒーローから → 段7。小春の視線は錠に向き、若当主が小春を見ている
- 【わた婚】虐げられた娘が大事にされる → 小春は親方の名でしか仕事ができない。依頼人の誤解がほどけるたびに、小春自身が「自分の腕」を認められていく
- `crossover.md` 原則6（恋と謎を同じ出来事で進める）→ 段2〜7が1つの錠で起こる

### 型の強み：毎話の小さな反転が、最終話の大きな反転の予行演習になる
毎話「思い込みが誤解だった」を見せ続けることで、読者は**小春と若当主の思い込みも誤解ではないか**と疑い始める。最終話の金庫で、その予感が回収される。

## 縦の謎

### 二人が信じていること（誤解）

| 人物 | 信じていること |
|---|---|
| 小春 | 七年前、先代が父に無理な仕事を急かし、父を死なせた。親方からそう聞かされて育った |
| 若当主 | 父（先代）は冷たく、息子を顧みなかった。金庫は父の冷たさそのもの |

### 真相（最終話で金庫が開く）
- 親方は、自分が作った錠の**合鍵をすべて隠し持ち**、顧客の蔵や金庫から少しずつ盗んでいた
- 小春の父はそれに気づき、顧客だった先代に打ち明けた
- 先代は証拠を自分の金庫に収め、**親方には開けられない錠**を小春の父に頼んだ。父は病で手が利かず、十二歳の小春が代わりにからくりを組んだ
- その直後、小春の父は事故に見せかけて死ぬ。先代もまもなく急死する
- 金庫の中には、親方の盗みの証拠、小春の父の遺言（娘を頼む）、若当主への先代の手紙（冷たくしたのは家督争いから息子を守るためだった）が入っていた
- **番号は小春の誕生日だった。** 先代は、錠を組んだ少女しか開けられないようにした

### なぜ七年開かなかったか（検算）
- からくり（逆回しの仕掛け）を知るのは、組んだ小春だけ
- 番号は先代しか知らない
- 先代の遺言は「壊すな。開けられる者が来るまで待て」。若当主は父を恨みながら、七年この遺言を守った（**恨みの裏にある情が、行動で見える**）
- 親方も密かに試したが開けられなかった。親方は、錠を組んだのは小春の父だと思っていた
- 小春は、父の最後の仕事を手伝ったことは覚えているが、どの家に納めたかは知らなかった

### 中盤の転換
小春が金庫のからくりを解いた（番号だけが残った）ことを親方が知る。**親方は小春に金庫を開けさせ、中身を奪おうとする。** 恩人が小春を若当主のもとへ送り出す理由が、ここで裏返る。

## 人物

| 人物 | 位置 |
|---|---|
| 小春（十九） | 錠前屋の奉公人。明治三十五年生まれ。父は腕のいい錠前師だった。父の死後、弟子だった親方に引き取られた。仕事はすべて親方の名で、給金はない |
| 若当主（二十六） | 華族の当主。十九で家を継いだ。無口。父を恨んでいる。七年前、父の書斎で錠を組む少女を見た。少女が落とした小さな錠前鉤を持ち歩いている |
| 親方（ヘイト役） | 小春に錠を教えた恩人。腕は確かで、町の信用も厚い。合鍵で盗み、小春の父を死なせた |
| 先代（故人） | 若当主の父。冷たい父を演じて息子を家督争いから守った。回想にだけ出る |

### 社内基準との照合
- ヘイト役は1人（親方）に集中している
- 親方はかつて小春を救った人（引き取り、育て、錠を教えた）。落差がある
- 毎日同じ店にいる
- 小春が逃げられない理由：住み込みの奉公で行き場がない。錠前師として表に出るには親方の名が要る（大正期に女性が独立した錠前師になれたかは要確認）
- ヒーローにも欠落がある（父に愛されなかったと思っている）

| 錠 | 依頼人の思い込み | 出てくる物 | ほどけ方 |

## コントラストの法則への対応
- 1〜3話は暗く：小春は親方の名でしか仕事ができず、給金もない。先代を恨んでいる。若当主は冷たく見える
- 4話以降は明るく：開けるたびに依頼人が救われ、小春の腕が認められていく。毎話の読後感は温かい

---

## 要確認
- 大正期に女性が錠前師として働いた例（奉公・家業の手伝いとしてはありうるが、独立できたか）
- 大正三年に華族の書斎にあった金庫（輸入品か国産か。竹内金庫は大正3年製があるので国産でも成立する）
- ダイヤル錠の番号に誕生日を使う設定が、当時の金庫の仕組みで成立するか（桁数）
- 大正期の徴兵制度と、兵役を逃れる手段（横の事件の1つで使う場合）
- 華族の家督相続（十九歳で当主になれるか。明治民法では成年は二十歳）
