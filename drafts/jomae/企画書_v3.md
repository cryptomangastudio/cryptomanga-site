ミステリーの点検で、穴が4つ見つかった。

| 穴 | 直し方 |
|---|---|
| 真犯人を指す手がかりがない | 毎話の錠から「あったはずの物が一つだけ消えている」。依頼人は「この錠も、あの店で納めてもらった」と何気なく言う。親方は、小春がまだ話していない金庫の仕組みを口にする |

その他：サブタイトルを「開錠帖」から「解錠帖」にした（壊さずに開けるのが解錠。「解」は「ほどく」で、毎話の「誤解がほどける」と同じ字）。戻したければ戻す。

30話構成にはまだ進まない。話数は書かず、「序盤・中盤・終盤」で配置する。

## 1. 規格

### タイトル
**『華族様の開かずの金庫を組んだのは、十二歳の私でした』**
**〜大正錠前師の解錠帖〜**

### キャッチコピー
**「若様が隠していたのは、父への恨みと、七年持ち歩いた私の錠前鉤でした。」**（35字）

### 全体あらすじ（538字）

大正十年、東京。錠前屋の小春は、どんな錠でも壊さずに開けられる。だが女の錠前師に前例はなく、仕事はすべて育ての親方の名で、給金もない。

子爵家の若当主・桐生惟臣が、七年開かない亡父の金庫を開けてほしいと店に来る。金庫は、作った金庫屋の職人にも開けられなかった二重錠だった。そのからくりは、十二歳の小春が病床の父に代わって組んだものだった。

錠を知らない惟臣は、小春が錠を読む手つきに見入り、口実を作っては開かずの錠を持ち込む。開けるたび思い出の品が出て、持ち主の長年の誤解がほどける。だが錠には必ず、同じ合鍵の傷があった。

初めて名を呼ばれ、自分の腕に給金を払われて、小春は惟臣に惹かれていく。けれど小春は、先代が父を死なせたと聞かされて育った。家督を狙う叔父は縁談を急ぎ、金庫の中身を欲しがっている。

ある夜、惟臣は七年持ち歩いた少女の鉤を、初めて小春に見せる。それは小春が作った、金庫の鍵だった。柄に刻まれた父の符丁は「はるを」。

金庫が開く。合鍵で盗みを重ね、父を死なせたのは、名を知られぬまま腕だけを磨いてきた親方だった。先代は父を守ろうとしていた。父の遺言は「はるをたのむ」。

誤解がほどけた夜、惟臣は言う。この家の錠は、すべて君が作ってくれ。小春は初めて、自分の名を錠に刻む。

## 2. 企画の核

**ログライン**：名を刻むことを許されない大正の女錠前師が、開かずの錠を開けるたびに人々の誤解をほどき、最後に自分と若当主の誤解をほどく。

| 読みどころ | 誰に効くか | どこで出すか |
|---|---|---|
| 謎：錠を読み、なぜ閉められたかを解く | 男性読者 | 毎話の前半 |
| 感情：中から出た物で、長年の誤解がほどける | 女性読者 | 毎話の後半 |
| 恋：錠を知らない若当主が、錠を読む娘に惹かれていく | 女性読者 | 毎話の最後の一歩 |
| 縦の謎：合鍵の主は誰か。先代の金庫には何が入っているか | 両方 | 毎話に痕跡を1つ |

## 4. ミステリーの設計

### 4-1. 謎の型

| 層 | 型 | 問い |
|---|---|---|
| 横（毎話） | **ホワイダニット** | この錠は、なぜ閉められたのか |
| 縦（全話） | フーダニット＋ホワイダニット | 合鍵の主は誰か。先代はなぜ金庫を遺したのか |

作品の型：**日常の謎 × 連作短編 × コージー**。殺人は毎話の中心にしない。父の死は過去の事件として縦の謎にだけ置く。

### 4-2. 縦の謎の設計表

| 項目 | 中身 |
|---|---|
| 真相（1文） | 合鍵で客の家から少しずつ盗み、それに気づいた小春の父を事故に見せかけて死なせたのは、親方である |
| 推理の筋道 | 消えた物の家はすべて親方の店の客（A）＋毎回同じ合鍵の傷（B）＋**一度も桐生家に呼ばれたことのない親方が、金庫の鍵穴の形を知っていた**＝書斎に忍び込んだことがある（C）→ 親方 |
| 先代の真相 | 父から親方の盗みを打ち明けられ、証拠を金庫に収めた。親方に開けられない錠を父に頼み、鍵を少女に託した。息子に冷たく振る舞ったのは、家督を狙う叔父から守るためだった |
| 親方の動機 | 師匠（小春の父）の陰で、腕はあるのに名が出なかった。客の宝を誰にも気づかれずに持ち出すことが、自分の腕の証明だった。見つかり、師を死なせた |
| 親方が小春を引き取った理由 | 小春の腕を自分の名で使うため。そして罪の意識から。両方 |
| 親方が「先代が父を死なせた」と教えた理由 | 疑いを逸らし、小春を子爵家から遠ざけるため |

### 4-3. 手がかりの配置

| 時期 | 手がかり | 隠し方 |
|---|---|---|
| 序盤 | 惟臣「七年、作った金庫屋の職人にしか見せていない。その職人にも開けられなかった」。**親方は一度も呼ばれていない** | 会話の中の一言。主題は金庫の古さと先代の遺言（竹内金庫は受注生産で、職人ごとに中の作りが違った史実に乗る） |
| 序盤 | 金庫の鍵穴は「くの字に曲がっている」。別の場面で、惟臣の手の中に「くの字に曲がった細い鉄」が一瞬見える | 後者の文の主題は、惟臣の手の火傷の痕にする（文の主題を変える） |
| 序盤 | 父は、娘に渡す道具の柄に、娘にしか読めない符丁を刻んでいた（小春の回想） | 父を懐かしむ感情の場面に置く（感情で覆う） |
| 序盤〜中盤 | 毎話、錠に同じ合鍵の傷 | 読者だけが気づく回数を重ねる |
| 序盤〜中盤 | 毎話、依頼人が「この錠も、あの店で納めてもらった」と言う | 世間話の列挙の中に入れる（並べて埋める） |
| 中盤 | 毎話、中から「あったはずの物が一つだけ」消えている | 誤解がほどける感動の直後に置く（目立つ情報の直後） |
| 中盤 | 親方が「あのくの字の鍵穴は厄介だろう」と口にする。小春はまだ鍵穴の話をしていない。親方は桐生家に呼ばれたことがない | 親方が小春を気遣う優しい場面の中に置く。小春はその場では気づかず、読者だけが気づける |
| 中盤 | 惟臣の母の宝石箱から、先代から母への手紙の束。先代は冷たい人ではなかった | 惟臣が弱みを見せる恋の山場と同じ場面（先代への疑いを揺らす） |
| 終盤 | 惟臣が、七年持ち歩いた鉤を初めて小春に見せる。小春は自分の作った鍵だと気づく。柄に符丁「はるを」 | 恋の告白と、謎の鍵の発見が同じ出来事 |
| 終盤 | 金庫の中の、先代が作った盗品の目録。毎話消えていた物が、すべて載っている | 横の謎が縦の謎に合流する瞬間 |

### 4-4. ミスリードと、その本当の理由

| 疑わしく見せるもの | 読者が疑うこと | 本当の理由 |
|---|---|---|
| 先代 | 小春の父を死なせた（小春の一人称の思い込み） | 先代は確かに父に錠を急がせた。親方に気づかれる前に証拠を封じたかったから。親方は、この半分の事実を使って小春に嘘を教えた |
| 叔父 | 金庫の中身を狙い、先代の死にも関わった | 叔父は後見人だった時期に家の金を使い込んでいた。金庫にその証拠があると恐れていた。合鍵を作る手段も技術もない。先代は病死 |
| 惟臣 | 小春を利用しているだけ（序盤、冷たく見える） | 父を冷たいと誤解したまま、同じ冷たさを身につけていた。小春の前でだけ不器用になる |

### 4-5. 心理的な盲点
親方は、町の信用が厚い腕のいい職人で、小春の育ての親。**いて当たり前で、誰も疑わない人**である（チェスタトンの「見えない男」の型）。
しかも小春自身も、世間から見えていない職人である。**見えない者同士が、同じ店にいる。**

### 4-6. フェアの検査

| 検査 | 結果 |
|---|---|
| 推理に使う手がかりが、解決より前に出ているか | 出ている（4-3のA・B・Cは中盤までにすべて出る。Cは序盤の「親方は一度も呼ばれていない」と、中盤の失言の2つで成り立つ） |
| 地の文に嘘がないか | 小春の「先代が父を死なせた」は一人称の思い込みとして書く。小春が知っている事実は隠さない |
| 専門知識で解いていないか | 解いていない。傷の位置、消えた物、店の客、形の一致、失言。どれも読者に分かる |
| 真相を感想欄で当てられても読ませられるか | 読ませられる。親方の動機（小春と同じ痛み）と、二人の誤解がほどける感情で読ませる |
| 叙述トリックを使っていないか | 使っていない（マンガ化で成り立たないため） |

## 5. 毎話の型「開ける・出てくる・ほどける」（中川様の案）

| 段 | 何が起こるか | ミステリーでの役割 |
|---|---|---|
| 1. 持ち込み | 惟臣が開かずの錠を持ち込む | 謎の提示。惟臣の口実（恋） |
| 2. 錠を読む | 錠の艶・擦れ・傷・埃から、誰がいつなぜ閉めたかを推理 | 手がかり。読者も分かる事実で |
| 3. 開ける | 開錠の手つき | 見せ場。専門性は手・耳・目の感覚だけで描く |
| 4. 出てくる | 中から思い出の品 | 手がかりの回収 |
| 5. 回想 | 持ち主の回想 | 動機（ホワイダニット） |
| 6. ほどける | 依頼人の長年の思い込みが誤解だったと分かる | 解決。感情の山場 |
| 7. 一歩 | 惟臣が小春の推理に見入る。名を呼ぶ。手当てする | ワトソン役の驚き＝ヒーローの執着 |
| 8. 縦の糸 | 合鍵の傷と、消えた物が1つ | 縦の謎の痕跡 |

## 6. 横の謎の例

| 錠 | 謎（なぜ閉めた） | 読者にも分かる手がかり | ミスリード（と本当の理由） | ほどけ方 | 消えた物 |
|---|---|---|---|---|---|
| 母の形見の手文庫 | 母はなぜ鍵を娘に残さなかったか | 錠の内側だけ艶がある＝毎晩開けていた | 箱に男物の櫛＝男がいた？（本当は娘の父の形見） | 母は奉公先を出られず、毎晩この箱に娘の成長を書き留めていた | 帳面の最後の一枚 |
| 蔵の二重扉 | 父はなぜ弟にだけ蔵の鍵を渡さなかったか | 内扉の落としの高さが、子どもの背丈に合わせてある | 兄が父に取り入った？（兄は何も知らなかった） | 家を継げない弟のための積立の証文があった | 証文の一枚 |
| 嫁入り箪笥 | 継母はなぜ一段にだけ錠をかけたか | 開けるのは簡単。見せ場は中身 | 継母は娘を嫌っていた？ | 継母が自分の着物を売って貯めた持参金 | 帯留め一つ |
| 内側から錠のかかった子ども部屋 | 兄はどうやって、なぜ部屋を閉めて出ていったか | 扉の下の隙間と、床の擦れ（日常の知識で解ける） | 兄は家族を捨てた？ | 兄には家を出る理由があった（要確認：理由の史実） | 懐中時計 |
| 智恵箱（秘密箱） | 芸者はなぜ開け方も知らない箱を大事にしていたか | 小春の専門外。手の感覚で解く | 旦那に捨てられた？ | 中に身請けの証文と、身請けの直前に死んだ旦那の遺書 | 簪一本 |
| 惟臣の母の宝石箱（中盤の山場） | 母はなぜ父の贈り物を一つも身につけなかったか | 箱の錠は一度も開けられていない（新しいまま） | 母は父を愛していなかった？ | 先代から母への手紙の束。先代は冷たい人ではなかった | ── （この回だけ消えた物がない。親方の客ではなかったから。これも手がかり） |

1話だけ倒叙回（先に「誰が閉めたか」を読者に見せる回）を入れると、型が変わって飽きにくい（仮説）。

## 7. 恋の線

### 探偵役とワトソン役
- **小春＝探偵役**：視線は錠に向く。恋に鈍い
- **惟臣＝ワトソン役**：錠が分からない。読者と同じ目線で小春の推理に驚き、黙って見入る
- ワトソン役の「探偵への驚きと敬意を読者に手渡す」役割が、そのまま惟臣の執着になる。惟臣の内面は地の文に書かず、台詞と行動で見せる

### 惟臣の執着の見せ方（毎話どれか）
口実を作って錠を持ち込む／給金を親方ではなく小春に払う／傷だらけの手を手当てする／小春を名前で呼ぶのは惟臣だけ／表では冷たい当主、小春の前でだけ不器用

### 恋の障害（3つ）
1. 身分差：子爵家の当主と、名も出せない職人
2. 思い込み：小春は先代が父を死なせたと信じている。惚れた男の家が仇の家
3. 縁談：叔父が華族令嬢との縁談を急ぐ

### 恋の山場（順番。話数はまだ決めない）

| 段階 | 出来事 | 謎との重なり |
|---|---|---|
| 出会い | 惟臣が小春の手を見て、七年探した少女だと気づく。小春は気づかない | 金庫の依頼 |
| 動き出し | 給金を小春に直接払われる | 最初の横の謎の着地 |
| 近づく | 惟臣の母の宝石箱。惟臣が初めて弱みを見せる | 先代への疑いが揺らぐ |
| 引き離される | 親方が小春を連れ戻そうとし、叔父が縁談を急ぐ。惟臣は小春を屋敷付きの錠前師に迎える | 親方の失言の直後 |
| 告白 | 惟臣が七年持ち歩いた鉤を見せる | **鉤が金庫の鍵だと分かる。恋と謎が同じ出来事** |
| 選ぶ | 仇同士になると思い、小春は屋敷を出ようとする。惟臣「開けなくていい。君がいればいい」 | 小春が自分で開けると決める |
| 求婚 | 誤解がほどけた夜、「この家の錠は、すべて君が作ってくれ」 | 小春が初めて自分の名を錠に刻む |

## 8. 人物

| 人物 | 位置 |
|---|---|
| 小春（十九） | 錠前屋の奉公人。明治三十五年生まれ。父は腕のいい錠前師。女の錠前師に前例がないため、仕事はすべて親方の名。給金なし。父は小春を「はる」と呼んだ |
| 桐生惟臣（二十六） | 子爵家の当主。十九で家を継ぎ、二十歳まで叔父が後見人。父を冷たいと誤解したまま、同じ冷たさを身につけた。錠が分からない。七年前、書斎で錠を組む少女を見た。少女が落とした鉤を持ち歩いている |
| 親方（ヘイト役・真犯人） | 小春の父の弟子で、父の死後に店を継いだ。町一番の錠前師と呼ばれるが、桐生家には一度も呼ばれていない。小春の育ての親で、錠を教えた恩人。師の陰で名が出なかった痛みを持つ。合鍵で盗み、師を死なせた |
| 叔父（ミスリード） | 惟臣の元後見人。家督を狙い、縁談を急ぐ。後見中に家の金を使い込んでいた。金庫を恐れている |
| 先代（故人） | 惟臣の父。親方の盗みの証拠を金庫に封じ、鍵を少女に託した。息子を叔父から守るため冷たく振る舞った。病死。回想にだけ出る |
| 家令 | 桐生家の家事と会計を預かる。先代の遺言「壊すな。開けられる者が来るまで待て」を知る唯一の使用人 |

## 9. 専門性の扱い（中川様の方針）

- 推理の根拠は、読者も分かる事実（艶、擦れ、傷の位置、形の一致、消えた物、人の言葉）にする
- 錠の仕組み・部品・手順・数値は書かない。「ひょっとこ錠」「イロハの文字盤」「智恵箱」は名前だけ出す
- 小春の腕は、気づく速さと手の感覚で描く
- 知識の裏づけは `drafts/jomae/錠前の知識.md`

## 10. 採点

| 軸 | 点 | 根拠 |
|---|---|---|
| A | 4 | 起点の一日＝七年前に書斎で錠を組む少女を見た日。物＝少女の鉤。**その鉤が金庫の鍵で、少女の手でしか開かない** |
