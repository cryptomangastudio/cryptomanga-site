# 方針転換『ほっこり連作』決定事項（2026-10-08、中川様）

## 方針
- ミステリー・サスペンスを軸から外す。軸は「扉を開けると、人の大切な思い出が出てくる」連作（ほっこり）
- ミステリーは縦糸の2〜3割。縦糸は、志乃の名／七年前に失くした鍵／若様との恋の三本
- 1話の型：依頼 → 錠の前の志乃 → 開ける → 中身 → 回想 → 志乃の行動 → 余韻
- 志乃の行動は助言ではなく行動（鍵を作り直して渡す／開けずに返す）

## 決定事項
| 項目 | 決定 |
|---|---|
| 親方 | 恩人のまま。名を刻ませない事情がある（女の名では錠が売れない時代と、志乃を守るため）。最後に、親方が志乃の名を打つ側に回る |
| 叔父・財産管理人・票を持つ四軒 | 廃止。若様の冷たさは、先代（と母）への誤解と、一人で家を背負う孤独から来る |
| 作品の題 | 『名も刻めない女錠前師は、開かずの箱の中の想いを届けます〜大正下町の錠前帖〜』（紹介文は作り直す） |
| 志乃の行動の型 | 鍵を作り直して渡す／開けずに返す（型崩し回）。ほかに「元の形に戻して渡す」「別の人につなぐ」は案として残す |
| 第1話の依頼 | 若様の母の文箱（出会い＋縦糸の入り口）。事件（押し込み）は入れない |
| 年齢 | 志乃十九歳。当時の十二歳は「父の図面どおりに最後の組みを担った」と役割を小さくする |
| 震災 | 終盤に残すかは、縦糸が決まってから（保留） |
