## 1. 規格

### タイトル
**『名も刻めない女錠前師は、開かずの箱の中の想いを届けます〜大正下町の錠前帖〜』**

| 検査 | 結果 |
|---|---|
| 誰の話か | 名も刻めない女錠前師。境遇と職業が分かる |
| 誰との話か | **言えない**（若様は題に出ない）。キャッチで補う |
| 何が起こるか | 開かずの箱の中の想いを届ける。毎話の型が分かる |
| 3つのうち2つ言えるか | 言える（誰の話か／何が起こるか） |
| 作品固有の言葉 | 女錠前師、開かずの箱、想いを届ける、錠前帖 |
| ジャンルの言葉 | 大正、下町 |
| 前半20字 | 「名も刻めない女錠前師は、開かずの箱の中の」。女錠前師と開かずの箱が残るので、種類が分かる |
| 真相を明かしていないか | 明かしていない |

### キャッチコピー（案）
**推奨：「箱を開けるたび、想いが届く。七年前に失くした私の鍵は、若様の左手の中にあった。」（37字）**

| 検査 | 結果 |
|---|---|
| ヒロイン目線か | 「私の鍵」。ヒロイン目線 |
| 誰との話か | 若様。題で言えなかった「誰との話か」を補う |
| 作品固有の言葉 | 箱、鍵、七年前、若様、左手 |
| 感情を行動で書いたか | 「左手の中にあった」＝七年間手放さなかった行動 |
| 真相を明かしていないか | 第1話のヒキまで。若様がなぜ持っていたかは明かしていない |

別案：「箱を開けるたび、誰かの想いが届いていく。ただ一つ、私の名だけが、どこにも刻まれない。」（40字）。名の縦糸を前に出す案だが、若様が出ず、「誰との話か」が言えない。

### ログライン
名を刻めない女錠前師が、開かずの扉や箱を開けるたび、中にしまわれた人の想いを届けていく。けれど、七年前に失くした彼女の鍵は、ずっと、最初の依頼人の左手の中にあった。

### 全体あらすじ

大正十年、東京の下町。女の錠前師など聞いたことのない時代に、どんな錠でも壊さずに開けてしまう十九歳の娘がいた。志乃（しの）である。腕のいい錠前師だった父を亡くし、父の弟子だった親方の源蔵（げんぞう）に育てられている。店の錠を実際に組み、開けているのは志乃だが、女の名では錠が売れない。仕上げた錠に打つのは、いつも親方の名だった。志乃の名を打ったことは、一度もない。

志乃は人前では「はい」と答えるのがやっとの無口だが、錠の前に座ると、人が変わったように話しかける。心の中は、これで結構、皮肉屋でもある。

ある冬の昼、親方が出かけた店に、子爵家の若様が訪ねてくる。洋服に手袋の、笑わない人だ。手には、亡き母の文箱を持っていた。鍵をなくして十四年、開けられずにいたという。志乃が箱を開けると、中には母が幼い息子に宛てた手紙が入っていた。母が息子を遠ざけたのは、胸の病をうつさないためだった。若様は、母に嫌われていたと思い込んで生きてきたのだ。

志乃は、箱の鍵を作り直して渡す。名は打たない。「この鍵は、誰の物でもないので」。若様は、初めて志乃の名を静かに呼んだ。けれど帰り際、若様の左手の手袋がほつれて、細い鉄の端が見えた。父の印が刻まれた、七年前に志乃が失くした鍵だった。

それから若様は、亡き母や先代（若様の父）が遺した、開かない物を次々と店へ持ち込む。机の引き出し、雛人形の箱、母の部屋の扉。表向きの理由は、遺品に向き合う勇気がないから。本当は、志乃の手を見ていたいからだ。そして、先代が遺した金庫を開けられる人を、待っているからでもある。先代の遺言は、「壊すな。開けられる者が来るまで、待て」。

町には、他にも開かない物がある。縫いかけの産着が入った、亡き老婆の裁縫箱。出兵から戻った兵の、開けてはいけない手文庫。志乃は、鍵を作り直して渡すこともあれば、開けずに返すこともある。助言は苦手なので、いつも行動で答える。

志乃は、辛い目にも遭う。長屋の老婆に、流しの錠前屋が高い錠を売りつけた。開けられる錠をわざと壊し、見積の十倍を請求したのだ。声が出ない志乃は、傷を見て、黙って控える。だが、その錠前屋が立ち会いの場で「開かない」と言い張ったとき、志乃は細工を一つずつ見せ、三つ数えて錠を開けた。錠前屋は、自分の道具の跡が錠に残っていることを、言い逃れできなかった。

季節がめぐり、志乃が親方の事情を知る日が来る。かつて同じ町にいた女の錠前師は、名を出したために同業から締め出され、店を畳んだのだという。親方は、志乃が同じ目に遭わないよう、自分の名で錠を売ってきた。志乃の名を刻まなかったのは、守るためだった。そして志乃は、自分が昔作った錠の内側に、小さな「志乃」の刻印を見つける。親方が、ずっと、人知れず刻んでいたのだ。

若様は、七年間持ち続けた鍵を、ついに志乃に差し出す。七年前、志乃の父が屋敷の金庫を仕上げた日、手伝った十二歳の志乃は、庭で鍵を失くした。その日の夕方に先代が亡くなり、若様は庭で光る鍵を拾ったのだ。若様は、持ち主を探さなかった。金庫を開けられる人は、自分から屋敷へ来る人だと決めていたからだ。志乃が自分の足で屋敷へ向かったとき、若様は鍵を返した。

志乃は、金庫を開ける。中には、先代の手紙（若様宛）と、志乃の父の手紙（志乃宛）が入っていた。そして金庫の内側には、父が刻んだ「志乃」の二文字があった。志乃の名が初めて刻まれた錠は、父の手によるものだったのだ。冷たく見えた先代が、不器用に息子を想っていたことも、これで分かる。

すべてが終わった冬、志乃は、新しい錠に、初めて自分の名を打つ。親方は、店の看板に、志乃の名を足した。

### 舞台の理由（年・都市・大正である必要）

| 理由 | 中身 |
|---|---|
| 一点物の錠 | 錠前がまだ一点ものの手仕事で、錠の艶・擦れ・傷に持ち主の暮らしが残る。量産品の時代には、毎話の型が成り立たない |
| 女性が名を出せない | 十年の時点でも、女の錠前師の前例はごく少なかったと考えられる（要確認）。「名を刻めない」に必然性がある |
| 華族と洋館 | 子爵家、洋館、蔵、文箱。下町の店と対になる |
| 一年で終わる | 30話は、十年の冬から十一年の冬まで。震災（十二年九月）の前に終わる。震災は、続編があれば扱う |

**新しさは舞台からではなく、「扉を開けるたび人の想いが届く」×「名を刻めない女職人の積み上げ」から出す。** 大正は棚が混んでいる（『わたしの幸せな結婚』以降、カクヨムにも大正の作品が多い）ので、舞台では差を付けない。

## 4. 毎話の型

| 段 | 何が起こるか |
|---|---|
| 1. 依頼 | 持ち主が、開かない物を持ち込む（または、志乃が呼ばれる） |
| 2. 錠の前の志乃 | 無口な志乃が、錠の前では饒舌になる。耳を寄せ、指先で探る |
| 3. 開ける | 結果と音だけを書く。仕組み・手順は書かない |
| 4. 中身 | 大切な物（7割）か、見たくない物（3割） |
| 5. 回想 | 持ち主の思い出。説明でなく、短い言葉で |
| 6. 志乃の行動 | 助言ではなく行動。鍵を作り直して渡す／開けずに返す／持ち主を探して届ける |
| 7. 余韻 | 余韻は短く。遺族のひと言で終えることもある |

配分（30話）：感動・温かい17、悲しい4、胸クソ3、スカッと6。胸クソは必ずスカッとにつなげる。重い題材（戦死・孤独死・引きこもり）は数話に絞り、暴力・虐待は直接描かない。

## 5. 縦糸の設計

縦糸は三本。答えはすべて優しいものにする。

| 縦糸 | 出す話 | 答え |
|---|---|---|
| 志乃の名 | 1、3、12、24、30 | 親方が、志乃を守るために名を刻ませなかった。内側に、ずっと小さな「志乃」を刻んでいた。最終話で、志乃が自分の名を打ち、親方が看板に名を足す |
| 失くした鍵 | 1、6、18、22、27 | 若様が七年間持っていた。志乃が庭で失くした日の夕方に先代が亡くなり、若様が庭で拾った。持ち主を探さなかったのは、金庫を開けられる人は、自分から屋敷へ来る人だと決めていたため |
| 恋 | 1、5、10、15、20、25、28、30 | 若様が先に惹かれ、距離を置いて見守る。志乃が自分から屋敷へ行く第25話で動き、第28話で若様が不器用に告白する。志乃は答えを保留にして金庫に向かい、第30話で結ぶ |

### 若様が鍵を返さなかった理由（案）
- 表：先代の遺言「開けられる者が来るまで、待て」。金庫を開けられるのは、志乃の父の印を読める志乃だけだと気づいていたが、強いるのは違うと考えた
- 裏：返せば、志乃は用が済んで店に籠もる。手放したくなかった
- 志乃が自分から屋敷へ来た第25話が、返す時になる

### 親方の事情（案）
- 昔、同じ町にいた女の錠前師は、名を出したために同業から締め出され、店を畳んだ（第12話で常連が語る）
- 親方は、その人を見ていた。志乃が同じ目に遭わないよう、技が育ち、世の中が追いつくまで、自分の名で錠を売ると決めた
- 志乃の名を刻まなかったことを、悔いていた。内側に小さく刻んでいたのは、そのため（第24話）

### 金庫（第29話）
中身は「謎」ではなく「贈り物」。先代の手紙（若様宛）、志乃の父の手紙（志乃宛）、内側の「志乃」の刻印。先代と志乃の父は友だった（第18話の写真）。
