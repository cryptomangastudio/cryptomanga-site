# 錠前の知識（企画『錠前』用、2026-09-28）

## 方針（中川様、2026-09-28）

> 専門性の高い話になりそうなので、避けられるところは避けて、専門性を出さないようにしたい。監修が入ると作品を作るのが大変になるので、濁すところはちゃんと濁したい。とはいえ知識は必要なので、この作品に必要な鍵の知識は網羅的に調べること。

**調べるのは網羅的に。書くのは雰囲気まで。** 濁すために知っておく。

各項目に「作中で使う言葉」と「書かないこと」を付けた。書かないことは、監修が要る細部（部品名、手順、数値、仕組みの説明）である。

## 1. 大正十年の錠の地図

| 種類 | 大正十年の状況 | 作中での位置 |
|---|---|---|
| 和錠 | 江戸時代に刀鍛冶が作るようになった。明治後期〜大正、洋館と開き戸が増えて**衰退しつつある** | 古い家・蔵・箪笥。「昔の職人の錠」 |
| 洋錠 | 明治に洋館とともに輸入（英国のチャブ錠など）。**大正3年、白磁のノブと鋳物の箱錠の「白玉錠」が国産第1号** | 洋館の扉。「新しい錠」 |
| 金庫 | 竹内金庫（日本最古、明治初め〜）。熊平（明治31年創業、竹内の代理店から）。イロハダイヤル、ひょっとこ錠 | 先代の金庫。銀行・商家 |
| 南京錠 | 江戸時代に中国経由で伝来。当初は「巾着錠」「西洋錠」 | 小物・物置 |
| 秘密箱 | 明治には「**智恵箱**」と呼ばれた。今の形は明治27年頃、箱根の指物職人・大川隆五郎の考案 | からくり箱の回 |

→ **小春は和錠と洋錠の境目の時代にいる。** 父から和錠を、世の中からは洋錠を学んでいる。この「古いものと新しいものの両方が分かる」が、小春にしかできない理由として使える。

## 2. 錠ごとの知識と濁し方

### 和錠・からくり錠
- 事実：内部に複数本のバネがあり、「引っ張って動かす」仕組み。からくり錠は、鍵が何本も要る、鍵穴が隠されているなどの工夫がある。蔵を持つ富裕層のもの。阿波錠・土佐錠・因幡錠・安芸錠が著名
- 作中で使う言葉：からくり、隠し鍵穴、鍵が二本要る錠、阿波錠のような産地名
- 書かないこと：バネの本数、内部の構造図
- 出典：[鍵の110番救急車 江戸からくり錠](https://www.kagi110qq.co.jp/works/91.html)、[ロックシステム第5話](https://locksystem.co.jp/news/column-kagijyoumonogatari_5/)、[シェアリングテクノロジー からくり錠](https://www.sharing-tech.co.jp/kagi/karakurijo/)

### 蔵の錠
- 事実：**鍵は長さ20〜30cm**、鉄製で取っ手は木。**先端の形・コブの有無と形・長さの3つが合わないと開かない。** 蔵は外扉と内側の引き戸の**二重扉**で、内側は「落とし」を上げ下げする。菊花紋の錠前飾りがある蔵もある
- 作中で使う言葉：腕ほどもある鉄の鍵、二重の扉、内側の落とし
- 書かないこと：3条件の具体的な寸法
- 出典：[ALSOK 鍵ものがたり 蔵の鍵](https://www.alsok.co.jp/person/keystory/04/)、[カギのまかせなさい 明治時代の蔵の鍵](https://ameblo.jp/kagitokey/entry-11098995089.html)

### 箪笥の錠
- 事実：**古い箪笥の鍵の大半は「両爪鍵」（通称・鉄砲錠）。構造は簡単で、小ネジ4か所で留まっているだけ**
- 作中での使い方：**技の見せ場には使わない。** 開けるのは簡単で、ドラマは中身の側に置く（嫁入り箪笥の回）
- 出典：[桐たんす百報](https://tansu.blog.jp/archives/52012616.html)

### 洋館の扉の錠
- 事実：明治に英国のチャブ錠（レバータンブラー錠）などが輸入された。**大正3年に白玉錠（白磁のノブ＋鋳物の箱錠）が国産第1号。** ピンタンブラー錠は1848年に米国のエールが発明し、日本には米国経由で入った
- 作中で使う言葉：白い陶器のノブ、舶来の錠、国産の新しい錠
- 書かないこと：レバーやピンの仕組み
- 出典：[ロックシステム第7話](https://locksystem.co.jp/news/column-kagijyoumonogatari_7/)、[Wikipedia ピンタンブラー錠](https://ja.wikipedia.org/wiki/%E3%83%94%E3%83%B3%E3%82%BF%E3%83%B3%E3%83%96%E3%83%A9%E3%83%BC%E9%8C%A0)

### 金庫（先代の金庫）
- 事実：竹内金庫は日本最古の金庫メーカーで、一品ずつの受注生産。職人によって内部が違った。イロハ23文字のダイヤル（内部の3枚の羽を合わせる）とひょっとこ錠を備えたものがある。明治の金庫は鋼板と鋳物の間に耐火材の砂を詰めた。大正11年製の竹内金庫の記録がある
- ひょっとこ錠：江戸時代の考案で明治によく使われた。ピッキングでは開かず、壊すか形の合う鍵を作るしかない
- 作中で使う言葉：イロハの文字盤、ひょっとこ錠、二重の錠、鍵と文字の両方が要る
- **書かないこと：ひょっとこ錠の内部の仕組み（円板の枚数など）、ダイヤルの回し方の手順、組み合わせの数**
- 出典：`references/fact-check.md` の「竹内金庫」の項

### 智恵箱（秘密箱）
- 事実：ルーツは江戸後期（1830年頃）。明治に「智恵箱」と呼ばれた。今の形は明治27年頃、箱根湯本の指物職人・大川隆五郎の考案。側面を決まった順にずらすと開く。**4回で開く箱から72回の箱まであり、開けるにも閉めるにも1536回かかる作品もある**
- 作中で使う言葉：智恵箱、〇回仕掛け
- **注意：智恵箱は錠前ではなく木工（指物）。** 小春の専門外なので、「錠前屋の手に負えないはずの箱を、手の感覚で開ける」回にできる
- 出典：[からくり箱とは](https://karakuri.gr.jp/about-karakuri/)、[Wikipedia 秘密箱](https://ja.wikipedia.org/wiki/%E7%A7%98%E5%AF%86%E7%AE%B1)、[箱根町観光協会](https://www.hakone.or.jp/931)

## 3. 開ける・合鍵・痕跡

### 痕跡（「錠を読む」の土台）
- 事実：**尖った金属で削ったような新しい傷は、不正に開けようとした跡。薄く細かい傷は、鍵を差すときの普通の傷。** 鍵穴のまわりの放射状の傷、潰れや反りも不正の跡。熟練者はほとんど傷を残さない
- 作中で使う言葉：新しい傷、古い擦れ、毎日開けられた錠の艶、乱暴な傷と丁寧な傷
- 書かないこと：道具の名前、開け方の手順
- 出典：[鍵の110番救急車](https://www.kagi110qq.co.jp/security/column208.html)、[鍵のトラブル救急車](http://kagi24.net/keyhole-picking-scratch-remedy/)

### 合鍵（縦の糸）
- 事実：**合鍵は純正の鍵より精度が低い。** 誤差が0.2ミリを超えると使えない。合鍵から合鍵を作ると誤差が積み重なる
- → **作中の「毎回同じ合鍵の傷」は、この事実から無理なく言える。** 親方の合鍵はわずかに狂っていて、差すたびに鍵穴の同じ所に当たる
- 作中で使う言葉：わずかに狂った鍵、同じ場所の同じ傷
- 書かないこと：誤差の数値、合鍵の作り方
- 昔の合鍵の作り方は確認できなかった。**作中では「型を取った」とだけ書く**
- 出典：[合鍵工場](https://keykojo.com/original-key-good-point/)、[合鍵工場 精度](https://keykojo.com/copy-key-precision/)

### 作品への提案：サブタイトルは「開錠帖」より「解錠帖」

小春は錠を壊さずに開けるので、使い分けでは「解錠」になる。**しかも「解」は「ほどく」で、毎話の「誤解がほどける」と同じ字である。**
『華族様の開かずの金庫を組んだのは、十二歳の私でした』〜大正錠前師の**解錠帖**〜

## 6. 濁し方の型

**小春の技は、手・耳・目の感覚で書く。部品・手順・数値では書かない。**

| 書かない | 書く |
|---|---|
| 「三枚目の羽を右に四十五度」 | 「指先に、かすかな引っかかりが来た」 |
| 「レバーを持ち上げてボルトを引く」 | 「中で何かが、ほどけた音がした」 |
| 「ピッキング痕は放射状」 | 「乱暴な傷だった。開けたい人ではなく、壊したい人の傷」 |
| 「合鍵の誤差0.2ミリ」 | 「わずかに狂った鍵が、毎回同じ場所に当たる」 |

- **専門用語は、名前だけ出して説明しない。**「ひょっとこ錠」「イロハの文字盤」「智恵箱」は、名前そのものが大正の雰囲気になる
- 数値は出さない。出すなら「腕ほどの鍵」のような比喩にする
- **読者が「本当にそうなのか」と気にするほど細部を書かない。** 気にさせたら監修が要る
