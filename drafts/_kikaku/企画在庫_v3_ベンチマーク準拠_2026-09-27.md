# 企画在庫 v3（ベンチマーク準拠、2026-09-27）

確定したベンチマーク（`references/benchmarks.md`）を物差しにして、企画を起こし直した。

- **メイン『薬屋のひとりごと』から骨組みを借りる**：ヒロインは恋に無関心で、恋はヒーローの側から来る／1話1事件をヒロインの専門知識で解く／横の事件が縦の陰謀に合流する／身分の低い場所の技能を身分の高い男が必要とする
- **サブ『わたしの幸せな結婚』から棚と情緒を借りる**：大正風の帝都と華族の家／虐げられてきた娘が初めて大事にされる／自己評価が少しずつ上がる
- **借りないもの**：中華後宮、毒と薬、宦官、異能、軍人、婚約から始まる導入。加えて代筆（ヴァイオレット・エヴァーガーデンと衝突）

ヒロインの職業は、大正に実在した「身分の低い場所の技能」から選んだ。職業ごとに衝突と史実を検索してある（`fact-check.md`、`works.csv`）。

## 1軍　K1『筆跡』（代書屋）── 20点／F4／衝突小

### ログライン
大正十一年。代書屋で他人の字ばかり書いてきた私は、字を見れば書いた人の嘘がわかる。
警視庁の警部が持ち込んだのは、七年前に死んだ妻の最後の手紙。彼はその一通だけを支えに生きてきた。
その手紙を書いたのは、十二歳の私だった。

### ベンチマークとの対応

| 借りたもの | この案でどうなるか |
|---|---|
| 【薬屋】恋はヒーローから | ヒロインの視線は文書の真偽に向く。警部が先に、彼女の字を見る目に惹かれる |
| 【薬屋】1話1事件 | 警部が、筆跡の真偽が争われる文書を1通ずつ持ち込む（遺言状、脅迫状、恋文、借用書、辞世） |
| 【薬屋】横の事件が縦に合流 | 毎話の偽文書の書き手が、少しずつ同じ筆癖に収束していく。七年前の手紙を偽造させた者に繋がる |
| 【薬屋】低い身分の技能を高い身分の男が必要とする | 大正後期、警察が筆跡鑑定の研究を始めた。警部は協力者を探している |
| 【わた婚】大正の帝都 | 代書屋の店先、警視庁、華族邸、万年筆と和紙 |
| 【わた婚】虐げられた娘が初めて大事にされる | ヒロインは女主人に拾われ、給金なしで使われてきた。**自分の字で書くことを禁じられ、他人の字しか書けない** |
| 【わた婚】自己評価が上がる | 最終的に、**自分の字で自分の名前を書く。** 縦の成長の線がそのまま結末になる |

### 人物

| 人物 | 位置 |
|---|---|
| ヒロイン（十九） | 代書屋の奉公人。尋常小学校を出た十二歳から店にいる。他人の字なら誰の字でも書ける。自分の字を持たない |
| ヒーロー（三十二） | 警視庁の警部。無口。七年前に妻を病で亡くし、妻の最後の手紙を肌身離さない |
| ヘイト役 | 代書屋の女主人。ヒロインに字を教えた恩人。依頼人の秘密を売って生きている |
| 七年前 | 病床の妻は、夫への最後の手紙を口述で代書屋に頼んだ。女主人は、妻が口にした言葉とは違う手紙を、妻の筆跡を真似て十二歳のヒロインに書かせた |
| 縦の謎 | 妻が本当に言い残したことは何か。なぜ女主人は文面をすり替えたのか |

### 採点の根拠

| 軸 | 点 | 根拠 |
|---|---|---|
| A | 4 | 彼を七年生かした一通を書いたのはヒロインだけ |
| B | 4 | 真実を言えば彼の支えを壊し、黙れば嘘を続ける。救済と破滅が同じ行為 |
| C | 4 | 女主人は字を教えた恩人で、偽造を命じた人。毎日同じ店にいる |
| D | 4 | 文書の持ち込みは職務。大正後期の警察の筆跡鑑定研究という史実に乗る |
| E | 4 | 帝都、代書屋の店先、華族邸。年の差十三歳の体格差 |
| 減点 | 0 | 設定が軽い。回想は手紙で運べる |
| F | 4 | 謎解き＋職能。恋はヒーローから。1通の文書が事件と二人の距離を同時に動かす |

### 懸念
- 字の鑑定は静かで、マンガでは見せ場を作る工夫が要る。**字の癖を大きなコマで見せ、並べて比べる**のが基本の見せ方になる
- ヘイト役を身近に置く形は、社内の『ミス・ペンドルトン』の原則（ロマファンでは身近に悪人を置かない）と逆になる。ただしサブの『わたしの幸せな結婚』も継母と異母妹を身近に置いて成功しているので、この棚では成立する

## 2軍　K5『錠前』（錠前屋）── 20点／F4／衝突未確認

### ログライン
大正九年。錠前屋の娘の私は、どんな錠でも開けられる。
華族の若当主が七年間開けられずにいるのは、亡き父が遺した金庫。
その錠を組んだのは、十二歳の私だった。

### 骨組み

| 項目 | 中身 |
|---|---|
| ヒロイン（十九） | 錠前屋の奉公人。親方の名前で仕事をしてきたので、世間は彼女の腕を知らない |
| ヒーロー（二十六） | 華族の若当主。父の急死で家を継いだ。父の金庫だけが開かない |
| ヘイト役 | 錠前屋の親方。ヒロインに錠を教えた恩人。七年前、金庫の注文主と組んでいた |
| 七年前 | 錠前師だった父は病で手が利かず、十二歳のヒロインが代わりに金庫の錠を組んだ。組み方を知るのは彼女だけ。まもなく父は死に、ヒロインは父の弟子だった親方に引き取られた |
| 縦の謎 | 金庫の中身。**中身は、若当主の父がヒロインの父を死なせた証拠だった**。開ければ二人は敵同士になる |
| 毎話の謎 | 開かない錠が1つずつ持ち込まれる（密室、手文庫、蔵、からくり箱） |

### 採点の根拠
A4（錠を組んだのは彼女だけ）／B4（開ければ二人が敵になる。開けなければ彼は父を知れない）／C4（親方）／D4（毎話の錠）／E4（洋館、金庫、真鍮、蔵）／減点0＝**20**、**F4**

### K1との違い

| | K1 筆跡 | K5 錠前 |
|---|---|---|
| 女性読者の感情 | 強い。偽の手紙・自分の字を持たない娘 | 中。親方の名で働く娘 |
| 男性読者 | 中。文書鑑定 | **強い。密室・金庫破り** |
| マンガの見せ場 | 静か。工夫が要る | **開く瞬間がそのまま見せ場になる** |
| 衝突 | 小（確認済み） | 未確認（「錠前×大正×女性」で見つからなかった段階） |
| 史実 | 大正後期の筆跡鑑定の始まり | 大正の国産金庫（竹内金庫） |

**女性が主客（女7：男3）という方針ではK1、男性にも読める度合いを最大にするならK5。**

## 控え　K3『修整師』（写真館）── 19点／F4／衝突中

大正十年。浅草の写真館で修整師をしている私は、写真の嘘を見抜き、嘘をつくこともできる。

- A：華族の若当主の母の肖像写真。痣を消せと命じられた十二歳のヒロインは、消した跡に針で小さな印を残した。彼はその印を見つけ、修整した者を探してきた
- **控えにした理由：柊サナカの明治ミステリー（女子写真伝習所の3人が写真の依頼から謎を解く）と、「写真修整×女性×依頼ミステリー」の核が重なる。** 減点−1（暴力の描写、乾板の知識量）

## 有望　K2『交換嬢』（電話交換手）── 17点／F4

大正十一年。電話局の交換手の私は、声を聞けば嘘がわかる。毎晩十一時、同じ男から呼び出しがある。「七年前の火事の晩、この回線をつないだ娘を探している」

- 史実：明治34年に交換手はすべて女性に置き換えられ、大正の花形職業だった。からかい電話も多かった
- A4（彼が覚えているのは彼女の声だけ）、B4（同じ晩、主任の命令で別の回線を切ったのも彼女）
- **弱点：二人が会う場面が少なく（D3）、交換台の前に座る絵が続く（E2）。** 小説では強いが、コミカライズでは弱い

## 有望　K4『染み』（悉皆屋）── 17点／F4

大正十年。着物の染み抜きを請け負う悉皆屋の娘は、染みを見ればその晩どこで何があったかがわかる。

- 職業と見せ場は良い（染み、着物、華族の婚礼衣装）
- **弱点：A軸が3点。** ヒーローが彼女でなければならない理由を、他の4案と同じ型に頼らずに作れていない
